# 证据、权限与听者边界

> 本文件回答三个最容易出错的问题：**凭什么说懂当地人怎么说**（证据分层）、**人物凭什么能做这件事**（权限与自述分离）、**换语之后谁被排除**（单语听者边界）。

---

## 一、四层证据（不得混称）

任何"本土化"声明都必须落到下面某一层，**逐层分开报告**：

| 层 | 内容 | 谁可以判定 |
|---|---|---|
| **L1 文字内部成立** | 台词属于此人此境，对象、权力、共同信息、交流目的是否改变说法 | 模型 + 文件证据可查 |
| **L2 材料证据校准** | 是否按**已提供材料**完成窄特征适配（材料须与人物、关系、活动相近） | 模型 + 文件证据可查 |
| **L3 真人复核** | 是否由**合适的当地 / 社群复核者**审过当前版本 | **只有真实复核者参与后**才能声明 |
| **L4 观众效果** | 是否有目标受众桌读、观看数据、留存或付费表现 | **只有真实数据后**才能声明 |

**L1、L2 可以由模型和文件证据检查；L3、L4 没有真实参与者就写「未测」。**

### 明确不能升级状态的五项

1. 模型生成的内容读起来顺；
2. 模型盲评 / 双模型一致；
3. 网页搜索、公开视频字幕、社交平台评论；
4. 演员 / 角色的身份、族裔、出生地猜测；
5. 舞台标注（`(in Spanish)`）、英文占位释义、或另一角色"似乎接得上"。

> **判据一句话**：**模型判断 ≠ 真人验证；资料检索 ≠ 社群认证。**

## 二、权限与自述分离

### 2.1 角色自述不是证据

人物说「**委员会给了我钥匙**」——**这只是角色自述，不是项目层授权证据**。

剧本里出现这类台词**不能**反过来证明：该角色真的持有钥匙、真的有权进入、真的被授权处置。**作者需要让它在场内可见地成立**，或者**把权限本身写成阻力**。

### 2.2 四项权限分别核验

| 权限项 | 不能从什么推出 |
|---|---|
| **钥匙 / 进入权** | 职位、亲属身份、居住地、自称 |
| **设备 / 系统操作权** | 职业名词、培训经历（未经场内建立） |
| **专业资格** | 头衔、制服、他人称呼 |
| **法定处置权** | 身份、紧急情境、"大家都听他的" |

**四项不得合并推导。** 给了钥匙 ≠ 给了系统权限 ≠ 给了执法权。

### 2.3 修复时的整段扫描

修掉评审点名的那一句之后，**必须重新扫描整段的"身份 → 权限"推导**——避免"只修被点名的一句，相邻动作仍在执行同一项未证权限"。

## 三、单语听者边界

### 3.1 换语五问（每次切换都要回答）

1. 谁听得懂？
2. 什么触发？
3. 完成什么功能？
4. 是否排除现场某人？
5. 对关系或行动造成什么后果？

### 3.2 铁律

- **涉及其钱、货物、安全、责任或下一步行动的关键信息**，英语单语者在场时**必须立即回到共同语言**；
- 被排除**必须产生可见反应**（不是在场上"自然没听见"）；
- 无证据时**不自动换语**——人物会两种语言 ≠ 此刻该用另一种；
- 只使用项目**明确给出**的语言能力和**已核验**用法。

### 3.3 孤立的语言标签

**孤立的 `eh`、`y'all`、`oi` 等地域标签**，若**没有材料支撑、且不承担对象功能**——**直接删除或改成真实交流动作**，**不再用"可能有功能"放行**。

**判据**：这个标签删掉之后，人物关系、信息或动作有没有变化？**没有变化 = 装饰 = 删。**

---

## 四、风格的证据边界（反向保护）

以上纪律都指向"不要乱加"，但**反向的过度修复同样是失败**：

| 失败方向 | 表现 |
|---|---|
| 过度修复 | 所有人都说碎句 / 每句都藏信息 / 每个地区都塞俚语 / **每个双语人物都随机切语** |
| 反向退化 | 把所有英语写成**无地域、无职业、无关系差异的中性功能对白** |

**受保护清单**（下游不得机械打碎）：完整句、冷面笑话、礼貌威胁、重复、仪式性称呼、类型化节奏。

**判断标准是节奏与角色功能是否成立，不是"像不像录音"。**

---

## 五、评审时的分项判断（不出总分）

每项用 `通过 / 风险 / 失败 / 未测`，附短原文与影响，**不计算总分、不用总分抵消关键失败**：

- **早期路由**：是否在写作前确认语言、地区、风格和未知，而非成稿后只换词；
- **声明准确**：状态是否与真实证据相符；
- **人物与对象**：听者、权力、共同信息和交流目的是否改变说法；
- **表达自由度**：直接/间接与完整/残缺是否独立选择；是否保住成立的完整句、安静场面和风格化节奏；
- **英语可表演性**：搭话、打断、自修、停顿、缩略式、称呼和脏话是否由现场触发，是否出现统一模板腔；
- **地方与社群边界**：细节是否改变行动或关系；是否从身份标签跳到口音、方言或性格；
- **多语因果**：切换的参与者能力、触发、功能和后果是否都成立；
- **连续性**：人物的语言选择能否随关系和场合变化，同时保持可识别的个人策略；
- **事实与冲突守恒**：语言适配是否凭空增加人物知识、权限或触发；地方物件是否挤掉主要筹码、造成冲突降级。

---

## 六、停止与回退条件

- 同一问题**连续两次**未改善 → 换实现方式、缩小批次，或回到上游构思；**不无限循环，也不假称通过**；
- 收益停滞时，如实记录为**模型能力 / 资料缺口 / 真人校准**瓶颈，**不继续堆规则**；
- 证据失效或与正文冲突时 → **主动降级** `language_status`，写明原因；
- 模型版本变化须**单独记录**，不与真人验证混称。
