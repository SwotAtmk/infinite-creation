## 第一部分 · 通用句法母版（六类基础句式·所有案例通用）

### 1.1 运镜-动作咬合句（最核心·每镜必用）

**骨架**：[复合运镜起手：焦段+机位此刻空间位置+怎么动(视觉目标)] → [人物在这个镜头里完成发力动作，同句带出特效+气场+粒子] → [运镜再动：运到哪/跟什么] → [下一动作命中：三层特效+动作与环境同拍炸裂+冲击帧+镜头受力]

**案例原句**（C16染布坊雨夜）："[复合运镜：斜侧急速推进➡️滑动变焦➡️高速跟拍] 女剑修身形暴起，踏碎地面水洼高速突进，数道凌厉暗红剑影撕裂滂沱雨幕，直扑男法修。[锚定：轻碰撞触发，暗红剑气划破雨幕，雨珠被剑气切碎四散飞溅]"
**案例原句**（C04掷刃瞬影）："镜头先贴凌云肩侧、顺前冲方向低机位猛窜、剑风几乎擦镜，就在前冲这一拍他身形炸成四五道水墨冰晶残影、淡金边勾着残影向后飘散、周身青白雾被风压倒拖成锥形飞白；镜头跟住最实那道残影一个Whip Pan甩到兽群头顶、急停钉死，停的这一瞬青锋已斜劈而下……"

**仿写要点**：①运镜和动作写在同一条长句里，不分成【位移】【运镜】两个标签块；②每个运镜动作必须写清"此刻在哪个空间位置、对准/跟随什么、运到哪"；③运镜方向=事件发生方向（能量上冲镜头抬升、火浪逼来镜头后撤、命中镜头猛沉回弹）；④同一种运镜持续≤2秒，同一种景别持续≤3秒。

### 1.2 特效三层构造句（每次命中/挥击必用）

**骨架**：主体层(动态动词+质感名词) + 边缘层(动态动词+质感名词) + 表面层(动态动词+质感名词) → 沿明确轴线飞行 → 命中：核心强光(白/金最亮) → 中层主色雾化扩散 → 外层暗色碎片遵循重力飞溅

**案例原句**（C03巨兽战）："剑身拖出厚重浓烈的藏青色能量拖尾，拖尾如燃烧绸缎般翻滚延伸长达数米，边缘粒子剧烈剥落，碰撞巨兽前肢瞬间炸裂环形冲击气爆"
**案例原句**（C02空间法则）："混沌戟横扫而出，戟刃切开空气时发出一声撕裂空间的尖啸，黑金半月弧光切向天帝脖颈！……弧光擦着鼻尖掠过，将身后一根三人合抱的石柱斜切成两段，上半截柱体沿着光滑的切面缓缓滑落，断面流淌着融化的金黑熔岩！"

**仿写要点**：①三层各给一个动态动词+一个质感名词；②三混合同框：能量体+水墨+流体必须同一拍同时在场、互相绞缠；③特效尺寸必须走尺度四件套；④首现写全，后续命中只锚定名称+写这一拍独有变化。

### 1.3 打击反馈链句（每次命中必用）

**骨架**：命中点(肉陷阻滞/形变凹陷/火花能量爆开) → 身体(弓身/后仰/旋转飞出/双脚离地拖行) → 武器(回弹震颤/脱手飞出/插入地面) → 环境(地面龟裂/建筑崩塌/尘浪碎石) → 镜头(震动/后挫/被冲击波推开/瞬态失焦)

**案例原句**（C06天帝对决）："戟尖与斧面碰撞，炸开黑金与金蓝混合光晕，环形冲击波将周围三米内玉砖掀飞，碎石呈放射状四溅。两把神兵相抵，戟尖抵住斧面中央，黑金色电弧与金蓝色电弧在接触点疯狂纠缠，发出刺耳尖啸。两人脚下地面因能量传导产生蛛网状龟裂"

**仿写要点**：①反馈按链条传导，每层都要有画面，禁止只写"打中了"；②震屏方向挂钩攻击方向：横斩左右震，纵劈上下震，大招全向+5°旋转分量；③环境破坏链式因果：拳风刮地→碎石飞→砸裂岩层→炸起尘柱，有先后顺序；④轻击=镜头微震+小碎片；重击=镜头短促震动+冲击环+碎石雨；终结=镜头被冲击波推后飞+剧烈震动+大范围崩塌。

### 1.4 蓄力压缩句（大招前必用·≤0.25秒且在高速动作中完成）

**骨架**：手/眼/刃特写 → 粒子从八方螺旋汇聚 → 材质微观细节 → 临界万物悬停(升格/子弹时间) → 镜头微震蓄压

**案例原句**（C09法相天地）："男主侧脸，嘴角缓慢上扬至邪魅弧度，眼神半阖间猛然睁开，瞳孔骤缩成十字星芒状。面部汗毛因静电竖立，周围空气开始电离产生蓝色电弧。背景火把被无形力场压扁拉长"
**案例原句**（C07剑来）："男主正面，嘴角流血，左眼眶碎裂（血纹延伸至颧骨），光影在鼻梁中线割裂（左侧暖，右侧冷），发丝被风撩动……血雾粒子环绕全身。男主双臂张开，剑指苍穹，左手掌心朝上凝聚血雾光球，脚下岩石剧烈震动，碎石悬浮"

**仿写要点**：①蓄力必须有微观特写（手部结印/武器刃口电弧/符文流转/脚步蹬地碎裂/肌肉发力）；②蓄力期画面不许静止——法阵边缘自动绞杀+敌方远程反击砸在屏障上+角色自身微沉浮/衣发狂舞；③蓄力越久爆发越狠，但打戏交锋段蓄力只能在高速位移或连段中完成；④临界瞬间用升格/子弹时间制造窒息感，与前后晃动形成反差。

### 1.5 群体结构句（群战/万剑/妖潮必用）

**骨架**：先定义群体组织结构(几路/几层/前部中部尾部) → 整体运动方式(鱼群/潮水/星河同相位) → 个体在结构里分工 → 镜头停在群体外部看整体轮廓

**案例原句**（C07剑来·万剑汇聚）："方圆百里内所有断剑、残刃全部拔地而起，剑身缠绕血色剑气（拉丝粒子流光，拖尾长度暴增），碎石、妖尸、木块全部磁浮离地（逆重力粒子场）……成千上万长剑从四面八方汇聚向男主高举的右臂，形成螺旋剑龙卷（剑尖指向掌心，粒子尾迹交织）"
**案例原句**（C03巨兽战·五道气旋）："5道巨型藏青色螺旋月牙气旋贴地犁射而出，每道气旋拖拽着厚重浓烈如熔岩般的能量尾迹，尾迹宽达数米，边缘呈燃烧态翻滚飘散，每道气旋裹挟真空刃撕裂地壳，地面犁出5道纵深沟壑"

**仿写要点**：①禁止"密密麻麻糊一团"，先定义分几路、分几层、每路的前部-中部-尾部；②整体像深海鱼群/星河/潮水同相位摆动，镜头停在群体外部看整体轮廓与S形/放射动线；③个体只在命中瞬间给近景，不追单个；④清场终结模式：跃起悬空→滞空蓄力→连续数十道月牙剑气脱手→扇形地毯式覆盖→每击独立爆炸逐次延伸→最后一道体积加倍炸出深壑。

### 1.6 收势/延迟揭示句（结尾必用·禁止双方同框摆pose）

**骨架**：动作收束(入鞘/合扇/咔哒) → 极短时间冻结 → 裂纹/效果延迟蔓延 → 延迟爆发或粒子逆流回收 → 镜头匀速拉远留动态背影与被改变的世界

**案例原句**（C02空间法则·绝对静默）："镜面开始出现一道细微的裂纹——从两人脚下的位置同时向中心延伸，两道裂纹在战场中央相遇，轻轻地碰撞了一下。然后一切再次归于静止。画面在绝对的静默中缓缓暗去"
**案例原句**（C03巨兽战·拖尾残网）："尘埃渐散，巨兽倾塌残骸散落战场，残骸表面仍有零星青色粒子缓缓升腾，空气中残留着男主先前所有斩击留下的厚重拖尾光带轨迹，数条藏青色光带在荒原上空交织成半透明的能量残像之网，久久不散，男主渺小背影立于崩塌巨兽前方"

**仿写要点**：①结尾必须是运动中收束/单方背影/宏观破坏余波/遗物定场；②人物越来越小却始终居中；③最后0.5-1秒可放缓节奏收束，但人物必须在运动中（转身离开/收刀入鞘/缓步前行/滑行收势）。

## 第二部分 · 按题材分类的句法养料（十一类）

### 2.1 群战割草/一人对多/清场类（代表：C04掷刃瞬影、C11拔刀斩、C15阿良天残腿）

- **模式A·逐斩差异化五连杀**（C04）：五斩必须有不同的攻击轨迹（刺入→横切→上挑→回旋→反手），每斩配不同的拖尾形态（放射性扩散→弧形气带→倒挂彗尾→环状尾迹→斜射贯穿），禁止五斩同形。
- **模式B·圆圈斩满月刀罡**（C04）："男主左脚为轴高速旋转，右脚划半圆激起沙尘放射状飞散。青霜水平划出完美满月藏青色刀罡——旋转过程中刃口持续拖出一圈完整的环形气流拖尾，如巨大的星环环绕男主……刀罡薄如蝉翼，刃口纯白灼亮。近二十具沙傀被同时拦腰斩断"
- **模式C·弹血滴微缩核爆**（C04）：用微观特写（液珠/指尖）制造尺度反差，微缩漩涡→弹指→核爆，从极小到极大的瞬间膨胀是高燃点。
- **模式D·威压球形能量场**（C11）："浓稠如墨的血红色威压从他周身爆裂迸发，呈球形能量场瞬间向外扩张……地面龟裂呈蛛网状塌陷数寸，碎石被压制贴地无法动弹，围困的敌军士兵被威压震慑出现短暂僵直"
- **模式E·刻字定格收束**（C11）：断面平滑如镜中央呈现巨大汉字+笔画边缘灼烧焦痕+能量涟漪向外扩散。

### 2.2 高阶对决/神魔级/空间法则类（代表：C02空间法则、C08双召唤灭世、C06黑金vs金蓝）

- **模式A·四场递进结构**（C02/C08）：第一场贴身绞杀·零距离(0-7秒)→第二场飞天穿梭·空间穿插(7-14秒)→第三场蓄力引爆·空间共振(14-21秒)→第四场终极对冲·大撕裂·大重塑(21-30秒)。30秒高阶对决标准四幕，每场有明确功能和时间锚点。
- **模式B·双色阵营全局锁定**（C06）："全局色彩锁定：全片所有水墨风格特效、能量流光、拖尾、粒子、冲击波、光晕、雷电等，男主方一律为黑金色，天帝方一律为金蓝色，绝无其他色彩介入。"——高阶对决必须在开头全局宣告双方配色，碰撞时才出现混合色。
- **模式C·空间法则写法**（C02）：空间法则不写"能量爆炸"，写"空间本身在折叠收缩/撕裂膨胀"——物质被空间折叠挤压成极薄一层、碰撞点膨胀成"空间消失的圆洞"、圆洞边缘是不属于任何颜色的混沌色。
- **模式D·双召唤仪式**（C08）：召唤过程分三步——能量裂缝/光茧→巨物局部探出（手/头）→完整百丈身躯挣脱而出。召唤物必须有明确的内部构造（三头六臂各持何武器/十二重结构各层图案）。
- **模式E·终局纯白爆闪→全新世界**（C02/C08）："那个点爆发出一种从未见过的光芒……一整秒的纯白，没有任何画面、没有任何声音……纯白退去。屏幕中浮现出全新的景象——整个战场被一种光滑的、静止的、镜面般的空间结构覆盖"

### 2.3 巨兽/体型反差类（代表：C03荒原男主vs巨兽）

- **模式A·全局构图锁定**："全片强制极低仰拍与广角透视，巨兽占画幅2/3以上，男主仅底部剪影或渺小近身，贯穿始终的体型反差构图。"
- **模式B·燃烧态绸缎拖尾**：拖尾不是"剑气"，是"厚实浓重的燃烧态光带，厚重如实体绸缎"——质感词决定画面厚度。多条拖尾残留交织成网是收束标志。
- **模式C·巨兽霸体反扑**：巨兽被斩后不是后退，是"暴怒→霸体反扑→把男主拍飞撞碎石柱"，保持巨兽压迫感；男主必须有受击反馈（单膝撑地/嘴角渗血/粒子紊乱）。
- **模式D·五道螺旋月牙气旋终结**：面状终结+血肉与能量混合爆裂+三色粒子放射喷射形成覆盖全屏的粒子蘑菇云。

### 2.4 大招递进/招式连展类（代表：C05八场递进大招、C07剑来名场面）

- **模式A·八场递进+诗意副标题**（C05）：大招递进必须一浪高过一浪——百米坑→连爆递进→坍缩球→光矛雨→熔岩海啸→升空恒星→宇宙级核爆→收束。每场配4-8字诗意标题+一句注解。禁止开场即最大。
- **模式B·环境逐级重塑**（C05）：搬山=山体从内部膨胀炸裂万吨岩石冲天；断江=江水被齐整斩断断崖水墙悬停半空；倒海=方圆百里海面凹陷成巨碗状倒卷成千米海啸幕墙；弑神=通天石像被重力场压扁再撕裂、深渊底部喷出熔岩柱；开天=苍穹被剑气劈开横贯天际的漆黑裂缝深处浮现银河星海。
- **模式C·名场面触发模式**（C07）：蓄势阶段（重伤/跪地/能量从毛孔渗出）→关键台词怒吼（"剑来！！！"）→球形冲击波荡平→万剑拔地汇聚→螺旋剑龙卷→压缩成巨剑虚影→万道剑雨射出→血雾莲花蘑菇云→全屏闪白渐暗。

### 2.5 变身/法相/觉醒类（代表：C09法相天地3.0、C13化魔法相天地）

特效发动时能量是三者同步联动的连续流动带：身体层（周身服饰表面萦绕属性能量沿纹理窜动）→臂膀层（能量从肩颈沿手臂爆发蔓延至手腕，被风压拉成流线型）→武器层（能量沿武器延伸至剑气根部，与手臂连贯无断点）→整体像"原本一团凝聚的能量物体被强风强行吹拉长"——身前压缩身后拉长。详见 moves-library.md 附录A节。

**密度样例**（一条节点句的合格密度）：

> 00:00—00:02，镜头先贴地极低机位、顺突进方向从画面左侧向右猛窜、地面积水在镜前倒掠[跟轨迹]，男主脚下白光炸起、低伏贴地横贯长街，深蓝衣摆与白电被风压倒拖成紫蓝锥形残影、电弧残影向后逐层飘散（高速移动气场），霸刀过顶重砸【目标：女主左肩】；镜头急推到兵刃交击点钉死的一瞬女主滑铲抡枪上架[聚焦命中]，同一拍紫蓝白刀气撞上金橙黑枪气，交击点青石板同步炸裂、积水压成环形水帘向两侧掀飞，120fps 冻结 0.2 秒：白芯爆亮、碎石水珠悬停、环境声抽空，下一帧爆速。【隐形剪辑点】前景溅起的水花擦镜。

> 🔴 **一条节点句的密度标准**：空间位置 ＋ 运镜链 ＋ 发力链 ＋ 三层特效 ＋ 打击反馈，五项必须在**同一句内**织入；"先写完动作再补运镜/补环境"即不合格（见铁律43）。

### C-2 · 装配纲要：30s 全场 · 双人大招串行施法

> 与 C-1 的唯一结构差异＝**大招段的装配位置**，其余段位同 C-1。

| 镜位 | 装配内容 | 要点 |
|---|---|---|
| 前段 | 交手轮次（冲刺 / 格挡 / 锁链绞杀 / 群剑鱼群 / 法阵） | 每 2 秒一个轮次，攻守交替，环境同拍破坏 |
| 大招 A 段 | 甲的大招**独立成镜**：施法 → 蓄力 → 成型全景定格 | 乙**仅在战场另一端远景备战**，血气盘旋、**不入主画面** |
| 大招 B 段 | 甩镜切至乙的大招**独立成镜** | 运镜须与 A 段差异化（A 半环绕 / B 仰拍环绕） |
| 对冲段 | 两招**都完全成型后**才切超宏观俯瞰对碰 | 超远景下两人身形仅占画面约 1%（渺小如尘） |
| 收束段 | 急推回全景 → 240fps 超升格冻结 0.3s → 白闪 → 环形冲击波 → 蘑菇云 → 收剑入鞘 → 胜者动态背影渐远 | 败者跪地剪影留原地；全片禁双方同框摆 pose |

> 镜头先切虫视仰拍[巨物压迫]再急速拉回超宏观俯瞰[展规模]：两道完全成型的大招先后压下、向中心对冲——沿途空气压成白色音爆锥、沙丘削平、断碑如蚁群碾碎；超远景下两人身形仅占画面 1% 如尘埃，两招各占半边天穹、中间沙漠被压出数里宽黑色裂谷。【隐形剪辑点】沙暴云层糊镜。

> 🔴 **串行铁律**：双人大招**禁在同一画面同时施法**——必须 A 独立成镜 → B 独立成镜 → 双方成型后才对碰（同画面同时施法＝双方都读不清，见铁律43）。
