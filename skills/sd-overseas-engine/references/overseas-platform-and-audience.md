# 海外平台与观众情境

> 本文件把三件事**分开**：故事是否成立（T1）、是否适合目标发行（T2）、在既定资源下如何实现（T3）。**三层互相校正，但不能用任何一层的标签替代另一层证据。**

---

## 一、T1 文本质量（与赛道①同底线）

检查剧本自身：人物判断与行动、反作用、结果、情绪、对白、首次理解、阶段闭环、连续性、概念负荷、主要观看回报。

**T1 不因字数短、场地少或用了热门题材自动通过，也不因存在大场面自动失败。**

---

## 二、T2 产品适配（只查已确认的条件）

**只检查项目已经确认或明确采用的**：目标观众与观看情境、平台 / 频道、终端、画幅、免费 / 广告 / 会员 / 逐集付费模式、真人 / AI 拟真人 / 动画、主角型或群像承诺。

**未知项标未知或工作假设。**

### 禁止的三类外推

1. 从"短剧"推出**固定付费集、9:16、前三秒统一刺激**；
2. 从"某平台是 9:16"推出**所有项目都是 9:16**；
3. 从"女性观众较多"推出**每部作品必须女主完成所有动作**。

### 目标写成可观察行为

- 首次观看能在本集关键选择前理解人物关系和筹码；
- 已知收费节点前既给出阶段回报，又留下由当前结果生长的下一问题；
- 主角型项目的关键结果能看出主角的必要选择及承担；
- 已确认 9:16 时，决定胜负的动作、物件和表情**不依赖横向多人同时可见**。

> **没有真实观众数据时，只能判断文本是否按目标设计，不能声称目标人群会付费、完播或喜欢。**

---

## 三、T3 制作适配（立项只做预检）

**立项阶段只做预检**：哪些故事方案可能与已知画幅、演员、场地、资产、动作、精确文字、特效或工具链冲突。**锁稿后**再做逐集场交接与试制。

预检用于**早发现会迫使故事重写的条件**，**不把镜头表、技术参数和预算表塞进剧本正文**。

### 成本不能由"场景大"或场次数单独推断

至少结合：场地是否可得与可复用、转场搬组、群演、特技与安全、天气 / 昼夜、儿童 / 动物、服化道、破坏性动作、VFX 或生成资产复用、角色一致性、口型与复杂接触、精确屏幕文字、周期和团队能力。

**AI 或动画也有一致性、重生成和资产管理成本**；虚拟大场景可能比真人小场景更容易，也可能相反。

### 已确认 9:16 时的竖屏预检

1. 关键主体、道具和反应能否在窄幅和平台 UI 安全区内读清；
2. 场面是否依赖横向多人同时站位？若依赖，能否改为前后层、上下层、进出画或动作接力；
3. 近景 / 特写是否有表演与信息价值，而非只因竖屏机械放大人脸；
4. 全景是否利用纵深、上下空间、门窗、楼梯或高差说明关系，而非一律删除；
5. 关键屏幕文字是否有可靠承载和后期方案。

> **画幅非 9:16 或未知时，不运行竖屏扣分。**

## 四、状态与交接

每层分别使用 `达标 / 风险 / 失败 / 未测`，并附**证据范围**；T3 另可用 `待试制`。

一份稿可以同时是：

> T1 文本达标、T2 某发行画像风险、T3 未测。

**这比笼统说"能交付 / 不能拍"准确得多。**

### 外部意见登记格式

收到外部意见（评审、平台、合作方）时先登记，再判断：

```
artifact_version / exact_scope / quoted_evidence_or_absence /
claimed_impact / applicable_product_condition / disposition / proposed_target
```

**当前稿已满足其事实前提时，否决该意见或将其改写为可选强度方案**——不能继续按旧版印象加危机、加术语、删大场面或抢走配角动作。

## 五、来源与边界

### 可用作校准边界的主要来源类型

- **平台官方投放规范**（如 TikTok Creative Codes、In-Feed 规格）——支持**对应平台**的 9:16 与安全区检查，同时仍列出其他画幅；
- **正式监管文件**（如广电总局微短剧管理办法）——定义微短剧的**播出渠道与终端口径**；
- **学术研究**（如竖屏画面研究）——支持**重新设计人物位置、景别和纵向空间**，而非取消全景。

### 三条边界铁律

1. 上述来源**均不证明**：统一付费点、女主模板、场地成本；
2. **平台名不等于公信度**——网站、抖音、B 站、知乎、小红书、TikTok、YouTube 用**相同证据标准**，但可读性不保证相同；优先**当事人原始访谈、正式投稿要求、作品与官方完整讲座**；自媒体经验与课程营销**分别标明**；
3. **同一团队被多个网站转述，不算独立佐证**。

### 检索记录要求

每条记录**原始 URL、作者、发布日期或未知、读取范围、适用产品与关键依据**。文字分全文 / 部分 / 仅摘要；视频分字幕或 ASR 已读、相关画面已核、未核画面。

**检索不足以支持的数字，不写进规则。**

## 六、与其他赛道的接口

- **国内剧（赛道①）**：平台合规走总控 `short-drama-director/references/platform-safety-compliance-guide.md`（国内平台安全转译）。**本文件不覆盖国内平台**。
- **海外剧（赛道②）**：本文件管**发行画像与制作预检**；语言与本土化纪律见 [语言与风格合同](language-contract.md) 与 [证据、权限与听者边界](evidence-and-authority.md)。
- **画幅**：最终画幅一律以总控 **B 锁（用户指定）** 为准。本文件的竖屏预检**只在画幅已确认为 9:16 时**运行。
