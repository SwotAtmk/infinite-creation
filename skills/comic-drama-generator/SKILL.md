# 3D漫剧生成器

## 概述

此技能提供完整的3D精品漫剧制作流水线，涵盖分镜脚本生成、角色生图提示词生成、场景生图提示词生成三个核心模块。输出内容可直接用于即梦Seedance 2.0等AI视频生成模型。

---

## 核心能力

### 1. 漫剧分镜脚本生成

**触发条件：** 用户提供小说片段、剧本或剧情描述，要求生成可用于AI视频生成的分镜脚本。

**执行流程：**

1. 熟读用户提供的小说片段或剧本
2. 合理安排剧情内容，不利于观众停留的剧情可酌情删减，但需保证剧情前后连贯
3. 制作完整的分镜脚本，共4段，每段15秒，每段最少6个分镜
4. 严格按照模板格式输出，**每个分镜必须标注「时长」字段**

**分镜模板：**

每段格式如下，每段独立输出：

```
【第X段 | 总时长：15秒】

分镜1：
- 时长：X秒（单镜2-6秒，同段所有分镜时长之和必须=15秒）
- 景别：[远景/全景/中景/近景/特写]
- 视角：[正面/侧面/背面/俯视/仰视/主观视角]
- 运镜：[固定/推镜头/拉镜头/摇镜头/移镜头/跟镜头]
- 画面内容：[详细描述人物动作、表情、位置关系]
- 台词：[旁白或内心独白，无台词则写"无"]
- 音效：[环境音/动作音效，无则写"无"]
- 音乐：[背景音乐描述，无则写"无"]
- 光影：[光照方向、强度、质感]
- 色调：[主色调，如冷蓝、暖黄等]
- 场景：[场景名称，需与场景提示词对应]

分镜2：
...
（每段最少6个分镜，每个分镜均标注时长）
```

**时长分配参考：**
| 景别 | 建议时长 |
|------|----------|
| 特写 | 2-3秒 |
| 近景 | 3-4秒 |
| 中景 | 4-5秒 |
| 全景 | 5-6秒 |
| 远景 | 5-6秒 |

**重要约束：**
- 4段内容必须剧情连贯，有起承转合
- **每个分镜必须标注「时长」字段，同一段内所有分镜时长之和必须 = 15秒（允许±0.5秒误差）**
- 台词要口语化，符合人物性格
- 每段结尾预留钩子（悬念/反转），提升完播率
- 输出时在每段标题注明总时长，如【第1段 | 总时长：15秒】

### 2. 角色生图提示词生成

**触发条件：** 分镜脚本已生成，需要为其中所有角色生成标准化的AI生图提示词。

**执行流程：**

1. 分析分镜脚本中出现的所有角色（主角、配角、路人）
2. 为每个角色生成独立的生图提示词
3. 严格遵守技术与环境限制
4. 确保同一角色在不同角度/表情的变体提示词风格统一

**角色提示词模板：**

```
【角色名称：XXX】

[技术与环境限制]
背景:纯白纯色背景，无纹理、无渐变、无杂物、无任何装饰元素
姿势:绝对标准的A-Pose，双臂自然下垂，呈A字形
比例:哥特式比例，高级时装插画视觉
视角:正前视，平视中心镜头，正交视角，零透视畸变，无广角、无仰俯角度、无镜头变形
表情:面无表情，自然双唇闭合，神态平静淡然，无喜怒哀乐
光照:全局均衡柔和漫射光
构图:完整全身立绘，从头到脚完整呈现，双脚鞋子完整入镜，头顶保留适量留白空间，画面居中对称构图
画质与渲染：8K分辨率，杰作，极致细节，专业角色设计表，清晰的材质纹理

[人物基础特征]
性别: [男/女/其他]
年龄：[具体年龄或年龄区间]
体型与肤色: [身高、体型描述、肤色]
风格: [3D Q版卡通 / 3D写实 / 二次元3D / 其他，整个漫剧必须统一]
色彩基调: [角色主色调]

[头部细节]
头发: [长度、颜色、发型，要求露出颈部和肩膀]
脸部: [脸型、五官特征]
眉毛: [形状、颜色、粗细]
鼻子: [鼻型描述]
眼神: [眼型、瞳孔颜色、眼神气质]

[身体与穿搭]
手部：[手型、是否有手套等]
腿部: [腿型、是否有袜子/裤子等]
衣服: [上衣详细描述，要求完全对称，剪裁清晰]
裤子: [裤子详细描述]
鞋子: [鞋子详细描述]
配饰: [首饰、配件等，要求无大件遮挡物，小巧贴合]
```

**重要约束：**
- 每个角色必须生成：正面A-Pose全身图提示词（用于即梦角色参考图）
- 可选生成：表情变体、角度变体（侧视、背视）
- 所有角色的"风格"必须统一（整个漫剧使用同一种3D风格）
- 色彩基调需与整体美术风格协调

### 3. 全场景生图提示词生成

**触发条件：** 分镜脚本已生成，需要为其中所有场景生成标准化的AI生图提示词。

**执行流程：**

1. 分析分镜脚本中出现的所有场景
2. 合并相同或相似的场景（如"客厅白天"和"客厅夜晚"可合并为"客厅"并标注光照差异）
3. 为每个唯一场景生成独立的生图提示词
4. 确保风格统一

**场景提示词模板：**

```
【场景名称：XXX】

[核心设定]
风格: [废土科幻、现代极简、中世纪哥特、3D卡通渲染等，需与角色风格统一]
时间与天气: [晨/昼/黄昏/夜，晴/雨/雪/雾等]
色彩基调: [场景主色调]

[空间与结构]
空间描述: [一句话概括这是个什么地方]
材质与细节: [地面、墙面、物体的材质和可见细节]
远景/边界: [视野尽头或窗外的景象]

[光影与镜头]
光源设定: [光从哪里来？自然光/人工光源/生物发光等]
光影技术: [丁达尔效应、全局光照、反射光、体积光等]
视角: [第一人称视角、无人机俯拍、广角仰视、水平平视等]
构图: [绝对对称构图、三分法则、引导线构图、框架构图等]

[技术与约束]
画质与渲染: Unreal Engine 5, Octane Render, 8K分辨率，杰作，极高细节
附加要求(指令): 不要有角色出现在场景里
```

**重要约束：**
- "不要有角色出现在场景里"是硬性要求，必须包含在提示词中
- 同一漫剧的所有场景必须使用相同的渲染引擎描述（统一用UE5或统一用Octane）
- 光影设定要与分镜脚本中的"光影"字段对应

## 完整工作流

当用户提供小说/剧本素材时，按以下顺序执行：

1. **生成分镜脚本** → 输出4段×最少6分镜 = 最少24个分镜，每个分镜标注时长，同段时长之和=15秒
2. **生成角色提示词** → 基于分镜脚本中的角色，输出每个角色的生图提示词
3. **生成场景提示词** → 基于分镜脚本中的场景，输出每个场景的生图提示词

**输出格式建议：**
- 分镜脚本：Markdown格式，清晰分段，每段用分隔线隔开，每个分镜含「时长」字段
- 角色提示词：每个角色独立section，标题用【角色名称】，提示词可直接复制使用
- 场景提示词：每个场景独立section，标题用【场景名称】，提示词可直接复制使用

---

## 风格统一原则

整个漫剧的美术风格必须保持一致：

1. **3D风格统一**：所有角色和场景使用同一种3D渲染风格（如全部Q版卡通，或全部写实）
2. **色彩统一**：主色调贯穿所有角色和场景
3. **渲染引擎统一**：角色用8K渲染标注，场景用UE5/Octane统一标注
4. **光影逻辑统一**：场景的光影设定要与角色在该场景中出现的分镜光影描述一致
5. **时长严格统一**：每段分镜脚本总时长严格=15秒，每个分镜单独标注时长

## 与即梦Seedance 2.0的适配说明

- 分镜脚本中的"画面内容"字段直接影响即梦的视频生成质量，描述越具体越好
- 分镜脚本中的"时长"字段对应即梦生成时的镜头时长设置
- 角色提示词生成的是"角色参考图"提示词，用于先生成固定角色形象，再投入即梦生成视频
- 场景提示词生成的是"背景图"提示词，可先生成场景图，再作为即梦的背景参考
- 建议工作流：生成角色参考图 → 生成场景参考图 → 将参考图+分镜脚本投入即梦Seedance 2.0生成视频
