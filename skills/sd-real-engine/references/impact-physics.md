# 真实受力反馈、空气动力与终结技 (Impact Physics & Finishers) · ★权威总控

> R1 打斗的"打击感" = 受力反馈 + 空气动力 + 环境破坏，三者的**真实物理感**，不是特效。本文件含受力写法规格、四层级空气反馈、终结技三幕 R1 版、以及平台合规转译词典（写实打斗必用）。

---

## 一、 原则：轻≠弱，轻=快而重

R1 每一击都要有受力反馈。没有受力的动作 = 空气假打（模型会把"打了一拳"渲染成"挥手"）。**关键重击必须写清受力反馈；轻击也要写清落点与微反应。**

---

## 二、 受力反馈四层级（按击打烈度选用）

| 烈度 | 写法要点 | 示例 |
|---|---|---|
| 轻击/试探 | 落点明确 + 微反震 | `拳峰落在对方格挡前臂，对方手臂轻微一震，后退半步` |
| 中击/变线拳 | 落点 + 明显形变 | `一记勾拳击中肋部，对方身体向右弓起，脚下踉跄两步` |
| 重击/崩拳 | 落点 + 大幅形变 + 位移 | `重拳砸中下颌，对方头部剧烈后仰，双脚离地向后倒飞撞在墙上` |
| 终结/绝杀 | 落点 + 连锁破坏 | `低位扫踢命中膝弯，骨骼传来受力脆响，对方单膝砸地，地面被膝盖砸出裂纹` |

**受击方形变清单**（按受击部位选用）：
- 头部：剧烈侧偏 / 后仰 / 下颌线紧绷 / 汗水甩出弧线；
- 躯干：弓成虾形 / 胸腹凹陷波纹 / 两脚离地；
- 四肢：手臂被别弯 / 膝关节反向受力 / 腿部弹开；
- 整体：横飞 / 后飞撞墙 / 踉跄后撤 / 单膝跪地。

## 三、 空气动力四层级（R1 弱化气爆，保留真实空气感）

| 层级 | 表现 | 写法 |
|---|---|---|
| 路径反馈 | 拳风/腿风扰动周围介质 | `拳风掀起对方衣摆，发丝被带得扬起` |
| 速度证据 | 快速位移的可见痕迹 | `快速收拳回防，空中留下半透明残影`（残影 ≤0.2s，禁拖尾特效） |
| 命中反馈 | 接触点微尘/水珠 | `拳头砸中时衣料绷紧声，地面灰尘被震起一朵` |
| 环境受力 | 介质被动作波及 | `扫腿带起的风把桌上报纸掀飞` |

> R1 禁"空气扭曲泛白/锥形音爆气穴/环形气浪炸裂"等夸张气效（R2/R3 体系）。写实版用灰尘、水珠、衣摆、碎屑做空气证据。

## 四、 终结技三幕（R1 写实版：破局 → 绽放 → 余震）

> 所有绝杀/决定性一击按三幕推进，禁止一击直接结束；但 R1 余震**以真实受力与环境破坏为主**，禁夸张冲击波。

### 第一幕 · 破局（0.5~1.0s）—— 打破攻防平衡
- **化劲/借力破防**：掌心一搭引开对方格挡，防线瞬间向两侧崩开；
- **重击破格**：全力一击砸在双臂上，硬生生弹开防御架子；
- **下盘破坏**：贴地扫腿/踩脚截腿，直接摧毁对方支撑根基；
- **入身/走圈绕背**：踏入攻击线内侧绕至死角，正面防守全部失效。

### 第二幕 · 绽放（1.5~2.5s）—— 全力输出
- **跃起下劈/跳砸**：起跳即落（腾空与落地按 `r1-combat-core.md` §八 口径），拳/腿/武器如重斧自上而下全力劈落，落地即卸力续接；
- **贯穿式寸劲直击**：半步崩拳/穿心钉桥/标指，劲力聚于一点直贯目标，衣料绷紧、接触点微尘震起；
- **多段连击**：连续重击带出受力位移（每击一个落点+一个反应）；
- **摔投贯地**：过肩摔/巴投/内股，身体沿巨大弧线轰入地面。

### 第三幕 · 余震（1.0~1.5s）—— 真实物理后果（R1 版）
- **地面碎裂与塌陷**：命中点地面蛛网状放射性龟裂，碎石被余力推散、弹跳两下落回地面（微克制的写法：`地面震起一圈灰尘，几颗碎石弹起`）；
- **受击者形变与嵌入**：身躯弓成虾形，倒飞深嵌墙面或砸裂地面（克制版：`重重撞在墙上，墙皮簌簌掉落`）；
- **环境连锁**：桌椅掀翻、货架倾倒、尘土弥漫（写实环境破坏优先，特效让位）；
- **终帧法则**：R1 允许克制收势或悬念收尾（见 `r1-combat-core.md` §七），不做夸张冻结式收镜。

## 五、 平台合规转译词典（写实打斗必用 · 不承诺 100% 通过）

> ⚠️ 写实真人打斗的直白血腥词汇会被主流平台拦截器报错。以下词典**保留打击感同时提升通过概率**。最终以各平台实时审核政策为准。

| 维度 | 高危拦截词（严禁出现） | 合规转译词（通常可渲染） |
|---|---|---|
| 击打受力 | 狠狠砸扁、打断骨头、击碎内脏 | `重拳沉劲贯入`、`拳峰接触点肌肉剧烈凹陷波纹`、`骨骼受力脆响`、`重重撞退横飞` |
| 面部创伤 | 满脸鲜血、打爆眼球、牙齿崩碎 | `嘴角擦出深色血痕`、`眉骨破损微红`、`汗水与细碎水珠飞溅`、`头颅剧烈后仰受力偏转` |
| 致命打击 | 刺穿喉咙割喉、扭断脖子毙命 | `指尖如枪直抵咽喉寸许`、`双手反向扣颈翻摔`、`反关节别臂制伏` |
| 环境破坏 | 炸飞碎尸、血流成河 | `地面瓷砖寸寸龟裂`、`水泥石柱爆开蛛网裂纹`、`碎石被余力推散`、`雨水倒影剧烈震颤` |
| 刀具/冷兵器 | 劈开脑袋、捅穿胸膛 | `利刃破空贴面划过`、`刀刃格挡溅出星火`、`刀身被架住震颤`、`刀锋划破衣袖见血痕` |

**转译三原则**：
1. **暴力后果 → 受力与位移**：不写器官损伤，写"头后仰/弓身/横飞/撞墙"；
2. **武器杀伤 → 破空与格挡**：不写刺入切割内脏，写"贴面/格挡/星火/衣破"；
3. **要害指向 → 寸许留白**：写"直抵咽喉寸许"而非"刺穿喉咙"。

## 六、 禁写清单（R1 受力域）

- ❌ 光波/冲击波/能量色带/法阵（R3 体系）；
- ❌ 骨碎/内脏/断肢/大出血直白描写（拦截风险）；
- ❌ "打飞""打趴"等结果词不写受力过程（无效描述）；
- ❌ 静止蓄力段（总纲铁律，蓄力挂运动中）。
