## 二、五大核心视觉风格全局声明模版

以下五套为①画质基准的引用块模版，按项目风格**全场声明一次**；未指定时默认首选 3D国漫。

### 1. 3D国漫风格（默认首选）

> UE5.5 Path Tracing + Lumen 全局光照 + Nanite 几何精度，次世代 3D 国漫大片质感，超写实 PBR 物理材质，8K 分辨率，12bit HDR1500，Kodak 5207 电影胶片颗粒，anamorphic flare 水平拉丝眩光，Bloom 仅高能接触点泛光，Time Ramp 帧率动态调控，动作捕捉级流畅度，面部结构全程稳定不变形。

### 2. 真人写实武侠

> 院线级实拍动作电影质感，超写实物理世界，自然环境光，35mm 电影胶片颗粒，低对比高宽容度，粗粝江湖质感，真实布料与金属磨损，严禁塑料发光特效。

### 3. 二次元热血动画

> 高品质日式剧场版热血动画风格，赛璐珞上色结合电影级全局光影，锐利干净线条，强对比边缘高光，夸张速度线与爆发式冲击波。

### 4. 暗黑赛博朋克

> 8K 超高清，霓虹高反差赛博电影质感，潮湿夜城超宽画幅，体积雾，全息故障扫描线，金属机械义体与发光线路高精度 PBR 材质表现。

### 5. 国风泼墨仙侠

> 传统东方水墨与现代 3D 渲染融合，毛笔飞白笔触，宣纸质感漫射，黑白浓淡干湿分明，大面积负空间留白与金色流光符文点缀。

**风格选用纪律**：

- 风格与双轨版本联动：修仙版默认 3D国漫或国风泼墨仙侠；写实版默认真人写实武侠；赛博题材用暗黑赛博朋克；番剧感项目用二次元热血动画；
- 风格声明只进①画质基准，全场统一，禁止逐镜更换、禁止同一稿混用两套风格；
- 风格内的数值参数（8K／12bit HDR1500／Time Ramp 等）属锁定参数，调用时不得改写。
