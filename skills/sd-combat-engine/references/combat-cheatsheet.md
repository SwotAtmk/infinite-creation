# 打戏速查库（Combat Cheatsheet · 运镜锁 / 动作库 / 类型专库）

> **本文档是打戏引擎规则库 · 权威文件**
> 融合来源：script-writing-studio 04b（摄影机行为锁 + 情绪运镜 + 动作戏 + 武侠兵器 + 超能力 + 战场群战 + 自由搏击）
> 定位：**速查工具**，不是规则库。命中强运镜/打斗/追逐/特殊转场/复杂摄影机行为时查阅。

---

## 〇、使用原则（7 条）

1. **不替代打戏主结构**：最终仍按本引擎既有规则输出（八步写作脑 / 一镜一动一反馈 / 黄金颗粒度等）。
2. **不替代投喂适配**：本文件只帮选镜头和动作节奏；最终提示词由 `sd-feed-engine` 转写。
3. **普通文戏不强制使用**：常规对话、简单反应镜头，不要硬套运镜组合。
4. **一段只选少量组合**：4-8 秒单元最多 1 个核心组合；10-15 秒单元最多 2-3 个组合。**不要把速查表变成炫技清单。**
5. **组合编号不进最终 prompt**：内部标签而已，最终提示词必须写成画面语言。
6. **运镜服务情绪或动作结果**：每个运镜必须回答"**为什么这么动**"。不能只因为好看而动。
7. **摄影机行为锁优先**：选任何运镜前，先锁定摄影机类型/位置/距离/高度/方向/稳定度/速度/起止状态/禁止项。**不要只写"手持/固定/跟拍"**，要写成可执行句。

⚠️ **动作密度回填节奏档位**：命中打斗/追逐/强钩子/危机爆点时默认建议 **高密度动作或强钩子**；普通紧张调度可建议 **短视频中高密度**；强情绪凝视或仪式感动作才保留 **电影感中速**。**不要把动作段压回 1-2 镜。**

## 一、摄影机行为锁速查（★ 核心）

> 用于把"固定/手持/退拍/跟拍"等模糊词，转成可执行摄影机行为句。

| 行为锁 | 适合场景 | 可写的摄影机行为句 | 禁止项 |
|---|---|---|---|
| **固定锁** | 对峙、审判、仪式感、冷静观察、权力压迫 | 摄影机固定在两人正前方眼平中景，主体保持画面中央，不推拉不摇移，只让人物动作改变画面 | 禁止随机漂移、自动推近、无动机变焦、突然换机位 |
| **固定过肩** | 冷静反打、潜台词对话、压住情绪 | 摄影机位于角色A左后方，过角色A右肩固定拍角色B近景，肩膀作前景虚化，镜头不移动 | 禁止越过肩膀另一侧，禁止突然切到背后反方向 |
| **手持微动** | 克制焦虑、私密不安、轻纪录片质感 | 摄影机在角色右前方近景距离手持，随呼吸轻微上下浮动，主体保持画面右三分之一 | 禁止剧烈晃动、主体出画、晃成动作戏 |
| **手持跟拍** | 追逐、逃亡、慌乱移动、压迫主观感 | 摄影机在角色右侧约 1 米处手持侧跟，速度与脚步同步，转弯时短暂甩动后重新稳住 | 禁止突然越轴、跟丢角色、空间方向反掉 |
| **手持快摇** | 暴怒、突发危险、快速发现目标 | 摄影机先贴近角色面部，角色猛然转头时快速甩向目标，运动模糊后停在目标中景 | 禁止无目标甩镜、连续多次乱甩 |
| **稳定器跟拍** | 角色穿场、进入空间、带观众移动 | 摄影机在角色背后三步距离稳定器跟拍，平稳穿过走廊或人群，肩线保持画面中央 | 禁止手持晃动、穿过墙体桌椅人群 |
| **前导倒退跟拍** | 角色逼近、边走边说、压迫感增强 | 摄影机在角色正前方胸口高度倒退跟拍，保持上半身中近景，角色前进一步镜头同步后退 | 禁止速度忽快忽慢、撞到角色脸上 |
| **侧跟/背跟** | 同步移动、追踪目标、行进对话 | 从角色左侧平行跟拍保持半身中景；或从背后三步距离跟拍，前方空间逐渐展开 | 禁止跟拍中改变角色左右位置、突然跳到另一侧 |
| **退拍/后撤** | 主体逼近、冲击、惊吓、揭示空间 | 主体突然冲向镜头，接近瞬间摄影机快速后撤到广角全景，露出身后阻挡物和空间关系 | 禁止无动机后撤、后撤后空间结构改变 |
| **缓推/窒息推近** | 情绪压迫、真相逼近、眼神聚焦 | 摄影机从中景缓慢推向角色眼睛特写，速度逐渐变慢，到眼神处停住 | 禁止空泛"电影感慢推"，必须说明推向什么 |
| **拉远/后拉揭示** | 孤立人物、揭示环境、反转信息 | 从手部或物件特写缓慢后拉，逐渐露出完整房间和隐藏在画面深处的人 | 禁止拉远后丢失主体、揭示信息不明确 |
| **横移揭示** | 多人站位、空间关系、隐藏物出现 | 摄影机沿桌边从左向右横移，前景杯子掠过后依次露出三人左右站位 | 禁止横移中越过轴线、前景遮挡关键表情 |
| **半环绕** | 权力变化、人物被包围、心理转向 | 摄影机围绕角色半环绕 90°，从左侧移动到正面，最后停在角色眼平近景 | 禁止 360° 炫技连用、绕到错误空间侧 |
| **升降/俯仰变化** | 从人到环境、权力高低、命运感 | 摄影机从角色胸口高度缓慢升到头顶俯视，露出角色被人群围在中心 | 禁止无功能升降、高度变化导致主体比例变形 |
| **视线摇镜** | 视线引导、发现目标、信息转移 | 先拍角色面部，视线移向门口后，摄影机跟随视线摇向门缝并停住 | 禁止摇向无意义空处、目标不清晰 |
| **甩镜切** | 急促换角度、动作高潮、转场 | 动作高潮瞬间向画面右侧快速甩镜，运动模糊遮满画面后切到同方向新角度 | 禁止无目标甩镜、甩后空间方向反掉 |
| **遮挡转场** | 自然切换、同场换角度、换场 | 前景人物或门框完全遮住画面，遮满瞬间切到下一角度，主体重新清晰 | 禁止遮挡物没有来源、遮挡后人物站位跳变 |
| **焦点转移（rack focus）** | 信息揭示、暗线物件、心理转移 | 摄影机固定不动，先让前景物件清晰，随后焦点转到后景角色眼神 | 禁止焦点对象不明确、同时推拉造成混乱 |
| **长焦压缩** | 压迫距离、监视感、人群挤压 | 使用长焦压缩空间，前景人群和后景角色距离被压近，角色像被环境挤住 | 禁止主背景黏成一团，必须保留主体轮廓 |

## 二、运镜选择流程

```
① 判断情绪或动作功能（这一动是为什么服务？）
② 判断节奏档位（动作段默认高密度）
③ 从速查表选 1-2 个核心组合
④ 先写摄影机行为锁（类型/位置/高度/方向/速度/起止+禁止项）
⑤ 一段内组合数：4-8 秒 ≤1 个；10-15 秒 ≤2-3 个
⑥ 组合编号不进最终 prompt
⑦ 写进画面语言（左/右、前/中/后景、摄影机在哪侧）
```

## 三、类型专库索引

| 类型 | 适用场景 | 核心语法 |
|---|---|---|
| **战场/群战/军阵** | 军阵、盾墙、骑兵冲锋、弓箭齐射、攻城、伏击、多人混战 | **战场层次 → 主行动线 → 群体压力 → 关键接触点 → 战线结果 → 段末状态** |
| **武侠兵器** | 刀剑、棍、暗器、武器对招 | 兵器物理逻辑 + 招法拆解 + 接触即反馈 |
| **超能力/异能** | 法术对轰、异能释放 | 特效尺度 + 能量逻辑 + 代价可视化 |
| **自由搏击** | 现代格斗、拳脚近身 | 打击点 + 受击反应 + 体力消耗 |

⚠️ **最终必须回填到本引擎既有输出规范**，不输出本文件内部编号。

## 四、战场动作速查（战场/群战专用）

**空间语法（必写）**：
```
战场层次 → 主行动线 → 群体压力 → 关键接触点 → 战线结果 → 段末状态
```

❌ **不要只写**"万人混战、战场惨烈"
✅ **必须写清**：主角在哪里、敌人从哪里来、镜头在哪一侧、战线怎么变

| 类型 | 可写动作 | 运镜建议 |
|---|---|---|
| 盾墙推进 | 前排盾牌从画面右侧压入，中景长枪从盾缝探出，主角被迫后退 | 低机位广角，保留盾线方向 |
| 长枪阵 | 枪尖形成斜向线压向前景，第一支枪擦过主角肩侧 | 长焦压缩枪尖密度，禁止枪杆乱向 |
| 骑兵冲锋 | 马蹄从远景烟尘中逼近，前景士兵举盾下蹲 | 地面低角度，写清冲锋方向 |
| 弓箭齐射 | 远景弓手抬弓，箭雨从上方斜落，中景盾牌接住第一波 | 先远景建立，再切盾牌接触点 |
| 伏击 | 两侧高处旗影晃动，箭矢从侧后方射入队伍 | 镜头跟主角视线转向伏击方向 |
| 攻城 | 云梯靠上城墙，守军推下滚木，前景士兵散开 | 广角俯拍建立上下空间 |
| 撤退 | 指挥者后退挥手，前排士兵交替掩护，伤者被拖离中景 | 手持侧跟，保持撤退方向 |

**战场动作分层要求**：前景主角动作 / 中景敌我接触 / 远景战线变化。交接时必须给：前中远景层次、主行动线、群体压力、关键接触点、战线结果。

**不适合本库的**：两人精细格斗、纯武侠屋顶追逐、强异能斗法 → 读对应子库。

## 五、工程语言 → 画面语言转换（交付前必做）

| 给人看的工程语言 | 给模型的画面语言 |
|---|---|
| 180 度轴线锁定 | 角色A始终在画面左侧，角色B始终在画面右侧 |
| 不要越轴 | 摄影机保持在两人正前方这一侧，不切到背后反方向 |
| A2 点位 / B2 点位 | 角色站在茶几左侧 / 角色坐在沙发右端 |
| 以沙盘为锚点 | 沙盘位于画面中央，人物围绕沙盘左右分布 |
| 高低落差 2 米 | 一人站在高台上俯视，另一人跪在台阶下仰视 |

**推荐用**：左侧、右侧、前景、中景、远景、画面中央、画面深处、摄影机在窗外/正前方、角色向画面右侧移动。
**谨慎用**：东南西北、180 度轴线、锚点编号、A1/B2 等管理编号。若必须保留点位，**必须同时翻译成可见画面**。
