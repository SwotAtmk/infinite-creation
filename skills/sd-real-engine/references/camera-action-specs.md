# 打斗镜头规格与空间铁律 (Camera & Action Specs) · ★权威总控

> 镜头是打斗的骨架。每个镜头必须把 5 维参数想清楚（设计检查表），落到镜行时只写三要素 + 动作 + 声音/台词。本文件含空间铁律、景别阶梯、机位-动作语义绑定、三手法六式衔接。

## 一、 镜头规格五要素（设计检查表 · 每次镜必想）

$$\text{格式}：[\text{景别}] · [\text{拍摄视角}+\text{角度}] · [\text{运镜方式}] · [\text{跟随目标}]$$

| 要素 | 标准选项 | 正确写法示例 |
|---|---|---|
| ① 景别 | 特写 / 近景 / 中近景 / 中景 / 全景 | `近景` / `中景` |
| ② 拍摄视角 | 正面(0°) / 侧面(90°) / 斜角(30°-60°) / 俯拍 / 仰拍 | `45°斜侧` / `正面0°` / `30°仰视` |
| ③ 角度 | 平视 / 仰视(N°) / 俯视(N°) | `平视` / `30°仰视` |
| ④ 运镜方式 | 跟拍跟镜 / 急速推镜 / 急速拉镜 / 甩镜闪切 / 升降运镜 / 环移(≤180°) / 定镜收束 | `急速推镜` / `跟拍跟镜` |
| ⑤ 跟随目标 | 角色、肢体或具体接触点 | `跟随右拳推进至心口接触点` |

> ⚠️ **镜行书写口径（落稿只写三要素）**：五要素是**设计检查表**；落到【时间轴分镜】镜行时只写 `[镜头N] 景别 · 视角角度 · 运镜。动作描述。声音：…。台词：…。`——不写"跟随@谁"（跟随目标作为运镜策略自然融进动作描述，如"镜头随其位移横移"），不用括号五要素连写的外部变体。

## 二、 空间感两大铁律

1. **中景/全景禁 90° 侧面正拍**：中景及全景（看到双人全身或大半身）**严禁 90° 侧面正拍**（街机横版廉价感）。必须 30°~60° 斜角拍摄，借前后人物遮挡与背景纵深制造对决压迫感。
   - **唯一例外**：近景/特写（胸部以上或手部细节对招）允许 90° 侧拍。
   - **多人同场注**：中景/全景改为「主角 + 当前对手 + 一人作前景遮挡」的 30°~60° 斜角分层构图；**特写禁 ≥3 人同焦**（脸崩 / 分身高发）。见 `multi-opponent-rules.md` §六。
2. **景别与动作幅度绝对匹配**：
   - 大幅动作（腾空/大步崩拳/飞踢/过肩摔/翻滚位移）→ 必须配 **全景/中景**，展现舒展身形与空间位移；
   - 小幅动作（短桥寸劲/指探面门/卸力擒拿/肘击）→ 必须配 **近景/特写**，放大击打密度与受力细节。

## 四、 景别阶梯跃迁（防平铺重复）

连续镜头景别/机位严禁平铺重复，按阶梯跃迁制造视觉推进感：

$$\text{标准阶梯} = \text{极微距特写（发力微观）} \to \text{超广角/低角度中景（攻防位移）} \to \text{宏观全景（环境破坏）} \to \text{鸟瞰/过肩收镜}$$

1. **严禁连续两个镜头使用相同景别+相同机位**；
2. **动作高潮前插入极微距特写**（指尖发力/肌肉绷紧/眼神聚焦），浅景深虚化背景；
3. **重击/终结技用宏观全景**展示环境破坏（墙面崩裂/桌椅掀飞/尘土扬起）；
4. **收尾用鸟瞰或过肩收镜**，配合烟尘/落叶遮挡转场（Occlusion Wipe）。

### Eye-Trace 视线流
- 相邻镜头的主体高光/视觉焦点保持在屏幕**同一象限**或沿动势方向连续过渡；
- 例：镜头1 右侧出拳 → 镜头2 自右向左的受力者，避免观众视线满屏搜索。

## 五、 机位-动作语义绑定表（先定动作语义，再定机位）

> ⚠️ 铁律：**机位不是随便选的，必须与发力方向/受力点/体量绑定**。先问"这个动作的语义是什么"，再查表选机位；严禁机位与动作语义错配。

| 动作语义 | 机位选择 | 为什么对 |
|---|---|---|
| 贴地横扫 | 低机位贴地跟拍 | 看到腿/武器水平切过，高度差制造切割感 |
| 重拳砸地/砸墙 | 大仰角中景 | 体量压迫感拉满 |
| 侧闪/绕背 | FPV 第一人称跟随或过肩 | 代入感最强，看穿动作轨迹 |
| 升空/跳起 | 俯拍起跳 → 仰拍升空 | 先压后升，力学过程可见 |
| 摔投贯地 | 低机位全景侧拍（30-45°） | 完整看到被摔者弧线舒展 |
| 近身缠斗 | 肩后过肩镜头 | 看两人重心的撕扯 |
| 挑衅/神态 | 特写浅景深 | 表情记忆点（必须挂动作上，禁静止） |
| 环境破坏 | 中景快速拉远 | 破坏结果整体呈现 |

## 六、 受击镜头工具箱（挨打方怎么拍）

> 受击不是"被打飞"三个字了事。按受击强度选用，让挨打方也有镜头语言：

- **短促径向震动**：命中瞬间镜头沿受力方向短促震一下（1~2 帧），模拟受力冲击传递到摄影机；
- **轻微轴向受力**：镜头随受击方向小幅偏转/倾斜，传递"摄影机也被波及"的重量感；
- **瞬时焦点变化**：受击瞬间焦点从攻方急切到受击方面部（痛苦细节），或随击飞目标快速转移；
- **动态模糊与速度匹配**：击飞/震退段加径向动态模糊，模糊方向与位移方向严格匹配，禁全屏均匀模糊；
- **Time Ramp 变速**：仅限极短受击瞬间（命中帧前后 0.2s 内加速/减速切换），禁整段升格慢镜。

## 七、 三手法六式镜头衔接（多镜剪辑阶段）

### 三手法
1. **换机位**：改变拍摄角度与视角，保持主体动作连续；
2. **切景别**：特写切中景，中景切全景，由微观入宏观；
3. **跨段反应**：攻击击出瞬间切受击方防御或受创表情。

### 六式
- ① 动作连续切（挥招前半段切命中后半段）；
- ② 反应镜头切（攻方重击切守方瞳孔骤缩/咬牙/咳血）；
- ③ 景别跳切（长距离突进由全景跳入近景）；
- ④ 视线引导切（主角转头看向右侧，顺视线切右侧出现的威胁）；
- ⑤ 遮挡过渡切（前景立柱/人影掠过遮挡瞬间完成场景切换）；
- ⑥ 动势匹配切（上一镜向右翻滚，下一镜向右滑步冲拳）。

## 八、 组内过渡铁律（视频模型硬约束）

- 视频模型**一镜生成、不支持硬剪辑切换镜头**：一组内的 3~4 镜必须写成连续运镜衔接（推/拉/摇/移/穿透/遮挡过渡）；
- 真硬切必须拆成**多段独立生成**、后期剪辑拼接（每段单独投喂）；
- 一镜长镜头（ONER）：整段只写一条运镜轨迹，机位变化写成"镜头随动作自然运动"（贴地→抬升→环绕→拉远），禁止写分镜号；动作放在同一条轨迹上展开。
