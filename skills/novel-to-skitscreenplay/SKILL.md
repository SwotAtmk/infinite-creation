# 小说转漫剧剧本 Skill

## Overview

本 Skill 将长篇小说转换为符合**漫剧视频**规范的剧本格式。

**漫剧的本质公式：**
> 电影的开头（3秒入戏）+ 电视剧的密度（每分钟3个冲突）+ 相声的节奏（不断抖包袱/反转）+ 情绪的毒品（极致的爽或虐）

转换时须同时满足：钩子 → 冲突 → 反转 → 情绪爆点 → 悬念，五步一循环。

**核心原则**：**人物细节优先**。心理描写、微表情、对话节奏、动作细节是人物立起来的关键，改编时不得省略。节奏标记是为了辅助拍摄，不能喧宾夺主。

---

## 一、漫剧节奏铁律（编剧层面的控制，不直接写在剧本里）

### 1. 开头：3秒入戏（电影感）

- 第1集第1场前3秒，必须有**强视觉 + 强情绪**
- 禁止从"早晨起床""走进办公室""慢慢吃饭"这类慢热开场
- 常用手法：**结局前置**、**危机开场**、**身份反差亮相**

```
❌ 错误开头：
场1-1 日 内 姜远家 人物：姜远
△姜远早晨醒来，看了眼手机，慢慢起床。

✅ 正确开头（结局前置）：
场1-1 夜 内 星瑞大厦董事会 人物：姜远、全体董事
△姜远坐在董事长位置，手指轻敲桌面。
姜远（微笑）："一年前，你们把我优化了。"
△全场死寂。
【闪回开始】
场1-2 日 内 公司技术部 人物：姜远、周宏达
△周宏达把离职协议甩在姜远桌上。
【闪回结束】
```

### 2. 密度：每分钟3个冲突（电视剧感）

- 每集3-5分钟 = 至少15个冲突点
- 冲突定义：人物目标受阻、情绪对立、信息差爆发
- **不在剧本正文中频繁标注【冲突：★】**，这些冲突通过人物动作和台词自然呈现

### 3. 节奏：不断抖包袱/反转（相声感）

- 每30秒至少一个反转或包袱
- 反转类型：身份反转、信息反转、能力反转、道德反转
- **反转点只在关键处用简单标注**，不要每集堆砌：

```
△周宏达得意地打开代码库。
周宏达：你看，没有你，系统跑得更好——
△屏幕亮起，全是 Error 红色警告。
【反转】姜远留下的架构，没人动得了。
```

- 包袱也用简单标注：

```
【包袱】
△姜远从包里掏出红烧肉保温盒，放在会议桌上。
周宏达（愣住）：你……在董事会上带红烧肉？
姜远（淡定开盖）："饿，先吃口。"
```

### 4. 情绪：极致的爽或虐（情绪毒品）

- 每集有主导情绪，但**不要在每个场次头部标注情绪标签**
- 情绪通过人物动作、台词、镜头语言自然呈现
- 只在集尾用简单标注提示情绪落点和下集悬念：

```
△姜远转身离开，周宏达瘫坐在地上。
△电梯门缓缓关上，姜远的脸在门缝中消失。
【悬念】他真的把整栋大楼收回来了？
【第1集 完】
```

## 二、人物细节优先规则

### 1. 心理描写处理

心理描写必须保留，转换为 `(OS)：` 画外音，并匹配 `△动作` 细节。**严禁把心理描写粗暴删改成简单动作**。

```
✅ 正确示例：
赵薇薇（微笑）："简单来说就是——恭喜你，被优化了。"
△姜远看着她，点了点头。
△赵薇薇愣了一下。嘴角的弧度出现了百分之零点三的波动，显然没见过这么快进入"接受"阶段的选手。
赵薇薇："你没什么想问的吗？"
△姜远低头翻了翻文件。
姜远："我饭卡上还有三百八十块钱，能退吗？"
△赵薇薇脸上的微笑裂开了一条缝，维持了大概零点五秒，又重新焊上。

❌ 错误示例：
赵薇薇："恭喜你，被优化了。"
姜远："我饭卡上还有三百八十块钱，能退吗？"
赵薇薇（微笑）："你可以去行政那边问一下。"
```

### 2. 微表情/微动作处理

原著中人物的微表情、眼神变化、肢体停顿、呼吸节奏等细节必须保留，用 `()` 或 `△` 写出：

- `()` 用于5字以内的表情/语气标注，紧贴台词：
  - `赵薇薇（笑容依旧）："恭喜"`
  - `周宏达（喉结滚动）："你……"`
- `△` 用于独立的动作、表情、细节描写：
  - `△赵薇薇接过文件的手，指尖在纸面上多停了一秒。`
  - `△周宏达肩膀塌了下去，整个人缩小一号。`
  - `△姜远端咖啡的手停住。`

### 3. 对话节奏处理

对话不能只是信息传递，必须保留：
- 停顿、重复、结巴
- 答非所问
- 潜台词（没说完的话）
- 人物的口头禅或语气习惯

```
✅ 正确示例：
周宏达："你来是想问我愿不愿意投资，或者收购。"
△周宏达点头。
姜远："我可以买下你的公司。"
△周宏达眼眶突然红了。

❌ 错误示例：
周宏达："公司撑不住了。"
姜远："我可以买下你的公司。"
周宏达："谢谢。"
```

### 4. 关键细节不得省略

以下类型细节必须保留，不得简写：
- 数字细节（金额、时间、数量、工号、代码行数）
- 道具细节（杯子缺角、领带歪、袖口咖啡渍）
- 环境细节（工位在厕所旁、冷白色灯光、地板反光）
- 人物关系细节（团建通知0次、代码被署名错工号、红烧肉配方比例）

## 三、格式系统

### 场号格式

`场x-y`，如 `场1-1` 代表第1集第1个场景。

### 场次头部信息

```
场1-1 日 内 公司技术部办公室 人物：姜远、赵薇薇、周宏达
```

| 要素 | 说明 |
|------|------|
| 场号 | 场x-y |
| 时间 | 日 / 夜 |
| 地点类型 | 内 / 外 |
| 具体地点 | 详细地点名称 |
| 出场人物 | 本场所有角色 |

**注意**：不要在头部标注【冲突：★】、【情绪：X】等冗余标记。

### 核心符号系统

| 符号 | 用途 |
|------|------|
| `△` | 人物动作 / 环境描述 / 镜头提示 |
| `()` | 伴随台词的微表情/语气，限5字内 |
| `(OS)` | 心理活动画外音 |
| `(OS-角色名)` | 特定角色的心理活动画外音 |
| `(VO)` | 电话 / 广播 / 旁白 / 群消息 |
| `(VO-角色名)` | 特定来源的画外音 |
| `【闪回开始/结束】` | 回忆片段标记 |
| `【角色字幕】` | 人物首次出场，必须保留 |
| `【时间字幕】` | 时间跳跃，必须保留 |
| `【反转】` | 关键反转点，简洁说明 |
| `【包袱】` | 喜剧包袱点 |
| `【悬念】` | 集尾悬念，必须保留 |
| `【第X集 完】` | 集尾标记，必须保留 |

## 四、转换规则

### 1. 心理描写（约500字）

- 转为 `(OS)：` 画外音 + `△` 动作
- 提取心理活动关键词，保留态度/自嘲/狠劲
- OS 内容控制在20字以内，超出拆分
- **必须保留原著心理描写的转折和细节，不能简化**

### 2. 环境描写（大段）

- 浓缩为 `△空镜：...` + 必要时 `【时间字幕】`
- 保留能渲染情绪的关键细节：光线、温度、气味、声音

### 3. 多人对话（5人以上）

- 精简至3人核心对话，其余转为 `(VO)` 背景音
- 配角出场 ≤ 3次 / 10集
- 在「人物出场控制表」中记录

### 4. 时间跨度（3年以上）

- 强制添加 `【时间字幕】`

### 5. 回忆杀（整章）

- 用 `【闪回开始】` 和 `【闪回结束】` 包裹

### 6. 台词语速

- 以 **3个字/秒** 计算台词时长
- 超长台词必须拆分，配合镜头切换

## 五、输出结构

转换完成后，按以下顺序输出，**简洁实用，不要冗余**：

### 1. 改编说明

- 原著名称、总字数、建议集数、总时长
- 核心钩子
- 情绪主线
- 人物弧光简述（每人1-2句话）

### 2. 人物表

每个核心人物包含：
- 姓名、年龄、身份
- **弧光轨迹**（起点 → 拐点 → 终点）
- 外形
- 表演提示（前期/中期/后期分别怎么演）

### 3. 主要场景表

| 场景 | 出现集数 | 关键道具 | 视觉特征 |
|------|---------|---------|---------|
| 公司技术部 | 1、2、4 | 马克杯、离职协议 | 冷光荧光灯，灰色隔断 |

### 4. 人物出场控制表

| 角色 | 出场集数 | 功能定位 |
|------|---------|---------|
| 姜远 | 1-10 | 男主，弧光核心 |

### 5. 主要道具清单

| 道具 | 出现集数 | 叙事功能 | 规格说明 |
|------|---------|---------|---------|
| 红烧肉 | 1、3、5、10 | 情感符号 | 老何手写菜谱 |

### 6. 集数结构表

| 集 | 建议时长 | 钩子（前3秒） | 反转数 | 情绪落点 | 悬念 |
|---|---------|-------------|--------|---------|------|
| 1 | 约4分钟 | 姜远坐在董事会上："一年前，你们优化我" | 3 | 爽 | 他到底是谁？ |

### 7. 完整剧本

按集输出，每集内部包含：
- 场号、时间、内外、地点、人物
- `△` 动作与 `(OS)` 心理
- `()` 微表情/语气
- `(VO)` 画外音/群消息
- `【反转】`、`【包袱】` 仅在关键处使用
- `【悬念】` 和 `【第X集 完】` 结尾

### 8. 拍摄技术说明（简要）

- 关键场景机位/灯光建议
- 配音/音效建议
- 3秒入戏、反转节奏、情绪曲线提醒

## 六、工作流程

### Step 1：读取小说

- 用户提供文件路径（.txt / .docx / .md），先用工具读取
- 用户直接粘贴文本，直接使用
- 确认总字数、章节数、核心人物

### Step 2：漫剧改编简报

输出一份简要简报供用户确认，**不要长篇大论**：

```
【漫剧改编简报】

原著：《XXX》
总字数：约X万字
建议集数：XX集（每集3-5分钟，总时长约XX分钟）

核心钩子：……
情绪主线：……

人物弧光：
- 男主：…… → ……
- 反派：…… → ……
- 女配：…… → ……

3秒钩子方案：第1集前3秒的具体画面/台词
是否确认？确认后按集输出。
```

### Step 3：按集转换

- 严格按格式输出
- 每集完成后自检：
  - 前3秒是否有强钩子？
  - 是否每30秒有反转或包袱？
  - 结尾是否有悬念？
  - 人物微表情/微动作细节是否保留？

### Step 4：输出完整文档

保存为 `.md` 文件，结构清晰，便于拍摄使用。

## 七、注意事项

1. **人物细节优先**：心理、表情、动作、对话节奏不得省略。
2. **减少冗余标记**：不要每个场次标【冲突】、【情绪】，只在关键反转处标【反转】，集尾标【悬念】。
3. **人物首次出场**必须加 `【角色字幕】`。
4. **时间跳跃**必须加 `【时间字幕】`。
5. **每集结尾**必须 `【悬念】` + `【第X集 完】`。
6. **配角出场**控制在3次/10集以内，超标时提示用户。
7. **台词语速**按3字/秒计算，超长台词拆分。
8. **闪回**用 `【闪回开始/结束】` 包裹。
9. **道具细节**要具体，不要写"一个杯子"，要写"缺口马克杯"。
10. **输出前自查**：是否把原著里"那个人愣了一下""手指停住""嘴角抽动"这类细节删掉了？如果删了，补回去。
