# 赛道分流规程

> **本文件是「〇·0 赛道强制分流」的唯一权威定义。** 总控 SKILL.md 〇节只写路由入口，赛道定义、判定信号、规则集映射、扩展方法一律以本文件为准。

---

## 〇、为什么要有这一层

**病根**：及以前，本套装只有**一套**剧本与视听规则，默认按**国内短剧**（红果 / 抖音付费强爽 / 漫剧）的语速、台词习惯、观众预设来写。一旦用户要做**海外剧**（非中文正文、真实地域口语、多语环境），这套默认值会**系统性出错**：

- 台词仍按中文 `3.5~6 字/秒` 计（英文应按词计）；
- 默认用中文剧本的**信息顺序、称呼频率、解释习惯**直接翻译成外语，产出"翻译腔"；
- 默认模型能判断"当地人就这么说"——**模型没有任何当地语料，却会自信地产出所谓地域腔**；
- 默认人物身份（职业、族裔、地域）可以推出其口音、换语、权限——**这是未经证据的推断**。

**解法**：把「做哪一类剧」升格为**先于一切创作锁的第零道锁**，让两条赛道各自挂自己的规则集，互不污染。

---

## 一、〇·0 赛道强制分流锁（第零道锁）

> **位置**：总控 SKILL.md 〇节，**排在 A·模型版本 / B·画幅 / C·交付形态 / D·段缝衔接 之前**。
> **规格**：与 A/B 锁同级——**用户未指定时，唯一正确动作是停下询问；禁止以任何理由默认赛道**。

```text
请先确认本次做哪一类（〇·0 赛道分流 · 第零道锁）：

1. 国内剧     —— 红果 / 抖音付费强爽 / 漫剧等中文短剧
2. 海外剧     —— 非中文正文 / 北美等真实地域口语 / 多语 / 方言项目
3. 解说叙事类 —— 解说 / 拉片 / 盘点 / 历史人物 / 历史事件 / 科普（正式赛道 · 挂载 sd-jieshuo-engine）
4. 其他       —— 广告片 / 宣传片 / PREVIS / 其他非剧集形态

回复示例：1    或    2（北美英语）
```

**分流时机**：**在最开始、任何创作之前**。分流结论写入任务基准表（P0A 基准表），全流程不再更改；确需改赛道 = 重开任务，禁止中途换赛道沿用旧产物。

**分流的实际作用**：决定**剧本层（P1）读哪一套规则**，以及**台词语言如何向下游（分镜 / 投喂 / 机检）传递**。

## 二、四赛道定义与判定信号

### ① 国内剧（默认赛道）

| 项 | 内容 |
|---|---|
| **判定信号** | 抖音 / 红果 / 快手；付费强爽、重生复仇、都市、古装、悬疑、甜宠；漫剧；中文正文 |
| **正文语言** | 中文 |
| **语言合同** | **不建立**（普通中文任务不填表） |
| **剧本质量基线** | 国内短剧节奏：`3.5~6 字/秒` 语速、黄金前 3 秒钩子、卡点与付费节点 |
| **平台合规** | `platform-safety-compliance-guide.md`（国内平台安全转译） |

### ② 海外剧

| 项 | 内容 |
|---|---|
| **判定信号** | 英文 / 非中文正文；北美（美国 / 加拿大）、欧洲、其他海外地区；多语混说、方言、移民社群；TikTok / YouTube / Reels / Shorts 等海外投放 |
| **正文语言** | **目标语言**（可能完全非中文） |
| **语言合同** | **必须建立**（第一句对白前，见 `sd-overseas-engine`） |
| **剧本质量基线** | 海外观众预设：**不预设中文短剧的强爽节奏**；台词按**目标语言**的语速与表达习惯计 |
| **平台合规** | 目标平台的投放规范（只约束对应投放物，不普适） |
| **额外挂载** | **`sd-overseas-engine`（L2 生产层 · 剧本层叠加）** |

### ③ 解说叙事类（挂载 `sd-jieshuo-engine`）

| 项 | 内容 |
|---|---|
| **判定信号** | 解说、拉片、盘点、逐帧拆解、口播影评、历史人物志、历史事件、科普、冷知识、知识区、"一口气看懂"、纪录片式旁白 |
| **子类型** | 历史人物志 / 历史事件战役 / 科普知识解说（**三选一，进入前确认**） |
| **正文语言** | 中文（历史/科普题材可中英混排） |
| **语言合同** | **不建立**（同①）；但**历史/科普题材须信源分级（T1/T2）** |
| **剧本质量基线** | 解说旁白语速 `4.5~6.5 字/秒`（金句 3~4）；钩子 0~3s、≤15 字；结尾金句；声画信息差纪律 |
| **平台合规** | 解说类字幕/封面规范 + **史料引用来源标注** |
| **额外挂载** | **`sd-jieshuo-engine`（L2 生产层 · 剧本层叠加）** |
| **规则集权威** | `sd-jieshuo-engine/SKILL.md` + 其 references（旁白稿 / 历史视觉 / 爆款公式） |

### ④ 其他（按需扩展）

| 项 | 内容 |
|---|---|
| **判定信号** | AI 广告片 / 宣传片 / 分镜预演 PREVIS / 武打动作设计 / 其他非剧集形态 |
| **规则集** | 复用现有全流程，**不套用剧集专属的集数 / 卡点 / 追看约定** |

## 三、各赛道规则集映射（读哪些文件）

> **本表是「分流落到哪个文件」的唯一对照。** 加新赛道 = 加一行。

| 阶段 | ① 国内剧 | ② 海外剧 | ③ 解说叙事类 |
|---|---|---|---|
| **P0A 立项** | 总控 〇节 + `track-routing.md`（本文件） | 同左 **+ `sd-overseas-engine/references/language-contract.md`** | 同左（**不建语言合同**；历史/科普题材另读 `sd-jieshuo-engine/references/history-visual-style.md`） |
| **P0B 决策** | `sd-decision-engine` | 同左 | 同左 |
| **P1 剧本** | `sd-script-engine` 六阶段链 | 同左 **+ `sd-overseas-engine/SKILL.md` 全程叠加** | `sd-script-engine` 六阶段链 **+ `sd-jieshuo-engine/SKILL.md` 全程叠加**（脚本 = 旁白稿 VO Script） |
| **P2 资产** | `sd-asset-engine` | 同左（**人物形象需注意族裔 / 地域形象不得刻板化**） | 同左（**场景风格一致 > 人物一致**；人物为插画形象、不做跨镜连续表演） |

## 四、剧本层分流点（P1 入口 · 用户指定的位置）

**分流必须发生在剧本层的最前面**，早于：模式选择、来源登记、IP 开发、分集规划、正式剧本。

```text
【剧本层入口】
  ↓
〇·0 赛道确认（第零道锁）
  ├─ ① 国内剧 → sd-script-engine 六阶段链（不建语言合同）
  ├─ ② 海外剧 → sd-script-engine 六阶段链
  │              ＋ 第一句对白前建立【语言与风格合同】
  │              ＋ 全程按 sd-overseas-engine 执行
  └─ ③ 解说叙事类 → 先定子类型（历史人物志 / 历史事件战役 / 科普知识解说）
                   ＋ 脚本 = 旁白稿（VO Script），全程按 sd-jieshuo-engine 执行
                   ＋ 历史/科普题材强制信源分级（T1/T2）
  ↓
（后续 P2~P5 照常）
```

**执行要点**：

- 赛道未确认前，**不进入模式选择**（sd-script-engine 第 0 步），不生成任何 IP / 分集 / 正文；
- 海外赛道的**语言与风格合同在「构思和写句面之前」生效**，不许写完后倒填；
- 用户明确只要纯正文时，合同存入**交接记录**，不塞进剧本正文；但**末尾补一行状态不能算作已完成前置路由**。

## 五、下游影响（台词语言 → 分镜 · 投喂 · 机检）

> 赛道一旦是海外剧，**下游不是"照旧"**——台词语言变了，语速、口型、字幕、机检口径全都要跟着变。

| 维度 | ① 国内剧 | ② 海外剧 | ③ 解说叙事类 |
|---|---|---|---|
| **台词语言** | 中文 | **目标语言逐字稿**（锁稿后逐字交接到制作） | 中文（解说词 = 旁白，非对白） |
| **语速基准** | `3.5~6 字/秒`（`dialogue-speed-check.md`） | **按目标语言重算**——英文约 `2.2~3.0 词/秒`（≈130~180 wpm），**禁用中文字/秒口径** | **解说旁白 `4.5~6.5 字/秒`**（金句 3~4），见 `sd-jieshuo-engine/references/narration-vo-script.md` |
| **对白语气位** | `台词：【角色（语气）："…"】` | 同格式，**台词内容为目标语言**，语气描述可用中文 | 解说词走 `声音：` 段（画外 VO），**台词字段 `台词：无。`**；出现对白时才用语气位 |
| **字幕** | 一般不需要（中文原声） | **需要**：外语正文 + 中文字幕（或目标观众语言字幕）**逐字锁定**，制作阶段不得自行改写 | **需要**：解说类逐词烧录字幕是标配（字幕后置、与旁白不重复） |
| **画外声 OS/VO** | 走 `vo-os-weaving.md` | 同左 **+ 换语时须核对单语听者是否被排除** | **全片 VO**——`vo-os-weaving` 的 ≤30% / 60~80 字/分钟卡口**不适用**（豁免），改用解说语速 + 声画信息差纪律 |
| **机检** | `C1~C26`（+增量主码 C27a~d 对话戏节奏 / C28a~c 台词机械化 / C29 资产状态偏离 / C30a~d 外挂指纹探针） | 同左 **+ 语言校准状态一致性**（声明与正文相符、不得自称 `human_reviewed`） | 同左，但 **C14 按赛道③ 分流豁免**（不判 VO 篇幅超配额）；另核对旁白句-画面映射与金句结尾 |
| **平台合规** | 国内平台红线 | 目标平台投放规范（**只约束对应投放物，不外推**） | 解说类字幕/封面规范 + 史料来源标注 |

**跨阶段守恒铁律**：换语、字幕或地方说法变化时，**同步**角色和单语听者"知道什么、是否被排除、何时获得共同语言信息"以及关系 / 行动后果。制作阶段**不得**因为"排了字幕"或"模型读起来顺"就升级本土化状态。

## 六、新赛道扩展四步法

> 用户后续要加"互动剧""知识付费""人物纪录"等新品类时，照这四步走即可，**不用动总控主干**。（「解说」已按此法转正为 ③，可作范例。）

1. **定赛道**：在 §二 加一节「赛道定义与判定信号」（表格：判定信号 / 正文语言 / 合同要求 / 质量基线 / 平台合规 / 额外挂载）。
2. **挂规则集**：在 §三 映射表加一列；规则集可写成**新子技能**（复杂、需独立分发）或**总控 references 文件**（轻量、仅剧本层少量差异）。
3. **开分流口**：在总控 SKILL.md 〇·0 的选项列表加一项；同步 §四 剧本层分流点分支。
4. **接校验**：在 `sd-qc-engine` 与 `validate_prompt.py` 加该赛道的核对项；同步 `scripts/check_package.py` 的断言，否则包级校验 FAIL。

**扩展纪律**：
- 新赛道的规则**不得回写污染国内赛道**（做成独立文件 / 子技能，不要就地改国内规则）；
- 新赛道的**体量、卡点、追看约定**不得默认继承国内短剧（见 §七 第 3 条）。

## 七、跨赛道铁律与禁止项

1. **赛道未确认 = 不开始**：与 A / B 锁同规格，禁止默认国内剧；用户说了但没说清（如"做个英语的"）时，追问一句确认赛道与目标语言。
2. **赛道决定规则，不决定质量下限**：两条赛道的质量底线相同（能看懂、有因果、台词属于此人此境）；差别在**节奏预设、语速口径、语言纪律、平台约束**。
3. **禁止跨赛道搬运约定**：
   - 不得把国内短剧的**付费节点、卡点频率、黄金 3 秒钩子**当作海外剧硬要求（海外投放模式不同）；
   - 不得把海外的**"场数不设固定下限"**当作可以省掉国内多集项目的分场要求；
   - 不得把某个赛道的**平台规则**外推到另一赛道（"某平台是 9:16" ≠ 所有项目 9:16）。
4. **海外赛道不得自称已完成本土化**：模型判断、网页检索、双模型一致，**都不能**升级到 `human_reviewed`（见 `sd-overseas-engine/references/evidence-and-authority.md`）。
5. **分流的痕迹要留**：任务基准表（P0A）必须写明赛道编号与（海外剧的）目标语言 / 地区 / 校准状态；后续阶段只在此基础上**新增证据**，不另建互相冲突的状态。
