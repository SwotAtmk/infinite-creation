# 0715 剧本硬格式

本文件是低自由度规范。除非用户本轮明确修改，否则逐项执行。

## 目录

- 字体、颜色与对齐
- 每集固定顺序
- 场次题头与人物表
- 动作、对白和声音术语
- 制作标记
- 完整模板

## 1. 字体、颜色与对齐

- 富文本或文档版：全文使用宋体；集标题14磅，正文12磅；正文行距约23.4磅。
- 集标题居中并加粗。
- 集前人物总表、场次题头、逐场人物表加粗。
- 正文中的对白人物名与对白不加粗。
- 需要出现在成片字幕中的文字使用钢蓝色 `#4682B4`，包括对白人物名、台词、`(O.S.)`、`(V.O.)` 和字幕内容。
- 一旦某物被列入关键道具表，它在剧本正文中的每一次文字出现都必须使用红色 `#FF0000`，包括首次出现、使用、转移、损坏、失而复得和伏笔兑现；不得只标其中一部分。
- `【本集完】` 右对齐。
- 在不支持颜色和对齐的纯文本界面，优先交付HTML增强文本；使用 `<span style="color:#4682B4">`、`<span style="color:#FF0000">`、`<div align="center">` 和 `<div align="right">` 保存语义。生成DOCX时改为真实样式，不保留HTML标签。

## 2. 每集固定顺序

1. 居中的集标题。
2. 下一行写加粗的本集人物总表。
3. 下一内容块直接进入第一场。
4. 每场依次为加粗场次题头、加粗逐场人物表、动作与对白。
5. 最后一行右对齐 `【本集完】`。

不输出“场景题头”“画面/动作”“对白”“特殊音效与视觉”“专业术语”等教学栏目名称。用户明确要求栏目版时，栏目名称必须独占一行，内容从下一行开始。

## 3. 场次题头

固定格式：

`**1-1. 地点 [内] [夜]**`

规则：

- 使用“集号-场号”。
- 场号后使用英文句点，并留一个空格。
- 地点后依次写空间属性和天时；使用半角方括号，只允许题头中的 `[内]`、`[外]` 和时间标签使用半角方括号。
- 常用时间标签：`[日]`、`[夜]`；必要时可用 `[清晨]`、`[黄昏]`、`[傍晚]`、`[凌晨]`、`[黎明]`。
- 多地点使用 `/`，下级空间使用短横线；不要把地点、内外和时间粘连。
- 场次题头整行加粗，不使用颜色。

## 4. 人物表

- 集标题下一行：`**本集人物：甲，乙，丙**`
- 每个场次题头下一行：`**人物：甲，乙，群众若干**`
- 用中文逗号分隔；年龄、时期、伪装、形态等放入全角圆括号。
- 纯空镜场可以写 `**人物：无**`，不要省略逐场人物表。

## 5. 动作与可见画面

- 所有环境、人物动作、镜头中可见变化均以 `△` 开头。
- 每个完整句子单独占一行；以 `。` 为主要断句，`！`、`？`同样结束一句。
- 每行描述一个可执行的画面动作或一个紧密动作组。
- 动作续写仍需另起一行并重新使用 `△`，不得形成无标记的小说段落。
- 禁止直接写不可拍摄心理和抽象形容词；按 [production-writing.md](production-writing.md) 具象化。

## 6. 对白

基础格式：

`角色名：（表演提示）“台词。”`

硬规则：

- 人物名后用全角中文冒号。
- 表演提示使用全角圆括号；没有必要时省略。
- 每一句台词都用一对中文双引号明确始末。
- 每个完整句子单独占一行；同一角色连续说多句时，每行重复人物名。
- 人物名、冒号、声音术语、引号和实际说出的台词使用钢蓝色；表演提示可保持黑色。
- 对白人物名和对白不得加粗。
- 脏话后立即添加黑色制作提示 `【做消音处理】`。

HTML增强文本示例：

`<span style="color:#4682B4">陈墨：</span>（冷笑）<span style="color:#4682B4">“你以为你能跑？”</span>`

## 7. 声音术语

本Skill采用用户裁决的专用语义，不得替换成其他行业解释：

- `(O.S.)`：人物处于当前场景中，镜头可以拍到，但人物没有真的发声、嘴唇没有动；观众可听见其内心独白。
- `(V.O.)`：画外叙述、回忆声音、旁白；或人物没有出现在镜头中，或镜头没有拍到说话者。
- 必须使用英文字母 `O`，不得写成数字零 `0.S.` 或 `V.0.`。
- 推荐格式：`角色名：(O.S.)“内心独白。”` 或 `角色名：(V.O.)“画外声音。”`
- 人物名、术语和台词全部使用钢蓝色。

## 8. 制作标记

- 制作标记统一使用全角六角括号 `【】`。
- 常用标记：`【音效】`、`【字幕：……】`、`【特写】`、`【景别：……】`、`【运镜：……】`、`【特效】`、`【插入闪回】`、`【闪回结束】`、`【蒙太奇】`、`【平行剪辑】`。
- 制作标记可独占一行，也可放在动作句中需要生效的位置；不得使用半角 `[音效]`、`[字幕]` 等写法。
- `【字幕：……】` 整体使用钢蓝色；其他不进入成片字幕的制作提示保持黑色。

## 9. 完整模板

```html
<div align="center"><strong>《剧名》第01集</strong></div>
<strong>本集人物：陈墨，周启</strong>

<strong>1-1. 废弃仓库 [内] [夜]</strong>
<strong>人物：陈墨，周启</strong>

△陈墨推开生锈的铁门。
△雨水沿着他的衣角滴在水泥地上。
<span style="color:#4682B4">陈墨：</span>（冷笑）<span style="color:#4682B4">“你以为你能跑？”</span>
<span style="color:#4682B4">陈墨：(O.S.)“门后还有一个人。”</span>
【音效】仓库深处响起金属拖地声。
<span style="color:#4682B4">【字幕：三分钟前】</span>
△周启把<span style="color:#FF0000">黑色钥匙</span>攥进掌心。

<div align="right">【本集完】</div>
```
