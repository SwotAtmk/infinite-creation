# 08 · 角色设定、武学绑定与场景风格预设库 (Character & Scene Presets)

## 一、 九大经典打戏角色资产卡与武学绑定

### 1. 太极（以柔克刚 · 刚柔互济）
* **绑定武学**：太极拳 / 八极拳 / 咏春拳 / 八卦掌
* **战斗逻辑**：远则太极化劲卸力，近则八极短打硬炸，中线咏春连环，走位八卦绕打。
* **劲气视觉**：黑白阴阳双色气焰，近身爆发凝聚成尖锥，化劲时呈涟漪散开。
* **角色铁律**：动作绝无生硬直撞，必有弧形导引与借力反击。

### 2. 红茶（暴力压制 · 刚劲顿挫）
* **绑定武学**：泰拳 / 散打 / 空手道 / 八极拳
* **战斗逻辑**：全刚无柔，泰拳膝肘内围绞杀，散打接腿快摔，八极铁山靠硬砸，全程暴烈前压。
* **劲气视觉**：橙红爆裂火焰，热浪翻涌，一招一炸，打完留下焦黑灼痕。

### 3. 白鸽（灵动机动 · 腿法宗师）
* **绑定武学**：巴西战舞 / 36路腿法 / 谭腿 / 跆拳道 / 截拳道 / 少林旋风地堂腿
* **战斗逻辑**：巴西战舞空翻弹跃闪避，36路大开大合连环抽踢，低位地堂腿偷袭破下盘，540°水平旋风腿终结。
* **劲气视觉**：紫黑色烈焰气旋，踢击弧线可视化为新月紫黑光刃。

### 4. 凛羽（形意穿刺 · 破招缠打）
* **绑定武学**：形意拳 / 八卦掌 / 擒拿 / 合气道 / 柔道 / 柔术
* **战斗逻辑**：70%时间形意直线穿刺与八卦走圈穿插，30%时间擒拿锁关节与柔道过肩翻摔，拿住立刻连打。
* **劲气视觉**：冰蓝银白霜雾（薄雾轻纱流动，非硬冰），唯有终结技凝聚为漫天冰暴。

### 5. 雷电（神速极杀 · 零前摇）
* **绑定武学**：截拳道 / 咏春拳 / 散打 / 武侠身法 / 八极拳速度版
* **战斗逻辑**：天下武功唯快不破，零前摇中线截击，打完三招对手才看到第一招残影。
* **劲气视觉**：纯紫与银白锯齿电弧，出招沿途留下不规则紫色闪电残痕与音爆云。

### 6. 芭乐（渐变绽放 · 灵巧降服）
* **绑定武学**：柔术 / 蔡拳 / 巴西战舞 / 跆拳道 / 形意拳
* **战斗逻辑**：站立蔡拳密集偏门快打，近身巴西战舞翻身换位，倒地巴西柔术锁臂降服。
* **劲气视觉**：浅粉渐变深粉花瓣气焰，轻击浅粉飘散，重击深粉炸裂如暴风。

### 7. 冰女（硬冰封杀 · 极度深寒）
* **绑定武学**：泰拳 / 八极拳 / 空手道 / 洪拳 / 擒拿
* **战斗逻辑**：泰拳膝肘与八极硬打硬攻，打到哪里硬冰就冻结到哪里，擒拿抓住直接结冰锁死。
* **劲气视觉**：蓝白渐变坚硬冰晶，命中点瞬间向外蔓延厚实冰甲与锐利冰刺。

### 8. 剑神（绝世剑尊 · 九剑无痕）
* **绑定武学**：武当玄门剑 / 独孤九剑 / 华山剑法 / 玉女剑 / 峨眉子午剑，佩专属「紫霄神剑」。
* **战斗逻辑**：九套剑法切换无痕，出剑即破招，看到剑光时剑已收回，点穴刺喉。
* **劲气视觉**：红紫瞬闪光轨，剑尖细长高亮白芒，剑脊格挡紫铜火星，终结满月红紫剑波。

### 9. 绯雪（极致前压 · 火焰刀宗）
* **绑定武学**：绯雪樱灼流单太刀术 / 火焰刀 / 焚樱刀禅 / 武侠身法，佩单柄「灼霜」长刀。
* **战斗逻辑**：不讲试探，不做退让，贴脸即连斩，刀刀破防，火红刀浪一路向前狂扑吞咬。
* **劲气视觉**：火红熔金刀焰，挥斩拖出厚重弯月火刃与暗赤尾焰碎火。

## 二、 二十大经典打戏场景参考库

1. **国风水墨 · 深山竹海古刹**：暴雨倾盆，狂雷横扫，青竹弯折，悬空青石栈道积水飞溅。
2. **写实纪实 · 城市雨夜小巷**：霓虹倒影，潮湿路面，铁制消防梯，雨滴水花飞溅。
3. **仙侠奇观 · 浮空云海仙台**：残破白玉石台，云层翻滚，万丈悬崖，流霞碎金。
4. **赛博朋克 · 霓虹废土窄巷**：全息广告投影，故障扫描线，机械义体反光，潮湿地面。
5. **大漠荒凉 · 千佛万窟绝壁**：漫天狂风黄沙，风化巨佛石窟，落日熔金，断壁残垣。
6. **太古极北 · 万丈玄冰残殿**：倒塌青铜梁柱，万载冻雪呼啸，深渊幽蓝寒光。
7. **地心烈焰 · 熔岩火海悬桥**：赤红熔岩翻腾，断裂黑石悬桥，地热热浪扭曲空气。
8. **东海极渊 · 惊涛天瀑龙阙**：万丈海啸狂卷，断裂盘龙青铜神柱，暴雨如注，漩涡撕咬。
9. **幽冥地府 · 忘川奈何血河**：惨绿磷火漂浮，血红彼岸花海，残破奈何石桥，阴雾遮天。
10. **宗门禁地 · 万剑插地天坑**：千万柄锈蚀古剑倒插成林，中央巨大剑碑倾颓，剑意森森。
11. **古罗马风 · 巨石角斗狂沙**：巨大环形石砌看台，漫天黄沙飞扬，烈日炙烤。
12. **虚空裂界 · 破碎星辰浮石**：虚空星云背景，悬浮陨石碎片，空间黑色裂缝交错。
13. **高山云巅 · 铁索连桥天险**：万丈悬崖间横跨粗大生锈铁索，云雾在脚下急速掠过。
14. **末日废墟 · 倾颓钢筋都市**：断裂高架桥，长满杂草的摩天大厦残骸，夕阳余晖。
15. **极简水墨 · 纯黑留白画镜**：大面积纯黑负空间，极淡水墨山水轮廓，脚下镜面水波。
16. **道家祖庭 · 九宫八卦石坪**：黑白阴阳鱼太极石阵，四周九根盘龙汉白玉华表。
17. **皇宫大内 · 金銮殿琉璃金顶**：倾盆夜雨，金色琉璃瓦连绵起伏，飞檐斗拱，闪电劈落。
18. **深海遗迹 · 沉没青铜龙宫**：透光海水，珊瑚巨柱残垣，气泡游戈，水下折射光斑。
19. **苍茫雪原 · 枯木荒村断桥**：积雪没膝，黑白枯树林，断裂木桥，寒鸦盘旋。
20. **魔宗血煞 · 祭血万魂魔坛**：暗紫魔雾升腾，巨大森白头骨祭坛，地面血纹符阵流转。
