# 视频平台格式：即梦（默认）

## 概述
字节跳动旗下AI视频生成平台，支持中文，镜头运动描述自然语言即可。

## Prompt 结构
```
[画面主体描述]，[场景环境]，[镜头运动]，[运动速度]，[情绪氛围]，[画风]
```

## 镜头运动词汇表
| 运动类型 | 推荐写法 |
|---------|---------|
| 推镜（向前） | 镜头缓慢推进，镜头快速推进 |
| 拉镜（向后） | 镜头缓慢拉远，镜头快速后退 |
| 横摇 | 镜头从左向右横摇，镜头缓慢水平扫视 |
| 竖摇（俯仰） | 镜头从上向下俯拍扫移，镜头仰角向上摇 |
| 横移（平移） | 镜头向左平移，镜头向右平移跟随人物 |
| 跟拍 | 镜头跟随人物移动，贴地跟拍 |
| 升镜 | 镜头缓慢上升，从低位升至全景 |
| 降镜 | 镜头从高处缓慢下降 |
| 静止 | 镜头固定，静止拍摄 |
| 环绕 | 镜头环绕人物旋转 |

## 运动速度修饰
- 缓慢（2-4秒内完成）
- 适中（正常速度）
- 快速/急速（0.5-1秒内完成）
- 升格慢镜（slow motion，动作放慢）

## 示例
```
17岁男生，短碎发，篮球服，坐在替补席上望向球场，室内体育馆暖黄灯光，镜头从侧面缓慢推进至近景，静止停留，日系动漫风格，情绪压抑克制，时长3秒
```

## 注意事项
- 即梦支持中文，自然语言描述镜头运动效果较好
- 建议在Prompt末尾注明「时长X秒」
- 升格慢镜写「升格慢动作」或「slow motion」均可识别
