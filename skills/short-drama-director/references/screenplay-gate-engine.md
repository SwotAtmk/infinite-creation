# 工业级五阶门控剧本引擎与去 AI 机械感视听法则 (Screenplay Gate Engine)

本模块规范了全题材（涵盖古装武侠、现代都市、悬疑脑洞、动作枪战、科幻等）短剧/漫剧从概念到专业剧本页的工业化生产标准。核心原则：**剧本即唯一真理源 (Screenplay as Source of Truth)**，所有角色、场景、道具资产自动从剧本文本双向绑定并派生。

---

## 一、 工业五阶门控开发流水线 (5-Stage Gate Pipeline)

动笔写剧本前必须依次通过五道门禁，严禁跳过结构直接写大段台词：

### Gate 1: Premise（核心前提与黄金 3 秒钩子）
* **30 字前提公式**：`[主角] + [核心欲望] + [不可抗力阻碍] + [失败的致命代价]`。
* **黄金 3 秒钩子类型**（必须明确选定其一）：
  1. 极端悬念钩（直接把枪口/刀尖对准主角咽喉，生死悬于一瞬）；
  2. 认知反差钩（看似最弱的外卖员/赘婿/乞丐，展现出颠覆常理的宗师特权）；
  3. 情绪爆发钩（至亲惨遭凌辱/婚约撕毁/绝境背叛，怒气值瞬间拉满）；
  4. 视觉奇观钩（天雷裂空/上古法相降临/超维异象爆发）。

### Gate 2: Structure（宏观三幕比例与分集卡点）
* **单集三幕时间比例**：铺垫建立 30%（0~30s） $\to$ 核心冲突危机 50%（30~80s） $\to$ 转折爆发与卡点 20%（80~100s）。
* **结尾卡点钩子（Cliffhanger）**：必须停留在决策关头、身份暴露瞬间、援兵突现或攻击命中的前一帧。

### Gate 3: Beat Sheet（场景因果节拍表）
* **场次存在性法则**：一场戏如果删掉后不影响后续剧情，则该场戏必须立即删除。
* **每场戏必须包含完整因果链**：`场景目标 -> 遭遇阻碍 -> 升级行动 -> 意外转折 -> 产生不可逆新局面`。

### Gate 4: Worldview & Entity Bounds（世界观与实体边界约束）
* **时代法则**：明确时代背景（古代/民国/现代/赛博未来），锁定法律、战力天花板与技术极限。
* **人际关系网络（Relationship Graph）**：明确上下级、仇恨、盟友关系，杜绝无动机叛变。

### Gate 5: Professional Script Page（语义化工业标准排版）
```text
[场景序号] [内景/外景] · [具体地点] - [日景/夜景]
出场人物：@角色A、@角色B
环境氛围：[空间构图、天气、主导光源与声音质感]

[动作描述]（遵循反形容词法则，只写摄像机能拍到的物理动作与空间位移）

@角色A（微动作指示：咬紧后槽牙，指节因用力而泛白）
“（台词内容，遵循冰山法则与潜台词）”

@角色B（冷笑，眼神下瞥避开对视）
“（台词内容）”
```

## 二、 去 AI 机械感三大法则 (Natural Screenplay Laws)

1. **角色压力与筹码追踪（Character Pressure Tracking）**：
   * 角色对话不是客气的问答，而是权力、信息与立场的隐秘博弈；
   * 每句对话必须有一方施压、另一方掩饰/反击，杜绝毫无立场的解释性闲聊。
2. **承重场景识别（Load-Bearing Scenes）**：
   * 区分“承重戏”（生死抉择、秘密揭穿、宗师死斗，投入最高视听与微表情密度）与“过场戏”（果断视听省略，一镜带过）。
3. **冰山对白（Iceberg Dialogue & Anti-Exposition）**：
   * 严禁角色向已经知情的同伴解释世界观设定（如“你明知道这本秘籍是天下第一……”）；
   * 双方已知信息一律转入潜台词、眼神与道具动作。
