## 一、Seedance 双档提示词转译引擎（2.0 vs 2.5）

| 维度 | Seedance 2.0 档位（单镜切片模版） | Seedance 2.5 档位（30s 一镜成片模版） |
|---|---|---|
| **单段时长** | 5s / 10s / 15s 单镜头独立生成 | 30s 完整长视频直出，多镜头连续叙事 |
| **时序控制** | 镜头序号（`Shot 1`、`Shot 2`）或细切时码 | **严格使用整数秒时间戳**（`0-7秒`、`7-15秒`、`15-23秒`、`23-30秒`） |
| **动作密度** | 每 2~3 秒 1 个核心攻防动词 + 1 个受力反馈 | 遵循「概括动线 + 少数记忆点动作」，严禁 3 秒内堆 10 个微操 |
| **音频控制** | 需外部挂载音频或后置 BGM | 原生音频自然句（`生成金属碰撞声与风雨声，无bgm`） |
| **多模态参考** | 1~5 个主体图/首尾帧参考 | 最多 50 个参考素材，支持多视图主体图与连续时间戳编辑 |
| **收束模式** | 协议 A/B/C/D 均可适用 | 推荐协议 C（光粒解构）与协议 D（反向错车背向出画硬切） |

**档位选择**：总控已锁定目标模型档位时跟随总控；未指定时，单场打戏（≤15秒）走 2.0 档单镜切片，完整打斗段落（20~30秒连续叙事）走 2.5 档一镜成片。

## 二、双轨制判定逻辑与参数替换规则

### 2.1 版本判断逻辑（按优先级）

**优先级 1 · 角色设定**
- 修仙者／修真者／武者（有内力）／妖／魔／仙／神 → 自动调用【修仙版】
- 普通人／特种兵／拳手／警察／黑帮／现代军人 → 自动调用【写实版】

**优先级 2 · 关键词触发**
- 修仙版触发词：灵力、剑气、法术、宗门、渡劫、元婴、金丹、法阵、御剑、真元、神识、符箓、魔气、仙气。
- 写实版触发词：都市、现代、格斗、拳击、武术、散打、搏击、街头、擂台、MMA、剑道。

**优先级 3 · 场景描写**
- 有超自然能力（隔空取物／能量爆炸／虚空悬浮）→ 修仙版；
- 纯物理格斗（拳拳到肉／撞墙碎物）→ 写实版。

### 2.2 混合场景过渡规则（都市修仙／解封爆发）

- **默认状态**：使用【写实版】（日常格斗／近身肉搏）；
- **爆发切换信号**：灵力升腾、眼睛发光、武器浮现符文、碎石悬浮 → 命中瞬间叠加【修仙版】能量爆炸，运镜切超广角大远景；
- **回落信号**：灵气收敛、光芒熄灭 → 切回【写实版】。

> 本模块是「混合场景（都市玄幻爆发）」的详细展开，不替代双轨制：纯仙侠/玄幻剧全程用修仙版；纯都市/现代剧全程用写实版；只有"日常写实+修仙爆发频繁切换"的混合题材才使用本小节的双态切换。打戏通用规则（八步链/铁律9特效/招式库/运镜五种融合句式/打击感体系）在能力爆发态中全部适用，本小节只规定态切换和能力受限特例，不改变打戏本身的写法。

#### 2.2.1 双态切换信号与过渡

**双态切换总览**：

| 维度 | 日常写实态 | 能力爆发态 |
|---|---|---|
| 特效 | 无超自然特效，纯物理 | 法阵/灵力/法术特效（附录A三层元素） |
| 气场 | 无 | 每节点绑定一个流动态写进动作句（铁律9/26，参数内部化） |
| 画质 | 胶片颗粒+生活质感+自然光 | 同画质+特效光+能量粒子 |
| 运镜 | 手持/斯坦尼康/固定，纪实感 | ACT/FPV/升降，冲击感 |
| 声音 | 环境音+Foley | 环境音+法术音效+低频boom |
| 角色状态 | 正常穿着/无发光 | 灵力雾气/眼睛发光/符文浮现 |

**写实→能力爆发态（触发信号，出现任意一个即切换）**：
①角色周身灵力雾气升腾/真气外露；
②眼睛变色/瞳孔发光/眉心印记亮起；
③武器/饰品发光，表面浮现符文；
④周围物体悬浮/地面碎石震起/空气扭曲；
⑤法阵在脚下/空中展开；
⑥角色台词暗示（"认真了""不再留手""解封"）。

**过渡方式（1-2帧，必须有因果，禁止硬切）**：
- 灵力雾气从角色身体向外扩散，雾气所过之处画面色彩微调（饱和度微升/对比度增强）；
- 法阵从一个光点扩展成完整阵法，光从阵纹中涌出照亮环境；
- 眼睛发光特写→拉中景，角色已被气场包围。

**能力爆发态→写实态（回落信号）**：
灵力雾气消散/真气收回体内；眼睛恢复正常/符文熄灭；法阵碎裂成光点消散；角色力竭/睡着/主动收功；战斗结束。

**回落过渡方式**：灵力雾气回流身体，最后一丝光从指尖收回；法阵碎裂成光粒向上飘散，光粒消散后画面恢复日常色调；角色打哈欠→灵力像泄气一样从身上漏走→恢复正常。

#### 2.2.2 能力受限角色爆发态降级表

🔴特例声明：以下特效降级规则**仅适用于剧本明确设定为能力受限的角色**（幼童身体/重伤/封印中/灵力耗尽/修为被废等），且仅在该角色亲自施法时生效。正常修仙角色的打戏仍按全尺寸（上移一档：常规起手70-100米/重击100-160米/终结160-310米/灭世310米以上）+周身气场（半径5-8米）执行，**不得滥用降级**。

当施法者是幼童/受伤/灵力不足的角色时，能力爆发态特效降级+不稳定：

| 项目 | 正常修仙版 | 能力受限版 |
|---|---|---|
| 法阵尺寸 | 数米至数十米 | 巴掌大到脸盆大，可能只有半个 |
| 法术尺寸 | 攻击起手即70-100米（上移，重击100-160/终结160-310） | 缩小到1-5米，甚至只有一束光 |
| 稳定性 | 稳定持续 | 闪烁/忽明忽暗/中途熄灭/颜色不对 |
| 气场 | 半径5-8米雾气 | 半径0.5-1米微弱雾气，时有时无 |
| 命中效果 | 三层能量爆炸 | 效果缩水（炸个坑/吹阵风/点亮灯泡） |
| 持续时间 | 整场战斗 | 数秒至十几秒，然后力竭 |

**写法要求**：
- 特效仍按附录A三层元素写，但尺寸用"巴掌大""一束""脸盆大小"等相对描述。
- 必须写出不稳定感：闪烁、滋滋声、中途熄灭、颜色偏差、施法者吃力表情（憋红脸/手抖/咬嘴唇）。
- 翻车时按"不靠谱能力翻车五段式"处理。
- **偶尔靠谱一次**：在情感/危机顶点，受限角色短暂爆发出完整规格的法术（1-2秒），然后立刻力竭，形成燃点。
- 🔴**召唤物不降级**：召唤物/帮手（如被召唤的神仙）若自身战力正常，其特效按正常修仙版尺寸，**不因召唤者受限而降级**。

#### 2.2.3 旁观者反应镜五型

能力爆发时必须穿插普通人/不知修仙者的反应镜头，形成"神仙打架+凡人懵逼"的反差喜剧。

**反应镜类型（各含动作链）**：
- **震惊型**：瞳孔骤缩→下巴微张→后退半步→揉眼睛（以为自己看错了）；
- **吐槽型**：面无表情→扶额→翻白眼→内心OS吐槽（闭嘴微表情+旁白）；
- **难以置信型**：眨眼→再眨眼→掐自己→接受现实（或拒绝接受）；
- **恐惧型**：脸色发白→后退→躲到障碍物后面→只露出半张脸偷看；
- **崇拜型**：眼睛变星星→嘴巴张开→双手握拳→变成小迷弟/小迷妹。

**规则（5条）**：
1. 反应镜**走日常写实态画质（无特效）**，与爆发态的华丽特效形成反差。
2. 反应镜在法术爆发后 **0.5-1秒插入，时长≤1秒**，然后切回 ACT/FPV/POV 沉浸运镜；**禁止在连击段/交锋段中间插入反应镜打断节奏**，只能在一击结束后的间隙插入。
3. 反应镜用 **35-85mm 中近景/特写，极浅景深奶油散景**，聚焦表情。
4. 反应镜可以用夸张 Beat 增强喜剧效果。
5. 旁观者从"不信→震惊→怀疑→接受→崇拜"的态度转变要有**渐进弧线**，不能一集就全信了。

#### 2.2.4 混合场景节奏配额

- 日常写实态占 **60%-70%**（生活/对话/喜剧/卖萌），能力爆发态占 **30%-40%**（法术/打鬼/召唤）。
- 每次能力爆发态持续**不超过20-30秒**（受限角色更短），然后回到写实态喘息。
- 爆发态之间**至少间隔1-2分钟**（2-3个10秒镜头）的日常戏，避免审美疲劳。
- 季终/高潮可以连续爆发态，但**必须有旁观者反应镜和角色力竭回落做呼吸点**。

### 2.3 双轨参数替换纪律

- 招式的**发力链、轨迹、命中效果照常执行，只换特效介质**（铁律38转译规则）；
- 【修仙版】能量介质从 moves-library.md 三层复合元素调用（三层×三混合×粒子三层）；【写实版】改用尘土／水雾／火星等物理介质拖尾（铁律39写实分支），禁塑料发光特效；
- 版本判定全场锁定，同一稿内禁止混轨（混合场景按 2.2 过渡规则切换，属剧情需要而非混轨）。

## 三、特效介质规范（打戏特效三大铁律）

### 3.1 铁律38·打斗分镜禁光效能量柱·特效一律物理实感

打斗分镜**默认禁用一切光效与能量形态特效**——不出现光、光柱、能量柱、能量波、能量球、光刃、光剑气、发光武器、通体发光、气场光环、符文发光、粒子光尘、七彩流光等任何「能量可视化」元素。力量感全部用物理实感介质承载。

**允许的特效白名单（物理介质）**：尘土／沙尘暴／尘墙、碎石飞溅／地裂／地面凹坑、木屑／竹屑／纸片、水花／水雾／雨幕激散、雪雾／碎冰屑（物理碎冰，非发光冰晶）、火星／刀刃摩擦火花（瞬间即灭，非持续光效）、布料与发丝激扬、断草落叶、烟尘余烬、汗珠雾化（守 ZeroBlood 协议）、气浪冲击的实体涟漪（水面波纹／草伏尘散）、衣物破碎布条、兵器金属应力白痕。

**转译规则**：旧规则／招式库／附录A里出现「能量／光／灵力／剑气光效」类描述时，调用时一律自动转译为物理介质——
- 「剑气撕裂空气」→「刀锋过处尘土被犁开一线、碎石向两侧崩飞」；
- 「能量对冲爆发」→「气浪对撞掀翻尘墙、地面蛛网状开裂」；
- 「灵力凝聚」→「周身气流卷聚尘沙成螺旋」。

招式的发力链、轨迹、命中效果照常执行，只换特效介质。

**禁止的写法**：任何「泛起X光」「涌出能量」「光芒大盛」「光柱冲天」「能量柱轰击」类表述；武器不发光（剑就是铁色剑，不是光剑）；不留廉价细丝状光轨（武器挥动的厚重属性能量拖尾除外，按铁律39执行——拖尾是轨迹残留，武器本体仍不发光）。

**例外通道**：仅当用户明确点名要「法术／能量／发光」类场面时才解禁，且解禁仅限该次任务、范围仅限用户点名部分（如用户说「最后大招发光」，则只有大招段允许光效，其余打斗段仍守本铁律）；武器挥动的属性能量拖尾为铁律39常设白名单，不受本铁律限制（拖尾≠武器本体发光≠光柱能量柱，两者并存：拖尾管「挥动轨迹」，本铁律管「环境与命中介质」）。

口诀：力量不发光，发光必廉价；尘土碎石水花布，物理实感才是真。

### 3.2 铁律39·武器挥动必拖厚重能量拖尾·燃烧绸缎光带

凡打斗分镜中的武器挥动（劈／砍／斩／刺／撩／扫／格挡反弹皆算），武器必须拖出厚重浓烈的属性能量拖尾，**五要素缺一不可**：

1. **燃烧态光带**：拖尾呈燃烧态光带，不是细线不是薄雾，是厚实浓重的一条实体质感光带；
2. **厚重如实体绸缎**：质感厚重如实体绸缎，有重量、有垂坠、有翻卷，像被强风扯住的燃烧绸缎；
3. **边缘高密度粒子流**：光带边缘翻滚着高密度粒子流，粒子持续剥落飞散（粒子类型绑定角色属性，从 moves-library.md 三层复合元素调用）；
4. **消散缓慢+残像留痕**：消散缓慢，禁止瞬散；拖尾残留于空气中形成短暂的视觉残像轨迹，收束镜可用「多条拖尾残留交织」做战场留痕与收束标志（C03拖尾残网收束同源）；
5. **叠加交织成能量网**：连续多段挥击的多条拖尾可在空中叠加交织成半透明的能量残像之网（高阶对决／大战收束标志）。

**颜色与风格绑定角色属性**：拖尾颜色／材质／粒子按角色属性定制，角色签名全剧一致；不同角色拖尾异色（铁律33分色同源）。

**与铁律38的衔接（优先级）**：本铁律是铁律38的常设白名单例外——武器本体仍不发光（剑仍是铁色剑，铁律38继续管武器本体），但挥动轨迹上的属性能量拖尾永远存在、必写；环境反馈／命中破坏仍按铁律38物理介质执行（拖尾是「轨迹残留」，命中是「物理破坏」，两者并存不打架）。写实版（普通人双轨）默认不带能量拖尾，改用尘土／水雾实体拖尾，除非用户点名。

**标准句（C03模式B直接套用）**：[武器]挥出，刃后拖出厚重浓烈的[属性色]能量拖尾，拖尾呈燃烧态光带、厚重如实体绸缎，边缘翻滚着高密度[属性粒子]流，消散缓慢，在空气中残留出半透明的视觉残像轨迹。

口诀：一挥一绸缎，燃烧不瞬散；粒子滚边缘，残像留空中；多挥交织网。

### 3.3 铁律44·取消光柱能量柱·0.5秒超高速·周身高级属性粒子·移动对碰动态模糊粒子

**①光柱与能量柱表现全面取消（绝对禁令，无例外通道）**：无论何种场面——包括用户点名法术／能量／发光解禁时——一律不出现光柱冲天、能量柱对轰、柱状能量体、光刃光柱对顶；力量与招式的可视化全部改由「周身属性粒子（本条③）+武器能量拖尾（铁律39）+物理介质反馈（铁律38）」承载；大招对轰写成**两团完全成型的粒子能量体互相撕咬翻涌、接触面层层剥落**，不写成两根柱子对顶。

**②0.5秒超高速**：开场或任意节奏段起手后0.5秒内即达超高速交战状态（铁律35「开局即中段」的量化硬指标）——首0.5秒内必须完成至少一次完整攻防转换或一次长距离高速位移，帧率即正常全速+强动态模糊，零铺垫、零加速过程描写、零起手蓄势；此后全场速度基准不低于此档。

**③周身高级属性粒子**：每个角色浑身（发丝、衣袂、皮肤周身、武器缠带）持续散发与自身属性对应的高级粒子——
- 颜色严格绑定该角色能量主色（三层主色已锁定）；
- 材质有层次（**核心亮粒+中层雾化+外层碎屑三粒层**）；
- 有流向（静止对峙时缓速上浮、动作加速时向后倒掠成粒子披风／粒子尾迹）；
- 有密度（随战斗烈度增减、大招蓄力时八方螺旋汇聚）。

此写法替代一切光环、光晕、通体发光的廉价表现，粒子是「穿在身上的属性」，不是「罩在外面的光壳」。

**④移动与对碰动态模糊粒子**：高速移动／瞬身／突进／踏空变向时，人物本体与残影之间拉出方向性动态模糊粒子流（沿运动轴线拖出成片粒子带、边缘晕散、速度越快带越长）；兵刃相交／掌拳对碰／能量对冲的瞬间，迸发高密度属性粒子+放射状或环状动态模糊（双向对冲时两色粒子对撞绞成涡流再炸散）——粒子必须带方向性速度感，禁止静态飘浮光尘。

**与铁律38/39的分工**：38管环境与命中的物理介质（默认白名单）、39管武器挥动的厚重拖尾、44管人物周身与移动／对碰的属性粒子——三者并存；属性粒子与能量拖尾属用户钦定常设白名单，不受38默认禁令限制，但三者都禁止退化为光柱／能量柱／光晕／光壳。

口诀：柱子全砍掉，粒子穿全身；0.5秒上强度，一动一糊皆是力。

## 四、铁律50·Seedance 2.5 官方提示词工程规范与避坑底线（六条）

1. **单段时长**：Seedance 2.5 原生支持单段最高 30 秒生成（一镜成片与多镜头叙事均可），无需强制拆成 10 秒；但段内子节点必须按整数秒（2~4 秒）有序排列。
2. **时间戳**：严禁小数点与冒号时码（如 00:03.2），必须整数秒（0-3秒 / 3-7秒）。
3. **严禁大分镜嵌套**：30 秒提示词不得写成 S01 0-10s / S02 10-20s / S03 20-30s 这类嵌套场次代码，必须从 0 秒一路连续推进到结尾。
4. **彻底清洗元指令与代码符号**：严禁出现 <音效：…>、★正面重击、模式K、协议C、【第一段】等给人类看的标记；模型不理解这些行业术语，反而会被特殊符号与尖括号占满有效注意力。
5. **原生音频与负向控制**：音频直接在结尾写自然句（`生成金属刀剑劈砍碰撞声、肉体受击闷响与狂暴雷鸣风雨声，无背景音乐（无bgm）`）；字幕排除写（`不要字幕，画面无任何文字与水印`）；在没有独立 Negative 框的文生视频环境下，严禁正文大段堆砌负面词——长篇「禁止站桩、禁止穿模」会诱发粉色大象效应，必须改为正向动作描述。
6. **与铁律43 A轨配套**：走单文本框时，本条即铁律43 A轨（默认单文本框模型：只输出一条连续干净的自然画面流——画质基准句→角色·场景·核心设定句→整数秒时间流→结尾自然句收束，严禁元指令与代码符号、严禁大段粘贴负面词列表）的执行细则；走三件套 B轨（有独立负面框／需要分镜剪辑稿）时，负面清单只出现在末尾独立负面块里。

口诀：整数秒、别嵌套、洗干净、音频负向都写自然句。
