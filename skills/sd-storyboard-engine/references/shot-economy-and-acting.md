# 镜头经济性与表演克制（经济性 · 人脸稀缺 · 表演 · **台词镜神态铁律＋供给库** · 站桩禁令 · 长镜头拆分 · 复合运镜 · 衔接）

本文件是分镜引擎的叙事与表演规则库。核心信条：每一个镜头都必须有存在的理由；表演是画面的灵魂，克制自然比歇斯底里有力量。

## 一、镜头经济性与节奏

**能删则删、能并则并**——每一个镜头都必须回答：这个镜头给了观众什么"新信息"？给不出新信息的镜头就是废镜。

**一镜多信息**：优质镜头一个画面同时推进多层——剧情 + 人物 + 情绪 + 空间。每个镜头至少承载两层信息，单层信息的镜头优先与相邻镜头合并。例：一个镜头同时完成"交代位置 + 暗示关系 + 累积情绪"三件事。

**三类冗余镜头直接删除**：

| 冗余类型 | 特征 | 处理 |
|----------|------|------|
| 信息重复 | 与上一镜传达相同信息 | 删除或合并 |
| 情绪重复 | 与上一镜情绪强度相同、无递进 | 删除（不同主体的反应镜头不算——反应内容不同即有新信息） |
| 功能重复 | 多个镜头做同一件事（如两次定场） | 只留一个 |

**快节奏段落（争吵/追逐/动作）**：镜头短促、每镜只给一个关键信息、景别跳跃更大、运镜更快；过渡用匹配切（动作/视线/图形匹配）或音桥完成，不加额外过渡镜，直接推进。

**慢节奏段落（留白/情感沉淀）**：允许少数长镜，但每个长镜内部必须有动作/微表情/光影变化持续发生，不允许"静止空镜撑时长"。

**节奏过渡**：快慢切换必须有过渡镜头或音桥/视桥，不允许硬切断裂。

**内部自检（不输出）**：全片通读一遍——(1) 删掉任意一个镜头，叙事是否仍完整？若完整则删。(2) 相邻镜头是否传达同一信息？若是则并。(3) 是否有纯过渡、无新信息的"过场镜"？有则删。

## 二、人物出现节制（人脸稀缺资源论）

**人脸是稀缺资源**——用多了廉价化。非人物镜头同样如此，仅用于点缀和丰富，不可喧宾夺主。叙事以人物镜头为主，非人物镜头像 seasoning，撒一点提味，不能当主菜。

**人物镜头 vs 非人物镜头**：

- 人物镜头：画面主体是人物（脸/全身/半身）——定场、过肩正反打、双人同框、情绪爆点特写、重要动作、权力关系建立。
- 非人物镜头：画面主体是环境/物件/局部肢体不露脸/光影——氛围点缀、情绪累积（物件承载）、留白、台词过渡、时间流逝。

**非人物镜头5类**：环境空镜、物件特写、局部肢体、光影变化、反应局部。使用时必须承载情绪或信息，不能是无意义filler。

**非人物镜头占比区间10%-20%**：

- 非人物镜头仅用于点缀和丰富，全片占比控制在10%-20%。
- 防人脸接力：连续6个人物镜头后可考虑切1个非人物镜头，但不强制——有叙事理由才切，不为切而切。
- 上限20%防非人物过度（叙事碎片化、节奏断裂）。
- 长对话中非人物镜头不作硬性穿插要求，仅在情绪需要时自然插入。
- 长台词切镜以人物反应镜头和动作过渡为主，非人物镜头不超过切镜总数的30%。

**非人物镜头必要性**：每个非人物镜头必须能回答——(1) 承载什么剧情/情绪？(2) 人物镜头能否更好替代？(3) 删掉影响叙事吗？回答不上来=凑数=删除。相邻非人物镜头不能信息重复。非人物镜头类型需多样化（至少2-3种）。情绪累积段落可用局部肢体外化情绪，但不拍表情的前提是该物件/肢体确实比人脸更有力。

## 三、台词约束

- 有台词写台词，标注说话人。无台词写"无"。
- 台词中保留原文标点，不增不减。
- 长台词必须切镜：一个人连续说话太久不切镜观众会疲劳。台词较长的拆分为多个镜头，中间插入反应镜头、空镜或动作过渡。原台词内容不删减，分配到多个镜头中。即使台词短，也须遵守"站桩说话禁令"——说话时要么有动作、要么切镜。**机检兜底：`C10`（单镜 >6s 告警 · talking head 风险）、`C27d`（同一说话人连续 ≥2 镜独占开口 = 站桩式对话）、`C27c`（开口次数不足）——但这三条都只判「稿子怎么写」，判不了「模型把 3 个 3s 镜合成一个长镜」；长独白段必须**在镜行里把切点写死**（每镜标注独立机位），不要只依赖时长累加。**

## 三·补、台词标点 → 可见表演映射（2026-10-10 并入）

台词的标点是**语义与语气的标记，不是演员可执行的时间点**。禁止写"说到逗号时""说到破折号时"；应写"说完这句话后""说到最后一个语义短句时""短暂停顿后""语气转折后"。

| 标点 | 对应可见表演（按需取 1–2 项写进镜行） |
|------|--------------------------------------|
| **，逗号** | 半口气、鼻吸、视线落到地面、手指停住、声音压低半拍 —— 对应呼吸 / 视线微移 / 短暂停顿，**不得写成无意义停顿** |
| **。句号** | 眼神停住、下颌松开、呼吸沉下去、沉默半拍、手指慢慢松开 —— 对应收尾余味，**不能一句说完表情清零** |
| **？问号** | 先判断角色"要的是什么"（答案 / 安慰 / 控制权 / 试探 / 真相 / 审判 / 撒娇 / 逼迫），再写眼神落点与尾音处理 —— **不得只写"疑惑地问"** |
| **！感叹号** | 能量上冲、气息压住、眼神压迫、手部用力、声音抬高但立刻收住 —— **不默认吼叫**；除非剧本明确要求，不主动写怒吼 / 爆哭 / 失控 |
| **……省略号** | 气断、卡喉、视线停住、嘴唇微张、说不下去、尾字被吞回 —— **不得当普通停顿处理** |
| **——破折号** | 突然刹车、改口、吞咽、被打断、情绪被截断、冲动刚起就被压回 |
| **（沉默）** | 必须写眼神路径 + 呼吸变化 + 身体泄漏 + 情绪余味 —— **不得只写"沉默"** |

**脸·声·词同步**：台词镜头必须做到表情、呼吸、停顿、重音与原台词标点一致——标点提供节奏线索，表演负责把它落在可见的身体上。

## 三·补二、台词重音落点（重音字显性化 · 2026-10-11 并入）

> 📌 **来源**：粉丝稿对照吸收（`粉丝稿对照审计_白凰学院撞人段_2026-10-11.md`）。粉丝稿把重音单列为【加重词汇】一行——核实发现：本包**早已在四处要求"围绕重音字做设计"**（`facs-micro-expression.md` 表情峰值对齐台词重音字；`short-drama-camera-system.md` §一 台词重音挂特写；本文档 §三·补 脸·声·词同步；`director-to-prompt-protocol.md` §发声层"『他』字重读"），**但从没有一处告诉创作者"这句的重音字是哪个"**——要求是隐性的，执行者只能靠猜。本节把这个隐性要求变成**可填字段**。

**判据**：每句台词，作者必须**显式指出 1 个重音字/词**——不是每个字都重，也不是整句都重。

**写法**（分镜稿单镜头模板已增此栏，紧跟「台词」）：

```
台词：A（低 · 平）："这表，你修的。"
重音：修
```

**三重用途**（重音字定下来，三处设计才有依据）：

| 用途 | 取用方式 | 权威 |
|---|---|---|
| **挂特写** | 一句里最重的那一下挂特写/放大，其余保持常规景别——**忌每句都特写** | `short-drama-camera-system.md` §一 |
| **表情峰值** | FACS 微表情的峰值必须**对齐重音字**，不是对齐台词开头 | `facs-micro-expression.md` |
| **配音重读** | 投喂时把重音落进发声描述（"『修』字重读"），模型才会念出该有的抑扬 | `director-to-prompt-protocol.md` §发声层 |

**三点纪律**：

1. **一句只标一个重音**——标两个以上等于没标；只有真正的对比句（"我**不**是这意思""**这表**，你修的"）才允许标两处；
2. **与语气位正交**——语气位管"怎么念"（力度/节奏/音色），重音管"重哪个字"，二者不互相替代；
3. ⛔ **`重音：` 栏属分镜层，投喂前必须剥离**——不得落进七段式正文（C12 拦截工作流规则词）；其效果由"画面内容里的表演描写 + 发声描述"承担。

**内部自检（不输出）**：(1) 每句台词是否标了重音？(2) 是否只标了一个？(3) 本镜若有特写，是否挂在重音句上？(4) 标了重音的句，表演峰值是否也对齐了这个字？

## 四、长台词切镜规则

台词较长时（大约超过两三句），必须在台词中间插入至少1个切镜点。切镜方式优先级（从高到低）：

1. 听者反应露脸（人物）——最自然、最有力
2. 动作过渡（人物）——说话人或旁人动作
3. 双人同框（人物）——关系镜头
4. **物件特写**（非人物，台词画外音）——桌上茶杯/手中信件/墙上挂钟/烟灰掉落
5. **局部肢体**（非人物，台词画外音）——手颤抖/指节发白/拳头紧握/脚步后撤
6. **环境空镜**（非人物，台词画外音）——窗外风景/天空云朵/远处街景
7. **光影变化**（非人物，台词画外音）——阳光移动/阴影拉长/烛火摇曳
8. **反应局部**（非人物，台词画外音）——手紧握茶杯/肩膀绷紧/背影微颤

人物镜头优先，非人物镜头作为点缀穿插，不作主力。

## 五、站桩说话禁令与长镜头拆分

**长镜头默认拆分 · 但不搞一刀切（2026-10-13 用户申明修订）**：

> **用户原话**：「我**也不知道你为了切而切**，像有一些剧情就**不适合这种来回的切**，**灵活懂吗？是服务剧情的**」。

**默认**：本欲用长镜头完成的段落，**优先**拆成多个镜头切换完成；若情绪需要连续沉浸，改用"微运镜 + 镜头内动作调度"——运镜极缓但不断、动作调度不断，让画面自行保持流动。

**⛔ 但"全片禁用一镜到底"是过度收口，已废止**。以下情形**允许保留长镜/一镜到底**，且必须保留：

| 允许长镜的剧情 | 理由 |
|---|---|
| **长镜压迫 / 空间调度**（跟随人物穿行、连续走位、全景一次性交代多人关系） | 切碎会破坏空间感与压迫感 |
| **沉默对峙 / 留白 / 静场** | 靠**时序连续**演情绪，切了就断 |
| **宣判 / 摊牌 / 一字一顿的压迫台词** | 不切 = 观众被钉在原地看着，是设计不是懒 |
| **打斗中的长镜调度**（招式连贯、无剪辑感） | 动作连贯性优先 |

**写作要求**：用长镜时，**必须在镜行内写明保留理由 + 画面内持续发生的动作/微表情/光影变化**（长镜不等于静止画面——内部必须有东西在动）。**⛔ 禁止"没有任何内部变化的静止长镜撑时长"**（那是废镜，与本条无关）。

**判准始终是剧情**：该切的时候切（争产/质问/抢话 → 高频正反打），该留的时候留（沉默/压迫/留白 → 长镜到底）。**「为切而切」与「该切不切」是同一种病。**

**站桩说话禁令（三秒铁律 · 同样服务剧情，非常态铁律）**：人物不允许站在原地静止不动地说话超过约3秒。任何含台词的镜头内，只要人物在说话，必须二选一：

- **一直有动作**——说话同时伴随持续、具体、可见的动作（走位、手势、做某事、转身、递物、起身坐下、整理物件等）。动作要写进画面内容，且必须推进叙事或情绪，不允许无意义小动作填时长。
- **切镜头**——说话人一旦静止，立即切走：换机位角度、换景别、切他人的反应镜头、切物件/环境空镜、切双人同框均可，但切出的新镜头必须承接并推动当前情绪。

> ⚠️ **例外（2026-10-13 补充）**：**刻意的静止是一种表演**——沉默对峙里"一动不动地盯着对方"、宣判时"说完就定住不动"，**都是有意的**，不受三秒铁律约束。判据是**这句台词的力道是否需要"定住"来放大**，而不是机械数秒。**写这类镜行时标明意图（如「刻意静止 · 压迫感」）即可。**

**切镜必须服务情绪渲染**：换角度、换景别、切反应镜头，每一次切镜都必须对情绪渲染起作用——推进情绪、揭示反应、累积张力、或提供留白。禁止"为切而切"的机械换机位：切出去的空镜/反应镜头若不能推动情绪，等于废镜，应删。

**禁止纯站桩正反打**：两人对话禁止"A静止说一句 → 切B静止说一句"的纯站桩正反打。每句台词要么伴随动作，要么在台词间插入反应镜头/空镜/双人同框，让画面持续"活"着。切镜仍须严守180°轴线与30°规则（见本文件"衔接约束"）。

**状态账 · 已达成动作不得重演（2026-10-18 粉丝实测并入 · 治「锁了又锁」）**：

一个动作只要在画面上**已经完成**，后续镜头就**不得再演一遍完成过程**。典型病灶（粉丝实拍）：铁门**已经锁好**，下一个镜头又切到有人在**把锁扣上**；人**已经坐下**，下一镜又起身再坐一次。

- **判据**：前一镜的画面状态 = **已完成态**（锁已合 / 杯已碎 / 人已倒地 / 门已开 / 外套已脱）→ 后一镜只能从**该状态的后果**起手（推门进入 / 看着碎片 / 跨过身体 / 穿着里衣），⛔ 不得重放「达成动作」。
- **写法**：跨镜承接只写**结果**，不写**过程**。`✅ 门锁已扣死，他从门缝里看她` ／ `⛔ 他伸手把锁扣上`（上一镜已扣过）。
- **例外（须写明动机）**：确实要"再锁一次"时，必须在镜行写清动机（`他不放心，又拽了两下确认`），否则一律按重复判。
- **与「动作相位七态」的边界**：七态是**镜内**拆格用的；本条管**镜与镜之间**的状态账，两者不重叠、不互相替代。
- **机检边界**：**无对应 C 码**（同义动作识别不可靠），靠本条 + `prompt-feeding-checklist` 第 37 项人工核。

**内部自检（不输出）**：每个含台词的镜头逐一自检——(1) 说话人是否静止？静止是否逼近或超过3秒？(2) 若静止，是否已切镜或已安排动作？(3) 切出的镜头是否真正服务情绪渲染？(4) 动作是否推进叙事而非填充？

## 五·五、 台词镜神态铁律与神态-动作供给库（粉丝实测反馈并入）

> 📌 **来源**：粉丝「森林」实测反馈（2026-09-29）——「现在这个 skill 生成提示词时，人物的**神态、动作等描写大部分时候是缺失的**，经常出现人物**"站桩"然后说台词**的情况」。核实发现：本站桩禁令（§五）已存在且很硬，但它只管到"**要么有动作、要么切镜**"——**"动作"里没有强制要求含神态/微表情**，且规则集中在动作语境。本节把钩子补到"**每一句台词**"这一层。

### 铁律（每句台词必过 · 一票否决）

**任何含台词的镜行，必须同时挂载「可见动作」与「可见神态」两项描写，缺一即视为废镜、必须重写。** 判据三条：

1. **神态必写**——每一句台词所在镜行，必须有一个**具体的面部/眼神/呼吸描写**（禁"表情平静""神色复杂"这类形容词，必须是看得见的肌肉动作）；
2. **动作必写**——同镜行必须有一个**具体的身体动作**（手部/重心/走向/与物件的交互），不允许"站着说"；
3. **两者同框**——神态与动作写在同一镜行内（分给相邻镜行不算），因为模型按"镜"渲染，分镜即丢失。

> ⚠️ **与 §五站桩禁令的关系**：§五 管"**不允许一直静止**"，本节管"**说的是什么状态**"——两条叠加生效：台词镜既不静止、又必须有神态。**只有"有动作"是不够的**——"她一边走一边说"满足了§五，但如果没写神态，仍然会被渲染成面无表情的念台词（这正是粉丝看到的现象）。

### 神态-动作供给库（按情绪取用 · 直接抄进镜行）

> 用法：先定该台词的情绪，再从对应行取 **1 个神态 + 1 个动作**，写进镜行。**同一场戏内不重复用同一条**（避免全片"抿嘴+握拳"一眼假）。取"藏七分露三分"原则（见 §六），神态宁小勿大。

| 情绪 | 神态（面部/眼神/呼吸 · 取一） | 配套动作（手部/重心/走向 · 取一） |
|---|---|---|
| **隐忍** | 下颌绷紧、喉结滚动一下、视线垂落再抬起 | 指节捏紧又松开、把物件放回原处、重心后压半步 |
| **讥讽** | 单侧嘴角极轻微上挑、眼皮微垂扫对方一眼 | 慢条斯理整理袖口、指尖在桌面轻叩两下 |
| **震惊** | 瞳孔收缩、呼吸乱了半拍、睫毛颤动 | 手中物件停住、身体几不可察地后仰 |
| **心虚** | 视线游移又移回、咽了口唾沫 | 手指无意识摩挲衣角、把身体转向光源背侧 |
| **决绝** | 眼神定住不再闪避、下颌线绷直 | 解开袖扣、把物件推到对方面前、起身 |
| **脆弱/压抑** | 眼眶泛红却别过脸、吸一口气压住哽咽 | 手指扣住桌沿、把眼泪逼回去并转开头 |
| **威胁** | 眉头压低、目光钉在对方脸上不移 | 上身缓慢前倾、手指点向对方 |
| **敷衍/轻蔑** | 嘴角平直不动、目光越过对方落到别处 | 边说边收拾东西、转身要走 |
| **动摇** | 嘴唇微张又合上、视线在物与人之间来回 | 手伸出去又收回、脚步虚浮半步 |
| **释然** | 眼尾放松、呼出一口长气 | 肩膀垮下来、靠向椅背 |

### 内部自检（不输出 · 每句台词过一遍）

对每个含台词的镜行逐一问：

1. 这句台词有没有配 **具体神态**？（"平静地说"不算）
2. 这句台词有没有配 **具体动作**？（"站着说"不算）
3. 神态与动作是否**写在同一镜行**内？
4. 本场戏是否**重复使用**了同一条神态/动作？（重复即换）
5. 神态是否**克制**（藏七露三）而非表情包式？

答不上任一条 → 该镜行重写。

## 五·六、听戏反应规则（对话戏必有 · 2026-10-10 并入）

**无台词角色不是"等着轮到自己说台词"**——他在听对方某个词、称呼、停顿或语气后产生反应。对话戏必须写"听"的反应，**不得让无台词角色表情清零或无意义站立**；否则对话戏塌成两段独白。

无台词反应镜头的完整链条：**听见什么后停住 → 眼神路径 → 呼吸变化 → 身体哪一处泄漏 → 最后余味停在哪里**。

常见听戏反应（按情绪取用，同一场戏内不重复同一条）：

- **眼神**：视线从对方眼睛移到嘴角 / 避开后又抬回 / 听到某个词后视线突然定住 / 视线扫向出口或对方的手；
- **手部**：手指停住 / 指尖扣紧道具 / 握拳又松开 / 拇指摩挲衣角；
- **呼吸**：呼吸断半拍 / 沉默里鼻息变轻 / 回答前吞咽 / 说完后留沉默；
- **身体**：肩线轻微缩紧 / 下颌压住 / 背脊突然挺直 / 重心后移 / 脚尖转向出口；
- **情绪**：眼眶起湿意但压住 / 听到关键字后先是无反应再是一颤（**迟到的反应**）。

**与神态铁律联动**：含台词的镜行走 §五·五（神态 + 动作双挂）；**无台词的听戏镜行按本节**——两者合起来保证"对话戏里没有一根木桩"。

## 五·七、对话戏节奏律（回合制切镜 · 开口密度 · 2026-10-13 用户实测反馈新增）

> 📌 **来源**：用户实测反馈（2026-10-13）——「我们现在出的台词就像**站桩式对话**，一个人说完另一个人说，缺乏**快速的正反打**；分镜也很呆板，15 秒切成三四段、每段里就几个词儿，**非常呆傻地去执行台词量控制**」。
>
> ⚠️ **与 §五站桩禁令的分工**：§五 / §五·五 / §五·六 三条管的是「**人物不能立成木桩**」（静止 / 无神态 / 无反应）；本节管的是「**切镜节奏不能呆**」——**三条全过、台词镜也可能仍然是"一言一镜轮流开口"的死节奏**。这是四个独立维度，必须四条全过。

---

### ★★ 总则：节奏服务剧情，规则不是模板（2026-10-13 用户申明 · 本节一切规则的适用前提）

> **用户原话**：「**你灵活一点，不要说我说啥就把它完全定死了，这个东西它本身是服务着剧情走的**」；
> 「我**也不知道你为了切而切**，像有一些剧情就不适合这种来回的切，**灵活懂吗？是服务剧情的**」。

**本节所有指标（回合制切镜 / 开口密度 / 短句化 / OS 补位）都是"常见对话戏别拍呆"的工具，不是每段都要套用的模板。** 判准永远是**这段剧情需要什么节奏**，而不是"规则说该切几刀"：

| 剧情性质 | 该用的节奏 | 本节指标 |
|---|---|---|
| **争产 / 质问 / 斗嘴 / 抢话 / 逼供** | **高频正反打**——快速来回、每切换嘴、短句砸 | 按本节全量执行（开口 ≥6 次/15s） |
| **沉默对峙 / 宣判 / 摊牌前静场** | **慢**——长镜压迫感、单镜承担、眼神与呼吸演满 | ⛔ **不执行开口密度下限**；标「**本段为静场/宣判段**」 |
| **情绪积累 / 回忆 / 独白** | **留白**——允许一人独占、允许空镜带声 | ⛔ 不执行开口密度下限；标「**本段为留白段/独白段**」 |
| **空镜 + 先声（公园空镜传来人声→切到两人对话）** | **声桥过渡** | 见 `dialogue-speed-check.md` §一·补三「空镜带声」——**合法且常用** |
| **打斗段** | 动作与音效主导 | ⛔ 不设台词下限 |

⛔ **禁止"为切而切"**：切镜点是**为了服务情绪/信息/关系**；若一段的剧情靠"沉默和静止"更有力，**就不该切**。用户批的是「**站桩式对话**」（该切不切、节奏死），**不是"任何时候都必须高频切"**。

⚠️ **与「固定机位为主」的关系**：文戏「固定为主、运镜 ≤2」同样是**默认倾向而非铁律**——若是长镜压迫 / 一镜到底的调度（如整段跟随人物穿行），**照做**。用户批的是"**该动的时候不动**"，不是"镜头必须永远静止"。

### 病灶实证（粉丝稿 vs 本方稿 · 2026-10-13 定量）

同一量级的对话段，粉丝稿《白凰学院捉鬼师》与本方一分钟四段稿对比：

| 指标 | 粉丝稿（30s 撞人段） | 本方稿（段2 · 15s 谈判） | 差 |
|---|---|---|---|
| 镜头数 / 时长 | **8 镜 / 30s** | 4 镜 / 15s | 粉丝更密 |
| 平均镜长 | **3.75s** | 3.75s | 持平 |
| **每镜开口人次** | **部分镜内 2 人交替（切镜换嘴）** | **每镜恒 1 人** | ★ 根因 |
| **单次发言字数** | **6~18 字（极短句来回）** | 8~25 字（长句成段） | ★ 根因 |
| **正反打频率** | **高频（切=换说话人）** | 低（切=换内容块） | ★ 根因 |
| OS 内心独白补位 | **有（2 处，零口型成本）** | 无 | 可抄 |

**根因定位（三条，全部在分镜层、不在台词层）**：
1. **「切」是按内容块切的，不是按回合切的** —— 本方把"这句归他、那句归你"当作切点，切完还是同一个说话人续说；粉丝稿**每切一次就换一张嘴**。
2. **把「固定机位」误读成「不切镜」** —— §四运镜规则写"文戏固定为主、运镜 ≤2"，被误执行成"一镜到底慢慢说"。**固定机位 ≠ 不切镜**：粉丝稿全程固定机位，但切得飞快。
3. **长台词切镜规则的触发门槛过高** —— §四触发条件是"台词较长（超过两三句）"，而**短句回合制对话根本不触发**，导致一条本该管所有对话戏的规则只覆盖了长台词。

### 三条硬指标（**适用前提：本段是"该有来回"的对话戏** · 见上方总则）

> ⚠️ **本节三条是"默认倾向"，不是每段必套的模板。** 若本段剧情属于**静场对峙 / 宣判 / 留白 / 独白 / 长镜压迫**（见上方总则表），**应在段落里显式标注「本段为静场段 / 宣判段 / 留白段」，三条指标不适用**——这类戏**靠沉默和静止更有力，切碎了反而毁掉**。
>
> ⚠️ **对话段全面豁免（2026-10-13 用户裁定 · 与下列三条同时生效）**
>
> **正反打的标准形态就是「固定机位 + 切镜换嘴」**——摄影机不动，靠切镜换说话人（粉丝稿实测：全程固定机位，靠高频切镜做出来回）。因此**对话段内**以下判据**全部豁免**（机检已实现）：
>
> | 被豁免的判据 | 原规则 | 豁免理由 |
> |---|---|---|
> | **C2 镜头数上限** | 段长 ÷ 3s（15s ≤5 镜） | 放宽到 **÷2s**（15s ≤8 镜）——5 镜做不出回合制 |
> | **C2 单镜下限** | ≥3s | 放宽到 **≥2s**——正反打实测 2s 一切 |
> | **C13 镜长雷同** | 同值占比 ≥70% 告警 | 回合制镜长本就高度整齐（2s 一切是标准形态），非「机械等分」 |
> | **C18j 固定镜过量 / 连排** | 固定 ≤10% / 禁连排 3 | 正反打就靠固定；若强求运镜，会逼出「为动而动」的乱加运镜 |
> | **C18k 运镜覆盖不足** | 段内 ≥4 种运镜 | 同上——对话段不该为凑多样性而加无叙事理由的运镜 |
>
> **非对话段（空镜 / 打斗 / 转场）以上判据照常生效。** 段落类型识别口径见机检 C27（含「对话/对白/文戏…」或 ≥2 条台词 → 判对话段；分不清则不判）。
>
> ⛔ **豁免不等于放任**：对话段仍受本节三条指标 + C27b/c/d 约束。**豁免的是「镜必须少、必须动」，不是「节奏可以呆」。** 反过来，**三条也不许把"该慢的戏"逼快**。

**① 回合制切镜（Round-based cutting）**
**对话段的切镜点 = 说话人切换点**，不是内容块边界。规则：
- **一次切镜至少换一个变量**：换说话人 / 换景别档 / 换机位角度 / 换主体（切听者反应）——四者至少占一；**只为"这句说完了"而切、其余变量全不变 = 废切**。
- **同一说话人连续占据 ≥2 个完整镜行 = 默认判"站桩式对话"、该段重切**（机检 **C27d**）。**例外**：该段为刻意设计的**长独白 / 宣判 / 静场段**（已显式标注）——此时允许一人独占，**但须在段内插入反应镜、空镜或听他者反应打断死寂**。
- **正反打基础型**：A 说 → 切 B 反应/回嘴 → 切 A → 切 B。**一个来回至少 2 个切点**。
- ⛔ **本节只要求"该切的时候切"，不要求"任何时候都切"**——「为切而切」与「站桩不动」是**同一种病**（都不服务剧情）。

**② 开口密度参考值（对话段专用）**
按**对话段**（非空镜段、非打斗段）计量，**15 秒 ≥6 次开口**（每次开口 = 一次说话人张嘴，含 OS）：

> ⚠️ **这是"常见对话戏容易拍呆"的参考下限，不是"每段必须张嘴 6 次"的配额。** 剧情该慢的段落（静场/宣判/留白）**不适用**，标注段落意图即可。

| 段落类型 | 开口密度下限 | 说明 |
|---|---|---|
| **对话段（文戏核心）** | **15s ≥6 次**（≈2.5s 一次） | 含正反打、含 OS |
| 混合段（对话 + 行动） | 15s ≥3 次 | 行动本身占时间 |
| **空镜段 / 转场段** | **不设下限**（可为 0） | 空镜本就不需要台词 |
| **打斗段** | **不设下限**（可为 0~2 句） | 打斗靠动作与音效，喊两声即可 |
| 独白/宣判段 | 不设下限，但须 ≤1 人独占 | 刻意设计的长独白 |

> ⚠️ **不是"为加而加"**：下限只对**对话段**生效。用户原话：「我在空镜的时候、在打斗的时候肯定不需要台词量呀，我可能就需要几句话，但是**正常的台词量这个要给别人补上**」。**空镜/打戏不设下限，正是为了让对话段敢写满。**

**③ OS 与短句化（密度来源）**
- **OS（内心独白）是零口型成本的台词来源**——不占口型同步、不占"谁在说话"的调度、可在任何镜行叠加。**对话段每 15 秒至少考虑 1 处 OS 补位**（角色内心吐槽/判断/纠错）。
- **短句化**：单次发言**目标 ≤15 字**，超过 20 字的长句优先拆成两次开口（中间插一个反应镜或换嘴）。**"一句长台词"改"两次短开口" = 密度翻倍且更真实。**

### 内部自检（不输出 · 每个对话段过一遍）

1. 本段切镜点，是否**每次切都换了说话人 / 景别 / 角度 / 主体**？有没有"只换内容不换变量"的废切？
2. 有没有**同一人连续两镜开口**？有 → 必须打断（插反应镜/空镜/换嘴）。
3. 本段开口次数是否达到**类型下限**（对话段 15s ≥6）？
4. 有没有**超 20 字的长句**可以拆成两短句 + 一次换嘴？
5. 有没有可以加 **OS** 的位置（尤其是"心里咯噔一下""这下完了""他又在演"这类）？
6. 本段是不是**空镜/打斗段**？是 → **下限不适用**，不要硬塞台词。

答不上任一条 → 该段落重切重写。

## 六、人物表演约束

**表演是画面的灵魂**——情绪必须通过"可见的身体"外化，而非台词直说、旁白解释或面部夸张。画面描述里，人物"在做什么"永远比"是什么情绪"更重要。

**克制原则（情绪不过激）**：短剧表演最大的敌人是过火。情绪一律"藏七分露三分"——用克制的动作暗示强情绪，胜过直接爆发。

- 禁止表情包式表演：五官扭曲、龇牙咧嘴、涕泪横流的过度哭嚎、捶胸顿足。
- 爆发≠嘶吼：愤怒可以是一句压低的声音、一个攥紧的拳头、一次缓慢的转身，而非吼叫+摔东西。
- 悲伤≠大哭：可以是红了眼眶却别过脸、咽下一口气、手指无意识地摩挲某物。
- 惊讶≠瞪眼张嘴：可以是一次短暂的停顿、呼吸乱了半拍、手里动作停住。
- 台词之外的"人声"同样克制：一次轻叹、半声哽咽、一下吸气，比完整哭腔更动人。

**表演三通道（写画面内容时至少启用一通道，重要情绪启用两通道）**：

1. **大动作层**——走位、坐立、转身、递物、靠近/后退、肢体占位。承载关系变化与空间推进。
2. **小动作层（手部/物件）**——指节发白、拇指摩挲、转笔、捏紧又松开、整理衣角、反复开关打火机。承载内心暗涌，是最自然的外化。
3. **微表情层（面部/眼神/呼吸）**——瞳孔收缩、嘴角极轻微的抽动、喉结滚动、屏息、睫毛颤动、视线游移又移回、呼吸变浅。承载极细腻的情绪转折。

**表演反规则**：强情绪反用"静"更有力——真相揭晓时人物反而一动不动；崩溃前兆是突然的安静与失神，而非立刻爆发。

**内部自检（不输出）**：每个含情绪的镜头自检——(1) 情绪是否只靠台词或形容词传达？(2) 是否写成了夸张的面部表情？(3) 是否有具体、可见、自然的小动作或微表情外化？(4) 动作是否克制（藏七露三）而非过火？

## 六·补、AIGC 假表演规避清单（废镜判据 · 2026-10-10 并入）

以下是 AI 视频最常见的假表演——**出现即视为该镜行需重写**（本清单为**内部自检用，不逐段输出**）：

突然瞪眼 / 机械微笑 / 大幅点头 / 频繁摇头 / 表情清零 / 五官同时用力 / 假哭 / 眼神乱飘 / 无意义甩头 / 舞台剧式大动作 / 特写里身体动作过大 / 悲伤默认爆哭 / 愤怒默认吼叫 / 震惊默认张嘴瞪眼 / 心动默认傻笑 / 紧张默认夸张喘气 / 对话时角色只轮流开口而无听戏反应 / 镜头运动与演员动作同时过载。

**用法（三条）**：

1. **正向优先**——先通过具体的画面与表演描述规避问题，不靠负面词；
2. **负面约束只写当前镜头最相关的 1–2 项**（如"不要假哭"），**不得每段机械堆长串负面词**——堆负面词会挤占主体动作与情绪描述，对模型是噪音；
3. **与 §六 情绪反规则联动**：情绪越强、外部动作越克制（**除非剧本明确写**崩溃 / 怒吼 / 痛哭 / 疯狂 / 跪地 / 失控）。

## 七、复合运镜

单一运镜易显单调，情绪重锤与关键动作段落应使用复合运镜——两种运镜叠加，一次完成多任务。常见组合：推镜+横移（逼近同时展现场景）、升降+环绕（史诗揭示主体）、跟拍+微摇（跟随中捕捉反应）、轨道+俯仰（精确构图+垂直揭示）。复合运镜不是堆叠炫技，必须服务于同一叙事目的，且仍需通过物理可行性检查。复合运镜中各单项仍受重技法频率上限与场景空间禁令约束（如"升降+环绕"同时占用两个重技法名额），单场复合运镜≤1次。表头标注格式：`推镜+横移`。

## 八、衔接约束

**180°轴线规则**：对话/对峙场景中，机位必须始终在两人连线的同一侧，不允许越轴。正反打时A在画面右看左，B必须在画面左看右——视线相对。越轴例外（需有叙事理由）：刻意制造空间混乱、镜头运动自然越轴、中性镜头过渡。

**30°规则**：同一主体的两个相邻镜头，机位角度差必须≥30°（或焦段差异显著），否则跳切。景别变化≥2级可弥补机位角度不足。正面与侧45度切换天然满足30°差，是正反打最顺手的相邻机位组合。

**景别跳跃规则**：相邻镜头景别差≤3级为大原则。>3级时必须有过渡（插入中间景别、动作匹配/视线匹配/图形匹配、音桥/视桥）。大景别直接切大特写是极端手法，必须有强烈叙事理由。

**视线匹配**：上一镜头人物视线方向，必须在下一镜头落点得到回应。A看向画面右→下一镜B在画面左。视线方向必须与180°轴线一致。

**运镜节奏衔接**：上一镜运动→下一镜可以运动或固定（运动到静止是合法的"句号"）；上一镜固定→下一镜突然快速运动会断裂，必须有过渡。运动镜头接固定镜头作为"段落句号"，必须有情绪理由。

**音桥与视桥**：音桥——下一镜头声音先于画面切入；视桥——上一镜视觉元素在下一镜延续（图形/颜色/动作匹配）。场景间转场优先考虑音桥/视桥。场景内切换直接切镜即可，不需要特效转场。慎用淡入淡出/溶解。

## 八·补、镜级状态栏（前态 → 后态 · 2026-10-11 并入）

> 📌 **来源**：粉丝稿对照吸收（`粉丝稿对照审计_白凰学院撞人段_2026-10-11.md`）。粉丝稿给每个镜头加了【结束状态】一行——核实发现：本包**已有**机检 **C18b**（"姿态回退：已坐起又躺回且无交代" → WARN）与故事板图"出口帧写全六项"铁律，**但文字分镜稿里没有对应的填报位**——等于机检在找一件从没写出来的东西。本节补上这个填报位。

**写法**（分镜稿单镜头模板已增此栏，紧跟「画面内容」）：

```
状态：坐 · 双手扶台面 → 起身 · 右手持表
```

**触发条件（条件必填）**：**本镜发生状态变化时必须写**——起身/坐下/躺下、拿起/放下/递交道具、换手持物、进出画、穿脱披挂、受伤/血污/衣物破损、门窗开合。**无状态变化写"—"**（静态对话镜不必硬填）。

**为什么必须有这一栏**：AI **逐镜生成、镜与镜之间没有记忆**。上一镜"已坐起"，下一镜若只写"她坐着说"，模型按字面渲染成坐姿——观众看到"坐起又躺回"的穿帮，**而稿面自身没有矛盾，矛盾只存在于两镜之间**。状态栏把这对前后态**放在同一行**，穿帮在出稿前就能被看见，不必等成片。

**三处接线**（一栏喂三处，不另立标准）：

| 接线对象 | 关系 |
|---|---|
| **机检 C18b 姿态回退** | 状态栏是给作者准备的**填报位**；C18b 在投喂正文侧兜底（WARN） |
| **故事板图出口帧六项**（`storyboard-sheet-template.md` §四） | 段末镜的状态栏 = 出口帧"人物/手位/道具状态"三项的文字分镜版；两处必须一致，矛盾＝**废图重出** |
| **位移当前态锚点**（总控 `asset-spatial-ledger.md` §三·7） | 有人物位移的段，状态栏后态须带当前位锚点（如 `@A 保持镜2进言位：帅案前半步`），防"起点实例+终点实例"双渲染 |

**内部自检（不输出）**：(1) 本镜有无状态变化？有 → 状态栏写了吗？(2) 上一镜的"后态" = 本镜的"前态"吗？（不等＝连续性断点）(3) 段末镜的状态栏与故事板出口帧六项一致吗？(4) 有位移的角色，后态里带当前位锚点了吗？

## 九、画面内容约束

- **必须"看图说话"**——不是写文学描述，是写屏幕上能看到什么。拒绝"她感到悲伤"，改为"她眼眶泛红，嘴角微颤，一滴泪从右眼滑落"。
- 不要写"镜头给到""我们看到"这种元描述——直接描述画面。
- 画面描述必须包含：人物位置/姿态（引用场景锚点名称）、光线方向（绑定光源锚点）、背景元素、关键细节。
- **★ 逐镜画面段最低三要素（2026-10-16 补强 · 治「画面提示词没有背景描述」）**：每个镜行的**画面段**（＝`台词：` 之前的部分）**必须同时出现**——① **人物位置/姿态**（绑场景锚点名）② **背景元素**（前景 / 背景**至少各一处**、且是**场景真实存在**的物件或环境行为）③ **光线方向**（**由段首【场景资产】「时段光影」基准继承**，口径见下方继承条）。**缺即 WARN**（机检 **C32**）。**不设镜数下限**——画面段缺背景是**逐镜缺陷**，一镜到底的单镜段同样适用（与 C18n/C18p 的"分布类判据需大样本"不同）。**豁免**：纯空镜（画面段写明「无人物」）/ 微距大特写（材质或光线二者其一即可）/ 模板骨架行与占位符行。
  - **病根**：本条此前**只有规则、没有断言**——机检对"画面段有没有背景"零校验，于是执行者只写人物动作（`王路冲进来扶住陈薇胳膊，陈薇脸色惨白`），**背景全空**；模型只好自行补背景 → **每镜背景不一致 = 跨镜穿帮**，且不由人控制。**"只写不检 = 不生效"**（同 §一 特写区间 2026-10-13 的历史教训）。
  - **正确写法**：`陈薇背抵窗台、双手抠着窗框，身后半拉的蓝布帘被夜风掀起一角，冷绿月光从东窗硬切在她侧脸上。`——位置（抵窗台）＋背景（蓝布帘 / 夜风）＋光线（东窗冷绿）三要素齐备。
  - **豁免两类**：① **纯空镜**（明确写"无人物"的环境镜——此时背景即主体）；② **微距特写**（画面本就是局部，只要求写**材质与光线**，不要求"背景层次"）。
  - ⚠️ **③ 光线方向的继承口径（★ 2026-10-16 修正 · 与 `model-adapters.md` §5.0.5b「光影单一基准」对齐）**：段首【场景资产】已立「时段光影」基准时，**③ 由段级基准继承、镜行只写增量**——此时逐镜**只判 ②（背景元素）**；**段内未立基准**时才逐镜要求 ②③ 齐备。**修正前本条与 §5.0.5b 互锁夹杀**：照 §5.0.5b 写（镜行不加光线）会被 C32 逐镜报"缺光线"，照本条写又违背"镜行只写增量"、且每镜复述主光会让模型**逐镜重新打光**（跨镜光线不一致）——执行者无合规写法。机检 C32 已按本口径实现（段级有基准 → 逐镜只判背景）。
- 禁止模糊方位词（"左边""右边""旁边"），必须绑定锚点。
- 室内镜头必须说明光源来自哪个锚点。
- **画面是进行中的瞬间，不是摆拍清单**。✅ "A正把茶杯往嘴边送，热气糊了她的睫毛" / ❌ "A端着茶杯，看着镜头"。
- 多主体（3人及以上）场景必须声明视觉中心：`视觉中心是X，其余元素为衬托X的环境层。`
- 纯场景（无人物）写材质、天气、时间、环境行为，不要凭空造角色。
- 画面细节必须服务主体或情绪，不允许"为细节而细节"的填充。
- 非人物镜头必须明确写出"无人物"或"局部肢体不露脸"，并说明承载什么情绪/信息。
- 非人物镜头若有台词，标注"画外音延续"。
- **画面层次丰富度**：画面内容应具备前景/中景/背景的层次，禁止"主体贴白墙"的单薄构图。前景可用场景真实存在的物件或人物局部做框架，背景要有环境行为（走动的人、飘动的帘、转动的风扇）让画面"活着"。层次必须来自场景真实元素，禁止凭空加道具。
- **表演细节进画**：情绪通过具体动作与微表情外化写入画面（见本文件"人物表演约束"），禁止用抽象情绪词代替。每个含情绪的镜头至少写一个可见的表演细节。

## 十、音频约束

- **严禁背景音乐（BGM）**：分镜稿全片不添加任何背景音乐、配乐、氛围音乐。说明——BGM 属总控管线后期声音设计范畴（sd-qc-engine `sound-design-template.md`），分镜稿层严禁混入，两层不冲突。
- 仅使用音效（SFX）和人声。
- 每个镜头区分两类：
  - **音效**：环境声和动作音（风声、脚步声、门吱呀声、杯子放桌声等）。
  - **人声**：台词之外的表演性人声（喘息、抽泣、轻笑、叹气等）。
- 音效和人声分别标注，不能混在一起写。
- 安静不等于加BGM——安静就是安静，用环境底噪即可。
- 若有音桥（声音先于画面切入或画面延续到下一镜声音），在音频字段标注"音桥入/音桥出"。
