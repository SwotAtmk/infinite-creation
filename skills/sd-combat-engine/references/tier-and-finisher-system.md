## 〇、 动作强度三档（先定档再套规则）

> ⚠️ **总纲铁律（2026-09-02 实测二次翻车后固化）：AI 视频没有"静止表演"能力。** 任何"对峙 2 秒 / 蓄势待发 / 留白 / 悬停 / 站立 / 特写定格"类静止段，模型都渲染成角色呆立几秒、节奏拖沓。**一切情绪与蓄力必须在运动中完成**：边打边蓄、上升途中蓄、后撤中蓄；神态挂载在动作瞬间（甩剑转身时冷笑），不单独成段。唯一允许的"定格"是**命中瞬间 1~2 帧微停顿（Hit-Stop）**，其余静止段默认禁用。

打戏规则按动作强度分档执行，避免对所有题材强制高燃套路：

| 档位 | 适用 | 开局硬撞 | 近景机枪对招 | 气爆/特效 | 终结定格 |
|---|---|---|---|---|---|
| **R1 写实克制** | 写实格斗、悬疑暗杀、追逐、喜剧打斗、儿童向 | 不强制，1.5s 内发生接触即可 | 可选 | 不强制，以真实受力反馈为主 | 允许收势/悬念收尾 |
| **R2 商业高燃（默认）** | 多数短剧/漫剧打戏 | 必选 0.5s 硬撞 | 必选 1 段 | 必选 | 必选高潮定格 |
| **R3 玄幻大招** | 仙侠/二次元/特效向 | 必选 | 必选 | 拉满 | 必选最高燃定格 |

**定档纪律**：① 未定档不得动笔写打戏；② 一集同一场战斗原则上单档，混档须写明切换点；③ **R3 档切换法术语言**——法宝媒介 + 五行术法 + 术法攻防 + 能量具象化 + 对军清场，**不硬套武侠物理打斗**（完整规则库见 `sd-xuanhuan-engine`）；④ **R1 档不套用高燃套路**（完整规则库见 `sd-real-engine`，其 `r1-combat-core.md` 另载 R1 版完播潜力自检）。

## 一、 15 秒打戏完播潜力评分（启发式，非平台预测模型）

$$\text{完播潜力评分} = 0.20 \times \text{开局吸引力} + 0.30 \times \text{节奏呼吸} + 0.25 \times \text{运镜丰富度} + 0.25 \times \text{情绪拐点}$$

> 说明：该公式是创作者自检用的**加权启发式评分**，用于衡量"完播潜力"而非真实完播率预测。**R1 档可选择性满足**（R1 专用版见 `sd-real-engine/references/r1-combat-core.md` §二）。

| 维度 | 权重 | 执行硬指标（R2/R3 档） |
|---|---|---|
| **开局吸引力** | 20% | **0~1.5 秒内必须发生攻防接触**（R2/R3 档：开局 0.5 秒内出现两种对立招式的正面硬撞 + 命中瞬间微停顿）。第一帧建议双人同框中近景，避免远景风景慢热铺垫。 |
| **节奏呼吸感** | 30% | 快慢交替，同节奏连续 $\le 5$ 秒。前面极速密集的连打，用**命中瞬间 1~2 帧微停顿（Hit-Stop）**或瞬间加速制造反差，**禁用慢镜/升格**（2026-09-02 实测破坏节奏）。 |
| **运镜丰富度** | 25% | **同运镜 $\le 2$ 秒，同景别 $\le 3$ 秒**。重磅终结招式采用三段式运镜（低仰蓄力 $\rightarrow$ 俯冲跟随 $\rightarrow$ 碰撞定格）。 |
| **情绪拐点** | 25% | 在 8~12 秒区间必须出现一次局势逆转、破防爆发或破绽抓取，让观众情绪剧烈反弹。 |
| **以高潮收尾** | 核心 | **R2/R3 档**：禁止 0.5 秒平缓收尾帧（如收腿落地/发丝飘落/气焰消散）。最后一帧停留在终结技命中、重创失衡、冲击波炸裂、碎石掀飞或倒地嵌墙的最高潮定格。**R1 档**：允许克制收势或悬念收尾。 |

### 开局硬撞新变体：零帧瞬移起手 ＋ 弹射迎击（2026-09-04 吸收）

- **攻方零帧瞬移贴脸**：第一帧即瞬移至对手面门前出招（残影/空间撕裂作瞬移痕迹），省略冲刺过程，开局冲击力拉满；
- **守方弹射迎击对冲**：守方不是原地挨打——弹射起跳/蹬地迎击，与攻方在空中或近身位对冲碰撞；
- 仍守开局铁律：0.5 秒内出现对立招式硬撞 + 命中瞬间微停顿；瞬移必须有视觉痕迹（残影/黑色空间裂隙/空气扭曲），禁无来由跳切。

## 二、 视觉巅峰五要素（最高触发原则）

$$\text{视觉巅峰} = \text{大幅动作} + \text{快节奏} + \text{全景/中景空间} + \text{特效生长} + \text{三段运镜}$$

* 五者必须在同一时间窗口同时爆发。缺任何一条都会导致视觉降级：
  * 缺大幅动作 $\rightarrow$ 全景画面空洞；
  * 缺快节奏 $\rightarrow$ 画面拖沓无力；
  * 缺全景/中景 $\rightarrow$ 局部特写看不到张力；
  * 缺特效生长 $\rightarrow$ 缺乏视觉爆点；
  * 缺三段运镜 $\rightarrow$ 像舞台剧摆拍。

## 三、 终结技三幕结构（破局 $\rightarrow$ 绽放 $\rightarrow$ 余震）

所有大招与终结技必须按三幕逻辑展开，**禁止一击直接结束**：

```
┌─────────────────────────┐       ┌─────────────────────────┐       ┌─────────────────────────┐
│   第一幕 · 破局 (Break)  │ ───>  │   第二幕 · 绽放 (Burst)  │ ───>  │   第三幕 · 余震 (Shock)  │
│ 打破攻防平衡, 制造绝对破绽│       │ 大招全力输出, 视觉巅峰  │       │ 冲击扩散, 骨肉形变与地裂 │
└─────────────────────────┘       └─────────────────────────┘       └─────────────────────────┘
```

### 1. 第一幕 · 破局（打破当前攻防平衡，0.5~1.0s）
* **化劲/借力破防**：掌心一搭引开对方格挡，防线瞬间向两侧崩开；
* **重击破格**：全力一击砸在双臂上，硬生生弹开防御架子；
* **下盘破坏**：贴地扫腿/踩脚截腿，直接摧毁对方支撑根基；
* **入身/走圈绕背**：踏入攻击线内侧绕至死角，正面防守全部失效；
* **时空截击**：在对方出招启动瞬间以更快速度截断其前臂，迫使其防御崩溃。

### 2. 第二幕 · 绽放（大招全力输出，1.5~2.5s）
* **凌空下劈 / 踏空暴扣**：腾空至最高点，腿/武器如重斧自上而下全力劈落，重力加持；
* **贯穿式寸劲直击**：半步崩拳/穿心订桥/寸劲标指，劲力聚于一点直贯心口，空气被击穿形成音爆气穴；
* **多段旋风连斩/连踢**：540°水平旋风腿/千霜环身斩/旋身连环铲，离心力叠加形成风暴；
* **神兵/神能绝杀**：
  * 剑法：红紫/冷白巨型满月剑光波正面贯穿，万剑归宗自虚空下坠；
  * 太刀居合：时停霜幕破裂，居合一闪拔刀，空间撕裂出细微电痕；
  * 火焰重斩：火红刀焰收束为极亮火核后爆燃成巨型弯月火海；
  * 摔投贯地：过肩摔/裏投/双膝跪压，将对手整个身躯沿巨大弧线轰入地面。

### 3. 第三幕 · 余震（终结技后的物理与环境反馈，1.0~1.5s）
* **地面碎裂与塌陷**：命中点地面呈蛛网状放射性龟裂，碎石受气浪掀起滞空；
* **环形冲击波扩散**：以命中接触点为圆心，高压气浪呈环形向外狂暴震荡，掀起尘帘；
* **受击者形变与嵌入**：受击者身躯剧烈弓成虾形，倒飞数米深嵌水泥墙体或砸裂地面；
* **气血/暗劲透体**：后背衣物"砰"地炸出放射状微孔，血雾自嘴角/创口呈锥形喷散；
* **终帧定格法则**：视频以最炸裂的瞬间（冲击波扩散/骨碎/嵌墙/刀光定格）作为最后一帧，严禁加入 0.5s 平静收势。

> **R1 写实版三幕**（独有口径，勿与本节混用）见 `sd-real-engine/references/impact-physics.md` §四。

## 五、 特效生长三段论（时间维度）

大招特效绝不能"啪"地直接满屏，必须呈现由内而外的生长过程：

1. **萌芽期（0.3~0.5s，攻击启动）**：出招点（指尖/拳面/刀格）泛起微弱但清晰的高亮星芒或气旋，预告大招来临，拉满观众期待；
2. **生长期（0.5~1.0s，位移与蓄力推进）**：能量沿出招轨迹快速膨胀壮大，密度与亮度呈梯度倍增，向攻击部位核心收束压缩；
3. **绽放期（0.2~0.5s，命中瞬间）**：能量在接触点彻底引爆，炸开巨型环形冲击波、满月光刃或地裂气浪，释放全部张力；
4. **余韵层（0.3~0.5s，环境留痕）**：地面焦痕冒烟、冰晶碎屑飘散、空气热扭曲波纹久久不散。

**段落分配**：前段（0-3s）一招一炸、开局亮眼即收；中段（3-12s）连打零特效保持干净、收尾重击带特效给节奏感；后段（12-15s）特效生长全开（萌芽 $\rightarrow$ 壮大 $\rightarrow$ 巅峰绽放），冲击波炸裂收尾。

> 特效**写法**（手绘化 / 分层 / 负面词）归 `vfx-rendering-mandate.md`；本节只管**生长的时间结构**。

## 六、 终结技前呼吸帧与急停弹射法则

$$\text{急停弹射效应} = \text{前置高速密集对攻} (\ge 1.5\text{s}) \rightarrow \text{瞬间极慢/定格呼吸帧} (0.3\sim 0.5\text{s}) \rightarrow \text{绝杀爆发}$$

* **原理**：没有高速铺垫的定格是无聊停顿；只有在前段高速机枪对攻后，画面突然插入 0.3 秒极慢镜头（汗珠滞空、眼神精光一闪、发丝悬停、小腹抱气），速度差瞬间形成"情绪弹簧"，将观众心理预期直接弹射进最终的绝杀大招中！
