# 语言与风格合同

> **本文件是海外剧赛道的立项接口。** 它属于**项目接口**，不是成稿后的润色标签——**写作前确定，后续随版本传递**。国内剧（赛道①）不填本表。

---

## 一、14 字段逐条定义

```
style_mode / target_language / country_or_region /
character_origin_and_current_place / family_or_work_languages /
audience / language_status / evidence_used / prohibited_inference /
protected_style / multilingual_participants / unresolved / local_review_needed
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `style_mode` | `naturalistic` / `stylized` / `hybrid` | **并写清允许保留的完整句、重复、机锋、仪式性表达或喜剧节奏**。不能因为"真人不会总这样说"就统一压成碎句。 |
| `target_language` | 语言名（如英语 / 西班牙语） | **本项目的正文语言**。多个目标语言时分别说明各自承担范围。 |
| `country_or_region` | 国家 / 地区 | 与语言**分开**——英语不等于美国，加拿大 / 英国 / 澳洲 / 爱尔兰各不相同。 |
| `character_origin_and_current_place` | 逐人物 | 出身地 + 当前所在地。**只作检索线索，不自动生成口音**（见 §四）。 |
| `family_or_work_languages` | 逐人物 / 家庭 / 职场 | 家庭与工作环境中实际使用的语言。**说明能力，不说明此刻该用哪种**。 |
| `audience` | 目标观众与观看情境 | 用户给定的还是假设的，要标明。 |
| `language_status` | 三选一 | 见 §二。 |
| `evidence_used` | 材料清单 | **只列实际读到**且与人物、关系、活动**相近**的材料；用户指定的虚构设定与现实证据**分列**。 |
| `prohibited_inference` | 禁推项清单 | 记录**不能从**地点、姓氏、族裔、职业、双语能力推出的：口音、换语、权限、资格、性格。 |
| `protected_style` | 风格保护项 | 本次受保护的风格特征（完整句 / 冷面笑话 / 礼貌威胁 / 类型化节奏 / 仪式性称呼等），供下游"不得机械打碎"参考。 |
| `multilingual_participants` | 逐次 | **谁懂哪些语言、谁在场、关键事实必须让谁听懂**。会两种语言**不自动触发换语**。 |
| `unresolved` | 未决项 | 尚未解决的问题。 |
| `local_review_needed` | 待复核项 | 需要当地 / 语言社群复核的具体条目。 |

## 二、三级状态

`language_status` 只能取一项：

| 状态 | 成立条件 | 产出承诺 |
|---|---|---|
| `region_unvalidated` | 只有宽泛地点或证据不足 | 产出**清楚可演的英语工作稿**；**不宣称**"当地人就这么说"；**不模仿**强方言 |
| `evidence_calibrated` | 有与**人物、关系、活动相近**的语言材料 | 只使用**证据支持的窄特征**（不扩大到手头材料未覆盖的人物或场景） |
| `human_reviewed` | 相关地区 / 语言社群的**合适复核者实际审过当前版本** | 可以声明已有人工复核，**并写明覆盖范围** |

**默认起点是 `region_unvalidated`**——证据不足仍可继续完成戏，只是降低承诺。

## 三、逐阶段更新权限

| 阶段 | 能做什么 | 不能做什么 |
|---|---|---|
| **统筹 / 立项** | 建立合同；证据不足时直接开工 `region_unvalidated` 工作稿 | 不能因为"要开始写了"就预设 `evidence_calibrated` |
| **研究** | 补证据，**提出** `evidence_calibrated`，**但只覆盖证据实际支持的**地区、社群、关系、活动 | 不能把一条材料的效果扩张到整个项目 |
| **创作** | 按合同写正文 | 不能因为正文读起来顺就升级状态 |
| **评审** | 核对**声明与正文是否相符**，发现问题提出降级 | **不自行升级** |
| **修复** | 保持或在证据失效时**降级** | 只有收到**可追溯的新证据或真实复核记录**才可升级 |
| **制作交接** | 继承锁稿状态，记录待完成的语言 / 字幕 / 表演复核 | 不通过制作便利改写证据等级 |

## 四、禁推项（`prohibited_inference` 的固定底线）

以下推断**一律禁止**，除非另有明确证据：

1. **从地点 / 姓氏 / 外貌 / 族裔 / 年龄 / 职业 / 州省 / 城市 → 口音或方言**；
2. **从"会两种语言" → 此刻该换语**；
3. **从职位 / 亲属身份 → 钥匙、进入权、系统权限、设备操作权**；
4. **从职位 / 身份 → 专业资格、法定处置权**；
5. **从角色自述 → 项目层授权事实**（人物说"委员会给了我钥匙"只是**角色自述**，不是授权证据）；
6. **从身份标签 → 性格、智力、偏好**。

**权限的四项分别核验**：钥匙 / 进入权、设备操作、专业资格、法定处置权——**不得合并推导**。

---

## 五、跨阶段守恒

换语、字幕或地方说法发生变化时，必须**同步**：

- 角色和单语听者**知道什么**；
- **是否被排除**；
- **何时**获得共同语言信息；
- 关系 / 行动的**后果**。

**守恒判据**：同一事实不能一处写未知、另一处写已确认。

---

## 六、交付口径

- **允许对读者说明时**：在**第一个场头前**用一句自然语言写清风格、校准状态、覆盖范围与证据边界；结构化字段留给内部评测或交接。
- **用户明确只要纯正文时**：合同存入**交接记录**，不写进剧本。
- **两种情况下都不成立的做法**：末尾临时补一行状态，并把它当作**已完成前置路由**的证明——**末尾补写 ≠ 前置路由**。

## 七、最小填写示例（示意 · 非模板产物）

> 本项目为英语正文、背景在加拿大某中型城市的家庭剧。语言状态：`region_unvalidated`（尚无该城市、该职业、该家庭关系的语言材料）。风格：`hybrid`——保留角色在压力下的完整陈述句与一次仪式性称呼，不整体碎句化。禁推项：不从角色姓氏推族裔口音，不从"会法语"推自动换语，不从护士身份推医疗处置权。待复核：第 2 集两处法语切换的用法。

**示例用途**：展示字段怎么填。**不得**作为下一个项目的模板产物直接套用。
