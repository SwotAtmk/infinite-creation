## ✨ 技能简介

`script-to-manga` 是一个专为 AI 漫剧/AI 视频创作者设计的 WorkBuddy Skill。

它能自动解析剧本的人物、场景、情绪、冲突强度，智能匹配最优漫画美术风格和影视基调，全自动分配运镜方案、构图光影参数，最终输出**影片级标准化 AI 视频提示词**，可直接粘贴至 Kling、即梦、Sora、Runway 等主流 AI 视频模型使用。
