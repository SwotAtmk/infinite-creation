## 剧本转分镜指令词（15秒标准版·全文）

```
请将上述剧本生成连续分镜，每个剧本段落对应一个分镜，时间固定为：
0s–4s
4s–8s
8s–12s
12s–15s

必须严格按照下面格式输出，不要加解释，不要加分析，不要加任何多余内容：

分镜：1
人物：XXXX
场景：XXXX
0s–4s：镜头类型：XXXX，人物可视化动作：XXXX ，运镜方式：XXXX，环境音与动作音：XXXX，台词：XXXX
4s–8s：镜头类型：XXXX，人物可视化动作：XXXX ，运镜方式：XXXX，环境音与动作音：XXXX，台词：XXXX
8s–12s：镜头类型：XXXX，人物可视化动作：XXXX ，运镜方式：XXXX，环境音与动作音：XXXX，台词：XXXX
12s–15s：镜头类型：XXXX，人物可视化动作：XXXX ，运镜方式：XXXX，环境音与动作音：XXXX，台词：XXXX

要求：

严格遵循"不增不删"的原则

1. 内容拆分
将原文剧情按 时间 / 场景 / 情节转折点 拆分成多个小节，每小节视频长度控制在 12秒左右
每小节的台词字数不超过 30个字
每个小节独立输出完整的描述词，便于逐段生成视频

2. 视频提示词原则
（1）叙事优先
严格遵循 "冲突铺垫 → 高潮爆发 → 结果呈现" 的叙事节奏
结合原文人物描写，台词用于铺垫冲突和宣布判决，再进入主角的反击与行动高潮
台词内容与画面动作必须同步，确保观众情绪随台词递进被有效调动

（2）视觉关键词密集
为最大化 AI 模型对画面的控制力，必须使用大量具体、高辨识度的视觉描述词汇
场景、角色、光影、特效混合使用（示例："幽蓝色的霓虹线路""血红色的赛博月亮""凌厉的金色电光""数码化的爆炸效果"）

（3）情绪 / 氛围主导
明确指示画面应传达的情绪，帮助模型设定色彩饱和度、景深和光照风格
描述中加入如 "宏大、压抑""傲慢的冷笑""眼神中爆发怒火" 等情绪词，并用色彩对比强化氛围（如"霓虹蓝和血月红对比"）

只根据原文改写，不胡编剧情；
强调画面感、镜头感、动作感、表情变化、情绪递进；
"人物可视化动作"必须写成能直接看见的表演动作，不要写空泛概括；
"环境音与动作音"只能写音效，不写音乐；
"旁白"负责叙述和心理推进，"台词"负责人物说出口的话，没有就写"无"；
整体要像成熟漫剧成片分镜，适合直接拿去生成视频。
宁可把动作、表情、镜头写细，也不要写成剧情概括；宁可像成片分镜，也不要像小说总结。
【闪回/回忆】该角色回忆之前出现过的镜头时使用
开始用【闪回】，结束用【闪出】

按照要求严格执行，全部输出完后停止，以下是我的小说内容：
```

## 分镜写作红线（输出后人工复查）

- 不增不删，只按原文改写
- 台词每节≤30字
- "人物可视化动作"=能直接看见的表演（❌"他很愤怒"→✅"攥拳砸桌，青筋暴起"）
- 环境音只写音效不写音乐
- 旁白管叙述、台词管说话，没有写"无"
- 回忆用【闪回】…【闪出】，且只回忆出现过的镜头

## 静/视标注（三七原则，AI分镜表出来后人工标注）

- 【视】只给：瞳孔/表情爆发、关键动作、反转揭示、消失/出现、结尾卡点 → 每集控制在6-8段
- 其余全【静】：静图+剪映关键帧推拉5-10%

## 镜头语言速查

| 情绪 | 镜头方案 |
|---|---|
| 压迫 | 缓推+特写 |
| 打脸 | 仰拍中景→旁人惊愕特写 |
| 虐点 | 极特写+闪白 |
| 卡点 | 急推切黑/拉远留白 |
