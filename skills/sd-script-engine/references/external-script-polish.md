# 外部剧本润色层（EXTERNAL_SCRIPT_POLISH · 剧本适配前置环节）

## 一、这一层为什么必须存在（结构性断链）

本包分镜引擎有一条**铁律**：**每句台词必挂「具体神态 + 具体动作」两项，缺一 = 废镜重写**（`sd-storyboard-engine/SKILL.md`）。

这条铁律**默认上游是本包剧本**——`sd-script-engine` 的产出自带神态、动作相位、状态栏、台词重音、场次因果脊柱。**闭环成立**。

但**外部标准剧本**（网文改编稿 / 平台约稿 / 第三方编剧稿 / 用户自带剧本）通常只有：

```
场景标题 + 「角色：台词」 + 少量结果性动作提示
```

**没有微表情、没有动作相位、没有状态栏、没有台词重音、没有场次因果连接。**

```
外部标准剧本
     ↓
分镜引擎铁律要求「每句台词挂神态 + 动作」
     ↓
执行者无米下锅 → 二选一：
    ① 现编（= 越权改用户剧本，用户没授权）
    ② 写空（= 撞铁律，判废镜重写）
```

**结论：本包此前是「自产自销闭环」，缺一个对外来剧本的适配入口。** 本层就是那个入口。

> **用户原话（2026-10-13）**：「这个分镜关联的是**你的 skill 出来的剧本**（因为你的 skill 出来的剧本有表情和动作的描述），**但外部的标准剧本不一定有微表情和丰富的动作描述，针对外部剧本应该要有一个剧本润色的动作，让它适配你的分镜**。」

---

## 二、触发条件（何时必须走润色层）

**同时满足前两项 + 命中第三项任一子条 → 必须走润色层**：

| 序 | 条件 | 说明 |
|---|---|---|
| A | **〇·1 素材来源 = ② 改编** | 原创（①）不走——原创走完整六阶段链，产出即自带表演层 |
| B | **输入物是「已成型的剧本」** | 有场次划分 + 台词行；**小说 / 大纲 / 梗概不是**（走完整六阶段链） |
| C | **检测到下列任一缺失**（外部剧本体检） | ① 台词行无神态标注；② 无动作相位（只有结果、无过程）；③ 无状态栏（人物状态/情绪/伤势/道具位置）；④ 无台词重音标注；⑤ 无场次因果脊柱 |

**C 项五条检测（逐条打勾，命中 ≥1 即触发）**：

```
□ 台词行形如「角色：台词」——角色名后无（语气）位、镜行无神态描写？
□ 动作提示是结果性的（「他生气了」）——而非过程性的（「下颌收紧、指节抵住桌沿」）？
□ 没有状态栏——人物此刻的情绪/伤势/道具在手位置无从查证？
□ 关键台词没有重音字标注？
□ 相邻场次之间没有因果连接——读不出「这一场为什么接在那一场后面」？
```

**免走条件（三项全成立才可免）**：外部剧本**已自带**神态 + 动作相位 + 状态栏。此时直接进 P3 分镜，但需在交接卡首行声明「外来剧本自带表演层 · 免润色」。

⛔ **〇·1 = ① 原创 / ② 改编但输入是小说大纲 → 不走润色层**（走完整六阶段链，见 `six-stage-pipeline.md`）。润色层**只服务"已成型的剧本"**，不替代编剧链。

---

## 三、润色边界（硬约束 · 不可越权）

**润色只补「表演层 + 调度层」，严禁触碰「台词层 / 事件层 / 人物层」。**

| 层 | 允许 | ⛔ 禁止 |
|---|---|---|
| **台词层** | ❌ 一律不动 | 改台词、加台词、删台词、改说话人、改语序 |
| **事件层** | ❌ 一律不动 | 增删事件、改事件顺序、改事件结果、改场次归属 |
| **人物层** | ❌ 一律不动 | 改人物关系、性格、身份、动机、结局 |
| **表演层** | ✅ 只补 | 神态（FACS 化）、动作相位、视线落点、语气位 |
| **调度层** | ✅ 只补 | 站位、进出场、场次过渡、道具在手位置与状态 |

**⚠️ 发现硬伤怎么办 —— 不得直接改**：

润色过程中若发现台词 / 事件 / 人物层存在硬伤（**人物降智、因果断裂、动机不成立、时间线矛盾**），**不得顺手改**（那是越权重写）。**另出《润色发现清单》（`POLISH_FINDINGS.md`）交用户裁定**——用户决定改则回 `sd-script-engine` 六阶段链处理，不改则原样保留。

**判据一句话**：**润色后的剧本，用户能指着任何一句台词说「这句还是我写的原话」——改了台词就是越界。**

## 四、润色产出物（六件 · 逐件交付）

| # | 产出物 | 从什么补到什么样 | 落点 |
|---|---|---|---|
| **1** | **台词神态补全** | `角色：台词` → 台词行补 `（语气）` 位 + 镜行补**具体神态**（FACS 四区：眉/眼/颧颊/嘴下颌） | 逐台词行 |
| **2** | **动作相位补全** | 结果性动作（「他生气了」）→ **过程性动作**（起-持-落三拍：`下颌绷紧 → 保持 → 牙关松开`） | 逐动作提示 |
| **3** | **状态栏补全** | 无状态 → 逐场补**人物状态 / 情绪 / 伤势 / 道具在手位置**（这是资产层与连续性台账的输入） | 逐场次 |
| **4** | **台词重音标注** | 无重音 → 逐关键台词标**重音字**（表情峰值须对齐重音字，非台词开头） | 逐关键台词 |
| **5** | **场次因果脊柱** | 场次之间无连接 → 逐场补 `前因 → 触发 → 后果`，标在**场次卡**上（与 `episode-planning.md` §CAUSALITY_AND_RELATION_TABLE 同构） | 逐场次 |
| **6** | **场次过渡设计** | 相邻场次硬接 → 按 `TRANSITION_AS_BEAT` **四类型**（动作桥 / 空镜叙事 / 声音桥 / 硬接需理由）补过渡设计 | 逐相邻场次 |

**润色稿格式**：**保持用户原剧本的场次编号与结构不变**，只在行内**就地标注**（推荐用行内括号夹注，不新增段落层级），确保「原稿 vs 润色稿」可**逐行对照**。

```
【润色示意】（左＝原稿，右＝润色后；台词一字未改）

原稿：  李明：我不签。
润色后：李明（压抑、一字一顿）：「我不签。」
        ▸ 神态：眉压低、下眼睑绷紧、唇线抿成一条直线（AU4+AU7+AU24）
        ▸ 动作相位：指节先抵住桌沿 → 保持 → 收回手插进口袋
        ▸ 重音：**不**签
```

## 五、回签流程（强制 · 不得跳过）

**润色产出物 = 创作决定**——补出来的神态 / 动作 / 过渡**不是用户写的**。

```
润色稿完成
     ↓
输出《润色确认卡 POLISH_CONFIRM_CARD.md》交用户
     ↓
用户逐条过 —— 三条路：
    ① 全部接受 → 润色稿冻结，进 P3 分镜
    ② 部分驳回 → 被驳回处按「不补」处理（分镜层该镜走中性表演，不得现编）
    ③ 全部驳回 → 放弃润色，回用户原稿（分镜层报 BLOCKED_REPORT 说明无米下锅）
     ↓
用户确认后才进 P3 —— ⛔ 不得默认自动通过
```

**《润色确认卡》必须逐项列出**：补了哪句台词的什么神态、补了哪个动作的什么相位、补了哪些过渡设计——让用户**能逐条驳回**，而不是「整体接受/拒绝」一个黑箱。

## 七、与下游的接线

| 下游 | 从润色稿拿到什么 |
|---|---|
| **sd-asset-engine（P2）** | 从**状态栏**提取人物外观/道具/场景三清单 |
| **sd-storyboard-engine（P3）** | 从**神态+动作相位**满足「每句台词挂神态+动作」铁律；从**重音标注**对齐表情峰值；从**过渡设计**落段缝 |
| **sd-qc-engine（P5）** | 从**场次因果脊柱**做跨集连续性台账 |

**接线声明**：润色稿进入 P3 前，须在交接卡首行声明「**已润色 · 用户已确认**」或「**外来剧本自带表演层 · 免润色**」——**不得静默跳过本层**。

## 八、⛔ 禁止事项（违规即退回）

1. ⛔ **改台词**——哪怕改得更好、更短、更顺口；
2. ⛔ **改事件**——增删、调序、改结果一律禁止；
3. ⛔ **改人物**——关系、性格、身份、动机、结局一律禁止；
4. ⛔ **不加工直接进分镜**——检测到缺失却不走润色层，等于把「无米下锅」问题推给下游；
5. ⛔ **润色后不回签**——补出来的表演层是创作决定，未经用户确认即进分镜 = 越权代笔；
6. ⛔ **把《润色发现清单》里的硬伤顺手改掉**——只报告，由用户裁定。

## 九、与「六阶段链」的分工（改前必读）

```
〇·1 = ① 原创     → 完整六阶段链（本层不参与）
〇·1 = ② 改编
    ├── 输入是小说/大纲/梗概 → 完整六阶段链（本层不参与）
    └── 输入是成型的外部剧本 → 【本润色层】→ P2 资产 → P3 分镜
                    ↓ 发现台词/事件/人物硬伤
                  《润色发现清单》→ 用户裁定 → 回六阶段链
```

**一句话**：**六阶段链是「造剧本」，润色层是「接剧本」。** 前者产出，后者适配。**颠倒或合并两者 = 越权**。
