## 示例 1：深夜翻墙逃跑（官方示例）

【剧本片段】四名初中生深夜翻墙逃离寄宿学校，雨夜潜行，紧张心虚

【1.漫剧美术风格】
日系少年漫、平涂二次元漫画

【2.影视画面基调】
冷调悬疑

【3.镜头运镜方案】
- 平行横移轨：跟随四人侧向移动，人物居三分线，展示团队行进状态
- 低角度跟随穿行运镜：机位贴近地面从背后跟进，强调偷偷摸摸的潜行感
- 定点呼吸抖动：轻微有节律抖动，增加真实紧张感，幅度控制在 ±2px

【4.构图光影摄影参数】
三分法留白构图 / 前后景分层构图（前景墙体虚化） / 雨夜低照度冷调光影 / 浅景深虚化前景障碍 / 24帧标准帧率

【5.AI视频最终提示词】
日系少年漫风格，平涂二次元质感，冷调悬疑校园影视画面，深夜阴雨寄宿学校外景砖墙，四名14岁初中生弯腰贴墙潜行翻越围墙，动作谨慎紧张，表情惊恐警觉，画面低照度冷青色调，前后景分层虚化，三分法构图，镜头平行横移跟随人物，低角度贴地穿行运镜，轻微呼吸手持抖动，无过度曝光，画面干净，漫剧动态流畅，真实雨夜环境肌理，无模糊画质，24帧标准帧率

## 示例 2：异能觉醒爆发（史诗高光）

【剧本片段】少年张云在废旧仓库中第一次激活龙纹异能，掌心涌出金色光龙，震碎周围玻璃，双眼变金色

【1.漫剧美术风格】
厚涂写实漫画、奇幻魔幻漫画

【2.影视画面基调】
史诗奇幻

【3.镜头运镜方案】
- 360°环绕轨：完整环绕张云一圈，强调觉醒时刻的爆发感
- 垂直拉升运镜：从腰部高度垂直上升至俯拍远景，展示能量扩散范围
- 希区柯克变焦：前推同步缩焦，面部表情扭曲强化，强调心理冲击

【4.构图光影摄影参数】
