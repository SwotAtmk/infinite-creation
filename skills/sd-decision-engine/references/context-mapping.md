# 情境映射库（Context Mapping · E01~E15 + 80/15/5 权重）

> **本文档是决策层核心规则库 · 权威文件**
> 融合来源：script-writing-studio 04 模块「情境映射」机制
> 术语口径：**全部换算为中文景别体系**（特写/近景/中景/中近景/全景/远景/大远景/微距），禁用 CLOSE-UP / LONG LENS 等英文术语。

---

## 〇、定位与边界

**本文件解决一个问题：这场戏该用什么镜头？**（原有体系只回答"怎么拍"——机位规格、镜长节奏、景别阶梯，但没有回答"选型依据"。）

- **本文件是"选择依据层"**：输出「情境 ID + 核心组合」，作为分镜设计的**输入**。
- **本文件不是"规格权威"**：机位角度/焦段/运镜的**具体写法**仍以总控 `short-drama-director/references/camera-specs-15rules.md` 与 `sd-storyboard-engine/references/short-drama-camera-system.md` 为唯一权威。
- **优先级**：若本文件的核心组合与已有铁律冲突（如 15 秒完播率公式、景别阶梯跃迁），**一律以铁律为准**，本文件降级为参考。

## 一、80/15/5 权重机制（核心）

每个节拍选定情境 ID 后，镜头设计按三层权重分配：

```
┌─ 核心组合（80% 权重 · 锁死必用）─────────────────────┐
│ 来自 ID 表"核心组合"列，全部必须用上                  │
│ ❌ 不允许 LLM 替换 / 删除 / 自由发挥                  │
└───────────────────────────────────────────────────┘
┌─ 辅助锚点（15% 权重 · 选 1-2）────────────────────┐
│ 据剧本细节选 1-2 个，用于增强情绪                    │
│ ✅ 选什么由 LLM 判断，但只能从该 ID 的辅助锚点里选     │
└───────────────────────────────────────────────────┘
┌─ 增强项（5% 权重 · 仅情绪峰值）────────────────────┐
│ 一段大分镜中最多 1 个镜头使用                        │
│ 命中点 = 该段戏的最高情绪峰值                        │
└───────────────────────────────────────────────────┘
```

**设计意图**：把"能自由发挥"的空间从 100% 压到 20%。核心组合锁死保证**稳定性**，辅助+增强保留**创作弹性**。

## 四、辅助锚点池（15% 权重选用）

> 使用规则：为每个节拍从**本池**选 1-2 条，与核心组合叠加。禁止跨 ID 混用。

| 锚点类别 | 可用锚点 |
|---|---|
| **焦段变化** | 换用相邻焦段（长焦→中长焦 / 广角→中焦）制造呼吸感 |
| **机位高度** | 微仰 / 微俯（幅度小于核心组合的"仰拍/俯拍"） |
| **前景插入** | 前景加虚化物件（门框/树叶/酒杯）制造纵深与窥视感 |
| **光线调整** | 侧逆光/轮廓光强化主体边缘；主光从暖转冷或反之 |
| **运动微调** | 缓推→固定 / 固定→微摇 / 手持微动幅度升级 |
| **空间压迫** | 压缩留白 / 加大主体占比 / 前移后景层 |
| **细节插入** | 加一个手部/眼神/道具的插入镜头（不占额外节拍） |

## 五、增强项池（5% 权重 · 每段最多 1 镜）

> 使用规则：**每段大分镜最多 1 个镜头**使用增强项，且必须命中该段**最高情绪峰值**。滥用即失效。

| 增强项 | 效果 | 使用前提 |
|---|---|---|
| **滑动变焦（Dolly Zoom）** | 空间扭曲、眩晕、认知崩塌 | 顿悟/失控瞬间 |
| **环绕运镜** | 360° 环绕主体，强调孤立或震撼 | 情绪顶点、身份揭示 |
| **极限景别跳跃** | 大远景 ↔ 微距直跳，制造视觉重锤 | 转折点、时间跳跃 |
| **升降镜头** | 大幅升/降，格局变化 | 命运转折、视角跃迁 |
| **慢动作定格** | 时间凝滞 | 关键瞬间（注意：静止目的须为"被截图/强调"，非拖延） |

⚠️ 增强项与总控「重技法名额」共享上限：荷兰角 ≤1/集、大仰角/大俯角各 ≤3/集、剧烈晃动 ≤3 段落。**增强项不得超配。**

## 六、选 ID 的优先级流程

```
1. 优先在本文件"基础速查表（12 个）"中找 → 命中即用
2. 找不到匹配 → 查"进阶速查表（3 个）"
3. 仍找不到 → 询问用户：
   "本节拍情境（如'失忆中的恍惚'）不在标准库中，
    请提供：期望核心组合（焦段+机位+运镜）/ 风格参考片"
4. 用户授权 → 临时定义 EX01 + 文档中标注"用户自定义情境"
```

**硬约束**：情境 ID 必须从 ① 基础表 ② 进阶表 ③ 用户自定义 三处之一获取。**禁止 LLM 临时编造 ID。**

## 七、雷区解锁标注规范

若情境 ID 解锁了某条雷区（见 `forbidden-zone-whitelist.md`），必须在情绪锚点表的"解锁雷区"列**显式标注**，且：

1. **内部四问 Q4 必须写明**"解锁理由 = 来自 ID Exx 白名单第 X 项"。
2. **通用后缀必须配套**（如解锁 E10 仪式威严 → 后缀加"强对称构图 / 仪式感"）。
3. **B 类工程性雷区（物体穿身等）永不解锁** —— 不允许出现在解锁列。

## 八、与体系的衔接（★必读 · 防冲突）

| 已有机制 | 本文件的关系 |
|---|---|
| `short-drama-director/references/camera-specs-15rules.md` 镜头规格五要素 | **本文件给"选什么"，规格写法定法以那份为权威** |
| 景别阶梯跃迁铁律 | 核心组合的景别若违反阶梯跃迁 → **以阶梯跃迁为准** |
| 15 秒完播率黄金公式 | 本文件不改变 15 秒结构，只在结构内分配情境 |
| 短剧视感机位体系（侧45度默认/常规≤30%） | 情境核心组合的机位角度须在该体系配额内 |
| `sd-storyboard-engine` 分镜输出 | 决策层输出（锚点表）作为分镜引擎的**输入依据** |

**一句话**：决策层决定"为什么用这个镜头"，机位体系决定"这个镜头怎么写"。**两层不越界。**
