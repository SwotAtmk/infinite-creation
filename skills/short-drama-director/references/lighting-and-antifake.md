# 真实光线物理引擎与日景防冷光规范 (Lighting & Anti-Fake)

---

## 一、 真实光线物理来源铁律

严禁无来源的情绪假光与廉价棚拍白光，光线必须具备明确的物理发光源：
* **日景白天**：侧面窗棂天光、林间丁达尔斑驳阳光、天空自然散射光；
* **夜景室内**：暖黄钨丝灯、破败日光灯管频闪、蜡烛烛火微光、霓虹灯管反射；
* **阴影要求**：阴影必须呈现自然的青灰/暗棕环境漫反射色阶，严禁死黑或全脸漂浮发白。

---

## 二、 日景防冷光防御机制 (Daylight Cold-Light Defense)

* **严禁词汇**：在日景/白天场景中，**严禁直接使用“冷白光、冰冷蓝光、刺眼冷光”**；
* **转译规范**：若需要表达白天肃杀、凄清、冷酷的氛围，必须转译为：
  `低饱和度影调，青灰色自然漫射阴影，背光面与高光处形成自然明暗阶梯，逆光边缘光勾勒轮廓`。

---

## 三、 三点布光与光型体系（Lighting Geometry）

任何一场戏的光，先落**布光三件**，再选**光型**，最后定**光比**（§四）——三者齐备才算写明照明。

**布光三件（缺一即「光影」字段不合格）**：

| 件 | 作用 | 写法要点 |
|---|---|---|
| **主光 key** | 定光源方向与人物立体感 | 必须写方向与来源（窗/灯/火/霓虹/天光），禁「柔和的光」这类无源写法 |
| **辅光 fill** | 抬起暗部、控制反差 | 写清是环境漫反射还是反光板；暗部**必须有间接光填充**，禁纯灰死黑 |
| **轮廓光 rim / 逆光** | 把人物从背景里「剥」出来 | 有源才给：窗/灯/火/霓虹；无源的糊黑侧脸不合格 |

**光位四件**（与 `sd-combat-engine/references/combat-iron-laws.md` 的光位系统一致，写进画面质量基准）：
主光方向 + 轮廓光 + 环境自发光当补光 + 眼神光。**眼神光是人物的「活」**——人物近景/特写默认给，禁空洞无光点的眼。

**光型速查**：

| 维度 | 取值 | 适用 |
|---|---|---|
| 软硬 | 硬光（明暗交界线利落）／软光（过渡绵长） | 硬光＝对峙/威压/真相；软光＝日常/回忆/柔情 |
| 方位 | 顺光／侧光（前侧 45° 为默认）／侧逆光／逆光 | 侧光是叙事默认；逆光是「离别/升华/揭示」 |
| 高度 | 顶光（压顶、审判感）／平位／底光（诡异、不安） | 顶光与底光都属强手段，慎用、不连用 |
| 人像三光 | **伦勃朗光**（侧前 45° 高位、暗部脸颊闭合倒三角光斑）／**蝴蝶光**（正前高位、鼻底对称小影）／**分割光**（正侧 90°、半边受光半边全暗）／环形光（正前、鼻影环而不交） | 伦勃朗＝性格深沉·权谋·内心挣扎；蝴蝶＝端庄·尊贵·冷艳；分割＝黑化·双重人格·心理撕裂；环形＝平实·日常 |

- **人像三光属「主光位」选择**，与光比（§四）正交搭配：伦勃朗 + `1:4` 是剧情叙事的标准组合；分割光只配 `1:8` 以上，且**仅限单场戏的少数镜**（半脸全暗极易触发「欠曝暗调」红线）。

* 光型必须与情绪匹配，且**一场戏内不来回换**（换就要有叙事理由，如「关灯」这类动作）。
* 光源动机铁律见 `sd-storyboard-engine/references/scene-space-adaptation.md`；本文件只管照明参数，不重复场景空间规则。

## 四、 光比量化与曝光红线（Ratio & Exposure）

**光比 ＝ 主光 : 辅光 的照度比**，用 `1:N` 写法，进【画幅风格】或镜行「光影」字段。禁写「强反差/弱反差」这类不可执行的形容词。

| 光比 | 观感 | 适用 |
|---|---|---|
| `1:2` | 平、干净 | 日常、轻松、信息交代 |
| `1:4` | 立体、有层次 | **常规叙事的推荐值**，与侧光 + 伦勃朗光同用 |
| `1:8` | 反差明确、压得住 | 对峙、压迫、审问、暗流 |
| `1:16` | 强反差、大面积暗部 | 悬疑、真相揭露、孤立——**仅限单场戏的少数镜**，不整场铺 |

**曝光红线（硬约束 · 全套场景通用）**：

* **曝光必须明亮充足**——暗部可深，但整体不能欠曝。
* **禁欠曝暗调**、**禁全脸漂白**（人脸高光必须留得住五官，不许一片白）。
* **禁死黑**（阴影必须呈自然青灰/暗棕环境漫反射色阶，不许纯黑无层次）。
* **禁无源情绪假光**（见 §一）。

> **与风格指数的边界**：`film_stock / grain / halation / palette / saturation` 属**色调字段**，不是照明；照明只管**光源·方向·光型·光比·明暗台阶**。风格指数写法见 `sd-storyboard-engine/references/short-drama-camera-system.md` 分镜「色调」字段与 I 画风锁段 8。

## 五、 双色温冷暖对冲（Kelvin Contrast）

高质感画面的纵深，一半来自**冷暖对抗**：主光一侧暖、轮廓/环境一侧冷（或反之），人物立刻从背景里「浮」出来。全片只有一种色温，画面就掉进棚拍感（一片暖＝广告、一片冷＝鬼片）。

| 戏剧场景类型 | 主光源色温（key） | 背景 / 轮廓对冲色温（rim · ambient） | 视觉心理效果 |
|---|---|---|---|
| 悬疑 / 谍战 / 暗杀 | 3200K 室内暖钨丝灯·烛火（暖橙黄） | 6500K 窗外冷月光·冷雨夜天光（深冷青蓝） | 逼仄孤立、危机四伏的生存压迫 |
| 赛博 / 现代都市 | 4000K 惨白日光灯管（工业青绿） | 霓虹粉紫 / 饱和钴蓝点光强反射 | 工业冷酷与迷幻欲望冲撞 |
| 仙侠 / 宗门 / 大殿 | 5000K 天空纯白天光漫射 | 2800K 神佛法相神光（纯金暖芒） | 庄严神圣、超凡脱俗的威压 |
| 废土 / 破庙 / 残垣 | 5500K 阴霾惨灰自然天光 | 1800K 焦黑战火余烬（猩红微弱火光） | 萧条绝望与未熄杀意对冲 |

- 写法：色温写进【画幅风格】或镜行「光影」字段，一句写清「主光 X 色温 + 对冲 Y 色温」，禁只写「冷暖对比」这类不可执行的形容词。
- ⚠️ **对冲不得突破 §四 曝光红线**：冷侧再冷，也必须是**可辨识的青灰/暗棕环境漫反射色阶**，不许压成死黑；暖侧不许过曝漂白。**色温解决「色」、不解决「亮」**——用冷暖分色，不用明暗分色。
- 与打戏域的关系：`sd-combat-engine/references/combat-iron-laws.md` 的「五色调色板 · 禁统一色温」是**打戏域内特化**（含能量自发光），本表是**通用叙事照明**的默认档；域内可加严，不可放宽。

## 六、 空间物理介质与微物理渲染（Atmospheric Mediums）

画面「有空气厚度」靠的是**光在介质中的散射**——空场无介质＝渲染感（假），有介质＝空间感（真）。四类介质按场景调用，不必每镜都写，一处写准即可：

* **丁达尔体积光（Tyndall Volumetric Light）**：天光穿过窗棂格栅 / 林木枝桠，在空气中形成**肉眼可见的实体光柱**——室内大窗、林间、破庙残垣的定场首选。
* **悬浮尘埃微粒（Suspended Dust）**：光柱中可见微细尘埃随气流缓慢翻滚——赋予时间沉淀感与密闭空间的静谧张力。
* **湿度漫反射（Moisture Sheen）**：雨后石板镜面水渍倒影、湿润发梢贴额带微光——增加通透度；雨戏收尾镜必写。
* **热浪空气扰动（Heat Distortion）**：高温火源 / 大招能量凝聚处，后景空间呈现热空气波纹折射与微弱火星飘散。

- ⚠️ **介质不替代光源动机**：丁达尔必须有来源（窗 / 林隙），无源的光柱就是假光（见 §一）。介质是「光源的可见载体」，不是独立光源。
- ⚠️ **不许为氛围硬加介质**：与叙事无关的尘埃 / 雾气只是噪点（雾一多，人脸就糊），介质必须服务于这场戏的空间质感。

## 六·补、 阴影侧取景（Shadow-Side Shooting）与纯实用光防溢染铁律（2026-10-14 粉丝 shotlist-builder 吸收）

> 📌 **为什么运镜好坏与布光强绑定？** 正面平光下，摄影机微移时人脸光影毫无变化，像纸片平移；唯有摄影机站在**人物阴影侧（shadow side）**取景，镜头哪怕只做 10~15 厘米微移，面部明暗交界线与高光轮廓就会产生真实的立体光影流动。

1. **阴影侧取景铁律（Shadow-Side / Upstage Shooting · Lubezki × Deakins 核心法则）**：
   - **摄影机优先在人物的阴影侧（shadow side）拍摄**——让人物面部朝向主光源自然受光，而摄影机从较暗的背光 / 侧逆光一侧取景；
   - 利用场景实用光（practicals）照亮面部轮廓线与湿润眼神光（catchlight），配合全程薄雾（atmospheric haze）增加景深层次（严禁无源刺眼可见光束 god rays）。
2. **纯现场实用光源锁定与防蓝光色溢（Practicals-Only & Anti-Blue Spill）**：
   - 写实 / 权谋 / 沉浸向场景优先声明**仅使用场景内实际存在的光源（practicals：窗户天光、烛火、宫灯、台灯、器物漫反射）**，严禁无源正面柔光箱、反光板把暗部拍平；
   - **防屏幕 / 冷光源色溢污染（Anti-Blue Spill）**：若场景内含发光屏幕、法阵或冷蓝光源，须显式声明 `仅作为背景元素发光，禁止冷蓝色溢（blue spill）直接污染人物面部皮肤与服装固有色`。
3. **60:30:10 情绪色彩配比公式（可并入【画幅风格】或分镜色调栏）**：
   - 按场次情绪锁死 `60% 主色 : 30% 辅色 : 10% 点缀色`（冷冽权谋对峙：`60% 冷青灰 + 30% 暗檀褐 + 10% 朱砂红点缀`；温暖内室：`60% 暖钨丝琥珀 + 30% 深胡桃木褐 + 10% 鎏金高光`；危机压迫：`60% 暗绯红 + 30% 墨黑 + 10% 烛火橙`）。

## 七、 权威边界（一个规则域一个权威）

* 本文件 ＝ **照明规则唯一权威**：光源来源、布光三件、光位四件、光型、光比、曝光、色温对冲（§五）、气氛介质（§六）。
* `sd-combat-engine/references/combat-iron-laws.md` 的「五色调色板 + 光位四件 + 丁达尔 + 禁白色体积光 + 禁统一色温」属**打戏域内特化**（含能量自发光），与本文件不冲突：**色板归色调，光位归本文件**；域内文件可加严，不可放宽。
* `sd-asset-engine/references/character-portrait-templates.md` 等资产侧的色温/光照方向/SSS 是**生图参数**，不是场记照明规则；两边数值不冲突即可，冲突时以本文件为准。
* 本文件未覆盖的照明细节，按上游域内文件执行。
