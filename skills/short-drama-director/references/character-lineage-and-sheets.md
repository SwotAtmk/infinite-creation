# 角色资产板与亲缘/多梯队遗传推导规范 (Character Lineage & Asset Sheets)

> 🔗 **流程位置：P2 数字资产包·第一批角色出图（见 `asset-first-pipeline.md` ★权威）**。本规范用于从 T1 男女主基准，推导并**直接出图** T2 亲属/反派、T3 功能配角（非文字推导），解决群像风格割裂与人脸变异。产出物 = 角色 4 View 资产板，进入《资产图册》。

---

## 一、 标准角色 4 View 资产卡构成（CURRENT）

每位 A/B 级核心角色的资产图必须包含以下要素：

1. **Face Close-up（面部特写）**：五官骨相、眉眼间距、瞳孔色泽、皮肤肌理。
2. **四格（Face Close-up + 3 Views）**：Face Close-up（头部近景/面部特写）+ 无脸 Front View（正面全身）、无脸 Side View 90°（侧面全身）、无脸 Rear View（背面全身），**四格等分布局**（**全图共 4 格 = 提示词必须显式声明的总数；不设独立大主图、任一视角不得重复、不得出现第 5 格**）。🗄️ LEGACY：旧「3/4 斜侧三视图」仅作历史兼容。**★面部锚点唯一（硬性）**：全图**仅 Face Close-up 一处渲染清晰五官**，其余三格一律**「无脸」——头部完整入画（不裁头/不砍头，保头身比）、面部不刻画五官**；三格全身统一**完整头顶至鞋**（不裁脚、不砍头、鞋必须画在全身格内）。**★四格纯图（硬性）**：**图上除图底部那行 ≤8 词英文音色速览标签 + 声纹波形外零文字**——不标视角名/「正面·侧面·背面·面部特写」/脸部处理/角色名/编号；**图底横向细节条必须入图**（2026-10-12 第五轮修正）= **① 声纹波形 / 频谱可视化（非文字图形 · 视觉一致性锚 · 不占入图文字名额）＋ ② ≤8 词英文音色速览标签 Voice Description Label（唯一允许入图的文字）**；**完整版 Voice Description（2–4 句）不入图**，转纯文本交付。逐格落位表见 `sd-asset-engine/references/character-portrait-templates.md` §七。
3. **Full Body（全身比例）**：身高比例尺（如 180cm / 168cm）、头身比（6.5~8 头身）。
4. **Detail Assets（细节材质）——文字描述项，不占图格（2026-10-10 修订）**：以下细节**不再单独出图格**，改为写进四格描述文字 / 复述块：
   - Fabric Texture（服装布料肌理，如哑光羊毛、做旧皮质）
   - Hair Style（发型流向与碎发高光）
   - Button / Cuff Design（纽扣、袖口与配饰细节）
   - Footwear（鞋履款式与材质——**必须画在全身格内**，不得依赖特写格）
5. **HEX Color Palette（标准色值）**：
   - Primary（主色调，如 `#1A1E24` 炭黑）
   - Secondary（副色调，如 `#8C7355` 暖卡其）
   - Accent（点缀色，如 `#C23B22` 暗朱红）

## 二、 亲缘与多梯队角色推导引擎

为保证群像戏（如家族、亲属、师徒）的视觉统一与真实感，严禁孤立生成配角。必须遵循以下推导法则：

### 1. 梯队划分
- **第一梯队（T1 - 核心基准）**：男一号、女一号。率先锁定脸模与核心画风。
- **第二梯队（T2 - 亲缘/亲密）**：父母、子女、兄弟姐妹、情侣、核心反派。
- **第三梯队（T3 - 功能配角）**：同门、手下、管家、路人。

### 2. 亲缘遗传推导算法（推导后直接出图）

当生成 T2 亲属角色时：
- **骨相继承**：继承 T1 角色 40%~60% 的下颌骨轮廓或眼眶深浅；
- **五官关联**：如母亲与女儿共享相同鼻型与眉形弧度，仅在眼尾纹理与面部胶原蛋白丰满度上作年龄化差异；
- **色彩呼应**：家族成员在服装 HEX 调色板中共享至少 1 个 Secondary/Accent 色值；
- **出图方式**：按上述继承参数，直接生成 T2 的 4 View 资产板（复用 T1 的底色/材质描述 + 差异化参数），并入 P2 第一批角色出图，锁定后进《资产图册》。

## 三、 输出指令规范

当用户输入 `/角色资产板`、`/角色遗传推导` 或 `/数字资产包` 时，系统按 `asset-first-pipeline.md` P2c·第一批执行：
1. 锁定 T1 男女主脸模与核心画风（出图）；
2. 按亲缘推导 T2/T3 并**直接出图**（非文字描述）；
3. 输出角色 16 项资产全量描述词（中英双语，可直投 Midjourney / 即梦 / SD，作为出图提示词）；
4. 交付角色 4 View 资产板 + 亲缘推导关系表 + 标准色值清单。
