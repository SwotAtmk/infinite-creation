# 打戏激烈度硬护栏与节奏零件库（拉片实证层）

> **定位**：本库是**打戏"到底打没打起来"的工程底线**，管的是**节奏与激烈度**——

>
> **来源**：吸收自外部包 `huhe-combat-director V2.1` 的**拉片实证层**（该层是对实际出片逐帧复盘后

## 一、第一原则：分层管理「能变的」和「不能变的」

> **实测痛点**：把配比写死后生成物反而僵（节奏被公式框住、每场打戏长得一样）；完全不给约束又会退回"不激烈 / 穿帮"。
> 解法不是二选一，而是**分层**——

| | **自由组合区（随戏份自由变）** | **硬护栏区（工程底线 · 不可动）** |
|---|---|---|
| **节奏零件** | 取用哪几个零件、顺序、次数、各自占比；情感段有无；反转几次 | 起手有形 / 中段有来有回 / 结尾有落点（§四·三铁律） |
| **时长** | 各零件时长分配、快慢交替的具体落点 | 整数秒时间戳、2~3 秒细切、**【快】总时长 ≥ 片长 40%**（下限护栏，§四·二） |
| **减速器** | 慢镜 / 定格放在哪一拍 | **黑白闪、定格帧、慢镜的次数配额上限**（§三） |
| **收束** | 四协议 A~D 择一（玄幻档另见 `sd-xuanhuan-engine` 收束四协议） | 必须有收束协议、严禁平缓收尾 |
| **时序** | 大招何时起手（按比例） | 大招释放完整展开、视觉主客反超不压缩 |
| **激烈度** | 每一段具体怎么打、怎么位移 | **§二 六条硬护栏——一条都不许破** |

> ⚠️ **别把下限当上限用**：【快】≥40% 是**防"打斗不激烈"的下限**，不是目标值。
> 快打碾压型天然能到 70%+，完全合法；蓄势一击型靠"静"造压强，只要【快】总量仍 ≥40% 即可。

## 二、★ 对抗激烈度硬护栏【实测校正 · 治"站桩摆拍" · 机检 C21 载体】

> **实测病征**：出片后逐帧看，**每 2~3 秒只有一个静态构图**——`对峙 → 特效 → 对峙 → 特效`，
> 全程零贴身对招，看着"燃"其实什么都没发生。
> **根因**：提示词给了时码分段，但**没强制"同一段内必须有位移与接触"**，模型遂把每个时间区间理解成一张画。

| # | 护栏 | 判据 | 机检 |
|---|---|---|---|
| ① | **每段必含"位移 + 接触"** | 每个时间区间内，攻守双方**都必须发生身体位移**（冲刺 / 滑退 / 翻滚 / 腾空 / 被击飞），且**至少一次实体接触**（兵器交击 / 拳脚着肉 / 抓握 / 撞击）。⛔ 严禁某区间只有"站着 + 发光" | C21a / C21b |
| ② | **相邻两段不许同构图** | 相邻时间区间的**机位或双方相对位置必须变化**。⛔ 严禁连续两段都是"两人隔着距离对视" | C21d |
| ③ | **贴身对招占比下限** | 15 秒片**真正贴身缠斗**（身体距离 < 1 个身位、有接触）**不得少于 5 秒**；30 秒片不得少于 10 秒。**"隔空对波"不计入贴身对招时长** | C21c |
| ④ | **禁止摆拍动词** | ⛔ 严禁「兵器抵住对手面部」（纯摆拍）→ ✅ 改为「兵器捅入对手肋下，对手横飞撞塌半面墙」 | AI 自检 |
| ⑤ | **自检判据：抽掉特效** | **抽掉所有特效后，剩下的纯动作应能连成一段打得起来的武打**；若抽掉特效后只剩俩人站着 → 激烈度不达标 | AI 自检 |
| ⑥ | **"隔空对波"的定位**（术语澄清） | **隔空对波 = 双方站立不动、各放能量光束在空中相撞**（Beam Struggle）。它看着燃，实则零接触、零位移，属"用特效冒充激烈"。**仅允许用在两处**：㈠ 高潮大招释放瞬间（1~2 秒，作收束点）；㈡ 短暂反制瞬间（≤0.5 秒，且**紧接着必须贴身**）。⛔ 严禁用它填充前中段本该贴身对招的时间 | AI 自检 |
| ⑦ | **【快】拍占比下限** | **【快】拍总时长 ≥ 片长 40%**（防"打斗不激烈"的通病）。意即：全片至少 **4 成时长**处于近身攻防对拆状态 | AI 自检 |

> **C21 触发门**：本组护栏**只对打戏稿生效**。机检脚本自动探测打戏信号词，也支持 `--combat on`
> 强制启用 / `--combat off` 关闭——**文戏稿不跑本组**（防误报拖垮整包机检可信度）。

## 三、减速器配额（上限护栏 · 与下限成对）

> **黑白闪、定格帧、慢镜都是"减速器"**——用一处就从【快】拍时间里扣一处。

| 片长 | 黑白闪 | 定格帧 | 慢镜 |
|---|---|---|---|
| 15 秒片 | ≤1 | ≤1 | ≤1 |
| 30 秒片 | ≤2 | ≤2 | ≤2 |
| 短于 8 秒 | 允许 1（招牌不省） | 建议全砍 | 建议全砍 |

- **黑白闪写法硬条**：必须写成**自然画面句**且带**手绘墨线属性**（见 `vfx-rendering-mandate.md` §五）；
  严禁术语标签 ⛔ `★插入黑白闪 #1`、`<黑白闪 2帧>`。
- 上限护栏（本条）与下限护栏（§二·⑦ 【快】≥40%、§四·二 中段双向受力）**成对使用**：
  只压下限 → 节奏失控；只压上限 → 打戏发闷。两者缺一不可。

## 四、打戏节奏零件库（本包命名 · 勿与「情绪节拍」混用）

> ⚠️ **术语避撞声明（重要）**：外部原名为"七段式情绪节拍元件库"。本包内
> **"节拍"一词已被 `sd-decision-engine/references/emotion-anchor-table.md` 的「情绪节拍」占用**
> （闲聊试探 / 害羞犹豫 / 鼓起勇气… 文戏情绪锚点，二义会造成同一个词两种法律）。
> 故本库统一命名为 **「打戏节奏零件」**，与情绪节拍**井水不犯河水**：一个管打戏骨架，一个管文戏情绪。

### 4.1 零件表（看清"必选 / 可选"）

| # | 零件 | 功能 | 内容要点 | 取用建议 |
|---|---|---|---|---|
| 1 | **蓄** | 对峙蓄势 | 低机位暗部起画、环境先到、气机锁死；**0.5 秒内兵刃必须已破空逼近**（严禁风景慢热铺垫） | ◇ 推荐起手；**很短的片可直接用【快】起手** |
| 2 | **快** | 贴身交锋 | 近身攻防对拆、火花飞溅、**双向受力（模式 K 强制）** | ★ **必选**，且**可重复取用多次**（连招加剧 = 再次取用【快】） |
| 3 | **停** | 战局反转 | 变招破防 / 主角挂彩 / 底牌掀开，台词点火 | ◇ 可选——**有反转才用**；势均力敌可停—快—停反复取用 |
| 4 | **慢** | 情感升华 | 升格慢镜聚焦决然眼神，色彩压深/切红，悲壮感 | ◇ 可选——**属"减速器"**，15 秒以内建议不用或 ≤1 秒；30 秒以上才给足额空间 |
| 5 | **静** | 万籁俱寂 | 完全静止定格 + **黑白闪** + 虚空银线起笔，声浪归零 | ◇ 可选——**大招前想制造压强就用**；短平快的秒杀戏允许【快】直接切【爆】 |
| 6 | **爆** | 绝杀降临 | 全屏闪白 + 空间贯穿 + **收束协议（A~D 择一）**，定格最燃瞬间 | ★ **必选** |

> **没有第 7 个独立零件**——**【快】会在中段被第二次取用**（连招加剧 / 大范围身法 / 器物形变 / 场景大破坏），
> 它仍是同一个零件，只是加码。**戏需要就取用 1 次，需要就连用 3 次。**

### 4.2 组合三铁律（★唯一不可动的骨架 · 只管首中尾）

任何时长、任何戏，只要求这三条成立，**其余全部自由**：

1. **起手必须有形**：开场 0.5~1.5 秒内必须出现**兵刃破空逼近或双人同框的物理接触**——禁止全景无人风景慢热；
2. **中段必须有来有回**：至少取用 1 段【快】，且必须**双向受力（模式 K）**——禁止单向殴打沙包；
3. **结尾必须有落点**：必须取用【爆】并配收束协议（A~D 择一）——**严禁平缓收尾帧**（收刀入鞘、微风吹发）。

### 4.3 参考组合范式（★可拆可改 · 按戏份选用，禁止当模板照套）

**以下范式只是若干条合法组合，不是必答题**——出稿时可跨范式混拼，也可自创（满足 §4.2 三铁律即可）。

| 范式 | 零件序列 | 适合什么戏 | 备注 |
|---|---|---|---|
| **A. 经典反杀型** | 蓄 → 快 → 停 → 快 → 慢 → 静 → 爆 | 强者压境 → 主角受创 → 绝境觉醒 → 大招终结 | 六件齐全的重装组合，信息量最大，适合 15~30 秒；**不是唯一解** |
| **B. 快打碾压型** | 快 → 快 → 停 → 爆 | 实力碾压、秒杀、开场立威 | 几乎全程对攻，无情感段；"打来打去"感最强 |
| **C. 双强对攻型** | 快 → 停 → 快 → 停 → 爆 | 势均力敌的宿敌对决 | 多轮攻防互换，【停】可循环多次 |
| **D. 蓄势一击型** | 蓄 → 静 → 爆 | 极短杀手锏、一击必杀、狙击式偷袭 | 靠极静制造压强、靠爆释放；**适合 5~8 秒超短片** |
| **E. 群战乱斗型** | 快 → 快 → 快 → 停 → 爆 | 多人混战、围杀、突围 | 靠镜头快切与空间调度替代情感段 |

**组合的三个自由度**：
- **循环**：`快-停-快-停-…-爆`——势均力敌的戏就该这么排，不必凑齐慢/静；
- **合并**：`慢+静` 可合为一拍（短片常见）；`静+爆` 直连是最凶的排列（压强最大）；
- **省略**：没有情感诉求就砍【慢】；没有反转就砍【停】；追求极速就砍【蓄】——**砍掉的时长全部并进【快】**。

## 五、交付前自检（本库专属四问）

出稿前逐条过一遍，**任一条答"否"即回炉**：

1. **抽掉全部特效**，剩下的纯动作能连成一段打得起来的武打吗？（§二·⑤）
2. **逐个时间区间**数位移与接触：有没有哪个区间只有"站着 + 发光"？（§二·①）
3. **相邻区间**的机位/相对位置变了吗？有没有连续两段都是"隔空对视"？（§二·②）
4. **贴身缠斗总时长**够不够片长的 1/3 吗？"隔空对波"是不是混进来充数了？（§二·③⑥）

> 机检：`python scripts/validate_prompt.py <稿件> --combat on`（C21a~d 兜底可机械判定的三项）

## 六、档位豁免（★让行 · 2026-10-12 用户裁定）

> **本库 §二 是「默认参考护栏」，不是打戏引擎之上的硬闸**。§二 的判据原型全部取自
> **现代近身肉搏**（见 §〇 病征：`对峙 → 特效 → 对峙 → 特效`），对**非肉搏戏型**外推会失真。
> 与打戏引擎本档规则冲突时，**以引擎本档为准**（联动条款见
> `combat-rhythm-and-load-guardrails.md` §七「档位豁免与放行条款」）。

| 戏型（先定档） | 不适用的护栏 | 说明 |
|---|---|---|
| **R1 写实 · 枪战 / 狙击 / 暗杀 / 追车 / 儿童向** | §二·① 相对位移+接触、§二·③ 贴身下限、§二·⑥ 隔空对波定位 | 交火本质是**中远距**：允许一方静止（据枪/瞄准/潜行），允许**零实体接触**；不得硬塞贴身 |
| **R1 写实 · 多人轮转**（1v2/1v3/2v2/3v3） | §二·③ 贴身下限 | 按 `sd-real-engine/references/multi-opponent-rules.md` 的三拍轮转与景别策略 |
| **R3 玄幻 · 术法对轰 / 远程法术 / 法阵 / 万剑归宗** | §二·③ 贴身下限、§二·⑥ 对波"仅两处" | 对波/对轰是玄幻档**合法主武器**；只保留"不得整篇只有对波、必须有点上活" |
| **R3 玄幻 · 大场面档**（法相 / 法天象地 / 巨兽 / 对军清场） | §二·①、§二·③ | 大场面是**宏观调度**：允许整段大远景/全景；"站定施展术法"是**施法**，不判"站着发光" |
| **R2 通用武侠 · 群战乱斗 / 对军** | §二·①、§二·③ | 靠镜头快切与空间调度，不按单人贴身戏模板 |
| **全部档位 ·【静】【慢】零件**（本库 §四） | §二·① "站着发光" | 【静】＝完全静止定格、【慢】＝升格——**是设计**，不判躺平 |

**保底（不放行）**：① 不得整场零位移、零接触、无收束（空转模板）；② 相邻区间机位不得完全相同连排 ≥3 段。
**一句话**：豁免的是"**肉搏几何模板**"，不是"**打得起来**"。
