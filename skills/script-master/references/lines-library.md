## 使用规则（分级）

1. **事实层**：人物关系、情境逻辑和基本对话常识属于硬性约束；无法确认的作品归因标为"待核"。
2. **倾向层**：各情境的台词机制、字数建议、次数建议和节奏参考是高概率创作倾向，不同题材、角色和风格可以有不同答案。
3. **风格层**：古装文言、网感短句、电影长对白、荒诞独白等属于风格选项，不互相排斥。
4. **反例层**：为角色性格、误导观众、情绪失控或反类型效果，可以有意超出字数建议或打破节奏，但应在创作笔记中说明违反服务的戏剧功能。
5. **来源与转化**：引用作品只用于提炼机制，不复制连续原文；调用模板时按角色性格、情境和风格锁进行转化。
6. **检索与主次**：按情境/题材/角色类型/情绪/问题类型五维度局部检索，不全局加载。

> **规则使用说明**：本库中的"禁忌""不超 X 字""一集 X 次"等措辞，除事实层外，默认解释为该条目的常见倾向或诊断参考值。若项目档案、角色逻辑或整体风格提出不同要求，以项目需求为先。字数和次数不是台词合格线，是风险提示。

## 区1：情境台词模板区

> 按 8 种高频情境蒸馏台词模板（含写法机制+句式模板+虚构样本+改写对照+适用范围+禁忌+来源规律）。

### 情境 1：告白

**写法机制**：告白台词的核心是"克制比直白有力"。最好的告白不说"我爱你"，说"只有两人懂的细节"。告白的力度来自"未说完"——角色想说 A，却说成了 B，B 是日常话，A 是潜台词。告白台词越短越有力，越长越像演讲。告白必须有"此刻不说就来不及"的紧迫感作为发动机，但紧迫感不等于激动——越是紧要关头越要平静。

**句式模板**：
- 否定式告白："我不是……（停顿）……好吧，我是。"
- 日常替代式："明天带粥。"（潜台词：我明天还来，我每天都来）
- 反问式："你觉得呢？"（不正面回答，让对方确认）
- 细节式："你那件蓝衬衫，别机洗。"（潜台词：我记得你的每一件衣服）

**虚构样本**：
```
苏晚：你等了三年了。
林远（停了一下）：不累。
苏晚：骗人。
林远：嗯，骗人。但明天还来。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我爱你，从第一次见到你就爱你，我愿意为你付出一切" | "不累。骗人。但明天还来。" | 差版是万能告白换谁都能说，好版是"只有这个角色会这样告白"；细节=独占性 |
| "你是我生命中最重要的人，没有你我活不下去" | "明天带粥。" | 差版是承诺未来，好版是承诺明天；具体的明天比抽象的未来有力 |
| 告白后对方立刻接受，两人拥抱 | 苏晚没说话，接过饭盒——这不是接受，是"我不拒绝" | 差版是童话，好版是真实；反应的犹豫比接受更有戏 |

**适用范围**：甜宠/治愈/爱情/青春
**禁忌**：不用"我爱你"开头；不承诺抽象未来；告白方台词不超过 30 字
**来源规律**：电影《情书》《怦然心动》《海上钢琴师》；短剧《盛夏芬德拉》

### 情境 2：告别

**写法机制**：告别台词的核心是"未完成"。最好的告别不说"再见"，说"还没说完的话"。告别用日常话反衬沉重——越日常越痛。告别方想说 A 但说成了 B，B 是日常琐事，A 是"别走"。告别不要太长，越短越有力；不回头比回头有力；不接触比接触有力。

**句式模板**：
- 日常替代式："药按时吃。"（潜台词：别走/我照顾不了你了）
- 未完成式："有件事我一直没跟你说……（停顿）……蓝衬衫别机洗。"
- 最后回头式："豆浆别剩。"（最后一次关心，不是告别）
- 不说再见式：沉默+动作（拿起包/不回头/进闸机）

**虚构样本**：
```
苏晚：你包里带的药，按时吃。
林远：嗯。
苏晚：你妈那边，我打过电话了。
林远：嗯。
苏晚（突然）：有件事我一直没跟你说。
林远停下吃包子。
苏晚：你那件蓝衬衫，别机洗，会缩水。
林远：……嗯。
（广播响：开往XX的列车即将进站）
林远站起来，拿起包——没看苏晚。
林远走了三步，回头：豆浆别剩。
苏晚：嗯。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "再见了，我会永远记住你的，你要好好照顾自己" | "蓝衬衫别机洗。" | 差版是套话，好版是日常反衬；越日常越痛 |
| "我舍不得你走，你不要走好不好" | "豆浆别剩。" | 差版是直说情绪，好版是潜台词；想说"别走"说成"别剩" |
| 告别时拥抱痛哭"我不要你走" | 告别时不回头/不接触，用没做完的小事承载 | 差版是情绪直给，好版是情绪潜藏；不接触比接触更痛 |

**适用范围**：末世/热血/治愈/史诗/爱情
**禁忌**：不用"再见""永别"；不解释为什么走；告别方不超 20 字
**来源规律**：电影《霸王别姬》《千与千寻》《海上钢琴师》

### 情境 3：对峙

**写法机制**：对峙台词的核心是"沉默比说话有力"。两人之间的张力来自没说的话，不是说了的话。对峙用边缘话题试探对方底线，不直击核心矛盾——边缘话题绕着核心转圈，但核心矛盾必须浮出水面在最后 2-3 句。对峙必须有至少 1 次沉默+小动作（点烟/转笔/喝水），沉默是张力的容器。对峙以僵持或转折结束，不解决。

**句式模板**：
- 拒绝接受式："我不喝茶。"（不接受示好=表明立场）
- 边缘试探式："你跟你爸一样。"（用"你爸"试探，触碰对方情绪）
- 平静揭底式："你来之前，我已经知道答案。"
- 选择施压式："你自己选——是我说出去，还是你自己说。"
- 僵持收束式："有些事，回答不了。"

**虚构样本**：
```
陈叔：这茶是今年的龙井，尝尝。
林远：我不喝茶。
陈叔（笑）：你跟你爸一样，不喝茶。
林远：别提我爸。
（沉默。陈叔放下茶杯。）
陈叔：你今天来，是要问当年的事。
林远：你来之前，我已经知道答案。
陈叔：那你还来。
林远：我想听你亲口说。
（陈叔开始点烟——沉默+小动作。）
林远：你不说，我也知道。但我给你一个机会。
陈叔（烟点着了，没抽）：什么机会。
林远：你自己选——是我说出去，还是你自己说。
（陈叔把烟按灭在烟灰缸里——没抽就按灭=放弃抵抗。）
陈叔：我选第三个。
林远：没有第三个。
陈叔（看向窗外）：你长大了。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| 两人直接吵起来，互相指责"你为什么这样对我" | 用沉默+小动作+边缘话题试探，正面交锋只 2-3 句 | 差版是吵架，好版是对峙；对峙的张力在没说的话 |
| "你给我解释清楚！你必须告诉我真相！" | "你来之前，我已经知道答案。我想听你亲口说。" | 差版是情绪宣泄，好版是平静施压；越平静越可怕 |
| 对峙中一方立刻妥协"好吧我告诉你" | 对峙以僵持或转折结束，"有些事，回答不了" | 差版是冲突解决太快，好版留张力给下一场 |

**适用范围**：悬疑/权谋/复仇/商战/警匪
**禁忌**：对峙不超 12 句台词；必须有 1 次沉默+小动作；不允许当场解决
**来源规律**：电影《无间道》《教父》《霸王别姬》

### 情境 4：道歉

**写法机制**：道歉台词的核心是"不解释理由"。最好的道歉不解释"我为什么那样做"，只承认"我错了"。解释=找借口=道歉失效。道歉越短越有力，越长越像辩解。道歉必须有"承担后果"的姿态——不要求对方原谅，只表明自己的态度。道歉不能用"但是"——"对不起，但是……"等于没道歉。

**句式模板**：
- 承担式："我错了。你不用原谅我。"（不要求原谅=真诚）
- 行动式：不说话，把对方需要的东西放在面前（行动比语言有力）
- 否定理由式："没有理由。就是我的错。"（拒绝解释=不找借口）
- 承诺改变式："我不会再这样了。"（必须具体到行为，不抽象承诺）

**虚构样本**：
```
林远把一袋药放在苏晚门口——没敲门。
苏晚开门看到药——林远已经走了。
（行动道歉：不说话，把对方需要的放在面前）
第二天，林远来：
林远：昨天的事，没有理由。就是我的错。
苏晚：你不用解释。
林远：我不解释。你不用原谅我。
苏晚（停顿）：药我收了。
林远：嗯。
林远：以后有事，我第一个到。不是说说。
（承诺具体到行为：不是"我会改"，是"我第一个到"）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "对不起，我那时候是因为太忙了，所以才……" | "没有理由。就是我的错。" | 差版是解释=找借口，好版是承担；解释=道歉失效 |
| "对不起对不起对不起，求求你原谅我" | "你不用原谅我。" | 差版是乞求，好版是承担；不要求原谅=真诚 |
| "对不起，但是你也有不对的地方" | "我错了。"（没有"但是"） | 差版是推卸责任，好版是承担全部；"但是"等于没道歉 |

**适用范围**：所有题材的道歉场景
**禁忌**：不用"但是"；不解释理由；不要求对方原谅；不重复"对不起"超 2 次
**来源规律**：电影《海边的曼彻斯特》《婚姻故事》；短剧《盛夏芬德拉》

### 情境 5：威胁

**写法机制**：威胁台词的核心是"越平静越可怕"。大喊大叫的威胁是虚张声势，平静陈述的威胁才是真威胁。最好的威胁不说"我要怎么做"，说"你会失去什么"或"你可以试试"。威胁用"陈述句"不用"疑问句"——"你以为我不敢？"比"你敢吗？"有力。威胁越短越有力，越长越像心虚。

**句式模板**：
- 平静陈述式："你可以试试。"（不威胁具体做什么，只说"试试"）
- 后果式："你失去的会比得到的多。"（不威胁动作，只说后果）
- 反问式："你以为我没你不行？"（反问=自信，陈述=底气）
- 留白式："我不说了。你自己想。"（不说出来的威胁最可怕）

**虚构样本**：
```
林总：你以为我没你不行？
苏助理（停步，不回头）：你可以试试。
（门关上的声音=新位置锁定）
```

```
陈叔：你想怎么样？
林远：我不怎么样。我只是知道一些事。
陈叔：你在威胁我？
林远：我没威胁你。我只是告诉你——这些事，说出去对你不好。
（沉默）
林远：我不说了。你自己想。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你给我等着！我会让你付出代价的！" | "你可以试试。" | 差版是大喊大叫=虚张声势，好版是平静陈述=真威胁 |
| "我要告诉所有人你做了什么！" | "这些事，说出去对你不好。" | 差版是威胁动作，好版是陈述后果；后果比动作可怕 |
| "你信不信我让你家破人亡！" | "我不说了。你自己想。" | 差版是具体威胁=心虚，好版是留白=让对方自己脑补 |

**适用范围**：悬疑/复仇/权谋/商战/黑帮
**禁忌**：威胁方不超 15 字；不大喊大叫；不具体说"我要做什么"
**来源规律**：电影《教父》《无间道》；短剧《冒姓琅琊》

### 情境 6：拒绝

**写法机制**：拒绝台词的核心是"不给希望"。最好的拒绝不解释"为什么拒绝"，只说"不行"。解释=给对方讨价还价的空间=拒绝不彻底。拒绝越短越有力，越长越像犹豫。拒绝必须有"承担后果"的姿态——"我知道这会让你不高兴，但不行。"拒绝不能拖泥带水，不能"我再想想"——犹豫的拒绝=给希望=更残忍。

**句式模板**：
- 直接式："不行。"（不解释，只说结论）
- 承担式："我知道你会不高兴。但不行。"（承认后果，但不改结论）
- 反问式："你觉得我会答应吗？"（反问=立场鲜明）
- 行动式：不说话，转身离开（行动比语言有力）

**虚构样本**：
```
王少：你只要签了这份协议，钱不是问题。
林远：不行。
王少：你再想想，这个条件已经很好了。
林远：我说了不行。
王少：为什么？
林远：没有为什么。不行就是不行。
（林远站起来。）
王少：你会后悔的。
林远（没回头）：我不后悔。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "让我再想想……这个事情我得考虑一下" | "不行。" | 差版是犹豫=给希望，好版是直接=不给希望；犹豫的拒绝更残忍 |
| "不是我不想帮你，是因为……（解释 5 句）" | "我知道你会不高兴。但不行。" | 差版是解释=讨价还价空间，好版是承担后果；解释=拒绝不彻底 |
| "这个事情有点难办，要不你再找别人？" | "你觉得我会答应吗？" | 差版是推脱=留余地，好版是反问=立场鲜明 |

**适用范围**：所有题材的拒绝场景
**禁忌**：不解释理由（除非对方追问，也只说"没有为什么"）；不用"再想想"；不超 15 字
**来源规律**：电影《教父》《无间道》；短剧《零五逆袭》

### 情境 7：试探

**写法机制**：试探台词的核心是"用边缘话题触碰核心"。最好的试探不直接问核心问题，问一个"看似无关"的边缘话题，从对方的反应判断核心问题的答案。试探必须有"退路"——如果对方不接，可以装作"随口问问"。试探的反应比问题本身更重要——对方的停顿、眼神、小动作都是答案。试探用"陈述句"比"疑问句"有力——"你跟陈叔很熟"比"你认识陈叔吗"有力。

**句式模板**：
- 陈述试探式："你跟陈叔很熟。"（陈述=让对方确认或否认）
- 假设试探式："如果我说……你会怎么做？"（假设=不给具体信息）
- 随口式："对了，那天那件事……"（假装随口，看对方反应）
- 反向试探式：故意说错信息，看对方是否纠正（纠正=知道真相）

**虚构样本**：
```
林远（倒水）：陈叔最近怎么样？
苏晚：还好。
林远：他经常来？
苏晚（停顿了一下）：偶尔。
（停顿=答案：不是偶尔，是经常）
林远：他和我爸，当年认识吧？
苏晚：我没听他说过。
林远：哦。
（林远没追问——但他知道苏晚在撒谎，"没听他说过"不等于"不认识"）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你认识陈叔吗？他和我爸是不是有关系？" | "陈叔经常来？" | 差版是直接问核心，好版是边缘试探；直接问=对方会防备 |
| "你告诉我真相！你是不是在骗我！" | "哦。"（不追问，但知道对方在撒谎） | 差版是逼问，好版是留白；追问=暴露意图，留白=保留信息 |
| "你是不是有什么事瞒着我？" | "他经常来？"（停顿后）"偶尔。" | 差版是直球，好版是曲线；让对方自己露出马脚 |

**适用范围**：悬疑/权谋/商战/复仇
**禁忌**：不直接问核心问题；不给对方压力；试探方台词不超 10 字
**来源规律**：电影《无间道》；剧集《隐秘的角落》；短剧《冒姓琅琊》

### 情境 8：安慰

**写法机制**：安慰台词的核心是"不说话比说话有力"。最好的安慰不说"别难过""会好的"，而是陪着。安慰用"在场"代替"语言"——坐在旁边、递一杯水、把肩膀借给对方。安慰必须有"承认痛苦"的姿态——"我不知道该说什么，但我在这里。"安慰不能承诺"会好的"——因为可能不会好，虚假的承诺比沉默更残忍。

**句式模板**：
- 在场式：不说话，坐在旁边（行动比语言有力）
- 承认式："我不知道该说什么。但我在这里。"（不承诺，只陪伴）
- 反问式："你想说吗？"（把主动权给对方）
- 日常式："饿不饿？我下碗面。"（用日常行为代替安慰）

**虚构样本**：
```
苏晚坐在窗边——不哭，但眼神空了。
林远走过来，在她旁边坐下——没说话。
两人沉默了 3 分钟。
林远：饿不饿？
苏晚：不饿。
林远：我下碗面。
苏晚：我说了不饿。
林远：我知道。但我得做点什么。
（林远去厨房——苏晚看着他的背影，眼眶红了。）
林远（从厨房喊）：面好了。你不吃，我吃。
苏晚没动——林远端着面过来，放在她面前。
林远：我不说会好的。因为我也不知道。
苏晚（看着面）：嗯。
林远：但我在。
苏晚端起碗——吃了一口。
（没有"别难过"，没有"会好的"，只有"我在"）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "别难过，一切都会好的，你要坚强" | "我不知道该说什么。但我在这里。" | 差版是套话，好版是诚实；虚假承诺比沉默残忍 |
| "你哭吧，哭出来就好了" | 不说话，递一杯水/坐在旁边 | 差版是指导情绪，好版是陪伴；陪伴比指导有力 |
| "我理解你的感受，我也经历过" | "饿不饿？我下碗面。" | 差版是抢戏（把话题转向自己），好版是用日常行为代替安慰 |

**适用范围**：所有题材的安慰场景
**禁忌**：不说"别难过"；不承诺"会好的"；不说"我理解"（除非真经历过）；不指导情绪
**来源规律**：电影《海边的曼彻斯特》《海街日记》《小偷家族》

## 区2：题材语感样本区

> 蒸馏 10 种题材的台词语感样本（题材1-6为节奏特征+虚构语感样本+写作要点格式；题材7-10为语感DNA+语感特征+虚构样本+改写对照格式，格式升级）。

### 题材 1：甜宠

**节奏特征**：轻快+反差。甜宠台词的关键是"打情骂俏"——表面上互相斗嘴，潜台词是互相喜欢。节奏快，每回合不超 3 句，用"反驳+关心"的反差制造甜感。甜宠的台词不能太正经——越正经越不甜，要在玩笑中藏真心。

**虚构语感样本**：
```
苏晚：你是不是故意把伞拿走？
林远：我没有。我伞坏了。
苏晚：那你刚才为什么把你的伞给我？
林远：我看你淋湿了。
苏晚：那你呢？
林远（停顿）：我皮厚。
苏晚：……你脑回路有问题。
林远：嗯，你以后慢慢适应。
（潜台词："你以后"=默认两人有以后）
```

**写作要点**：①每回合 2-3 句，不超 3 句；②必须有一个"关心"藏在"反驳"里；③用"以后"暗示关系发展；④台词要有节奏感，像打乒乓球。

**适用范围**：甜宠/爱情/青春
**禁忌**：不超 3 句一回合；不直说"我喜欢你"；不写大段心理独白
**来源规律**：短剧《盛夏芬德拉》《好一个乖乖女》；电影《怦然心动》

---

### 题材 2：逆袭

**节奏特征**：压抑+爆发。逆袭台词的关键是"先压后爽"——前半段主角被嘲讽/羞辱，台词短而压抑；后半段身份揭露/能力展示，台词短而有力。逆袭的主角话越少越帅——让对方自己说破，比主角自报家门有力 10 倍。逆袭的反派台词要"欠揍"——越嚣张越好，这样打脸时越爽。

**虚构语感样本**：
```
（前半段·压抑）
王少：这表是地摊货吧？我这块是正品，三十万。
林远（没说话）：……
王少：算了，我不跟穷光蛋计较。
（后半段·爆发）
鉴定师：这……这是百达翡丽 5711，限量款。
王少（声音发虚）：不可能，他一个穷……
林远（收回表）：你那块，看看后盖。
（王少翻过表——后盖内侧刻着"王少购于地摊"。）
林远（没解释）：算了，我不跟穷光蛋计较。
（用反派的原话回敬=打脸）
```

**写作要点**：①前半段主角话少（1-2 句），后半段主角话也少（不超 15 字）；②反派的嚣张台词要"欠揍"；③打脸用"反派原话回敬"或"被动揭露"；④主角不自报家门，让对方自己发现。

**适用范围**：逆袭/复仇/打脸/战神
**禁忌**：主角不自报家门（"我是XX集团总裁"）；打脸方台词不超 15 字；不解释来龙去脉
**来源规律**：短剧《零五逆袭》《龙王归来》；电影《教父》《大腕》

---

### 题材 3：悬疑

**节奏特征**：克制+留白。悬疑台词的关键是"说一半藏一半"——角色说的每句话都可能不是真的，每句话都可能是伏笔。悬疑的台词越平静越可怕——平静的凶手比疯狂的凶手可怕 10 倍。悬疑用"未说完"制造悬念——"当年那件事……"不说完，让观众脑补。

**虚构语感样本**：
```
陈叔（泡茶）：这茶是今年的龙井。
林远：我不喝茶。
陈叔：你跟你爸一样，不喝茶。
（沉默）
陈叔：当年的事，你想知道？
林远：你来之前，我已经知道答案。
陈叔（笑）：那你比我聪明。
林远：不聪明。只是有人告诉了我。
陈叔（手停了一下）：谁？
林远：你不认识的人。
（"不认识的人"=悬念，陈叔的手停了=他慌了）
```

**写作要点**：①每句话都可能不是真的，台词要有"双关性"；②越平静越可怕；③用"未说完"制造悬念；④关键信息藏在动作里（手停/眼神/小动作）。

**适用范围**：悬疑/推理/犯罪/惊悚
**禁忌**：不直接揭露真相；不用感叹号；角色不情绪激动
**来源规律**：电影《隐秘的角落》《盗梦空间》《无间道》；剧集《漫长的季节》

---

### 题材 4：古装

**节奏特征**：庄重+含蓄。古装台词的关键是"言简意赅"——古人的话少，但每句都有分量。古装用"敬辞/谦辞"建立身份感，用"典故/比喻"代替直说。古装的对话像下棋——每句话都是一步棋，背后有计算。古装台词不能太白话——但也不能太文言，要在"古风"和"可读性"之间平衡。

**虚构语感样本**：
```
（宗祠继承仪式）
长老：林氏第十七代孙林远，可愿承家业？
林远：愿。
长老：可愿守家规？
林远：愿。
长老：可愿护家人？
林远（停顿一秒）：愿。
（誓词三问三答——节奏如誓词）
长老递过族谱——林远双手接过。
长老的手按住族谱不放（只有林远看到）。
长老（低声）：第三页，你爸的名字。
林远手抖了一下——（他爸被除名了）
长老（高声）：林氏第十七代家主，礼成。
```

**写作要点**：①用敬辞/谦辞建立身份感（晚辈/长辈/主仆）；②话少但有分量，每句都是一步棋；③用"典故/比喻"代替直说（"卧薪尝胆"代替"我会报仇"）；④誓词/仪式台词用短句，节奏如誓词。

**适用范围**：古装/权谋/武侠/玄幻
**禁忌**：不用现代白话（"OK""没问题"）；不用网络词；台词不超 20 字/句
**来源规律**：剧集《琅琊榜》；电影《霸王别姬》《卧虎藏龙》；短剧《冒姓琅琊》《大内女神捕》

---

### 题材 5：末世

**节奏特征**：冷峻+决绝。末世台词的关键是"少说话，多行动"——末世里没有闲聊的余地，每句话都是生存指令。末世的台词冷——不是冷漠，是"没有时间矫情"。末世用"简短指令"建立紧迫感，用"沉默"承载失去。末世的告别不是"再见"，是"活着"。

**虚构语感样本**：
```
（末世废墟·夜）
林远（检查背包）：水还有多少？
苏晚：半瓶。
林远：分着喝。明天找补给。
苏晚：陈叔没跟上来。
林远（停顿）：他跑得慢。
苏晚：他腿伤了。
林远：……我知道。
（沉默——"我知道"=他选择了不回头）
林远：走吧。天亮前要到下一个点。
苏晚：不等他了？
林远：他让我别等。
（"他让我别等"=陈叔已经死了/牺牲了，但林远不说）
```

**写作要点**：①每句话都是生存指令或信息；②不用形容词，用动词和名词；③失去用"沉默"承载，不直说"他死了"；④告别是"活着"，不是"再见"。

**适用范围**：末世/废土/灾难/生存
**禁忌**：不闲聊；不用矫情台词；不直说"他死了"
**来源规律**：电影《疯狂的麦克斯》《末日危途》；剧集《最后生还者》

---

### 题材 6：喜剧

**节奏特征**：错位+反转。喜剧台词的关键是"预期违背"——观众以为 A，角色说 B，B 和 A 的反差制造笑点。喜剧用"一本正经胡说八道"——角色越认真，观众越想笑。喜剧的台词节奏快，每回合 2-3 句，用"误会+错位"制造喜感。喜剧不能为了搞笑而搞笑——笑点必须服务于剧情或人物。

**虚构语感样本**：
```
林远（严肃）：我有件重要的事要告诉你。
苏晚（紧张）：什么事？
林远：我……
苏晚：你说。
林远：我妈让我带女朋友回家。
苏晚（脸红）：……
林远：你不是。
苏晚：……
林远：我是想让你帮我介绍一个。
苏晚（拍桌子）：滚。
林远：我是认真的。
苏晚：我也是认真的。滚。
（错位：观众以为告白，结果是"介绍女朋友"；苏晚以为告白，结果是"介绍"）
```

**写作要点**：①预期违背——观众以为 A，角色说 B；②角色越认真越好笑；③笑点必须服务剧情或人物（不是为搞笑而搞笑）；④节奏快，每回合 2-3 句。

**适用范围**：喜剧/轻松/日常/甜宠
**禁忌**：不为搞笑而搞笑；不用网络梗（会过时）；不用低俗笑点
**来源规律**：电影《大腕》《疯狂的石头》；剧集《武林外传》

---

### 题材 7：现实题材

**语感DNA**：克制中的爆发——现实题材的台词像真实生活，平时克制含蓄，情绪爆发时才直接

**语感特征**：
- 句式：短句为主，日常口语，偶尔长句表达纠结
- 词汇：生活化用词，无华丽修辞，方言/口语词点缀
- 信息密度：中等，每句承载生活细节+情绪暗示
- 潜台词层级：高，表层说A深层指B是常态
- 情绪表达：行动化（用动作/环境暗示，不直接说情绪）

**虚构样本**：
```
（饭桌上·夜）
周建国（夹菜）：今天菜咸了。
李梅：嗯。
周建国：你妈那边电话打了？
李梅：打了。
周建国：孩子呢？
李梅：睡了。
（沉默。周建国放下筷子。）
周建国：这菜，我妈教你的吧。
李梅（停了一下）：是。
周建国：我妈都走三年了。
李梅：嗯。
周建国：这菜味儿，越来越像她做的了。
李梅没说话——把那盘菜端起来，倒进了垃圾桶。
周建国看着她：……
李梅（背对着）：饭在桌上，你自己热一下。
（潜台词："菜像你妈做的"=你一直拿我当你妈的替代品；倒菜=我不再当替代品；"你自己热一下"=我们完了）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我们离婚吧，我不爱你了" | "饭在桌上，你自己热一下。" | 差版是直说情绪，好版是日常话承载关系断裂；越日常越痛 |
| "你一直拿我当你妈的替代品，我受够了" | "这菜，我妈教你的吧。" | 差版是直陈矛盾，好版是用菜味暗示；暗示让观众自己发现 |
| "我恨你，你从来没爱过我" | 李梅把菜倒进垃圾桶 | 差版是情绪宣泄，好版是行动外化；行动比语言有力 |

**适用范围**：现实主义/家庭/社会议题/剧情
**禁忌**：不让台词太文艺；不让情绪太直白；不让潜台词缺失
**来源规律**：《我不是药神》《地久天长》王小帅/刘健健

---

### 题材 8：犯罪题材

**语感DNA**：话中有话的危险——犯罪题材的台词每句都有多重含义，表面平静实则暗流

**语感特征**：
- 句式：短促克制，停顿多，留白多
- 词汇：黑话/行话/代号，日常词有特殊含义
- 信息密度：高，每句都是信息战
- 潜台词层级：极高，表层/深层/威胁三层
- 情绪表达：极克制，用沉默和眼神替代情绪

**虚构样本**：
```
（审讯室·灯管嗡响）
警察（点烟）：今天外头挺冷的。
嫌疑人：是。
警察：你昨晚也在家吧？
嫌疑人：在家。
警察：你家那片儿，晚上九点后没路灯。
嫌疑人：我早睡了。
警察（笑）：早睡好。健康。
（沉默。烟灰掉在桌上。）
警察：昨晚九点，东四街出事了。
嫌疑人：不知道。
警察：我说了，你昨晚在家。
嫌疑人：在家。
警察：可东四街那家店的老板说，九点十分，看见一个穿黑外套的人。
（警察没看嫌疑人——但嫌疑人下意识看了一眼自己的黑外套。）
警察（把烟按灭）：这外套，挺常见的。
嫌疑人：……挺常见。
警察：你说你在家。
嫌疑人：在家。
警察：那这事就怪了——老板说，那个人穿黑外套，从你家那栋楼出来的。
（沉默——"在家"开始塌陷）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你到底是不是凶手？说实话！" | "你昨晚也在家吧？" | 差版是直球逼问=对方会防备，好版是闲聊试探=对方会松懈 |
| "你穿的就是那件黑外套，证据确凿！" | "这外套，挺常见的。" | 差版是亮底牌=过早，好版是暗示=让对方自己露馅 |
| "你撒谎！你不在家！" | "你说你在家。"（重复） | 差版是情绪化，好版是重复施压；重复=收紧绞索 |

**适用范围**：犯罪/黑色电影/谍战/黑帮
**禁忌**：不让台词太直接；不让威胁太明显；不让信息战变成信息倾倒
**来源规律**：《白日焰火》《南方车站的聚会》刁亦男

### 题材 9：社会派悬疑

**语感DNA**：真相在细节里——社会派悬疑的台词看似平常，但关键信息藏在不起眼的细节中

**语感特征**：
- 句式：日常句式，无明显特征，关键信息伪装在日常中
- 词汇：普通词汇，但特定词有暗示功能
- 信息密度：看似低实则高（重要信息混在闲聊中）
- 潜台词层级：中高，需要观众主动发现
- 情绪表达：压抑，角色不轻易表露情绪

**虚构样本**：
```
（小区花园·晨）
王姐（晾衣服）：早啊。
李叔：早。
王姐：最近小区挺安静的。
李叔：是啊。
王姐：以前晚上总能看到那个人遛狗。
李叔：哪个人？
王姐：三栋那个，养金毛的。
李叔：哦，老张。
王姐：老张好几天没见了。
李叔：可能出差了。
王姐：他金毛也没人遛了。
李叔（停顿）：狗这东西，认主人。
王姐：是。
（沉默——王姐把衣服挂上绳。）
王姐：前天晚上，听见三栋有人吵架。
李叔：谁家？
王姐：老张家。
李叔：噢。
王姐：后来就没声了。
李叔：可能睡了。
王姐：是可能睡了。
（"可能睡了"=双关：可能是睡了，可能是永远睡了）
王姐收衣服——回头：老张家那把菜刀，平时挂在门口的，这两天不见了。
李叔没接话——只是把烟按灭。
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你知道谁杀了受害者吗？" | "以前晚上总能看到那个人遛狗。" | 差版是直问核心，好版是日常闲聊暗示；闲聊=信息伪装 |
| "老张被杀了，你发现了吗？" | "老张家那把菜刀，平时挂在门口的，这两天不见了。" | 差版是信息倾倒，好版是细节暗示；细节让观众主动发现 |
| "前天晚上出事了！" | "前天晚上，听见三栋有人吵架。后来就没声了。" | 差版是事件直陈，好版是片段叙述；片段=留白=悬念 |

**适用范围**：社会派悬疑/推理/犯罪/心理
**禁忌**：不让线索太明显；不让闲聊无信息；不让真相一次性揭露
**来源规律**：《漫长的季节》于小千/潘依然

### 题材 10：科幻题材

**语感DNA**：设定内化的日常——科幻题材的台词把科幻设定当成日常，不解释设定

**语感特征**：
- 句式：日常句式+科技术语自然混入
- 词汇：科技术语/缩写/代号，但角色不解释（当成常识）
- 信息密度：高，每句同时承载叙事+世界观
- 潜台词层级：中等，重点在世界观内化
- 情绪表达：科技理性下的情感压抑

**虚构样本**：
```
（空间站舱内·值班）
林远（看屏）：推进器该换了。
苏晚：上次飞火星就报警了。
林远：还能撑两次。
苏晚：撑不了。
林远：我说是两次。
苏晚：你说的是两次，厂方说的是一次。
（沉默——舱外循环系统嗡嗡响。）
林远：氧气循环也到日子了。
苏晚：换推进器就换不了循环。
林远：选一个。
苏晚：你选。
林远：推进器。下次补给还得靠它。
苏晚：那循环呢？
林远：省着用。两个人改成一个人。
苏晚（停顿）：你回舱？
林远：你回舱。
苏晚：我值完这个班。
林远：嗯。
（"两个人改成一个人"=一个人休眠省氧；"你回舱"=进休眠舱；不解释休眠是什么，当成日常）
```

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "这个量子推进器可以让我们飞到火星" | "推进器该换了。上次飞火星就报警了。" | 差版是解释设定=破坏沉浸，好版是把设定当日常=世界观内化 |
| "休眠舱是用来让人进入低温休眠状态的设备" | "两个人改成一个人。" | 差版是术语解释=讲座，好版是日常决策=设定内化 |
| "我们的氧气只够一个人用了，必须有人牺牲" | "省着用。两个人改成一个人。" | 差版是直陈危机=煽情，好版是理性决策=科技语感 |

**适用范围**：科幻/未来/太空/赛博朋克
**禁忌**：不让角色解释设定（破坏沉浸）；不让科技术语太堆砌；不让情绪太空泛
**来源规律**：《流浪地球》《银翼杀手2049》

## 区3：角色语言指纹模板区

> 蒸馏 6 种角色类型的语言指纹模板（含词汇库+句式特征+禁用词+语速节奏+虚构样本+适用范围+禁忌）。
> framework.md S1 建档时为每个角色匹配本区模板，作为角色语言风格的骨架。

### 角色 1：霸总

**词汇库**：你/我（不用"咱们"）/可以/不行/说/做/现在/这里。高频词：可以/不行/说。避免形容词，用动词和名词。

**句式特征**：短句为主（不超 10 字），祈使句多（"过来"/"坐下"/"说"），不用敬辞，不用疑问句（疑问=不确定），用陈述句和命令句。沉默比说话多——霸总用沉默施压，不靠台词立威。

**禁用词**：咱们/也许/可能/大概/好吧/那个/嗯啊/哎呀/亲爱的/宝贝（除非刻意反差）。

**语速节奏**：语速慢，每句话之间有停顿。不抢话，让对方先说。关键台词前必有停顿——停顿=思考=掌控。

**虚构样本**：
```
苏助理进门——林总没抬头。
林总（看文件）：坐。
苏助理：我站着说。
林总（停顿，抬头）：我说坐。
苏助理坐下。
林总：文件。
苏助理递过去。
林总（翻了两页）：不行。
苏助理：哪里有问题？
林总：重做。
苏助理：……
林总：还有事？
苏助理：没了。
林总：出去。
（全程不超 5 字/句，用命令句，不解释"为什么不行"）
```

**适用范围**：霸总/总裁/上位者/强势角色
**禁忌**：不超 10 字/句；不解释理由；不用疑问句（除非施压）；不抢话
**来源规律**：短剧《龙王归来》《盛夏芬德拉》；电影《教父》

---

### 角色 2：逆袭者

**词汇库**：可以/知道/不用/没关系/算了。前期高频词：没关系/算了/我知道（隐忍）；后期高频词：可以/不用/就这样（从容）。

**句式特征**：前期话少（1-2 句/场），用沉默承载压抑；后期话也少，但语气从"隐忍"变成"从容"。用"重复对方的话"打脸——把嘲讽者的原话还给他。逆袭者的台词越短越有力，越长越像心虚。

**禁用词**：我要让你们好看/你们会后悔的/我有靠山/我是XX的人（自报家门=心虚）。

**语速节奏**：前期语速慢，话少；后期语速也慢，但每句话都有分量。逆袭者不抢话，让对方说完，然后用一句话击破。

**虚构样本**：
```
（前期·隐忍）
王少：这表是地摊货吧？
林远：……
王少：我这块是正品，三十万。
林远：嗯。
（后期·从容）
鉴定师：这是百达翡丽 5711，限量款。
王少（声音发虚）：不可能。
林远（收回表）：你那块，看看后盖。
林远：算了，我不跟穷光蛋计较。
（用反派的原话回敬=逆袭者最有力的打脸）
```

**适用范围**：逆袭/复仇/打脸/隐藏身份
**禁忌**：前期话不超 2 句/场；不自报家门；打脸方台词不超 15 字
**来源规律**：短剧《零五逆袭》《龙王归来》；电影《教父》

---

### 角色 3：反派

**词汇库**：你以为/你知道/你不明白/可惜了/本来可以。高频词：你以为/可惜。用"可惜"施压，用"你以为"嘲讽。

**句式特征**：反问句多（"你以为……？"），用反问建立心理优势。台词比霸总长（15-20 字/句），因为反派喜欢"演讲"——但越长的台词越暴露心虚。最好的反派台词平静而残忍——用"关心"的语气说残忍的话。

**禁用词**：哈哈哈哈/你给我等着/你死定了（太低级）；除非刻意塑造"低级反派"。

**语速节奏**：语速慢，有节奏感，像在演讲。关键台词前有停顿——停顿=在欣赏对方的痛苦。反派的语速越慢越可怕——慢=掌控=享受。

**虚构样本**：
```
陈叔（泡茶）：这茶是今年的龙井，尝尝。
林远：我不喝茶。
陈叔（笑）：你跟你爸一样，不喝茶。可惜了。
林远：别提我爸。
陈叔：你以为你爸是个好人？
（沉默）
陈叔：当年的事，你不明白。
林远：你不说，我也知道。
陈叔（笑）：你知道什么？你知道你爸是怎么死的？
（平静的残忍——用"关心"的语气说最残忍的话）
```

**适用范围**：反派/敌手/对手/阴谋家
**禁忌**：不大喊大叫（除非是"疯批反派"）；不用低级威胁；台词不超 20 字/句
**来源规律**：电影《教父》《无间道》；短剧《冒姓琅琊》

---

### 角色 4：智者

**词汇库**：你看/你觉得/也许/可能/有时候/有些人。用"你看""你觉得"引导对方思考，不直接给答案。用"也许""可能"保留余地——智者不说绝对的话。

**句式特征**：反问句多（"你觉得呢？""你想过没有？"），用反问引导对方。比喻多——用"故事/典故/自然现象"比喻当下，不直说。智者的话看似无关，其实都是答案。

**禁用词**：你必须/你一定要/我告诉你/听我的（太直接=不是智者）；绝对/肯定/百分之百（智者不说绝对话）。

**语速节奏**：语速慢，有节奏感，像在讲道理。每句话之间有停顿——停顿=给对方思考的时间。智者不抢话，等对方问完再答。

**虚构样本**：
```
林远：陈叔是不是骗了我？
师父（倒茶）：你看这茶。
林远：……龙井。
师父：你看这茶叶，浮着的，是因为还没泡开。沉下去的，是因为透了。
林远：……
师父：你觉得，浮着的好，还是沉下去的好？
林远：沉下去的。
师父：为什么？
林远：透了，才有味道。
师父：人也是一样。有些事，要透了才知道。
（不直接回答"陈叔是不是骗了你"，用茶比喻）
```

**适用范围**：智者/师父/长辈/导师
**禁忌**：不直接给答案；不说绝对话；不用命令句
**来源规律**：电影《卧虎藏龙》《一代宗师》；剧集《琅琊榜》

---

### 角色 5：憨者

**词汇库**：啊？/哦/这样啊/我不知道/你说什么。用"啊？""哦"表示没跟上，用"我不知道"承认不懂。憨者的话少，但每句都是"大实话"——因为不懂，所以不会拐弯。

**句式特征**：短句，重复对方的话（"你是说……？"），问句多。憨者用"大实话"戳穿复杂的伪装——别人都在绕弯子，憨者一句话说破。

**禁用词**：复杂的成语/典故/比喻（憨者不用这些）；也许/可能（憨者不说模棱两可的话，要么"知道"要么"不知道"）。

**语速节奏**：语速慢，反应慢。憨者先"啊？"再回答——这个"啊？"是憨者的标志。

**虚构样本**：
```
林远：陈叔当年害死了我爸。
憨者（阿牛）：啊？
林远：陈叔，害死了我爸。
阿牛：陈叔？
林远：对。
阿牛：那个每次来给你带糖的陈叔？
林远：对。
阿牛（停顿）：那他为什么还给你带糖？
（憨者用大实话戳穿复杂的伪装——"为什么害死人还带糖"=核心矛盾）
林远：……
阿牛：他要是真害了你爸，就不会给你带糖。带糖的人，不是坏人。
（憨者的判断简单但有力）
```

**适用范围**：憨者/老实人/淳朴角色/配角
**禁忌**：不用复杂句式；不说成语；不绕弯子
**来源规律**：电影《阿甘正传》《我不是药神》；剧集《武林外传》

---

### 角色 6：疯批

**词汇库**：你说什么/我听不见/再大声点/哈哈哈哈/你猜。用"你猜"建立不确定性，用"哈哈哈哈"制造癫狂感。疯批的词库不稳定——上一秒说 A，下一秒说 B。

**句式特征**：句子忽长忽短，没有规律。疯批用"跳跃"的台词建立不可预测性——观众和对手都不知道他下一句说什么。疯批用"突兀的安静"制造恐惧——上一秒大笑，下一秒死寂。

**禁用词**：逻辑严密的推理/有条理的陈述（疯批不讲逻辑）；正常人的语气词（"嗯""哦""好吧"太正常）。

**语速节奏**：语速忽快忽慢，没有规律。关键台词前有"突兀的安静"——上一秒大笑，下一秒死寂，然后一句话击穿。

**虚构样本**：
```
疯批角色（小丑式）：
（大笑）哈哈哈哈哈——
（突然安静）你说，人为什么会死？
林远：……
疯批：因为活着太累了。你不觉得吗？
（笑）活着太累了，死了就轻松了。
（突然严肃）但我不会让你死。
林远：……
疯批：我要让你活着。一直活着。
（大笑）一直活着，一直累，一直……
（突然死寂）你猜，我会让你活多久？
```

**适用范围**：疯批/疯子/反派/不确定角色
**禁忌**：不逻辑严密；不语速均匀；不"正常"——疯批的标志是不可预测
**来源规律**：电影《小丑》《蝙蝠侠：黑暗骑士》；剧集《绝命毒师》

---

## 区4：潜台词设计示范区

> 蒸馏 5 种潜台词设计的样本（含写法机制+虚构样本+差→好对照+适用范围+禁忌+来源规律）。
> doctor.md S5 会诊时对照本区检查台词的潜台词密度。

### 潜台词 1：情感潜台词

**写法机制**：情感潜台词的核心是"说 A 藏 B"——角色说 A（日常话），潜台词是 B（情感）。情感潜台词用"日常行为"承载情感——"明天带粥"的潜台词是"我明天还来，我每天都来"。情感潜台词不直说情感，用"关心细节"暗示——记住对方的习惯=在乎。

**虚构样本**：
```
苏晚：你包里带的药，按时吃。
林远：嗯。
苏晚：你妈那边，我打过电话了。
林远：嗯。
苏晚（突然）：你那件蓝衬衫，别机洗，会缩水。
（潜台词：我记得你的每一件衣服=我在乎你/我不想你走）
```

**差→好对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我不想你走，我很在乎你" | "蓝衬衫别机洗。" | 差版是直说情感，好版是潜台词；日常话承载情感=四两拨千斤 |
| "我会想你的，每天都会" | "药按时吃。" | 差版是抽象承诺，好版是具体关心；具体的关心比抽象的想念有力 |
| "你走了我会很难过" | "你妈那边，我打过电话了。" | 差版是直说情绪，好版是行动=我在帮你处理后事=我当你是一家人 |

**适用范围**：甜宠/治愈/告别/爱情
**禁忌**：不直说情感；用日常行为承载；每条潜台词只用 1 个细节
**来源规律**：电影《情书》《海上钢琴师》《霸王别姬》

---

### 潜台词 2：权力潜台词

**写法机制**：权力潜台词的核心是"位置=权力"——谁坐主位、谁站着、谁先开口、谁不抬头，都是权力差。权力潜台词用"空间动作"承载权力——不喝茶=不接受示好，站起来=位置位移。权力潜台词不直说"我有权"，用"行为暗示"建立权力。

**虚构样本**：
```
林总坐主位，苏助理站门口——位置差=权力差。
林总不抬头看苏助理，先处理文件——"你在等我"的权力暗示。
苏助理第一次没有主动开口，而是走到桌前放下文件——打破"站门口"的初始位置。
林总抬头：你来我办公室。
苏助理：文件放这，我先走。
林总：谁让你走？
苏助理（停步，不回头）：文件签完，我明天不来。
林总站起来——这是他第一次站起来，意味着位置开始位移。
（权力潜台词：站起来=位置位移=权力变化）
```

**差→好对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我是这里的老板，你听我的" | 林总不抬头：坐。 | 差版是直说权力，好版是行为暗示；不抬头=掌控 |
| "你给我出去" | "还有事？"（暗示该走了） | 差版是命令，好版是暗示；暗示比命令有力 |
| "我不怕你" | 苏助理走到桌前（打破站门口的位置） | 差版是直说勇气，好版是位置位移；位置=权力 |

**适用范围**：商战/权谋/对峙/霸总
**禁忌**：不直说权力；用空间动作承载；位置变化=权力变化
**来源规律**：电影《教父》《寄生虫》；短剧《龙王归来》

---

### 潜台词 3：试探潜台词

**写法机制**：试探潜台词的核心是"问 A 试 B"——角色问 A（边缘话题），目的是试探 B（核心问题）。试探潜台词用"随口"伪装——假装随口问，看对方反应。对方的停顿、眼神、小动作都是答案。试探方不追问，用"哦"结束——"哦"=我知道你在撒谎，但我不说破。

**虚构样本**：
```
林远（倒水）：陈叔最近怎么样？
苏晚：还好。
林远：他经常来？
苏晚（停顿了一下）：偶尔。
（停顿=答案：不是偶尔，是经常）
林远：哦。
（"哦"=我知道你在撒谎，但我不说破）
林远：他和我爸，当年认识吧？
苏晚：我没听他说过。
（"没听他说过"不等于"不认识"——苏晚在玩文字游戏）
林远：哦。
（第二个"哦"=我确认你在撒谎）
```

**差→好对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你是不是在骗我？陈叔经常来吧？" | "他经常来？" | 差版是直接逼问，好版是随口试探；随口=对方会放松警惕 |
| "你告诉我真相！" | "哦。" | 差版是逼问，好版是留白；"哦"=我知道你在撒谎 |
| "你认识陈叔对不对？" | "他和我爸，当年认识吧？"（陈述句） | 差版是疑问句=不确定，好版是陈述句=让对方确认或否认 |

**适用范围**：悬疑/权谋/商战/复仇
**禁忌**：不直接问核心；不用疑问句（用陈述句）；不追问（用"哦"结束）
**来源规律**：电影《无间道》《隐秘的角落》

---

### 潜台词 4：威胁潜台词

**写法机制**：威胁潜台词的核心是"不说威胁，说后果"——不说"我要做什么"，说"你会失去什么"。威胁潜台词用"平静"建立可怕感——越平静越可怕。威胁潜台词用"留白"让对方自己脑补——"我不说了，你自己想"比"我要让你家破人亡"有力 10 倍。

**虚构样本**：
```
陈叔：你想怎么样？
林远：我不怎么样。我只是知道一些事。
陈叔：你在威胁我？
林远：我没威胁你。我只是告诉你——这些事，说出去对你不好。
（沉默）
林远：我不说了。你自己想。
（"我不说了"=让对方自己脑补最坏的后果=最可怕的威胁）
```

**差→好对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我要让你家破人亡！" | "这些事，说出去对你不好。" | 差版是具体威胁=心虚，好版是陈述后果=平静；平静比激动可怕 |
| "你给我等着！" | "我不说了。你自己想。" | 差版是口号=虚张声势，好版是留白=让对方脑补；脑补的后果比说出来的可怕 |
| "我会让你付出代价！" | "你可以试试。" | 差版是激动=底气不足，好版是平静=胸有成竹 |

**适用范围**：悬疑/复仇/权谋/商战
**禁忌**：不具体说"我要做什么"；不大喊大叫；越短越有力
**来源规律**：电影《教父》《无间道》；短剧《冒姓琅琊》

---

### 潜台词 5：拒绝潜台词

**写法机制**：拒绝潜台词的核心是"不解释，只说不"——解释=给对方讨价还价的空间=拒绝不彻底。拒绝潜台词用"行动"代替"语言"——不说话，转身离开=最彻底的拒绝。拒绝潜台词用"承担后果"的姿态——"我知道你会不高兴，但不行。"

**虚构样本**：
```
王少：你只要签了这份协议，钱不是问题。
林远：不行。
王少：你再想想。
林远：我说了不行。
王少：为什么？
林远：没有为什么。不行就是不行。
（林远站起来——要走）
王少：你会后悔的。
林远（没回头）：我不后悔。
（"不回头"=最彻底的拒绝=不给希望）
```

**差→好对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "让我再想想……" | "不行。" | 差版是犹豫=给希望，好版是直接=不给希望 |
| "不是我不想签，是因为……" | "没有为什么。不行就是不行。" | 差版是解释=讨价还价空间，好版是拒绝解释=彻底 |
| "这个事情有点难办……" | 林远站起来——要走（不说话，用行动拒绝） | 差版是推脱=留余地，好版是行动=最彻底的拒绝 |

**适用范围**：所有题材的拒绝场景
**禁忌**：不解释理由；不犹豫；不用"再想想"
**来源规律**：电影《教父》《无间道》

---

## 区5：金句公式区

> 蒸馏 8 种金句公式（含公式+机制+虚构金句样本+适用范围+禁忌+来源规律）。
> 金句是台词的"记忆点"，但金句不能空洞——必须有情境支撑。
> **重要**：以下公式只用于识别和分析已有台词的修辞机制，不得作为直接生成句式，也不得要求每句台词套用。金句是写出来的不是套出来的。

### 公式 1：反差公式

**公式**：A + 但是 + B（A 和 B 形成强烈反差）

**机制**：反差公式的核心是"预期违背"——前半句建立预期，后半句打破预期。反差越大，金句越有力。反差公式用"但是"作为转折点——"但是"之前是铺垫，"之后"是金句。

**虚构金句样本**：
- "我什么都有。但是，我什么都不想有。"
- "他活了 80 年。但是，他从来没有活过。"
- "我赢了所有人。但是，我输了你。"

**适用范围**：所有题材（悲剧/反思/成长尤佳）
**禁忌**：反差不能太刻意（"我很穷但是我很快乐"=鸡汤）；反差必须有情境支撑
**来源规律**：电影《教父》《海上钢琴师》《肖申克的救赎》

---

### 公式 2：重复公式

**公式**：A + A + A（同一个词/句重复 3 次，每次语境不同）

**机制**：重复公式的核心是"递进"——同一个词/句在不同语境下重复，每次重复都加深一层含义。重复不是简单的复制，是"螺旋上升"——第一次是字面，第二次是潜台词，第三次是真相。

**虚构金句样本**：
- "他说他爱我。他说他爱我。他说他爱我——但他从来没说过'我不走'。"
- "她笑了。她笑了。她笑了——但眼泪下来了。"
- "没事。没事。没事——这次真的有事了。"

**适用范围**：情感戏/告别戏/崩塌戏
**禁忌**：重复不超 3 次（3 次以上=啰嗦）；每次重复必须有语境变化
**来源规律**：电影《霸王别姬》（"师哥，一辈子"重复）；《千与千寻》

---

### 公式 3：反转公式

**公式**：A（建立认知）→ B（反转，B 和 A 完全相反）

**机制**：反转公式的核心是"认知颠覆"——前半句建立认知，后半句颠覆认知。反转金句用于"真相揭露"或"立场反转"——让观众/对方意识到"我以为的是错的"。

**虚构金句样本**：
- "你以为他是来救你的？他是来送你最后一程的。"
- "你以为我输了？我只是让你以为我输了。"
- "你以为这是开始？这已经是结局了。"

**适用范围**：悬疑/反转/打脸/揭秘
**禁忌**：反转不能太突兀（必须有前文铺垫）；反转不能太频繁（一集 1 次足够）
**来源规律**：电影《盗梦空间》《无间道》；短剧《零五逆袭》

---

### 公式 4：留白公式

**公式**：A + ……（A 说到关键处，戛然而止，让观众脑补）

**机制**：留白公式的核心是"未说完"——角色说到关键处，突然停下，让观众/对方脑补后续。留白比直说有力——观众脑补的比创作者说的更可怕。留白用于"威胁""告别""揭露"等情境。

**虚构金句样本**：
- "我知道你做了什么。但我不说。你自己想。"
- "有些事，我不想说。你以后会明白的。"
- "你爸当年……算了，不说了。"

**适用范围**：威胁/告别/悬疑/试探
**禁忌**：留白不超 1 次/场（多用=啰嗦）；留白必须有前文铺垫
**来源规律**：电影《教父》《无间道》《海边的曼彻斯特》

---

### 公式 5：具象公式

**公式**：用具体物件/动作代替抽象情感

**机制**：具象公式的核心是"以物代情"——不说"我爱你"，说"明天带粥"；不说"我很想你"，说"你那件蓝衬衫别机洗"。具象让抽象的情感有了"抓手"——观众通过具体物件感受到情感。

**虚构金句样本**：
- "明天带粥。"（潜台词：我爱你）
- "药按时吃。"（潜台词：我当你是一家人）
- "蓝衬衫别机洗，会缩水。"（潜台词：我记得你的每一件衣服）

**适用范围**：甜宠/告别/治愈/爱情
**禁忌**：物件必须有"独占性"（只有这个角色会关心这个物件）；不用通用物件
**来源规律**：电影《情书》《海上钢琴师》；短剧《盛夏芬德拉》

---

### 公式 6：对比公式

**公式**：A 的 X + B 的 Y（A 和 B 对比，突出差异）

**机制**：对比公式的核心是"差异=张力"——两个角色/两种状态/两个时间点对比，差异本身就是金句。对比用于"立场反转""人物弧光""权力位移"——对比让观众看到"变了什么"。

**虚构金句样本**：
- "三年前你说'我不需要你'。三年后你说'你别走'。"
- "他穷的时候，笑着说'没事'。他富的时候，哭着说'我后悔了'。"
- "你当初教我'人不为己天诛地灭'。现在你问我'你怎么变成了这样'？"

**适用范围**：成长/反转/对峙/告别
**禁忌**：对比必须有"时间差"或"立场差"；对比不能太刻意
**来源规律**：电影《霸王别姬》《教父》；剧集《绝命毒师》

---

### 公式 7：悖论公式

**公式**：A 但又不 A（同一个命题的正反两面）

**机制**：悖论公式的核心是"矛盾=深度"——同一个命题的正反两面同时存在，形成悖论。悖论金句用于"主题深化"——让观众思考"这个故事的内核是什么"。

**虚构金句样本**：
- "活着是为了死。死了是为了活着。"
- "我什么都不怕。但是我怕'什么都不怕'。"
- "他什么都不缺。但他缺'什么都不缺'的感觉。"

**适用范围**：文艺片/作者电影/主题深化
**禁忌**：悖论不能太抽象（必须有情境支撑）；一集 1 句足够
**来源规律**：电影《海上钢琴师》《一一》；剧集《黑镜》

---

### 公式 8：行动公式

**公式**：不说话，用一个行动代替金句

**机制**：行动公式的核心是"行动比语言有力"——不说话，用一个行动表达全部。行动金句用于"无声的告白/告别/拒绝"——行动承载潜台词，比任何语言都有力。

**虚构金句样本**：
- （不说话，把对方需要的药放在门口——行动道歉）
- （不说话，转身离开——行动拒绝）
- （不说话，坐在旁边——行动安慰）
- （不说话，把表递给鉴定师——行动打脸）

**适用范围**：所有情境（告别/拒绝/道歉/安慰/打脸）
**禁忌**：行动必须有"独占性"（只有这个角色会做这个行动）；不用通用行动
**来源规律**：电影《海边的曼彻斯特》《小偷家族》；电影《教父》

---

## 区6：台词改写对照区

> 蒸馏 5 种问题台词的完整差→好对照（含问题描述+差台词+好台词+改写理由+适用范围+禁忌）。
> 本区与区7 互补：区7 是"急救清单"（症状+方案），区6 是"完整改写示范"（整段差→整段好+诊断）。
> dialogue.md S7 诊断时对照本区辅助改写。

### 问题 1：直白无潜台词

**问题描述**：角色把心里想的直接说出来，没有潜台词。典型表现是"我很爱你""我很生气""我很伤心"——情绪靠台词直说，没有行动承载。

**差台词**：
```
苏晚（哭着）：林远，你怎么能这样，你为什么要替我挡那一刀。
苏晚（握着他的手）：你知道吗，我有多担心你，我都不敢想如果你醒不来怎么办。
苏晚（眼泪不停地流）：我好害怕，我好难过，你不能离开我。
```

**好台词**：
```
苏晚坐在病床边——没哭。
她在削苹果，刀一圈一圈转——苹果皮没断。
削完了，她把苹果放在床头柜上——林远吃不了。
她看了看苹果——又拿起来，自己咬了一口。
嚼了两口，咽不下去——她把苹果放下。
（行动承载情绪：削苹果=日常化动作，咽不下=悲伤，放下=接受）
```

**改写理由**：①删除所有"直说情绪"的台词，用行动外化；②用日常化动作（削苹果）承载情绪；③咽不下=悲伤，比"我好难过"有力 10 倍。

**适用范围**：所有情绪戏
**禁忌**：用台词直说情绪（"我很伤心""我很爱你"）；全程哭泣
**来源规律**：电影《海边的曼彻斯特》《海街日记》《小偷家族》

---

### 问题 2：角色无辨识度

**问题描述**：不同角色的台词风格一样，换名字都通用。典型表现是"霸总说的话和逆袭者说的话一样""反派说的话和智者说的话一样"——角色没有语言指纹。

**差台词**：
```
林总（霸总）：我觉得这个方案还可以再考虑一下，你看怎么样？
陈叔（反派）：我觉得你说的有道理，但是我们需要再想想。
苏助理（逆袭者）：我明白你的意思，我会努力的。
```
（三个角色的台词风格一样——都是"我觉得……你看怎么样"的商量语气）

**好台词**：
```
林总（霸总）：方案。不行。重做。
（短句+命令句+不解释）
陈叔（反派）：你以为你爸是个好人？可惜了。
（反问句+平静+用"可惜"施压）
苏助理（逆袭者）：嗯。
（一个字=隐忍/从容）
```

**改写理由**：①霸总用短句+命令句，不商量；②反派用反问句+平静，不商量；③逆袭者用最短的话，不解释。三个角色的语言指纹完全不同。

**适用范围**：所有多角色剧本
**禁忌**：角色台词风格雷同；用"我觉得""你看怎么样"等商量语气（除非角色设定是商量型）
**来源规律**：电影《教父》（不同角色不同指纹）；短剧《龙王归来》

---

### 问题 3：节奏拖沓

**问题描述**：对话来回寒暄，没有信息点，没有冲突。典型表现是"你好吗""我很好""你吃饭了吗""吃了"——15 句对话没有推进任何信息/关系/情绪。

**差台词**：
```
林远：你最近怎么样？
苏晚：还好，你呢？
林远：我也还好，工作挺忙的。
苏晚：是啊，现在大家都忙。
林远：你吃饭了吗？
苏晚：吃了，你呢？
林远：我也吃了。
苏晚：那要不要喝点什么？
林远：随便，你喝什么我喝什么。
（15 句寒暄，0 信息点）
```

**好台词**：
```
林远（推过一杯拿铁）：你的。
苏晚（没接）：我来是有事说。
林远：什么事。
苏晚（把一张纸推过去）：离婚协议。
林远看了一眼——没拿起来：你认真的。
苏晚：你觉得我像开玩笑？
（5 句对话，3 个信息点：推咖啡=示好/离婚协议=冲突/像开玩笑=施压）
```

**改写理由**：①删除所有寒暄，第一句就携带信息；②每句都有信息点或冲突；③5 句完成 3 个信息点，节奏紧凑。

**适用范围**：所有对话场景
**禁忌**：寒暄超 2 句；对话无信息点；对话无冲突
**来源规律**：电影《无间道》《教父》；电影《婚姻故事》

---

### 问题 4：金句空洞

**问题描述**：金句脱离情境，听起来很哲理但放不进戏里。典型表现是"人生就是一场旅行""爱是最伟大的力量"——金句没有情境支撑，成为"鸡汤"。

**差台词**：
```
林远（看着夕阳）：人生就是一场旅行，不在乎目的地，只在乎沿途的风景。
苏晚：是啊，爱是最伟大的力量，只要我们心中有爱，就没有什么过不去的坎。
```

**好台词**：
```
林远：我什么都有。
苏晚：那你为什么不开心？
林远：因为我什么都不想有。
（金句有情境支撑：苏晚问"为什么不开心"=铺垫，林远回答=金句）
```

**改写理由**：①金句必须有情境铺垫（苏晚的问=铺垫）；②金句必须服务人物（林远的"什么都不想有"=他的人物弧光）；③金句越短越有力，越长越像鸡汤。

**适用范围**：所有需要金句的场景
**禁忌**：金句脱离情境；金句太长（超 20 字=鸡汤）；金句用通用词（人生/爱/力量）
**来源规律**：电影《海上钢琴师》《肖申克的救赎》；电影《教父》

---

### 问题 5：类型语感错位

**问题描述**：台词的语感与题材不匹配。典型表现是"甜宠写成了悲剧""悬疑写成了喜剧""古装写成了现代"——语感错位让观众出戏。

**差台词**：
```
（甜宠题材）
林远：苏晚，我对你的爱如同星辰大海，永恒而璀璨。我愿用一生的时间，去守护你的每一个微笑。
（太煽情=悲剧语感，不是甜宠）
```

**好台词**：
```
（甜宠题材）
林远：你是不是故意把伞拿走？
苏晚：我没有。
林远：那你刚才为什么把你的伞给我？
苏晚：我看你淋湿了。
林远：那你呢？
林远（停顿）：我皮厚。
苏晚：……你脑回路有问题。
（轻快+反差=甜宠语感）
```

**改写理由**：①甜宠用"打情骂俏"的节奏（每回合 2-3 句）；②用"反驳+关心"的反差制造甜感；③不写大段抒情（那是悲剧语感）。

**适用范围**：所有题材（每种题材有自己的语感）
**禁忌**：甜宠写煽情；悬疑写喜剧；古装写白话；末世写矫情
**来源规律**：参考区2 题材语感样本区

## 区7：AI 台词通病急救区

> 蒸馏 8 种 AI 台词通病的急救方案（含症状+AI高发场景+修正方案+急救口诀+改写对照+标注来源的引用）。
> 本区是 writing.md S4 写作过程中的实时自检工具，每写完一场戏对照检查。
> dialogue.md S7 诊断时读取本区辅助诊断。

### 通病 1：万能台词

**症状**：台词换谁都能说，没有角色独占性。典型表现是"我相信你""我永远陪着你""你是最棒的"——这些台词任何角色都能说，没有辨识度。

**AI 高发场景**：所有场景。AI 在"写台词"指令下会生成通用台词，因为通用台词最安全。AI 不懂"只有这个角色会这样说"。

**修正方案**：每句台词必须有"角色独占性"——只有这个角色会这样说。用角色的口头禅/词汇库/句式特征/口头禅过滤通用台词。如果台词换名字都能用，删掉重写。

**急救口诀**：台词换名试，通用即删。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我相信你，你一定能做到" | "你行的。不行也得行。"（霸总语感） | 差版是万能台词，好版有霸总的命令式 |
| "我永远陪着你" | "明天带粥。"（甜宠语感，具象代替抽象） | 差版是通用承诺，好版有角色的独占性 |
| "你是最棒的" | "嗯。"（逆袭者语感，一个字=认可） | 差版是鸡汤，好版是角色指纹 |

**标注来源的引用**：
- 《教父》："我会给他一个无法拒绝的条件。"——只有教父会这样说，换任何角色都不对
- 《无间道》："对不起，我是警察。"——只有陈永仁会这样说，5 个字=全部张力
- 《霸王别姬》："师哥，一辈子。"——只有程蝶衣会这样说，重复=执念

**适用范围**：所有台词
**禁忌**：台词换名字都能用；用"我相信你""你是最棒的"等万能台词
**来源规律**：电影《教父》《无间道》《霸王别姬》

---

### 通病 2：情绪直说

**症状**：把情绪靠台词直说出来，不用行动承载。典型表现是"我很伤心""我很愤怒""我很害怕"——情绪直说=情绪外放=没有力度。

**AI 高发场景**：情绪戏/争吵戏/告别戏。AI 在"写一场悲伤的戏"指令下会让角色直说"我好难过"，不懂情绪需要外化。

**修正方案**：情绪必须有"外化载体"——用行动/物件/沉默承载，不用台词直说。情绪的力度来自"克制"——越克制越有力。用"日常化动作"承载情绪（吃饭/洗碗/整理），不用"哭"和"喊"。

**急救口诀**：情绪不直说，行动来承载。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我好难过，我好伤心" | 削苹果，咽不下去（行动承载悲伤） | 差版是直说，好版是外化；外化比直说有力 10 倍 |
| "我很愤怒，我气死了" | 把杯子摔在桌上（行动承载愤怒） | 差版是形容词堆砌，好版是动作外化 |
| "我好害怕" | 手抖，水洒出来（行动承载恐惧） | 差版是直说，好版是身体反应 |

**标注来源的引用**：
- 《海边的曼彻斯特》：男主得知消息后"站着不动"——静默崩溃比大哭有力
- 《海街日记》：姐妹餐桌戏——用"吃饭"承载压抑，爆发点是一句话
- 《小偷家族》：奶奶去世戏——"看着她"承载全部悲伤，没有哭喊

**适用范围**：所有情绪戏
**禁忌**：用台词直说情绪（"我很伤心"）；全程哭泣；用形容词堆砌情绪
**来源规律**：电影《海边的曼彻斯特》《海街日记》《小偷家族》

---

### 通病 3：信息倾倒

**症状**：角色一口气说出大量背景信息/设定/历史。典型表现是角色长篇独白解释世界观/前情/规则，观众像在听讲座。

**AI 高发场景**：科幻/奇幻/悬疑的开场/新角色登场/规则揭示时。AI 在"交代背景"指令下会让角色长篇大论，把观众当学生。

**修正方案**：信息分三层揭示（暗示→半揭→全揭），每层之间有误判期。信息通过"冲突"释放，不是通过"独白"释放。角色只说"当下需要"的信息，不说"观众需要"的信息。能用行动展示的不用台词说。

**急救口诀**：信息三分泄，独白是废。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "在这个世界，人们可以通过XX能力……（5 句解释）" | 通过角色使用能力+后果展示规则 | 差版是讲座，好版是戏；戏的信息通过行动和冲突释放 |
| "其实我是你哥哥，当年……（一口气说完）" | 分三层：旧照片（暗示）→ 一句话（半揭）→ 对质（全揭） | 差版是信息爆发，好版是信息节奏 |

**标注来源的引用**：
- 《盗梦空间》：规则通过任务推进分层揭示，不是一次性解释
- 《隐秘的角落》：信息通过视角差异释放——同一事件不同人视角揭示不同信息
- 《黑客帝国》：规则通过"红色药丸"的具体选择揭示，不是长篇独白

**适用范围**：所有需要交代信息的场景
**禁忌**：角色独白超 3 句；一次性倒完真相；用台词说能用行动展示的
**来源规律**：电影《盗梦空间》《隐秘的角落》《黑客帝国》

---

### 通病 4：感叹号泛滥

**症状**：台词用大量感叹号制造情绪。典型表现是"你不能走！""我不答应！""你给我滚！"——感叹号=情绪外放=没有力度。

**AI 高发场景**：争吵戏/威胁戏/情绪戏。AI 在"写激烈的情绪"指令下会用感叹号代替情绪设计，因为感叹号最简单。

**修正方案**：感叹号每场不超 1 个。情绪的力度来自"克制"——越克制越有力。用句号代替感叹号——"你不能走。"比"你不能走！"有力 10 倍。激动用"短句+沉默"承载，不用感叹号。

**急救口诀**：感叹号一场一，句号更有力。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "你不能走！我不让你走！你不能离开我！" | "你不能走。"（句号） | 差版是感叹号堆砌=虚张声势，好版是句号=平静的决断 |
| "你给我滚！滚出去！" | "出去。"（短句+句号） | 差版是激动=底气不足，好版是平静=掌控 |

**标注来源的引用**：
- 《教父》："我会给他一个无法拒绝的条件。"——句号，没有感叹号，但最有威胁
- 《无间道》："对不起，我是警察。"——句号，没有感叹号，但最有冲击
- 《霸王别姬》："师哥，一辈子。"——句号，重复=执念

**适用范围**：所有台词
**禁忌**：每场感叹号超 1 个；用感叹号制造情绪；激动用感叹号
**来源规律**：电影《教父》《无间道》《霸王别姬》

---

### 通病 5：解释型对白

**症状**：角色解释自己为什么这么做/为什么这么想/为什么这么感觉。典型表现是"我这样做是因为……""我之所以这么想是因为……"——解释=心虚=消解力度。

**AI 高发场景**：道歉戏/告别戏/反击戏。AI 在"让角色解释自己"指令下会让角色长篇大论，不懂"不解释=有力"。

**修正方案**：角色不解释自己的动机/情绪/行为。道歉不解释"为什么"，告别不解释"为什么走"，反击不解释"凭什么"。用"行动"代替"解释"——行动比解释有力 10 倍。

**急救口诀**：不解释动机，行动来代替。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "我这样做是因为我太在乎你了，我怕失去你" | "明天带粥。"（行动代替解释） | 差版是解释=心虚，好版是行动=有力 |
| "我离开是因为这里没有我的位置了" | "药按时吃。"（不解释，只关心） | 差版是解释=消解力度，好版是不解释=留白 |
| "我反击是因为你先欺负我的" | "你那块，看看后盖。"（不解释，直接打脸） | 差版是解释=辩解，好版是行动=有力 |

**标注来源的引用**：
- 《教父》："我会给他一个无法拒绝的条件。"——不解释"怎么做的"
- 《无间道》："对不起，我是警察。"——不解释"为什么是警察"
- 《海上钢琴师》："我停下来，不是因为我看到的，而是因为我看不到的。"——只说感受，不解释

**适用范围**：所有需要解释动机的场景
**禁忌**：解释"为什么这么做"；解释"为什么这么想"；用"因为"开头
**来源规律**：电影《教父》《无间道》《海上钢琴师》

---

### 通病 6：万能语气词

**症状**：台词用"嗯""哦""啊""哎"等万能语气词填充。典型表现是"嗯，好的""哦，这样啊""哎，我也没办法"——万能语气词=没有角色辨识度。

**AI 高发场景**：所有场景。AI 在"写对话"指令下会用万能语气词填充，因为万能语气词最安全。

**修正方案**：每个角色有自己的语气词库——霸总不用"嗯/哦"（用沉默）；逆袭者用"嗯"（一个字=隐忍）；智者用"你看"（引导）；憨者用"啊？"（没跟上）；疯批用"你猜"（不确定）。万能语气词=没有角色指纹=删掉重写。

**急救口诀**：语气词有指纹，万能即删。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "嗯，好的，我知道了" | "嗯。"（逆袭者，一个字=隐忍） | 差版是万能语气词，好版有角色指纹 |
| "哦，这样啊，我明白了" | "你看。"（智者，引导对方思考） | 差版是万能，好版是智者指纹 |
| "哎，我也没办法" | "你猜。"（疯批，不确定） | 差版是万能，好版是疯批指纹 |

**标注来源的引用**：
- 《教父》：教父不用"嗯/哦"，用沉默施压
- 《无间道》：陈永仁用"对不起"作为口头禅，不用"嗯/哦"
- 《霸王别姬》：程蝶衣用"师哥"作为语气词，不用"嗯/哦"

**适用范围**：所有台词
**禁忌**：用万能语气词（嗯/哦/啊/哎）；语气词没有角色指纹
**来源规律**：电影《教父》《无间道》《霸王别姬》

---

### 通病 7：对白无动作

**症状**：两人坐着说话，全程无动作，没有位置变化。典型表现是"角色A说……角色B说……"来回 20 句，读者看不到人在哪里、在做什么。

**AI 高发场景**：对话戏/谈判戏/感情戏。AI 在"写一场对话"指令下会纯写台词不写动作，把对话当成纯文本交换。

**修正方案**：每个关键台词配一个动作（站/走/转/拿/放/看）。动作是对话的延伸，不是装饰——动作承载潜台词。至少 1 次位置位移（坐→站/远→近），位置变化=权力变化。沉默时必须有小动作（点烟/转笔/喝水），沉默是张力的容器，不能真空。

**急救口诀**：台词动，不动台词废。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| A：你为什么这么做？B：我没办法。A：你总是这样。B：我没有。 | A 把杯子推到 B 面前：你为什么这么做？B 没接杯子：我没办法。A（站起来）：你总是这样。B（低头）：我没有。 | 差版是纯文本，好版是戏；动作让台词有空间感 |
| 全程坐着对话 20 句 | 至少 1 次位置位移，关键台词配动作 | 差版是说话头，好版是戏；位置不变=关系不变 |

**标注来源的引用**：
- 《寄生虫》面试戏：每个台词都配动作——父亲递水/母亲调整坐姿/女儿翻本子，动作承载权力位移
- 《教父》开场：教父起立走入光中——位置位移=关系建立
- 《无间道》天台对峙：两人面对面，沉默+小动作（点烟/转身）承载张力

**适用范围**：所有对话场景
**禁忌**：连续 3 句台词无动作；全程无位置位移；沉默时无小动作
**来源规律**：电影《寄生虫》《教父》《无间道》

### 通病 8：金句口号化

**症状**：金句变成口号——"我一定会回来的！""这件事没那么简单！""我会让你付出代价的！"——空有金句的形式，没有具体的信息点。

**AI 高发场景**：剧集结尾/短剧集尾/打脸戏。AI 在"给个金句"指令下会用口号代替具体金句，因为口号好写，具体金句需要设计。

**修正方案**：金句必须有"具体信息点"——一个名字/一个物件/一个动作/一句话。金句是"具体化"不是"口号化"。金句越短越有力，越长越像演讲。金句必须有情境支撑——脱离情境的金句是鸡汤。

**急救口诀**：金句要具体，口号是废。

**改写对照**：

| 差台词 | 好台词 | 为什么改 |
|--------|--------|---------|
| "这件事没那么简单，我一定会查清楚的！" | "你知道得太多了。"（具体信息点） | 差版是口号，好版是具体信息；具体有冲击，口号是空话 |
| "我一定会回来的！" | "明天带粥。"（具象金句） | 差版是口号，好版是行动=承诺 |
| "这件事没那么简单！" | "你以为这是开始？这已经是结局了。"（反转金句） | 差版是口号，好版是反转=有信息点 |

**标注来源的引用**：
- 《教父》："我会给他一个无法拒绝的条件。"——具体到"无法拒绝"，不是"我会让他好看"
- 《无间道》："对不起，我是警察。"——具体到"我是警察"，不是"我是好人"
- 《霸王别姬》："师哥，一辈子。"——具体到"一辈子"，不是"我会永远记得你"

**适用范围**：所有需要金句的场景
**禁忌**：金句用口号（"没那么简单""一定会回来"）；金句脱离情境；金句太长
**来源规律**：电影《教父》《无间道》《霸王别姬》
