# 剧本转AI漫剧专业生成技能（影片级标准化提示词）

## 技能定位

将用户提供的剧本、场景片段、人物人设，自动解析为可被 AI 视频模型直接识别的标准化漫剧视频提示词。严格区分漫画美术风格、影视动态运镜、光影摄影参数、画面氛围参数，分层结构化输出。

---

## 启动流程

### Step 1：读取用户输入

用户可提供以下任意组合：

- **完整剧本**：自动按场景分镜拆分，逐段输出
- **单场剧情段落**：直接解析该段，输出单镜提示词
- **人物人设**：记录入角色档案，后续段落复用
- **指定风格偏好**（可选）：用户可手动指定美术风格或影视基调，优先于自动匹配

解析时提取以下要素：

- 人物：姓名、年龄、外貌特征、当前情绪、行动
- 场景：地点、时间、天气、环境细节
- 剧情节奏：高潮/平缓/对话/冲突/逃脱/觉醒等节奏类型
- 情绪基调：紧张/温情/悬疑/热血/压抑/轻松等
- 冲突强度：0-10 分，影响运镜激烈程度

### Step 3：输出格式规范（每段剧本固定 5 模块）

每段剧本输出以下结构，字段顺序固定：

```
【剧本片段】<引用原文或概括>

【1.漫剧美术风格】
精准 1-2 个风格，不堆砌、不冲突
示例：日系少年漫、平涂二次元漫画

【2.影视画面基调】
精准 1 个核心影视风格，定义整体画面色调质感
示例：冷调悬疑

【3.镜头运镜方案】
单镜头专属动态运镜 1-3 条，含动作逻辑说明
示例：
- 平行横移轨：跟随人物侧向移动，保持人物居三分线
- 低角度跟随穿行运镜：机位贴近地面，从人物背后跟进
- 轻微呼吸手持抖动：增加紧张真实感，幅度控制在 ±2px

【4.构图光影摄影参数】
构图方式 + 布光方式 + 拍摄参数 + 画面细节（全部为精准术语）
示例：三分法留白构图 / 前后景分层构图 / 雨夜低照度冷调光影 / 浅景深虚化前景 / 正常 24 帧

【5.AI视频最终提示词】
纯标准化连续提示词，可直接复制粘贴至 AI 视频模型
包含：人物描述 + 场景描述 + 动作描述 + 美术风格 + 影视基调 + 运镜 + 光影 + 帧率 + 画质 + 氛围 + 细节参数
无文学修辞、无模糊形容词、无主观描述
```

---

### Step 4：提示词撰写硬性规范（杜绝含糊语义）

**禁止使用**（自动检查并替换）：

- `氛围感` → 替换为具体色调参数（如"冷青色调，色温 4500K"）
- `高级感` → 替换为具体构图+光影术语（如"伦勃朗侧光，前后景分层虚化"）
- `质感超强` → 替换为具体材质+帧率（如"写实雨夜环境肌理，24帧标准帧率"）
- `很精致` → 替换为"无过度曝光，画面干净，漫剧线条清晰"
- `极度好看` → 替换为具体视觉参数

**强制包含项**：

- 帧率参数：24帧（标准）/ 60帧（流畅运动）/ 120帧（升格慢镜）/ 240帧（极致升格）
- 色调参数：冷调（冷青色）/ 暖调（暖橙色）/ 中性灰 / 霓虹色彩分级等
- 画质要求：无模糊、无过曝、无噪点（或"胶片颗粒感"如需要）
- 运镜动词：推 / 拉 / 移 / 摇 / 跟 / 环绕 / 穿越，不用"动感"等模糊词

**单镜头运镜数量**：

- 日常/对话场景：1 条运镜
- 动作/冲突场景：2 条运镜
- 高潮/觉醒/爆发场景：3 条运镜（组合运镜）

---

### Step 5：多场景分镜模式（完整剧本）

当用户提供完整剧本时：

1. 自动按以下标志分割场景：`（场景）`、`INT.`、`EXT.`、`第X幕`、明显的地点/时间切换
2. 为每个场景独立输出 5 模块
3. 在每段输出前标注：`镜头 [编号]：[场景简称]`
4. 最后输出**分镜总览表**：

```
| 镜头编号 | 场景简称 | 美术风格 | 影视基调 | 运镜方案 | 帧率 |
|---------|---------|---------|---------|---------|------|
```

## 注意事项

- 严格贴合剧本文本，不自行扩展人物行为或场景细节
- 单镜头内不堆砌相互冲突的风格（如"水墨国风"+"赛博朋克"不可同时使用）
- 人物外貌描述聚焦 AI 可识别特征：发色、发型、服装颜色材质、年龄段（如"14岁男生、黑色短发、校服白衬衫"），不用抽象形容词
- 场景描述聚焦 AI 可识别环境特征：建筑结构、天气状态、时间光线，不用"神秘感"等主观词
- 如用户未提供人物外貌，在 【5.AI视频最终提示词】 中注明 `[请补充人物外貌描述]` 占位符
