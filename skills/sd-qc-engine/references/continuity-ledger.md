# 连续性台账（跨镜/跨集一致性管理）

> 精编自《灵境AI漫剧制作流 V3.9.0》manju-continuity-supervisor

## 〇、定位与边界

- **目的**：把锁定剧本、**资产台账（按素材形态：M0《外观档案册》/ M1《资产编号册 + 素材接线单》/ M2《资产图册》）**、分镜与投喂稿合并为单一事实源，逐场记录人物账、场景账、时间轴账，检查状态生效区间，防跨镜/跨段/跨集穿帮。
- **冲突优先级**：`用户硬约束 → 剧本事实 → 已锁定设计决定 → 资产依据（M2 资产参考图 / M1 编号与外观要素 / M0 文字档案） → 保守假设`。冲突必须记录来源与处置，禁止静默取舍。
- **写入隔离**：只写台账与冲突报告，不修改任何剧本、资产、分镜、投喂文件；发现冲突路由回责任阶段（裁定：原 V3 公共信封/阶段目录交付机制由总控《剧组产出册》台账承担，台账本身以本模板 markdown/json 形式交付）。

### 验收证据与范围

- **M0/M1 验收提示词**：核对角色、道具、九宫格整板固定 16:9，内部布局独立声明，成片跟 B 锁；核对文字档案与接线单，不填写“图片已核验”。**M2 核实图**：登记实际图像来源、尺寸/比例及逐项核验结果；无法读取图像时标“未核验”，不得冒充通过。
- **P4.5 与 P3CLEAN_GRID 分列验收**：P3CLEAN_GRID 指 P3 的 CLEAN_GRID 生产资料，P4.5 是预演故事板沟通附件（`sd-storyboard-engine/references/p45-previs-storyboard.md`）；名称、用途与原有权威文件均保留，不改名互替。M0/M1 验收两者提示词，M2 才增加实际图面检查。
- **生成段、真实剪辑镜头、镜内时间片分账**：时间戳或面板边界不等于剪辑点；连续运镜逐段核对可通行路径、起终机位、遮挡与轴线，不用全片禁长镜代替检查，也不新增辅助运镜 1/3 阈值。
- **模型能力经验不是官方断言**：项目实测、制作倾向须标“经验/待验证”及适用条件；无可追溯官方依据不得写成模型绝对能力或限制。
- **规则加载不等于已读**：切片 coverage 仅代表本页输出；记录实际读取范围、未读范围与续页，不从标题清单或预填回执推导全量已读。

## 一、人物账（跨镜/跨集）

每个人物逐场记录，一项都不能缺：

| 账目项 | 检查要点 | 穿帮病灶（实测） |
|---|---|---|
| 站位 | 段初位置 + 相邻段无移动时不得漂移（依托物/相对位） | 上一段「秀兰身后半步」，下一段凭空变「八仙桌旁」 |
| 朝向 | 与轴线一致；转头有交代 | 无故反转朝向、跳轴 |
| 服装/造型 | 基础年龄/脸体层与 LOOK 妆容/发型/服装层分开；伤损、固定装饰有生效区间 | 隐形换装、饰品消失 |
| 道具持拿 | 持有者、左/右手位、道具状态（完损/位置）；离手必有落点 | 道具换手、凭空消失/出现 |
| 姿态状态 | 撑起/坐起/起身一旦发生，后续镜保持或显式交代回退过程 | 前镜已坐起，后镜又躺回（C18b） |
| 表情/动作/口头禅 | 引用角色锁定版本；招牌项必须有**来源 + 触发条件 + 频率上限 + 禁用场景**四项登记，且**不每镜机械复读** | 语言习惯漂移、声线突变 |
| 声音身份 | 音色/语气基线引用同一角色版本，场次只写情绪调制 | 跨段音色突变 |

**跨段生死线（与总控法则 20「人物账连续·摆位必入画」完全同一口径）**：

1. **摆位必入画**：站位声明摆了位的每个人，本段镜行至少带到一次（正拍/焦外身影/全景群像/反应镜头均算）；实在给不了镜头，站位括号写明 `段末离画 / 退场·去向`——出稿机检 **C17** 兜底（单人站位段不触发）。
2. **入画要交代**：离场的人重新入画，站位必须写 `段初自门口入画` 等方式。
2b. **新面孔首现要交代**（2026-10-13 新增 · `segment-splicing.md` §四·补二）：**相邻两段在场人物集合不同**时，后段**新增的具名人物**必须有①画内入画 / ②画外先声 / ③空镜转场 / ④末镜行句尾一句过渡之一（`（在场）`静默人物可走软口径「首镜一句已在场」）——出稿机检 **C17e** 兜底（WARN 参考级）。
3. **站位不漂移**：相邻段没写移动的人，位置/朝向/依托物不得无交代改变。
4. **（在场）标记口径**：核心人物行无标记=本段有台词或明确动作反应，`（在场）`=画面可见但无台词无反应；两级的人都必须进站位声明，禁自创其他标记。

## 二、场景账

| 账目项 | 检查要点 |
|---|---|
| 场景固定物 | 摆设、出入口位置跨镜一致 |
| 天气/时间 | 段与段之间有因果演进或显式跳变；无凭空晴转暴雨 |
| 光源 | 实际光源（灯火/天光）方向与存在状态连续；体积光不误当场景固有资产 |
| 空气介质 | 雾/烟/尘/雨的来源、密度、运动、沉降/衰减有状态区间；清洁空气不被无故替换 |
| 尺度参照 | 巨构/巨兽场景保持熟悉参照物，参照物不消失 |
| 空间损毁 | 打斗/灾害损毁有持续区间与解除节拍 |

## 三、时间轴账

- 逐场记录入口时间 → 各节拍时长 → 出口时间；**Seedance 侧整数秒口径**（禁时间码、禁小数秒，与总控一致）。
- 每段时长 ≤ 模型上限（2.5=30s / 2.0=15s，机检 C1）；相邻镜头无断档/重叠（C3）。
- 台词时长按语速倒推（3.5~6 字/秒；判定按最快档 6 字/秒），禁拉伸凑时（C15）；镜长按剧情倒推，禁机械等分（C13）。

## 四、逐场台账模板

每场一份，入口状态 → 变化清单 → 出口状态：

```json
{
  "scene_id": "SC-001-001",
  "entry_state": {
    "characters": [],
    "actor_identity_refs": [{
      "character_id": "",
      "voice_id": "",
      "active_expression_codes": [],
      "active_gesture_codes": [],
      "approved_deviations": []
    }],
    "looks": [],
    "props": [],
    "positions_directions": [],
    "set_state": "",
    "time_weather": "",
    "practical_lights": [],
    "atmosphere_state": {},
    "scale_evidence_state": {}
  },
  "changes": [{"beat_id": "", "change": "", "new_state": ""}],
  "exit_state": {},
  "must_carry_forward": [],
  "unresolved_conflicts": []
}
```

字段说明：

- `entry_state/exit_state`：本场入口/出口的人物账全量快照（站位、朝向、服装、道具持拿、姿态、光源、天气、空气介质、尺度参照）。
- `changes`：每处状态变化必须挂 `beat_id`（触发节拍）——没有触发节拍的变化是穿帮隐患。
- `must_carry_forward`：必须带进下一场/下一集的状态（伤损、持拿中的道具、未解除的天气）。
- `unresolved_conflicts`：未决冲突，逐条写来源与建议路由。

**资产引用表**：台账另附一页，逐项记录 `asset_id`、**素材形态（M0/M1/M2）**、版本、生产状态、参考图路径（**M0/M1 留空——本包不持有图**）、职责、允许覆盖范围——**`TEXT_SPEC`（文字设定）在 M0/M1 下是合法资产形态，不是"伪装"**（对齐总控 `short-drama-director/references/asset-delivery-modes.md`）；只有 **M2** 下才要求"参考图路径"非空，且此时 `TEXT_SPEC` 不得冒充已锁定资产参考图。

> ⚠️ **本表随素材形态改判**：**M0/M1 下"参考图路径"列必然为空，这不是缺陷**——不得因此索要图片或判定台账不完整。**禁止**在下游写"已与《资产图册》核对一致"之类未做过的断言（机检：`gate_check.py` 闸门 6B）。

## 五、质量门（台账放行标准）

- 所有下游可见资产与人物身份引用存在，同一角色的音色/语气/表情/动作版本一致。
- 没有隐形换装、声线突变、语言习惯漂移、饰品消失、道具换手、空气介质突变、尺度参照消失、场景跳位、姿态无声回退、站位无交代漂移。
- 每处状态变化有触发节拍，且持续到明确解除。
- 摆位必入画对账通过（每人本段至少带到一次，或写明离画去向）。
