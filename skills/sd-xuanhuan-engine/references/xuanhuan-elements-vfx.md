# 04 · 十三类三层复合元素与玄幻特效体系 (Xuanhuan Elements & VFX Arsenal)

## 一、 能量四态系统（先定形再有光）

严禁使用“一团光芒”、“强烈能量束”等无轮廓描述，能量必须归属于以下四态之一：

1. **态一 · 附着态（贴刃缠身）**：能量死死咬在兵器或肢体表面。剑脊走主流能量，刃口烧至白炽最锐，金色/紫色电弧顺金属纹理螺旋攀附。挥斩时爆亮延展，收势瞬间回缩贴刃。
2. **态二 · 脱体态（斩击光刃）**：离开载体独立飞行的实体。具备明确的几何截面（半月形、月牙薄刃、破空光锥），厚度扁平，边缘带水墨飞白或锯齿，飞行时切割空气留痕。
3. **态三 · 聚集体（万剑/法阵群流）**：先钉单体、再写集合。单体为标准尺寸冷银飞剑（剑尖向前、剑柄在后），整体按三维鱼群组织（前部错层锋线、中部穿插补位、后部追入回填），外部机位展现宏观流动，禁止平面剑板。
4. **态四 · 移动气场态（流向尾流）**：静止蓄力时能量向心汇聚翻涌；极速位移时衣摆与属性真气被风压倒拽，拉出锥形流光长拖尾，身体前端形成透明空气音爆锥。

## 三、 十三类三层复合元素标准库全解

1. **水墨黑白三层（剑仙/居合专属）**：外层水墨晕染飞白 + 中层青蓝水浪翻涌 + 内层白炽冰晶核心，边缘附着金色细碎流光符文。
2. **墨黑紫电三层（魔宗狂刀专属）**：主体浓稠墨黑吸光液态流体 + 边缘暗红搏动血纹 + 表面狂暴跳跃纯紫锯齿电弧，末端爆裂细碎火星。
3. **赤红三层（长枪/霸王枪专属）**：主体半透明赤红熔岩能量 + 表面金色螺旋转动符文 + 前端纯白高压激波锥。
4. **暗金白三层（体修/金刚拳宗专属）**：主体暗金液态真气（厚重金属质感）+ 前端纯白压缩激波 + 周围环绕土黄石屑与金色古道纹。
5. **紫蓝白三层（九霄神雷专属）**：主体紫蓝粗壮雷柱（内部电浆翻腾）+ 纯白树枝状分叉跳跃电弧 + 外围金色雷印，伴随黑色细微空间裂隙。
6. **金橙黑三层（焚天火刃专属）**：主体纯金火核 + 边缘橙红翻涌火浪 + 外层黑色螺旋升腾烟尘，高温使空气剧烈热浪扭曲。
7. **幽蓝白三层（玄冰剑修专属）**：主体幽蓝半透明冰晶 + 中层纯白浓厚霜雾 + 外层蓝色水浪流动，表面浮现六边形冰裂符文。
8. **透翠绿三层（风系神速专属）**：主体完全透明高压风刃 + 中层翠绿流动风纹 + 边缘金色极细光芒。
9. **土褐金三层（地脉厚土专属）**：主体粗糙土黄岩石尖刺 + 中层深褐地脉裂隙 + 外层金色厚土符文。
10. **黑紫金三层（虚空裂隙专属）**：主体纯黑虚空裂缝（吞噬一切光线）+ 边缘紫色飘散余烬 + 周围金色空间扭曲碎纹。
11. **金紫黑三层（神识摄魂专属）**：主体金色精神水波纹 + 中层深紫神念流体 + 外层墨色阴影扩散。
12. **金白羽三层（圣道金身专属）**：主体纯金神圣光柱 + 中层白炽净化光芒 + 外层飘落的金色羽刃与神圣光轮。
13. **暗绿毒瘴三层（万毒魔煞专属）**：主体墨绿腐蚀性流体 + 中层惨绿翻腾毒雾 + 表面暗紫气泡爆裂。

## 四、 角色劲气性格库与冷暖色彩对冲

### 1. 经典角色签名劲气速查
* **太极**：黑白阴阳双色，螺旋凝聚尖锥与重甲，刚柔并济；
* **白鸽**：紫黑色气焰，新月弧刃与飞旋刀轮，踢技轨迹强可视化；
* **红茶**：橙红色爆裂火焰，一击一炸，蛮力与热浪翻涌；
* **凛羽**：冰蓝银白霜雾，寒气渗透如纱如雾，唯有终结技化作冰暴；
* **雷电**：纯紫与银白电弧，零前摇瞬闪残影，雷光撕裂虚空；
* **芭乐**：浅粉渐变至深粉，花瓣飘散到花蕾暴风，越打越浓烈；
* **冰女**：蓝白渐变硬冰，结晶蔓延与冰刺封杀，触碰即冻结；
* **剑神**：红紫色瞬闪光轨，剑尖细锐白光、剑脊紫铜火星，出剑即收；
* **绯雪**：火红刀焰，沿刀锋前扑吞咬，贴脸连斩，火潮断空。

### 2. 冷暖色彩对抗铁律
* **同色相撞大忌**：严禁“蓝剑打蓝雾”、“黑焰打黑夜”，视觉缺乏辨识度。
* **高反差对冲**：暖色能量（赤红/金橙）必须砸在冷色环境或冷色防御（青黑/深蓝）上；冷色能量（冰白/紫电）必须撕裂暖调光尘。
* **三方强分离**：`主冲击色 vs 敌人主体色 vs 场景基底色` 必须两两可辨。
