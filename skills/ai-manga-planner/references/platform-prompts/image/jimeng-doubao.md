# 出图平台格式：即梦 / 豆包

## 概述
字节跳动旗下AI出图平台，支持中文Prompt，对国内用户友好。

## Prompt 结构
```
[镜头类型]，[主体描述]，[场景环境]，[光线色调]，[情绪氛围]，[画风标签]
```

## 支持中文，推荐写法
- 直接用中文描述，自然语言即可
- 关键词之间用中文逗号分隔
- 画风词可中英混用

## 推荐画风标签（日漫）
```
日系动漫风格，漫画风，赛璐珞渲染，高清精细
```

## 场景标签示例
- 热血场景：`热血漫画风，速度线，动感，少年漫画风格`
- 情感特写：`情绪化表情，眼神特写，柔和光线`
- 闪回场景：`褪色冷白调，回忆感，低饱和度`

## 负向提示词（即梦支持）
```
低质量，模糊，水印，签名，3D渲染，写实风格，残缺手部
```

## 示例
```
近景镜头，17岁男生，短碎发，眼神锐利，篮球服11号，左手腕白色护腕，坐在替补席上，向前方看，表情平静，室内体育馆暖光，日系动漫风格，赛璐珞渲染，高清精细
```

## 注意事项
- 即梦/豆包支持中文，不需要翻译
- 角色一致性可通过「参考图」功能上传人物参考图来强化
- 分辨率选择 16:9 横版适合漫剧分镜
