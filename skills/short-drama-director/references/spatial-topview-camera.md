# 空间顶视图与机位调度图规范 (Spatial Top-View & Camera Blocking Ledger)

本规范用于通过 2D 俯视平面坐标与机位网格（如 2x2 四图合一），精确锁定演员空间站位、视线方向、运动轨迹与机位编号（CAM1~CAM4），彻底解决 AI 视频生成中的跳轴（180° 轴线违规）与空间穿帮问题。

---

## 一、 空间四图合一网格架构（2x2 布局）

针对连续剧集（如 Ep1~Ep4）或核心高潮场景，采用四分屏顶视图架构：

```text
┌─────────────────────────────────┬─────────────────────────────────┐
│ 第 1 集：主卧 / 潜入与惊醒       │ 第 2 集：卫生间 / 搜寻与对抗     │
│ [CAM1 主全景] [CAM4 俯拍特写]    │ [CAM2 正拍双人] [CAM3 过肩反打]  │
│ 演员A (床) ───视线───> 演员B(门) │ 演员A (洗手台) <─── 演员B (门框) │
├─────────────────────────────────┼─────────────────────────────────┤
│ 第 3 集：客厅 / 质问与逼近       │ 第 4 集：书房 / 档案与反杀       │
│ [CAM1 斜角全景] [CAM3 移动推镜]  │ [CAM2 特写微表情] [CAM4 顶视全景]│
│ 动作轴线：红虚线 (严禁非法越轴)  │ 动作轴线：蓝虚线 (已做中立镜过渡)│
└─────────────────────────────────┴─────────────────────────────────┘
```

## 二、 机位命名与调度三铁律

### 1. 标准摄像机编码（CAM1~CAM4）
- **CAM1（主建立镜头 / 空间全景）**：30°~60° 斜角俯拍或中远景，确立空间几何与角色左右朝向。
- **CAM2（正拍 / 双人交锋中景）**：平视或微仰角，承载二人对抗与动作发起。
- **CAM3（过肩反打 / 单人近景）**：主观视点过肩镜头，捕捉对手压迫感与生理反应。
- **CAM4（特写 / 顶视俯拍 / 动力学跟随）**：微表情特写、要害接触俯拍或大招运镜。

### 2. 180° 动作轴线与越轴防护
1. **建立主轴线**：在两名角色视线/动作连线上确立 180° 动作轴线。所有 CAM1~CAM3 必须严格布置在轴线的同一侧（如观众视点左侧）。
2. **合法越轴三种手段**：
   - **镜头内过轴**：摄像机在单个镜头内跟随角色走位连续旋转穿过轴线；
   - **中立镜头过渡**：中间插入正面正对两人的中立镜头（Neutral Shot）或特写细节（Cutaway），下个镜头再切至反侧；
   - **剧烈反弹/受击倒地**：角色受到重大物理打击翻滚位移后，重新建立新轴线。
3. **禁止 90° 侧面正拍**：中景全景必须使用斜角，保持透视进深感与空间立体度。

---

## 三、 输出指令规范

当用户输入 `/顶视图` 或 `/机位调度` 时，系统将针对当前分镜场景，输出：
1. 空间坐标描述（角色位置坐标、门窗障碍物、光线入口）；
2. 机位部署表（CAM 编号、镜头焦段、拍摄高度、镜头任务）；
3. 轴线保护提示（标明主轴线位置与是否涉及合法越轴）。
