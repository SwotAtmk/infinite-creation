## 〇、定位与分工：它是什么、不是什么

**一句话**：**每场一张的多格连续叙事图**——九格/六格/四格属于同一故事世界，从左到右、从上到下**连续发生**，每一格是独立成立的电影截图，**身份锁/场景锁/风格锁全程稳定**。

**三大用途**：
1. **固定人物**——跨格身份锁 = 最直观的角色一致性预演件；
2. **剧情推演**——一张图看完一场戏的起承转合（给用户/甲方/团队看剧情走向）；
3. **构图参考**——景别覆盖清单强制全机位语言，可直接当分镜构图的草稿参考。

### 与包内四类「格/板」产物的分工（六不替代）

| 产物 | 一格 = 什么 | 人物 | 每什么一张 | 归属 |
|---|---|---|---|---|
| **九宫格场景图** | 一个机位/子区域 | **禁止人物** | 每场景 | `sd-asset-engine/references/scene-grid-template.md` |
| **故事板图 CLEAN_GRID** | 一个**动作相位**（不等于剪辑点） | 有 | 每段 | `storyboard-sheet-template.md` §五 |
| **SHOT_TEXT 卡** | 一整镜（线稿+参数+台词+调度） | 有 | 每镜 | `storyboard-sheet-template.md` §十一 |
| **15 格动作 PREVIS** | 打戏动作预演格 | 有 | 每段打戏 | `sd-combat-engine/` |
| **★ 剧情分镜格（本文件）** | **一场戏里一个连续叙事瞬间**（独立电影截图） | 有（身份锁） | **每场** | **本文件** |

**互不替代**：剧情分镜格管**一场戏的叙事推演与人物锁定**；故事板管**一段的动作相位**（面板≠剪辑点）；SHOT_TEXT 管**逐镜执行参数**。要"这张图把这场戏讲一遍、人物别走样"→ 本文件。

## 一、规则（V4.0 原文 · 全部保留）

- **每场一个**分镜格；
- 格数按剧情弹性：默认**九宫格（3×3）**，剧情简单可用**四宫格（2×2）**，中等复杂度可用**六宫格（2×3 或 3×2）**——**禁止为版式好看凑格**；
- 诸格属于同一故事世界，从左到右、从上到下连续发生；
- 每一格是独立成立的电影截图；
- 人物/场景/道具/风格全程稳定（**身份锁/场景锁/风格锁**）；
- **镜头语言覆盖**：至少 1 个大远景或广角空间建立、1 个全身、2 个中景或半身、1 个侧面或三分之二侧面、多人场景 1 个过肩（单人场景不得为凑形式新增第二人）、1 个近景或面部特写、1 个眼神/手部/关键道具特写、平视/低机位/高机位至少各 1、正面/侧面/背面/三分之二侧面至少 3 种；
- **不得连续三格**相同景别/相同机位高度/近似构图；
- **连续性**：时间连续（动作不无故回到起点）、动作连续（动作匹配，道具不回到原位、保持同一只手）、空间连续（第一格建立空间轴，不瞬移，门窗家具不漂移）、视线连续（正反打视线匹配）、银幕轴线（默认轴线同侧，越轴先加中性镜头或运动过渡）；
- **表演连续**：表情强度逐格发展，不无故跳变；近景特写保留原始面部特征；手部特写正确手指数；
- **摄影光学**：广角建立空间但避免极端拉伸；中景自然压缩；近景特写控制景深保证眼睛表情清晰；Cinematic lighting 落实为明确主光方向/辅光比例/轮廓光来源/环境反射；Realistic material 体现木石金属织物皮革玻璃的具体反射粗糙度纹理；Natural depth of field 随景别变化；Film color grading 全格统一。

## 二、默认叙事结构（按格数缩放）

**九格（3×3 · 默认）**：
- 第一行·建立空间与触发事件：格1 大远景/广角建立空间+人物位置 → 格2 人物进入或全身定位 → 格3 动作触发（中景/侧面）；
- 第二行·展开关系与推进动作：格4 人物叙事中景/半身/过肩 → 格5 核心动作中间态 → 格6 反应或空间变化（近景/侧面/背面）；
- 第三行·细节、结果与悬念：格7 眼神/手部/道具细节特写 → 格8 动作后果或角色决定（近景/中近景）→ 格9 结尾悬念（留白近景/背影/远景/关键细节）。

**六格（2×3）**：建立（格1~2）→ 推进（格3~4）→ 细节与悬念（格5~6）；
**四格（2×2）**：建立（格1）→ 推进（格2）→ 转折（格3）→ 悬念/落点（格4）。

> 格数选择依据 = **该场的叙事节拍数**，不是镜数（格≠镜：一格可对应一镜或半镜的内容预演，投喂仍以投喂稿镜行为准）。

## 三、输出格式（提示词模板 · V4.0 原文 + 图N对接）

```
【剧情分镜格】第X集·场次X｜场景名
● 素材形态声明：M1 编号占位（人物 图1/图2…、场景 图N、道具 图N——生成时挂对应资产图）
● 格位规划（3×3 / 2×3 / 2×2，按剧情）：
  格1：[景别+机位高度+角度] 画面内容（动作中间态优先）
  格2：[景别+机位高度+角度] 画面内容
  …（按格位顺序）
● 连续性锁定：同一人物身份/服装/场景结构/道具位置/光源方向/时间天气/风格
● 镜头语言覆盖清单：大远景/全身/中景/侧面/过肩/近景特写/道具特写/平视低机位高机位（核对）
● 风格渲染：渲染质感 + 色彩体系 + 光影 + 画风
● 负向提示词：卡通、Q版、低幼、模糊、畸形、水印、文字、杂物、多余人物、画面割裂、镜头编号、红框箭头、参数说明、干净数码锐度、CG感、海报构图
```

**对接口径（V7.x 增补）**：
1. **画面内严禁文字**（格号、参数说明都由负向提示词压掉）——与故事板 CLEAN_GRID 同口径；
2. 人物描述与【核心人物】瘦身行同源（不重复写服装细节，挂 图N 身份锁）；
3. 场景结构与场景资产 图N 一致（空间结构写死，跨格不得漂移）；
4. 画风与 I 画风锁 / 段9【STYLE】一致；
5. 出图后入《资产图册》另立「剧情分镜格」栏目，编号 `图PDG-{场号}`，**不占视频投喂素材槽**（用途是预演与参考；若要当风格参考图入投喂，按素材红线重新计算）。

## 四、使用三时刻 · 必出/豁免规则 · 用户触发

### 4.1 用在哪里（流程内三个时刻，缺一不可）

| 时刻 | 谁用 | 干什么 | 为什么非它不可 |
|---|---|---|---|
| **① P2.5→P3 之间：人物一致性试金石** | 执行者（自己） | 资产图（立绘/场景九宫格）出来后，**先出本格生 1 张图**，验证身份锁/场景锁拼进真实构图走不走样 | 走样**先修资产再进分镜**——别等 20 多镜生完才发现脸不对，那是全片最大返工源 |
| **② P3 剧情确认：给用户/甲方看的走向确认件** | 用户 | 一张图看完一场戏的起承转合，拍板"这场戏这么演对不对" | 比读文字分镜表直观一个量级；确认后留档作对照 |
| **③ 逐镜生图期：构图草稿参考** | 执行者 | 景别覆盖清单强制全机位，逐镜生图时对照构图 | 不直接入投喂（要入按素材红线重算），但能防"全场都是中景" |

### 4.2 必出 / 豁免规则（条件必出，禁止静默跳过）

> 📋 **交付清单格式（P3 收尾逐场写）**：`剧情分镜格：场1 ✅ 四宫格 / 场2 ⛔豁免（纯空镜场，理由：__）`——**不列清单又没出 = P3 未完成，禁止进 P4**。

**必出（命中任一即出）**：
1. **重场戏**——该场含情绪转折/剧情反转/冲突峰值/表白·摊牌·抉择类钩子；
2. **多人物对手戏**——同场 ≥2 人且有互动（对手戏是身份锁价值最大的场景）；
3. **用户点名**——用户要看剧情走向、要推演图、要"固定人物的四宫格/六宫格/九宫格"。

**豁免（可不出，但必须在 P3 交付清单写「豁免场次 + 一句话理由」）**：
- 单镜信息过场（无叙事转折、纯过渡）；
- 纯空镜场 / 纯转场蒙太奇（无人物可锁）。

> **判断口诀**：这场戏值不值得用户在生视频**之前**看一眼？值得 → 出。

### 4.3 别人怎么用（两条触发路径）

- **用户话术直触**：「出剧情分镜格 / 推演宫格 / 剧情推演四宫格·六宫格·九宫格 / 固定人物的推演图」→ 按本文件 §三 模板直接出；
- **流程内自动触发**：P3 出分镜时，对每场先过一遍 §4.2 必出三情形——命中即随该场分镜**一并产出**，并在 P3 交付清单列出「出卡清单（场次×格数）+ 豁免清单（场次+理由）」。

### 4.4 门禁自检（逐项核对后才算完成）

  - [ ] 每场一个？
  - [ ] 连续叙事（从左到右从上到下讲得通）？
  - [ ] 景别互补（覆盖清单达标）？
  - [ ] 不得连续三格同景别/同机高/近似构图？
  - [ ] 人物/场景/风格三锁写明？
  - [ ] 画面内无任何文字？
  - [ ] 必出场次全覆盖 / 豁免场次已列理由？
