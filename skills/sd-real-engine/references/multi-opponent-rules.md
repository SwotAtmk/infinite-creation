# 小规模多点战斗调度 (Multi-Opponent Choreography) · ★多人战斗唯一真源

> 本文件是 **小规模多点战斗（同场 2~4 人）的唯一真源**：1v2 / 1v3 / 2v2 / 3v3。
> 凡任务中出现「两人以上同场交手」，本文件的规则**覆盖** `r1-combat-core.md` / `camera-action-specs.md` / `render-adapters.md` 中的 1v1 默认写法（轴线锁定、开局构图、站位声明、景别策略）。
> **铁律 1~6 全部继续生效**，本节只做多人场景的补充与例外。本文件未写到的部分，回到 `r1-combat-core.md`。

---

## 一、 适用边界与人数上限（硬约束）

| 项 | 口径 |
|---|---|
| 覆盖范围 | **同场 2~4 人**：1v2 / 1v3 / 2v2 / 3v3 |
| 同镜「正在交手」人数 | **≤3 人**（含主角）；第 4 人及以上只能是「未交手的施压位」或「背景人物」 |
| 同框人数 | 中景 / 全景可 4 人；**特写禁 ≥3 人** |
| 超出范围 | 5 人以上群殴混战**不在本包范围** → 拆成若干 2~4 人子场，逐段生成后剪接 |

**为什么有上限**：视频模型对同框角色的注意力是有限的——同框 4 人以上同焦，必然出现糊脸、动作融合、分身。**人数上去了但每张脸都糊，观感远差于两个人打得好。**

---

## 二、 主角唯一锚点法则（★核心，违者 P0）

多人场景**必须指定唯一视觉主锚点**（主角 `@CHR-A`）：

1. **全部运镜与焦点围绕主角**；其余角色一律是「主角的对手」，**禁平均分配镜头**；
2. **主线镜头里主角必须在场**（可被遮挡、可背对、可出画半身），**禁整镜只拍配角互殴**；
3. **焦平面上限 2 人**（主角 + 当前对手）；第三人只能作为**移动前景 / 遮挡物 / 焦外剪影**。

- ❌ **反例**：镜头 2 单独拍两个配角互相打，主角不在画面 → 观众立刻失去追踪目标，人多反而更乱；
- ✅ **正例**：镜头 2 过肩拍主角正面，画面右下角是第二人持械的**焦外剪影**正在压上。

## 三、 多轴管理（替代 1v1 的单轴锁定）

`render-adapters.md` §三 的「左A右B · 全段禁越轴」是 **1v1 口径**；多对多改为 **主轴 + 从轴** 两层：

| 层 | 定义 | 规则 |
|---|---|---|
| **主轴** | 主角 ↔ **当前主要对手**（同一时刻只有一个） | 全段稳定、**禁越轴**、承载 8~12s 情绪拐点 |
| **从轴** | 其余人相对主角 / 主要对手的侧位 | 可随位移自然变化；**同镜内不得反向** |

**主轴切换三时机**（只有这三种合法）：

1. 当前主要对手**被击退 / 倒地 / 出画**；
2. 主角**主动转身换向**（必须写清转身动作）；
3. **新威胁介入**（从画面外进入）。

**禁瞬切**：切换必须写清动作因果。
`✅ 主角侧身让过左侧来拳，顺势转身面对右侧扑来的第二人。`

## 四、 三拍轮转制（★本档第一大废片来源）

> **多人战斗最容易出站桩** —— 模型会让「没轮到的角色」原地待命。这是本档 **P0 最高发项**。

同一时间**最多一人**与主角发生实际接触；其余人必须处于以下三种**可见动态**之一，不得静止：

| 状态 | 含义 | 写法 |
|---|---|---|
| **压上** | 正在接近 | 大步切入 / 抢位 / 举起兵器 / 从画面边缘进入 |
| **被击退** | 刚挨完打 | 踉跄后撤 / 撞翻物体 / 扶墙 / 武器脱手飞出 |
| **绕位** | 在找角度 | 侧向围绕 / 换位 / 封住退路 / 捡起掉落物 |

**P0 判据**：任一角色连续 **≥1s** 既无位移也无受力动作 → 判「**站等**」= P0 阻断。

- ❌ **反例**：主角打甲的时候，乙站在原地举着刀看；
- ✅ **正例**：主角打甲的同时，乙从左侧压上；主角余光扫到，**以甲的身体为屏障顶住**（甲被推得撞向乙）。

**被围 ≠ 打不完**：1v3 必须走 **破围点** —— 主角始终在移动中寻找并击穿最弱的一环（站位重叠 / 背光 / 持械迟钝的那个），**不是原地轮流对招**。

## 五、 节拍弧（多人版，替代单挑弧）

- **单挑弧**（`r1-combat-core.md` §三）：接敌 → 试探 → 施压 → 破防 → 逆转 / 收势
- **多人弧（本档采用）**：

```text
接敌（接触第一个）→ 被围（形成人数劣势）→ 破围点（击穿最弱一环）→ 逐个击破（连续清算）→ 收势
```

1. **8~12s 情绪拐点从「逆转」挪到「破围点」**——主角从被压制转为反制的那个瞬间；
2. **逐个击破必须节奏加速**：后续对手的解决速度**明显快于**第一个（体现「打通了」），**禁三人打三遍同样长的时间**；
3. **收势用动作表达「不敢上了」**：剩余敌人**停步 / 后退 / 转头看同伙**；禁旁白解释。

## 六、 群像镜头规则（与单挑相反：人越多，镜头越收紧）

| 场景 | 镜头策略 | 禁 |
|---|---|---|
| 建立空间（本组第 1 镜，可选） | 全景 / 中景 **30°~60° 斜角**，一次性交代人数与相对位置 | 禁 90° 正侧拍（街机横版感，沿用 `camera-action-specs.md` §二） |
| 主角对单人交手 | 近景 / 中近景，**过肩带出第二人的存在** | — |
| 主角被两人以上施压 | **越肩**：第二人放前景剪影或焦外，避免三人同焦 | 禁三人同焦特写 |
| 击退 / 摔倒某一人 | 低机位或斜侧中景 | — |
| 多人同框 | 中景 / 全景（借前后遮挡分层） | **特写禁 ≥3 人**（脸崩 / 分身高发） |

- **视线引导（强制）**：主角**转头 / 侧目看向新威胁** → 下一镜**必须**切到该威胁（六式④「视线引导切」在多人场景是**强制项**，不是可选）；
- **Eye-Trace**：多人场景同屏焦点上限 **2 个**；第三人只作移动前景 / 遮挡物。

## 七、 防「分身 / 复制人」（多人专属）

多人场景触发分身 / 复制人的概率远高于单挑——**三个穿同款黑西装的人，最容易被渲染成同一个人被复制三次**。

**强制差异化锚点**：每人至少 **2 项不同**，写进【核心人物】段：

> 体型（高 / 矮 / 壮 / 瘦）· 发型（长 / 短 / 束 / 秃）· 服装（颜色 / 层次 / 配件）· 兵器（长短 / 形制 / 持法）· 站位习惯（左撇 / 沉步 / 前倾）

**服饰统一时**（如黑衣保安队）**必须用配件 / 兵器 / 体型做区分**：
`✅ 一人持短棍、一人持长棍、一人赤手；左侧者体型偏壮、右侧者偏瘦高。`

**负面词叠加**（在 `render-adapters.md` §六 默认三区基础上追加）：
`同一人物重复出现、服装互换、多手多脚、人物融合、同脸复制`

## 八、 站位声明（多人版格式）

`render-adapters.md` §三 的「一行式」是 **1v1 格式**；多人改为 **三行制**：

```text
【站位声明】
主轴：@CHR-A（画面左·背靠墙面锚点·侧身45°朝右）↔ @CHR-B（画面右·朝左），全段禁越轴；
从轴：@CHR-C 位于 B 外侧（画面右后），@CHR-D 位于 A 外侧（画面左后）；
全员动态：A 锚点→中央对决区（抢攻）；B 右位→中央（迎击）；C 右后→切入中央（压上）；
         D 左后→退至门边（被击退，武器脱手）
```

- **三条线缺一不可**：主轴行（含轴线锁定）+ 从轴行（其余人相对侧位）+ 全员动态行（逐人 `起点→终点` + **动作原因**）；
- **禁瞬移**（沿用 1v1 口径）：每一步位移必须有攻击 / 闪避 / 击退的因果；
- **禁画图**（沿用 1v1 口径）：禁俯视 ASCII 空间图 / 坐标表。

## 九、 时长、镜数与拆组

| 人数 | 单组镜数 | 组时长 |
|---|---|---|
| 1v1 | 3~4 镜 | ≤15s |
| **1v2** | **4~5 镜** | ≤15s |
| **1v3** | **5~6 镜** | ≤15s |
| **2v2 / 3v3** | — | **直接拆 2 组**（每组聚焦一条主轴线） |

1. **每人至少一个「受力镜头」**：每个交过手的对手都必须被**清晰地打中一次**（有完整受力反馈），否则观众记不住「有几个人」，也感受不到人数劣势被解除；
2. **拆组边界**写在「破围点」或「击退一人之后」——**禁止在交手中间拆**，否则跨段末帧对不齐（段缝画面锁依赖可截的末帧；【接续状态】文字腿 2026-10-09 已废止）；
3. 字数门禁（唯一真源见 `render-adapters.md` §六）在多人场景**照常适用**：人多信息量大，优先**压缩单镜描述**、必要时**拆组**，**禁删掉某个对手的动作**。

## 十、 S5 机检增项（多人场景叠加，与 SKILL.md 三·S5 并行）

1. **人数核对**：同镜「正在交手」≤3 人；特写内 <3 人；总同场 ≤4 人；
2. **站等扫描**：逐镜检查每个在场角色是否有位移或受力动作，出现 `原地 / 站立 / 旁观 / 等待 / 不动` 类描述 → 判 P0；
3. **主角在场**：每个镜行主角必须在场或被明确交代去向；
4. **主轴唯一**：同一时刻只有一条主轴，主轴切换均有动作因果；
5. **差异化锚点**：每个非主角角色在【核心人物】段有不少于 2 项外形差异；
6. **分身负面词**：`同一人物重复出现 / 服装互换 / 人物融合 / 同脸复制` 已写入【强制禁止项】；
7. **受力完整**：每个交手对手至少一次完整受击描写。

## 十一、 负例与正例（P0 判据）

- ❌ 主角站定，甲出拳 → 主角挡 → 甲退回，乙再出拳 → 主角挡 → 乙退回（**轮流出招 = 多人版站桩**）；
- ❌ 三个对手同时扑上来乱成一团（模型会把动作糊成一坨，看不到任何有效接触）；
- ❌ 三人同框近景 / 特写（**脸崩 / 分身**）；
- ❌ 打甲时，乙丙原地举械旁观（**站等**）；
- ❌ 三个对手平均分配镜数、解决速度一样（**无进度感**）；
- ❌ 镜头只拍配角互殴、主角不在画面（**丢失主锚点**）；
- ✅ **1v3 正例全链**：主角背靠墙抢先接触甲（接敌）→ 乙丙从两翼压上、封住退路（被围）→ 主角侧身让过甲、顺势把他推向乙制造冲撞（破围点）→ 趁乙被撞歪一记低位扫腿放倒丙（逐个击破·加速）→ 转身面对甲，甲后退未再上前（收势）。
