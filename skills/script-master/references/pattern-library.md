# 优秀剧本规律蒸馏库

> **当前版本**：v2.1（系统统一版本号）| 更新日期：2026-07-17 | 库内演进：v5.0
> **定位**：本文件是跨项目复用的创作规律库，存放从优秀剧本中蒸馏出的抽象写作机制。
> **与对标 DNA 的区别**：对标 DNA 是针对单个作品的临时提取，附属于项目档案；本库是持久化的规律集合，任何项目都可按题材/平台/集长检索调用。
> **调用方**：framework.md（S1-S3 建档时检索匹配规律）、writing.md（S4 写作前读取节奏/钩子/爽点约束）、doctor.md（S5 会诊时对照规律检查）。

---

## 使用规则（分级）

1. **事实层**：作品名、媒介类型、平台来源等属于硬性事实，无法确认时标为"待核"。
2. **倾向层**：各规律中的节奏值（秒数、集数、间隔）和结构要求是特定平台/集长/题材的创作倾向，不是所有项目都必须遵守的硬规。
3. **风格层**：短剧爽感节奏、电影慢节奏、连续剧长线铺垫等属于风格选项，不互相排斥。
4. **反例层**：为反类型、生活流、实验叙事或特定创作意图，可以有意打破节奏值或结构要求，但应在创作笔记中说明违反服务的戏剧功能。
5. **来源与转化**：规律只用于提炼写作方法，不复制原文；调用时按题材、平台、集长、风格、节奏、来源类型六维度局部检索，结合本项目转化。
6. **版权边界**：来源作品仅标注作品名和类型，不复制任何受版权保护的内容；蒸馏出的规律是写作方法而非内容本身。

> **规则使用说明**：本库中的"必须""不能""禁忌"等措辞，除事实层和版权边界外，默认解释为该条目在特定适用范围内的创作倾向或诊断提醒。短剧节奏表中的秒数/集数是平台经验值，长片、剧集、生活流和实验叙事不适用时可以跳过。

## 规律维度

每张 DNA 卡片按以下维度蒸馏规律：

| 维度 | 蒸馏内容 |
|------|---------|
| 单集节奏曲线 | 一集内部的情绪/冲突/信息释放的节奏起伏规律 |
| 多集递进结构 | 跨集的故事推进、压力升级和角色成长节奏 |
| 开场钩子 | 集首/片首如何在前几秒抓住注意力 |
| 集尾钩子 | 集尾如何制造悬念驱动追更 |
| 信息揭示顺序 | 世界观/人物背景/关键信息在什么时点以什么方式释放 |
| 爽点蓄力与释放 | 爽点前如何蓄力、释放时的节奏和强度 |
| 冲突升级方式 | 冲突如何从个人层升级到关系层再到生存层 |
| 角色出场效率 | 新角色出场如何快速建立辨识度和功能 |
| 反差与喜剧机制 | 反差如何制造、喜剧节奏如何控制 |
| 世界观解释方法 | 世界观规则如何自然融入剧情而不 exposition dump |
| 台词特征 | 台词长度、功能分布、角色辨识度策略 |
| 旁白/OS/VO 使用 | 旁白的使用时机、功能和替代方案 |

## DNA 卡片

### 卡片 001：《零五逆袭》

**来源元数据**：
- 作品名称：《零五逆袭》
- 类型：竖屏短剧
- 题材：逆袭 / 身份反转
- 平台：短剧平台
- 风格：标准偏浓烈
- 节奏：R1 短剧节奏

**检索标签**：逆袭 / 身份反转 / 短剧 / R1 / 浓烈

#### 规律 1：编号即身份——用数字代号制造悬念
- **规律**：主角以编号（如"零五"）而非名字出场，编号本身构成悬念——观众不知道编号背后的身份，而身份揭示就是核心钩子。
- **观察依据**：标题与主角命名策略
- **适用范围**：逆袭、身份反转、组织/机构题材
- **禁忌**：编号必须服务于剧情逻辑（如实验体、特工编号），不能为悬念而悬念
- **置信度**：中

#### 规律 2：低位起步——在最惨处境中开局
- **规律**：主角开局处于社会最底层或最屈辱处境（被编号、被控制、被鄙视），与后续逆袭形成最大落差，落差越大爽感越强。
- **观察依据**：逆袭题材通用结构
- **适用范围**：所有逆袭题材
- **禁忌**：开局惨但不能无逻辑，主角的惨必须有具体反派或制度造成
- **置信度**：高

#### 规律 3：身份揭示分层释放——每集揭一层
- **规律**：主角的真实身份/能力不是一次性揭露，而是每集揭示一层，每层揭示都引发新的冲突和关系变化。
- **观察依据**：多集递进结构
- **适用范围**：连续短剧、身份反转题材
- **禁忌**：不适用于单集完结的短剧
- **置信度**：中

### 卡片 002：《银发保镖》

**来源元数据**：
- 作品名称：《银发保镖》
- 类型：竖屏短剧
- 题材：银发 / 动作 / 反差
- 平台：短剧平台
- 风格：标准偏喜剧
- 节奏：R1 短剧节奏

**检索标签**：银发 / 动作 / 反差喜剧 / 短剧 / R1 / 喜剧

#### 规律 1：年龄反差即钩子——老年人做年轻人的事
- **规律**：核心设定的年龄反差（银发老人当保镖）本身就是最强钩子，打破观众对老年人的刻板印象，在前3秒制造认知冲突。
- **观察依据**：标题与设定策略
- **适用范围**：银发题材、反差喜剧、年龄反转
- **禁忌**：反差不能只有噱头，老人的能力必须有合理来源（退伍军人/隐退高手等）
- **置信度**：中

#### 规律 2：实力碾压但外表低调——扮猪吃虎变体
- **规律**：主角外表低调（银发老人），实际实力碾压，每次出手都是一次"身份揭示"，爽点来自旁观者的认知反转。
- **观察依据**：动作场面设计
- **适用范围**：扮猪吃虎、实力隐藏题材
- **禁忌**：不适用于主角实力需要成长线的项目
- **置信度**：高

#### 规律 3：代际冲突包裹价值观碰撞
- **规律**：银发主角与年轻角色之间的代际冲突不只是喜剧元素，更承载价值观碰撞（经验vs技术、沉稳vs冲动），让喜剧有深度。
- **观察依据**：角色互动设计
- **适用范围**：代际题材、喜剧
- **禁忌**：代际冲突不能变成说教
- **置信度**：中

### 卡片 003：《旺夫的我，谁也不惯》

**来源元数据**：
- 作品名称：《旺夫的我，谁也不惯》
- 类型：竖屏短剧
- 题材：女性成长 / 旺夫 / 独立
- 平台：短剧平台
- 风格：标准偏浓烈
- 节奏：R1 短剧节奏

**检索标签**：女性成长 / 旺夫 / 独立 / 短剧 / R1 / 浓烈

#### 规律 1：标题矛盾即主题——"旺夫"与"谁也不惯"的张力
- **规律**：标题中"旺夫"（传统女性角色）与"谁也不惯"（现代独立态度）构成矛盾，矛盾本身就是主题——女性可以旺夫但不是靠顺从，而是靠实力。
- **观察依据**：标题策略与主题设计
- **适用范围**：女性成长、矛盾人设
- **禁忌**：主题不能靠台词直说，必须通过行动展示
- **置信度**：中

#### 规律 2：帮助不等于依附——女性赋能的爽点设计
- **规律**：女主帮助男主成功（旺夫），但每次帮助都展示女主自身的能力和价值，而不是牺牲自我。爽点来自"她比他更强"的认知反转。
- **观察依据**：角色关系与爽点设计
- **适用范围**：女性成长、甜宠变体
- **禁忌**：不能写成女主单方面付出，男主必须有成长和感恩
- **置信度**：中

#### 规律 3：打脸对象从外人到家人——冲突升级
- **规律**：前半段打脸外人（看不起女主的人），后半段打脸家人（要求女主顺从的人），冲突从外部升级到内部，情感代价同时升级。
- **观察依据**：冲突升级结构
- **适用范围**：女性成长、家庭冲突
- **禁忌**：家庭冲突不能简单化，家人不能是纯粹反派
- **置信度**：中

### 卡片 004：《出狱后，厉先生宠她上瘾》

**来源元数据**：
- 作品名称：《出狱后，厉先生宠她上瘾》
- 类型：竖屏短剧
- 题材：甜宠 / 出狱 / 霸总
- 平台：短剧平台
- 风格：浓烈
- 节奏：R1 短剧节奏

**检索标签**：甜宠 / 霸总 / 出狱 / 短剧 / R1 / 浓烈

#### 规律 1：出狱即重生——用刑期制造信息差
- **规律**：女主出狱后世界已变（人际关系变化、旧人地位翻转），刑期制造的时间差成为天然信息差，每次发现"世界变了"都是钩子和爽点。
- **观察依据**：开局设定
- **适用范围**：出狱题材、时间跳跃
- **禁忌**：变化必须有逻辑，不能为反转随意设定
- **置信度**：中

#### 规律 2：霸总宠但不控制——"尊重式霸总"趋势
- **规律**：区别于传统霸总的控制欲，新型霸总的"宠"体现为尊重女主选择、在关键时刻支持而非替代。宠的强度靠行动力度，不靠控制力度。
- **观察依据**：角色关系设计，与《盛夏芬德拉》"尊重式霸总"趋势一致
- **适用范围**：甜宠、霸总题材
- **禁忌**：不能回到"霸道=控制"的旧模式
- **置信度**：高

#### 规律 3：宠与复仇双线并行
- **规律**：甜宠线（厉先生宠她）和复仇线（出狱后清算旧账）双线并行，宠线提供情感爽点，复仇线提供情节爽点，两线交叉时爆发最强高潮。
- **观察依据**：双线结构
- **适用范围**：甜宠+复仇复合题材
- **禁忌**：两条线必须最终交汇，不能各写各的
- **置信度**：中

### 卡片 005：《离婚后，爸妈带我走上巅峰》

**来源元数据**：
- 作品名称：《离婚后，爸妈带我走上巅峰》
- 类型：竖屏短剧
- 题材：离婚 / 家庭支持 / 逆袭
- 平台：短剧平台
- 风格：标准偏浓烈
- 节奏：R1 短剧节奏

**检索标签**：离婚 / 家庭 / 逆袭 / 女性成长 / 短剧 / R1 / 浓烈

#### 规律 1：离婚不是终点而是起点——用婚姻破裂触发成长
- **规律**：离婚在开场前15秒完成，不是剧情重点而是触发器。真正的故事是"离婚后我反而更好了"，离婚的痛苦被迅速转化为逆袭动力。
- **观察依据**：开局节奏
- **适用范围**：离婚逆袭、女性成长
- **禁忌**：不能在离婚过程中拖太久，15秒内进入"离婚后"
- **置信度**：高

#### 规律 2：原生家庭从阻力变助力——反转家庭叙事
- **规律**：传统短剧中原生家庭常是阻力（吸血父母/偏心公婆），本作反转为助力（爸妈带我走上巅峰），打破"家庭=压迫"的刻板叙事，提供新鲜感。
- **观察依据**：家庭关系设定
- **适用范围**：家庭题材、女性成长
- **禁忌**：助力不能是无条件的，父母也需要有自己的动机和成长
- **置信度**：中

#### 规律 3：前夫后悔线作为持续爽点
- **规律**：前夫的后悔不是一次性爆发，而是随着女主越来越成功逐步加深，每集给一个前夫"发现女主比以前强"的微镜头，构成持续爽点。
- **观察依据**：爽点节奏设计
- **适用范围**：离婚逆袭、打脸题材
- **禁忌**：前夫不能太蠢，后悔必须有逻辑支撑
- **置信度**：中

### 卡片 006：《被骗就返现，这项目我投了》

**来源元数据**：
- 作品名称：《被骗就返现，这项目我投了》
- 类型：竖屏短剧
- 题材：系统 / 返现 / 投资 / 喜剧
- 平台：短剧平台
- 风格：喜剧
- 节奏：R1 短剧节奏

**检索标签**：系统 / 返现 / 投资 / 喜剧 / 短剧 / R1 / 喜剧

#### 规律 1：把社会痛点变成系统金手指——现实焦虑的喜剧化
- **规律**：把"被骗"这个普遍社会焦虑转化为"被骗就返现"的金手指，用喜剧消解焦虑。系统规则本身就是最大的笑点和钩子。
- **观察依据**：核心设定设计
- **适用范围**：系统喜剧、社会痛点喜剧化
- **禁忌**：不能把真实诈骗轻描淡写，需要明确是虚构系统设定
- **置信度**：中

#### 规律 2：投资决策即喜剧节奏——每次投资都是一次反转
- **规律**：主角每次"投了"都是一个喜剧节拍——观众期待结果（赚还是亏），结果总是出人意料。投资决策的节奏就是全剧的节奏骨架。
- **观察依据**：喜剧节奏结构
- **适用范围**：系统喜剧、投资题材
- **禁忌**：反转不能每次都同一个模式，需要变化
- **置信度**：中

#### 规律 3：系统的代价设计——金手指不是无代价的
- **规律**：返现系统有使用条件或代价（如必须先被骗才能返现），代价本身制造喜剧效果（主角主动找骗子上门），让金手指不沦为无脑爽。
- **观察依据**：系统规则设计
- **适用范围**：系统题材、金手指设计
- **禁忌**：不适用于无系统的现实题材
- **置信度**：高

### 卡片 007：《我以旗袍藏利刃》

**来源元数据**：
- 作品名称：《我以旗袍藏利刃》
- 类型：竖屏短剧
- 题材：女性力量 / 旗袍 / 暗藏身份 / 总裁
- 平台：短剧平台
- 风格：标准偏浓烈
- 节奏：R1 短剧节奏

**检索标签**：女性力量 / 旗袍 / 暗藏身份 / 总裁 / 短剧 / R1 / 浓烈

#### 规律 1：文化符号即武器——用传统元素赋予女性力量
- **规律**：旗袍不是装饰而是武器载体，传统文化符号被赋予实战功能。文化符号与动作功能的结合制造独特视觉记忆点。
- **观察依据**：核心视觉设定
- **适用范围**：文化题材、女性动作、视觉驱动型项目
- **禁忌**：文化符号不能只是噱头，必须与角色身份和剧情逻辑深度绑定
- **置信度**：中

#### 规律 2：柔美外表与致命实力的反差
- **规律**：旗袍的柔美外表与藏利刃的致命实力构成反差，每次揭露实力都是一次视觉和认知的双重冲击。反差不只是设定，而是每场戏的节奏工具。
- **观察依据**：角色设计与动作场面
- **适用范围**：反差人设、女性动作
- **禁忌**：实力揭露不能太频繁，需要保持悬念
- **置信度**：中

#### 规律 3：视觉美学驱动叙事——每个画面都是海报
- **规律**：旗袍+利刃的视觉组合让每个关键画面都具备"海报级"传播力，剧集本身成为视觉内容传播素材。
- **观察依据**：视觉传播策略

老周在城中村开了个回收站，最恨欠账。邻居阿芳求他代购廉价仿制药救白血病的儿子，他开价翻三倍："我又不是慈善机构。"药到手那天，阿芳的儿子已经没了。老周看着阿芳抱着药盒坐在灵堂门口，没说话。半个月后，病友群找上门，他犹豫了一夜，按原价代购了第二批。第三批，他不收运费。第四批，他自己贴钱补差价。警察找上他时，仓库里堆着两百份药，他没跑。审讯室里他只问了一句："那个孩子，临走前疼不疼？"他不知道答案，但他知道，下一次他不会再开价翻三倍了。

**改写对照**：

**适用范围**：现实主义/社会议题/剧情/传记
**禁忌**：不让主角突变英雄；不让道德立场非黑即白；不让社会议题变成说教

### 卡片 034：《暴裂无声》

**题材标签**：现实主义/社会隐喻/悬疑
**作品层级**：电影
**核心DNA**：失语者的无声呐喊——主角不会说话，用沉默和行动表达比语言更强烈的情绪

**题材维度**：
- 节奏：压抑渐进，沉默中爆发——前半段沉默寻找，后半段真相在无声中崩塌
- 钩子：开场建立主角的"失语"设定——不会说话的牧羊人找丢失的孩子，失语本身就是悬念
- 爽点：真相揭露的震撼+无声的悲怆——不是爽，是憋到极致后的情感溃堤
- 人设：失语主角靠行动表达——不说话但每个动作都重，比嘶吼更有力量
- 冲突：底层vs权贵的力量悬殊——不会说话的牧羊人对上有钱有势的煤老板，力量绝对不对等
- 台词：极简，靠动作和环境叙事——主角无台词，其他角色台词也克制，信息靠画面承载
- 视觉：荒原+矿业废墟的隐喻——干裂的土地、废弃的矿井、羊骨，环境即隐喻

**写作机制**："用沉默和行动替代台词推进叙事"的核心是：失语不是缺陷，是表达方式。主角不说话，但每个行动都必须承载比语言更重的信息——他找孩子不靠问，靠翻山、靠追踪、靠死磕。设计失语主角的三个原则：第一，行动即台词——每个动作都要有明确的"问询/控诉/愤怒"指向（砸东西=愤怒，沉默跟随=质问）；第二，环境即内心——用荒原、废墟、羊群外化主角无法说出的情绪，环境是他的"台词"；第三，沉默制造不对称——其他角色说话越多越显虚伪，主角越沉默越显真实，对比产生张力。隐喻不能直白——矿业废墟暗示资源掠夺、孩子失踪暗示底层被吞噬，但都不点破，让观众自己感受。失语主角绝不能有"内心独白"补足语言，那会破坏设定，必须用纯行动和纯视觉承担叙事。

**虚构样本**：
```
哑巴石匠老姜的儿子在矿上不见了。他不会说话，拎着锤子去了矿上。工头冲他喊"不知道"，他站在原地不动。工头叫人轰他，他不躲，锤子往自己手心一砸，血滴在煤渣上。工头吓白了脸，终究没敢动手。他沿矿区走了一圈，捡回一只孩子的鞋。第二天他又去，这回带了全村的人。他不说一个字，只是把鞋摆在矿门口，人群就懂了。矿长出来谈判，递烟，赔钱，他不接。他指了指矿井的方向，又指了指自己的嘴。没人听懂，但所有人都看见了他眼睛里的东西——那不是请求，是最后通牒。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 失语主角到处问人找孩子，靠别人转述信息 | 主角沉默行动，每个动作都是问询和控诉 | 问人破坏失语设定；行动表达比语言更有力量 |
| 用内心独白补足主角的心声 | 用环境和行动外化情绪，绝不给内心独白 | 内心独白消解失语张力；纯行动才有冲击 |
| 隐喻直白点破（旁白说"矿区吞噬了底层"） | 隐喻藏在环境里不点破，让观众自己感受 | 直白变说教；不点破才有余味 |

**适用范围**：现实主义/悬疑/艺术片/社会隐喻
**禁忌**：不让失语主角"内心独白"（破坏设定）；不让叙事依赖台词；不让隐喻太直白
**来源规律**：《暴裂无声》忻钰坤

### 卡片 035：《白日焰火》

**题材标签**：犯罪/黑色电影/爱情
**作品层级**：电影
**核心DNA**：罪案中的爱情——犯罪调查的表层下，是两个孤独灵魂的相互靠近

**题材维度**：
- 节奏：缓慢压抑，像东北的冬天——案情推进慢，人物情绪推进慢，慢出味道
- 钩子：开场碎尸案+主角的失败人生——警察丢了工作、妻子离婚，案件和人物同时跌入谷底
- 爽点：真相揭露+冰冷的浪漫——不是破案的爽，是"两个孤独的人短暂靠近"的情感震颤
- 人设：失败警察+神秘女人——都是有伤的人，伤让他们互相吸引又互相危险
- 冲突：职责vs情感——警察该抓她，却又被她吸引，职责和情感撕裂主角
- 台词：克制，话中有话——每句话都说一半，另一半靠沉默和眼神
- 视觉：冰雪+煤灰的黑色美学——东北冬天的灰白色调，冰场、煤堆、夜色，冷到骨子里

**写作机制**："在类型片表层下写人物关系"的核心是：犯罪是骨架，人物是血肉，骨架不能盖过血肉。设计原则：第一，案件服务于人物——每个案件进展必须同时推进人物关系，破案不是为了真相，是为了让两个人靠近或疏远；第二，爱情必须是冷调的——不是甜宠，是两个有伤的人互相取暖又互相伤害，温暖里掺着危险；第三，真相不能太简单——真相揭露要让"破案"和"失去"同时发生，主角赢了案子输了感情。节奏要慢，慢才能压出人物的情绪厚度，快节奏会逼着只讲案件。台词要克制，话中有话，角色从不直说情感，情感藏在问案的过程里。视觉要冷——冰雪、煤灰、夜色，环境温度外化人物温度。最终的情感不是团圆，是"明知是该抓的人却短暂地爱过"的悲怆。

**虚构样本**：
```
老陈是码头上的临时工，前警察，因酒精度日。一具女尸漂上来那天，他认出了死者戴的戒指——三个月前他在小酒馆见过这戒指的主人，那个总坐角落喝闷酒的女人。他开始"帮"新来的刑警查案，其实只想再见那个女人的妹妹一面。妹妹和姐姐长得像，话更少。他请她吃饭，她不吃；他送她回家，她不谢。案子查到一半，他发现死者最后见的男人就是妹妹的相好。他没有上报。那天晚上下大雪，他站在妹妹楼下抽了一夜烟，天亮时去派出所自首，说他隐瞒了线索。他没说为什么。妹妹也没来看他。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 警察查案抓住罪犯，案件为主线，感情点缀 | 警察在查案中爱上嫌疑人，人物关系为主线 | 类型片表层下写人物才有黑色电影质感；纯破案变平庸 |
| 两人爱情甜蜜升温，互相表白 | 冷调爱情，克制话中有话，温暖里掺危险 | 甜宠削弱黑色质感；冷调才符合有伤之人的相互靠近 |
| 真相简单，破案即大团圆 | 真相让破案和失去同时发生，赢了案子输了感情 | 大团圆削弱悲怆；得与失同时发生才有情感震颤 |

**适用范围**：犯罪/黑色电影/悬疑/文艺
**禁忌**：不让犯罪盖过人物；不让爱情太甜（必须是冷调的）；不让真相太简单
**来源规律**：《白日焰火》刁亦男

### 卡片 036：《南方车站的聚会》

**题材标签**：犯罪/黑色/社会切片
**作品层级**：电影
**核心DNA**：逃亡者的最后布局——被追杀的人用最后的生命布置一个局

**题材维度**：
- 节奏：夜间游荡感，像在梦里走——逃亡不是狂奔，是夜色里的游荡，节奏飘忽
- 钩子：开场偷车贼大会+意外杀人——地下世界的荒诞集会开局，意外杀人启动逃亡
- 爽点：布局揭露+宿命感——不是逃脱的爽，是"明知必死仍布下最后一局"的悲壮
- 人设：逃亡者的冷静+赏金猎人的复杂——逃亡者不慌，赏金猎人也有情，人设都反套路
- 冲突：逃亡vs救赎——不是逃命，是用最后的命换家人的安顿，逃亡即救赎
- 台词：方言+黑话+极简——地方话和黑话制造真实感，台词极简不解释
- 视觉：霓虹灯+城中村的赛博朋克感——潮湿的城中村、霓虹反光、夜市，底层奇观

**写作机制**："逃亡者的主动性"是反套路的核心——不是被动逃跑，是在逃亡中布局。设计原则：第一，逃亡即行动——主角从逃亡第一刻就在计划，逃跑只是表象，布局才是内核；第二，赏金机制制造多方博弈——警察、赏金猎人、同伙、家人四方势力，每个都有自己的算盘，主角要在多方夹缝中落子；第三，结局必须是宿命——主角注定死，但死前要完成布局，"必死"和"布成局"同时发生才有悲壮感。节奏要有梦游感——夜色、潮湿、霓虹，逃亡像在梦里走，现实感被弱化，宿命感被强化。台词用方言和黑话制造地气，不解释不翻译，真实感来自"听不懂但能感受"。视觉上城中村+霓虹的赛博朋克感不是炫技，是底层社会的奇观化——熟悉的现实变得陌生，才是黑色电影的视觉。

**虚构样本**：
```
帮会老三阿德误杀了一个兄弟，老大开了三十万悬赏他的人头。阿德没跑远。他知道跑了家里妻儿也活不成，于是找了码头上的"野鸡"小梅，许她一半赏金，让她去"举报"自己。小梅贪钱答应了，却不知道阿德真正的局是——让她拿举报赏金养他妻儿，而悬赏的三十万会被人截杀灭口。阿德在城中村游荡了七天，白天睡网吧，夜里去确认小梅的每一步。第八天警察围上来，他没反抗。枪响的时候他正看着江对岸妻儿的窗户。小梅拿到钱那天才发现，举报赏金不是三十万，是阿德早就托人存进她账户的自己的积蓄。她站在ATM前哭了整夜。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 主角一路逃跑，被动躲避追杀最终被抓 | 主角在逃亡中布置最后的局，逃跑是表象布局是内核 | 被动逃亡平庸；主动布局才有反套路张力和悲壮 |
| 结局主角奇迹脱逃或被救 | 结局主角必死，但死前完成布局，必死与布成局同时发生 | 奇迹脱逃削弱宿命感；必死才显悲壮 |
| 视觉奇观与叙事脱节，纯粹炫技 | 城中村霓虹的赛博朋克感是底层奇观化，服务于宿命氛围 | 炫技无叙事功能；奇观要外化黑色氛围 |

**适用范围**：犯罪/黑色/悬疑/动作
**禁忌**：不让逃亡者被动；不让结局太简单；不让视觉盖过叙事
**来源规律**：《南方车站的聚会》刁亦男

### 卡片 037：《悬崖之上》

**题材标签**：悬疑/谍战/历史
**作品层级**：电影
**核心DNA**：绝境中的信任博弈——特工在被捕处境中靠信任和猜疑存活

**题材维度**：
- 节奏：紧张紧凑，多线并行——4人小队空降后立即分头行动，多线同步施压
- 钩子：开场跳伞降落+立即遭遇危机——特工落地即陷入包围，第一场就是生死试探
- 爽点：智斗+反转+牺牲——不是动作爽，是"在敌人眼皮底下传递信息"的智力爽+为战友赴死的悲壮
- 人设：特工的伪装+敌人的多面——特工每人有伪装身份，敌人也有多重面孔，人设即谜题
- 冲突：信任vs猜疑+任务vs生存——既要防敌人又要防内鬼，既要完成任务又要活下来
- 台词：话中有话+信息战——每句话都有表层（说给敌人听）和深层（传给战友），台词即暗号
- 视觉：雪夜+哈尔滨的冷峻——白雪、黑衣、夜色，冷峻到极致的谍战美学

**写作机制**："信任博弈"的核心是每句话都有表层和深层双重含义。设计原则：第一，双重语境——角色每句台词都同时说给两个对象（敌人听表意，战友听暗意），写台词要标注"表层"和"深层"两层；第二，试探即推进——每个场景都是一次试探，A试B、B试A、C试A，试探的结果推动信息流动和信任变化；第三，信息差制造悬念——观众知道多少、角色知道多少必须分层设计，"观众比角色多知道一点"或"角色比观众多知道一点"都产生悬念，但不能让所有人信息对等。反转必须有铺垫——每个反转前要有至少2处伏笔，反转不是"突然"而是"揭晓"，让观众回看时恍然大悟。信息战不能变成信息倾倒——不能让角色长段独白解释局势，信息要靠试探、暗示、行动碎片化释放。

**虚构样本**：
```
审讯室里，特务头子老周给"自己人"老林倒茶："这次行动，辛苦了。"老林接过茶，没喝——茶杯放右侧是安全，左侧是危险，老周故意放左侧。老林笑了笑："该辛苦的辛苦，不该辛苦的不辛苦。"意思是：我知道你在试我。老周也笑："茶凉了，我让人换。"意思是：你还有时间。门外，真正的同志小赵听见了，却听不懂——她不知道老林是同伙。老林端起茶，喝了一口，凉的。他在告诉小赵：别动，暴露了。小赵转身离开，脚步比来时快了半拍。老周没放过那半拍。他记下了。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 特工直接执行任务，靠动作和枪战推进 | 特工在执行中互相试探信任，靠台词双层含义推进 | 直接执行无张力；试探博弈才是谍战核心 |
| 反转突然出现，无任何伏笔 | 反转前埋至少2处伏笔，反转是"揭晓"非"突然" | 突然反转是耍赖；有伏笔的反转才让观众恍然大悟 |
| 角色长段独白解释局势和计划 | 信息靠试探、暗示、行动碎片化释放 | 独白是信息倾倒；碎片化释放才有信息战质感 |

**适用范围**：悬疑/谍战/犯罪/心理
**禁忌**：不让信任博弈太简单；不让反转无铺垫；不让信息战变成信息倾倒
**来源规律**：《悬崖之上》张艺谋/全勇先

### 卡片 038：《唐人街探案》

**题材标签**：悬疑/喜剧/推理
**作品层级**：电影
**核心DNA**：喜剧外壳下的本格推理——笑点和线索同步推进，观众在笑中接收信息

**题材维度**：
- 节奏：快节奏，笑点+线索交替——喜剧节奏跑，推理线索藏在笑点间隙，不闷场
- 钩子：开场+凶案+喜剧人设——主角一出场就带喜剧缺陷（结巴），凶案紧随其后，笑点和案件同步开场
- 爽点：推理揭露+喜剧反转——破案的智力爽+喜剧的情绪反转双管齐下
- 人设：结巴侦探+莽撞搭档——互补型双人组，一个负责脑一个负责手，缺陷即萌点
- 冲突：推理vs混乱——侦探要逻辑，搭档总添乱，混乱反而提供线索，冲突即协作
- 台词：喜剧+推理台词混合——同一段台词既搞笑又埋线索，一句话两用
- 视觉：曼谷+鲜艳色彩——热带的鲜艳、唐人街的杂乱，色彩制造喜剧基调

**写作机制**："喜剧和推理共生"的核心是笑点不是干扰，是信息的载体。设计原则：第一，笑点即线索——每个喜剧桥段必须同时埋一条推理线索，搞笑的动作/台词/误会背后藏着关键信息（如搭档添乱时无意撞见的细节成为破案关键）；第二，缺陷即功能——主角的喜剧缺陷（结巴）不能只是笑点，必须在关键时刻成为推理工具（结巴暗示他在紧张，紧张暗示他知道真相）；第三，混乱即推进——搭档的莽撞不是纯添乱，混乱制造的场景反而推进调查，"误打误撞"是合法的推理路径。节奏要快，喜剧节奏跑起来推理才不枯燥，但快不能丢线索——每个笑点后观众必须能回溯出一条信息。推理不能被喜剧稀释——最后的推理揭露要严肃、要本格、要让观众服气，喜剧只是外壳不是内核。

**虚构样本**：
```
结巴侦探老唐和莽撞搭档大坤查一桩密室杀人案。大坤一进门就踩到香蕉皮摔进尸体怀里，被警察按住。老唐边结巴边解释："他他他不是凶手，他他他蠢。"这逗笑了所有人，但老唐眼睛盯着大坤脚下的香蕉皮——香蕉皮是新鲜的，密室里不该有新鲜水果。审讯时大坤撞翻了证物桌，一盒火柴撒了一地，老唐发现火柴少了三根。他结巴着问保姆："阿姨，您您您平时抽烟吗？"保姆说不抽。老唐笑了："那那那少了的三根，是谁抽的？"大坤还在道歉，老唐已经锁定了凶手——那个说不抽烟却备了火柴的保姆。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 先搞笑再推理，喜剧和推理分段进行 | 搞笑中暗藏线索，笑点和线索同步推进 | 分段让推理变枯燥；同步推进让观众在笑中接收信息 |
| 喜剧缺陷纯搞笑，与推理无关 | 缺陷即功能，关键时刻成为推理工具 | 纯搞笑浪费戏份；缺陷变工具让喜剧服务于推理 |
| 推理揭露也用喜剧方式，不够严肃 | 推理揭露严肃本格，让观众服气，喜剧只是外壳 | 喜剧稀释推理削弱爽感；严肃揭露才有智力爽 |

**适用范围**：悬疑/喜剧/推理/商业片
**禁忌**：不让喜剧盖过推理；不让线索太明显；不让推理太枯燥
**来源规律**：《唐人街探案》陈思诚

### 卡片 039：《流浪地球》

**题材标签**：科幻/灾难/家庭
**作品层级**：电影
**核心DNA**：带着家逃亡——科幻设定下包裹的是中国式的家庭情感

**题材维度**：
- 节奏：大片节奏，灾难升级——从太阳危机到木星危机到点燃木星，灾难阶梯式升级
- 钩子：开场建立世界观+父子冲突——科幻设定和人物冲突同步开场，世界观靠人物关系带出
- 爽点：视觉奇观+牺牲+团圆——奇观爽+父亲牺牲的情感爽+父子和解的团圆爽，三层叠加
- 人设：父亲的隐忍+儿子的叛逆——中国式父子，一个不说爱一个不懂爱，冲突即情感
- 冲突：任务vs家庭+生存vs牺牲——父亲要在任务和家庭间选，全人类生存和个人牺牲撕裂
- 台词：克制+情感爆发——平时克制不煽情，关键时刻一句台词引爆情绪
- 视觉：冰封地球+木星危机——冰封的城市、巨大的木星，奇观有叙事功能

**写作机制**："科幻外壳下写家庭情感"的核心是科幻是设定，家庭是核心。设计原则：第一，世界观靠人物带出——不靠旁白解释科幻设定，靠父子冲突、爷爷回忆、家庭对话自然释放世界观信息，设定服务于人物；第二，灾难即情感试炼——每次灾难升级都要同时考验一段家庭关系，灾难不是为了炸，是为了把人物逼到情感临界点；第三，牺牲必须有情感支点——科幻里的牺牲不能只是"为人类"的宏大叙事，必须有具体的家庭情感支点（父亲为儿子牺牲），宏大才落得到地；第四，视觉奇观要有叙事功能——冰封地球不是炫技，是"家回不去了"的视觉化，木星危机是"父子永别"的外化，奇观必须承载情感。台词克制到关键时刻爆发，平时不煽情，爆发才有力量。

**虚构样本**：
```
航行第十七年，工程师老刘和儿子小刘在地下城冷战了三年。小刘偷偷报名了地表救援队，老刘知道后只说了一句："你妈走的时候你才七岁，你记不记得她最后一句话？"小刘不答。木星引力捕获地球那天，地下城断电，老刘被派去手动重启反应堆，小刘的救援队正好在地表。通讯恢复的最后一秒，老刘听见小刘喊"爸"。他按下重启键，反应堆活了，地下城亮了，他却困在了辐射区。他用最后的力气录了一段话："你妈最后说，让你爸别硬撑。我硬撑了十七年，这回听她的。"小刘在地表听见，没哭，只是把救援队的旗帜插得更直了些。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 科幻灾难片只讲救援，人物是工具 | 救援中包裹父子情感，灾难是情感试炼 | 纯救援无情感锚点；家庭情感让宏大叙事落到地 |
| 牺牲是"为全人类"的宏大叙事，无具体支点 | 牺牲有具体家庭情感支点（父亲为儿子） | 宏大叙事悬空；具体支点才让观众共情 |
| 视觉奇观纯炫技，与叙事无关 | 奇观承载情感（冰封=家回不去，木星=父子永别） | 炫技无叙事功能；奇观要外化情感 |

**适用范围**：科幻/灾难/家庭/商业大片
**禁忌**：不让科幻盖过情感；不让情感太煽情；不让视觉奇观无叙事功能
**来源规律**：《流浪地球》郭帆/龚格尔

### 卡片 040：《疯狂的外星人》

**题材标签**：科幻/喜剧/讽刺
**作品层级**：电影
**核心DNA**：用底层视角解构科幻——外星人降临不是世界大事，是底层小人物的麻烦

**题材维度**：
- 节奏：喜剧节奏+荒诞升级——麻烦越来越大越来越荒诞，节奏跟着荒诞跑
- 钩子：开场建立主角的底层身份+意外遭遇外星人——主角是耍猴的，外星人砸进他猴笼，反差即钩子
- 爽点：荒诞+反转+讽刺——不是科幻爽，是"外星人被当猴训"的荒诞爽+反转的讽刺爽
- 人设：底层小人物的实用主义——主角不管外星人是星际大事，只管能不能换钱，实用主义即人设
- 冲突：外星人vs底层逻辑——外星人的高科技逻辑撞上小人物的市井逻辑，逻辑错位产生喜剧
- 台词：方言+市井+荒诞——方言制造地气，市井话制造真实，荒诞台词制造反差
- 视觉：破败+科幻的反差——破烂的猴戏班子+外星科技，反差即视觉笑点

**写作机制**："用底层视角解构宏大设定"的核心是外星人是设定，底层逻辑是核心。设计原则：第一，宏大设定降维处理——外星人降临在主角眼里不是世界危机，是"又来个麻烦"，降维产生荒诞；第二，底层逻辑碾压宏大逻辑——外星人有高科技，主角有市井智慧，市井逻辑反而"赢"了，错位产生讽刺（耍猴的把外星人当猴训）；第三，讽刺藏在荒诞里不直说——不直接批判"人类自大"或"科技傲慢"，让荒诞场景自己说话（外星人被当猴训=人类对外星文明的傲慢被反讽）；第四，底层逻辑不能失真——主角的市井算计、贪小便宜、讲江湖义气必须真实，真实才有讽刺力度，失真就变闹剧。科幻设定可以荒诞但不能严肃——严肃会杀死喜剧基调，要保持"一本正经地荒诞"。

**虚构样本**：
```
耍猴人老耿在庙会支摊，一颗"陨石"砸进了猴笼。笼里的猴子吓跑了，"陨石"里爬出个绿皮玩意儿。老耿的第一反应不是报警，是看看能不能卖钱。绿皮玩意儿叽里咕噜说话，老耿听不懂，拿猴鞭抽了一下："站直了，听话。"绿皮玩意儿居然站直了——它的文明等级远超人类，但它没见过猴鞭。老耿乐了，给它套上猴面具，编进猴戏班子。世界各国的探测器在找外星人，老耿在教外星人骑独轮车。直到有一天绿皮玩意儿摘下面具，用一口方言说："兄弟，我饿了。"老耿愣了三秒，递过去一个肉夹馍："要辣不？"绿皮玩意儿点头。那天的猴戏，卖得最好。
```

**改写对照**：
| 差写法 | 好写法 | 为什么改 |
|--------|--------|---------|
| 外星人降临引发世界危机，主角拯救世界 | 外星人降临变成小人物的麻烦，主角只想换钱 | 世界危机套路化；底层视角解构才荒诞有趣 |
| 直接批判"人类自大""科技傲慢" | 讽刺藏在荒诞场景里不直说，让场景自己说话 | 直说变说教；藏起来才有讽刺力度 |
| 底层主角失真，行为为搞笑而搞笑 | 底层逻辑真实（市井算计/贪小便宜/讲义气） | 失真变闹剧；真实才有讽刺力度 |

**适用范围**：科幻/喜剧/讽刺/荒诞
**禁忌**：不让科幻设定太严肃；不让讽刺太直白；不让底层逻辑失真
**来源规律**：《疯狂的外星人》宁浩

## 维护规则

1. **新增卡片**：分析新样本后，按卡片模板新增 DNA 卡片，编号递增。
2. **通用规律升级**：当同一规律在3张以上卡片中出现，提取到通用规律区，标注来源卡片编号。
3. **置信度更新**：随样本积累和实际创作验证，更新规律置信度（高/中/低）。
4. **淘汰机制**：置信度持续为低且在3个以上项目中验证无效的规律，标记为【已淘汰】并说明原因，不直接删除。
5. **版本记录**：每次更新在文末附版本记录。
