# 构图雷区白名单库（Forbidden Zone · A/B 双态系统）

> **本文档是决策层核心规则库 · 权威文件**
> 融合来源：script-writing-studio 04-field-methods 第 13 节
> 核心机制：**雷区不是绝对禁令，是"默认禁止 + 特定情境解锁"的双态系统。**

---

## 〇、两类雷区的本质区别

| 类别 | 性质 | 可否解锁 | 处理方式 |
|---|---|---|---|
| **A 类 · 艺术性雷区** | 艺术选择（库布里克式正面居中、暴力美学断关节） | ✅ 白名单情境可解锁 | 命中白名单 → 配套约束 → 显式标注 |
| **B 类 · 工程性雷区** | AI 视频生成的纯技术错误 | ❌ **永不解锁** | 强制写进「限制」字段规避 |

> **判定口诀**：这个"错误"有没有艺术上的理由？有 = A 类；没有 = B 类。

---

## 一、A 类 · 艺术性雷区（7 条 · 可解锁）

### A1 · 正面居中

```
默认状态：禁止
默认理由：舞台感 / 破第四面墙 / 视觉平庸
解锁白名单（必须命中其一）：
  □ ① 异化时刻（库布里克式 / 表现精神失序）→ 关联 ID：E13
  □ ② 仪式感（婚礼 / 葬礼 / 加冕 / 审判）→ 关联 ID：E10
  □ ③ 对峙瞬间（审讯 / 法庭 / 决斗的凝固一刻）→ 关联 ID：E04
  □ ④ 强迫观众参与（直视镜头 / 第四面墙击穿）
  □ ⑤ 风格化作者印记（韦斯·安德森式强对称美学）
  □ ⑥ 权力凝固（君主 / 反派的"被供奉"瞬间）→ 关联 ID：E02
解锁后强制约束：
  - 必须配套：对称布景 / 静态运镜 / 长焦压缩
  - 通用后缀必须含："强对称构图 / 仪式感 / 风格化"
  - 内部四问 Q4 必须写明"解锁理由 = 来自 A1 白名单第 X 项"
未命中白名单 → 仍按默认禁止
```

### A2 · 头顶贴边

```
默认状态：禁止
默认理由：视觉压迫不适
解锁白名单：
  □ ① 表现"被天花板压住" / 牢笼感 → 关联 ID：E14
  □ ② 阶级压迫 / 角色被环境吞噬
  □ ③ 监视感（顶部空间被填满 = 被注视）
解锁后约束：
  - 必须配合广角镜头（强化压迫）
  - 通用后缀加"压迫感 / 闭塞空间"
未命中白名单 → 留出 headroom（头顶留白）
```

### A3 · 死压中线（主体永远居中）

```
默认状态：禁止
默认理由：构图平庸 / 缺少视觉张力
解锁白名单：
  □ ① 异化 / 程式化（库布里克 / 艾舍尔式镜像）→ 关联 ID：E13
  □ ② 童话仪式感（韦斯·安德森式）
  □ ③ 强对称美学的明确意图
解锁后约束：
  - 整段戏所有镜头必须保持对称美学（不能只这一镜对称）
  - 通用后缀加"强对称构图 + 风格化"
未命中白名单 → 用三分法 / 黄金分割
```

### A4 · 眼神无空间（视线指向画面外但该侧无留白）

```
默认状态：禁止
默认理由：空间错乱 / 视觉不适
解锁白名单：
  □ ① 凝视虚空 / 失控 / 心理失序
  □ ② 表现角色被"看不见的力量"包围
  □ ③ 主观恐惧（看不到的威胁源）
解锁后约束：
  - 必须配合长焦虚化背景
  - 后缀加"凝视虚空 / 心理失序"
未命中白名单 → 留出 noseroom（视线方向留白）
```

### A5 · 断关节（框边切在关节处）

```
默认状态：禁止
默认理由：视觉不适 / 画面"残缺感"
解锁白名单：
  □ ① 强调局部（手 / 脚 / 嘴）= 微距 / 特写镜头
  □ ② 暴力美学（昆汀式 / 北野武式）
  □ ③ 抽离感叙事（局部代替整体 / 局部蒙太奇）
解锁后约束：
  - 必须是有意为之的"微距 / 特写"选择
  - 不能是中景 / 全景中的"无意切到关节处"
  - 配套微距 / 长焦
未命中白名单 → 框边切大臂中段、大腿中段、胸口或腰部
```

### A6 · 背景过亮（背景比主体亮，主体被吃）

```
默认状态：禁止
默认理由：主体不明 / 视觉中心丢失
解锁白名单：
  □ ① 神性显现 / 顿悟瞬间 / 死亡 → 关联 ID：E15
  □ ② 逆光剪影（角色身份被有意模糊）
  □ ③ 回忆 / 梦境的"过曝"质感
解锁后约束：
  - 必须明示"逆光剪影"或"过曝梦境感"
  - 后缀加"高调过曝 / 神性光线 / 梦境质感"
未命中白名单 → "限制：主体光比背景亮 1-2 档"
```

### A7 · 多人正面平铺（所有人正脸朝镜头）

```
默认状态：禁止
默认理由：舞台感 / 静态合影感
解锁白名单：
  □ ① 全家福 / 法庭 / 仪式 / 集体宣誓 / 教科书风格
  □ ② 强迫观众参与（破第四面墙）
  □ ③ 仪式威严（多人朝贺）→ 关联 ID：E10
解锁后约束：
  - 必须配合对称布景
  - 后缀加"仪式感 + 集体凝视"
未命中白名单 → 用侧脸 / 背影 / 半侧 制造朝向变化
```

## 二、B 类 · 工程性雷区（7 条 · **永不解锁**）

> 这些是 AI 视频生成的**技术错误**，**艺术上没有任何理由保留**。强制用「限制」字段规避。

| 雷区 | 描述 | 强制规避（写进「限制」字段） |
|---|---|---|
| **物体穿身** | 树枝/灯柱/路标从角色头顶或身体长出 | "限制：背景物体不与角色身体重叠" |
| **角色服装突变** | 上一镜白衣下一镜灰衣（同场戏） | "限制：服装/发型与上一镜完全一致" |
| **杂乱前景刺眼物** | 前景虚化中出现光斑/反光板边缘 | "限制：前景虚化中无刺眼光斑/异物" |
| **比例失调** | 手比头大 / 透视错乱 / 多手指 | "限制：身体各部位比例符合解剖学" |
| **重复元素无重点** | 背景多个相同形状物让画面无重点 | "限制：背景元素有主次层次" |
| **空鸡蛋构图** | 主体周围全空白无视觉支撑 | 加前景物件 / 框架式构图 |
| **道具状态突变** | 杯里水量、烟头长度突变 | "限制：道具状态与上一镜延续" |

> ⚠️ **B 类雷区出现 = 必修 bug** —— 不允许在任何情境下保留。

## 三、多人构图次级雷区

> 这不是独立雷区，是 A1/A7 的衍生场景，仅速查用。

| 雷区 | 默认规避 | 解锁参考 |
|---|---|---|
| **眼睛同高** | 通过站姿/坐姿/俯仰角制造高低差 | 仪式 / 法庭可解锁（参见 A7） |
| **一字排开** | 三角形构图 / 前后景纵深 | 仪式宣誓可解锁（参见 A7） |
| **视线散乱** | 至少 2 人共同看向焦点 | 表现集体困惑 / 失序时可保留 |

## 四、微距 / 特写专属雷区（无解锁 · 强约束）

> 不属于 A/B 分类——是微距镜头的**结构性必填项**，无解锁概念。

| 雷区 | 描述 | 规避方法 |
|---|---|---|
| **主体不明** | 微距构图未指明主体 | **强制写明"X 占满画面"** |
| **失焦** | 微距景深极浅，焦点没对在关键点 | 写明焦点："焦点在烟头红色火星" |
| **杂物入画** | 微距镜头里混入与剧情无关的杂物 | "限制：画面中只有 [指定物]，无其他物件" |

---

## 五、类型化构图雷区

| 类型 | 常见雷区 | 规避 |
|---|---|---|
| **武侠** | 角色站姿过于现代（叉腰/手插兜） | 古典站姿："手负于背"/"剑指在前" |
| **现代都市** | 室内构图过于"舞台感"（面对镜头说话） | 自然朝向，避免破第四面墙（除非命中 A1 白名单 ④） |
| **动画/漫剧** | 物件比例失调（手比头大） | "限制：身体各部位比例符合解剖学"（B 类·不解锁） |
| **悬疑** | 关键道具反而构图弱化 | 关键道具至少给一个独立特写镜头 |
| **爱情** | 双人构图距离过远显疏离 | 物理空间靠近 + 前景遮挡制造亲密感 |

## 六、雷区自查流程（生成完每个大分镜后过）

```
对每个分镜检查：

① 是否触犯 B 类工程性雷区？
   → 是 = 立即重写（写进「限制」字段规避），不允许保留
② 是否触犯 A 类艺术性雷区？
   → 是 → 继续：
      ②a 是否命中该雷区白名单？
         → 否 = 重写（改回默认规避写法）
         → 是 = 继续
      ②b 配套约束是否已加？（对称布景/后缀/广角等）
         → 否 = 补齐
      ②c 是否已在锚点表"解锁雷区"列显式标注？
         → 否 = 补标
③ 微距/特写镜头是否满足结构性必填项？（主体明确/焦点写明/无杂物）
   → 否 = 补齐
```

## 七、与「限制」字段的自动链路

**链路**：雷区判定 → `限制`字段生成。

```
B 类雷区命中 → 自动生成对应「限制：…」句 → 注入分镜镜行的【限制】位
A 类雷区解锁 → 自动生成配套后缀 → 注入通用后缀
```

**衔接总控**：`限制`字段的**最终写法规格**以总控 `short-drama-director/references/prompt-feeding-checklist.md` 为准，本文件只负责"判定该写哪条"。
