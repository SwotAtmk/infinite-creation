# 三大子类型爆款公式与情绪动线

> 解说叙事类不是一种，是三种。三类共用"钩子→拆解/叙事→揭秘/Wow→升华"骨架，但**情绪动线与钩子方式不同**。定子类型是进入本引擎的前提。

---

## 一、通用爆款结构（三层骨架）

```
0~3s   钩子（完播率与前 3 秒跳出率强负相关，r≈-0.89）
3~15s  认知闭环起步（抛出核心问题/冲突）
中间   2~5 个亮点/爆点，每 15~30s 一个小高潮，交替"信息增量 + 情绪释放"
结尾   总结清单式梳理 / 金句升华 / 互动引导
```

**通用爆点节奏**：铺垫把情绪往下压 → 转折抬升认知 → 金句收尾。

---

## 二、子类型 A · 历史人物志

**情绪动线（0~100%）**：

| 段位 | 内容 | 占比 |
|---|---|---|
| 反差人设钩子 | 最反常识的身份对比 | 0~10% |
| 出身与困顿 | 微时的处境、一个微光 | 10~30% |
| 关键转折/高光 | 2~3 个转折点 | 30~65% |
| 跌落/结局 | 命运的收束 | 65~85% |
| 评价与升华 | 后世评价金句 | 85~100% |

**公式**：`极致人设反差 + 出身逆境/微光 + 2~3 个关键转折 + 命运结局 + 后世评价金句`

**主骨架**（B 站"一口气看懂 XX"格式）：按**时间线梳理一生**，以"出身 → 转折 → 巅峰 → 结局"为主轴；标题即钩子。

**钩子示例**：
- "48 岁还是流氓，54 岁就当了皇帝。"
- "他一生只打过一场仗，却让匈奴十年不敢南下。"
- "他是亡国之君，却写出了中国最有名的词。"

## 三、子类型 B · 历史事件/战役/朝代

**情绪动线（0~100%）**：

| 段位 | 内容 | 占比 |
|---|---|---|
| 悬念结果前置 | 先把最反常识的结果/悬念甩出 | 0~10% |
| 背景与起因 | 为什么会有这一战 | 10~35% |
| 过程层层拆解 | 因果链推进 | 35~70% |
| 关键人物决策 | 谁在哪一步押上了什么 | 70~85% |
| 影响与遗留 | 改变了什么 | 85~100% |

**公式**：`结果悬念前置 + 因果链逐层拆解 + 关键决策点 + 影响/遗产升华`

**三层结构叙事**（推荐骨架）：宏观环境（国际局势/经济）→ 国家层面（现实考量/反应）→ 个人层面（人物决策/回忆录）。**把宏大历史落到"人"的身上**，是严肃历史解说的核心生产力。

**钩子示例**：
- "澶州城下一纸盟约，让两国和平了一百二十年——但签它的皇帝，差点不敢过河。"（仅示范句式，**史实以资料为准**）

**信源要求最高**：历史事件类必须有**史料意识**——引用原始史料、把不同史料的矛盾摆出来（承接 `sd-recon-engine` 信源分级）。

## 四、子类型 C · 科普/知识解说

**情绪动线（0~100%）**：

| 段位 | 内容 | 占比 |
|---|---|---|
| 反常识/痛点钩子 | 推翻一个常识认知 | 0~10% |
| 生活场景切入 | 从身边事引入 | 10~25% |
| 知识拆解 3~5 步 | 模块化讲解 | 25~70% |
| Wow Moment | 那个"原来如此"的时刻 | 70~85% |
| 价值升华/生活应用 | 落到观众自己身上 | 85~100% |

**公式**：`反常识结论 + 身边事切入 + 类比拆解(3~5步) + Wow时刻 + 应用升华`

**科普中国四段公式**：痛点/好奇心 + 核心知识拆解（3~5 个易懂模块）+ "Wow Moment" + 价值升华。**强调类比**（"黑洞就像一个宇宙下水道，连光都逃不掉"）。

**科普核心生产力**：**"身边事切入 + 通俗类比 + 趣味人设"**（参考账号形态：李永乐=结合新闻讲数理；无穷小亮=场景化+吐槽+知识）。

**钩子示例**：
- "你手机电池不耐用，可能不是电池的错——是你在用错误的方式充电。"
- "你可能一直做错了——关于 X 的 90% 的人不知道的真相。"

## 五、四模块拆解结构（复用用户既有拆解模板）

若用户已有《视频拆解》工作流（元数据模型 / 台词逐句 / 视听参数 / 时间切片提示词四模块），**解说类可直接复用该结构**——只需把"角色台词"替换为"旁白句"：

| 模块 | 剧情版 | 解说版（替换后） |
|---|---|---|
| 核心元数据与底层模型 | 视频类型/故事核心/情绪动线/爆款公式 | 同左（公式换成 §二~四 对应子类型） |
| 全量台词逐句对照 | 按幕逐句：角色/台词/写作手法/传播爆点 | 按段落逐句：**旁白句**/写作手法/传播爆点 |
| 工业级视听语言与分镜参数 | 镜头运动/景别/光线/色彩/主体/背景 | 同左（**场景风格为第一约束**） |
| 分镜时间切片 + 提示词 | 5s 切片：主体/场景/动作/镜头/氛围 | 同左（**切片单位 = 旁白句**） |

## 六、出稿自检清单

- [ ] 子类型已定（历史人物志 / 历史事件战役 / 科普知识解说）；
- [ ] 情绪动线按对应子类型的段位占比铺排；
- [ ] 钩子在 0~3s、≤15 字，方式匹配子类型；
- [ ] 中间有 2~5 个爆点，每 15~30s 一个小高潮；
- [ ] 结尾有与钩子呼应的金句；
- [ ] 历史类有史料意识（T1/T2 分级）；科普类有类比与 Wow Moment；
- [ ] 用户已有拆解模板时用四模块结构承接，零摩擦。
